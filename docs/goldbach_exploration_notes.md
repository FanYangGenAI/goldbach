**定位声明**：以下全部是有限范围内的数值实验，用于形成直觉、筛选方向。没有任何一条构成证明，也不能排除超出计算范围的反例。

记号：r(N) = #{(p,q) 素数有序对 : p+q=N}；HL(N) = 2C₂ · ∏_{p|N,p>2}(p−1)/(p−2) · ∫₂^{N−2} dt/(log t · log(N−t))，C₂ = 0.66016…（孪生素数常数）。E(N) = r(N)/HL(N) − 1。

## 1. 实验1：r(N) 与 Hardy–Littlewood 预测（全量 N ≤ 2²⁵ ≈ 3.36×10⁷）

| 指标 | 结果 |
|---|---|
| 平均偏差 mean E（N≈1.8×10⁷） | −0.0005（N≈2×10³ 时 −0.06，单调趋于 0，属低阶项） |
| E 的标准差（N≈3×10⁷） | 0.0017 |
| std(r − HL) 随 N 的幂律 | **N^0.446**（HL 本身 ∝ N^0.848，故 √HL ∝ N^0.424） |
| N>10⁵ 中最差比值 r/HL | **0.918**（N=144128）；没有任何 N 接近 0 |
| (r−HL)/√HL 分布（N∈[X/2,X]） | 近似高斯：sd=0.77，偏度 0.003，超额峰度 0.014 |

图：`exp1_comet.png`（彗星图）、`exp1_ratio.png`（除以奇异级数后所有条带塌缩到 1）、`exp1_fluctuations.png`、`exp1_zscore_hist.png`、`exp1_spectrum.png`。

**观察 1.1 — 奇异级数几乎吸收了全部算术结构。** 彗星图的多条带完全由 ∏(p−1)/(p−2) 解释；修正后残差的功率谱从 ~10⁸ 倍中位数的谱线降到 ~6×10⁴ 倍，剩下的谱线仍在 1/3、1/5、2/7…处。

**观察 1.2 — 剩余谱线来自“素数赛跑”（Chebyshev 偏差）。** 用 π(X;q,a) 各剩余类的实际计数预测 E 按 N mod q 的类均值：mod 3 预测 (0, +4.2e−4, −4.2e−4)，实测 (0, +5.5e−4, −5.5e−4)；mod 5、mod 7 符号与模式也一致，幅度在同一量级。也就是说，HL 之后剩下的“结构”是素数在剩余类间的有限规模不平衡，而不是新的算术规律。

**观察 1.3（最值得跟进）— 真实素数的涨落比随机模型“更安静”。** Fano 因子 Var(r−HL)/HL：真实素数约 0.35→0.58（缓慢上升），独立 Cramér 模型对有序计数应为 ≈2；Granville 型模型（先用 p≤z 筛，再随机）在大 N 时都高于真实值（z=7: ~1.3，z=50: ~1.5）。解释：真实素数相当于被所有 ≤√N 的素数筛过，筛法压低了方差。这与 Montgomery–Soundararajan 关于短区间素数计数方差的结论同类。涨落规模 ~N^{1/2} 与 GRH 下的平方根消去一致。

## 2. 实验2：和/差对偶、指数和、ax+b 普适性（X = 2²⁴ ≈ 1.68×10⁷）

| 指标 | 结果 |
|---|---|
| r(n)/(2C₂Li₂) 与 d(n)/(2C₂Li) 的相关（d = #{p : p+n 也是素数}） | **0.9998**（同一个奇异级数） |
| 去掉奇异级数后残差 E_sum 与 E_diff 的相关 | **−0.10**（X=2²⁰ 时 −0.16，随规模减弱；按 n mod 30 分类去均值后仍 −0.10） |
| corr(E(N), E(N+h)) 与 h 的奇异因子的相关 | **0.96** |
| \|S(a/q)\|²/π(X)² 实测 vs (μ(q)/φ(q))² | 1/3: 0.244 vs 0.25；1/5: 0.062 vs 0.0625；1/7: 0.027 vs 0.0278；1/11: 0.0098 vs 0.01；q 含平方因子处为 0 ✓ |
| #{p≤2×10⁶ : ap+b 素数} / Bateman–Horn，a∈{1,2,3,4,6}，每个 600 个 b | 均值 0.998–0.999，标准差 0.003–0.004，全部落在 [0.986, 1.013] |

图：`exp2_sum_vs_diff.png`、`exp2_lag_corr.png`、`exp2_exponential_sum.png`。

**观察 2.1 — 和与差是同一个傅里叶对象的两面。** r(N)=∫S(α)²e(−Nα)dα，d(h)=∫|S(α)|²e(−hα)dα。主弧（α≈a/q）给出完全相同的奇异级数；图 `exp2_exponential_sum.png` 显示 |S(α)|² 的尖峰恰在 a/q、高度 (μ(q)/φ(q))²。真正的难点全部在次弧（尖峰之间的“噪声底”），哥德巴赫与孪生素数在这里的区别是 S² 与 |S|² 的相位：和问题需要次弧上的相位不相干，差问题只需要模长。

**观察 2.2 — 哥德巴赫计数之间的相关由“差”的奇异级数控制。** E(N) 与 E(N+h) 的相关在 h≡0 (mod 6)、尤其 h=30、210 处出现峰值，模式与孪生型奇异因子 S(h) 相关 0.96。这是“和/差对偶”的直接数值体现。不过很大一部分可归因于观察 1.2 的赛跑效应（N 与 N+6 同属 mod 3 类）。

**观察 2.3（未解释）— 和残差与差残差弱负相关（−0.10）。** 它不来自奇异级数（与 log S 的相关仅 −0.005），也不来自 n mod 30 的类均值。它随规模减弱，可能是有限规模效应。值得到 10⁹ 规模复查（适合 GPU 的 FFT 任务）。

**观察 2.4 — 关于你的 ax+b 想法。** 在仿射映射 p ↦ ap+b 下（N−p 是 a=−1 的情形，孪生是 a=1,b=2，Sophie Germain 是 a=2,b=1），计数/Bateman–Horn 的比值分布对 a 几乎没有区别。数据告诉我们：在“计数”层面，仿射结构的全部信息就是一个局部（逐素数）的奇异级数；加法和乘法的纠缠只通过“哪些剩余类被禁止”进入。所以如果 ax+b 统一框架要有新东西，它必须作用在次弧/相位层面，而不是密度层面。

**观察 2.5 — 关于量子/关联函数类比。** 有两个可以落地的对应：(i) |S(α)|² 就是素数指示函数的“结构因子”（散射谱），主弧尖峰相当于布拉格峰，次弧相当于漫散射底；(ii) 观察 1.3 的“亚泊松”涨落（Fano<1）在物理上对应反聚束、类费米子的刚性，与黎曼零点的 GUE 对关联是同一类现象。可检验的方向：E(N) 的方差随窗口长度的标度是否符合 Montgomery 对关联给出的形式。

## 3. 实验3：覆盖视角（全量偶数 N ≤ 10⁹）

### 3.1 最小哥德巴赫素数 p_min(N)

- 10⁹ 以内的每个偶数 N≥6 都找到了分拆（与已知的 4×10¹⁸ 验证一致，此处只作代码校验）。
- 33 个纪录点，与 OEIS A025018/A025019 一致，例如 3526958→727，60119912→1093，721013438→**1789**（10⁹ 内最大）。
- 纪录值 / log²N：从 ~3.2 缓慢增至 4.3，比 log²N 增长得更快，与 log²N·log log N 型启发式相容。
- 各量级平均 p_min：10³: 7.3，10⁶: 20.3，10⁹: 36.4，近似线性于 log N（每个数量级 +≈5.3）。
- 尾部：P(p_min ≥ 101) = 8.4%，≥211 为 1.3%，≥503 为 2.1×10⁻⁴，≥1009 为 6×10⁻⁷。

### 3.2 “还差多远才是反例”：筛的幸存者曲线

对每个 N，令 S_z(N) = #{p ≤ N/2 : N−p 没有 ≤z 的素因子}。反例要求 z=√N 时 S_z=0。

- 对 5 个 N（含两个纪录保持者和一个高度合数 N=96996900），在整个 z∈[3, √N] 上 S_z 都精确地沿“独立性预测” π(N/2)∏_{l≤z, l∤N}(1−1/(l−1)) 下降，**在 z=√N 时实测/预测 = 0.905–0.912 对所有 N 都一样**。这正是 Mertens 悖论的常数 e^γ/2 ≈ 0.890（有限规模修正后）：朴素的“独立覆盖”在 z=√N 处必然多估一个固定常数。这也是筛法“奇偶性障碍”在数据中的样子：筛法本身分辨不出幸存者是素数还是两个大素数之积。
- 纪录保持者（p_min 很大的 N）幸存者比例最低，因为它们不被 3、5、7 等整除，覆盖效率最高；但仍有约 9.3 万个幸存者（N=37998938）。

### 3.3 对抗性贪心覆盖：如果每个模 l 的剩余类可以自由选

固定 Y，对 l=3,5,7,…，每次选择能“覆盖”最多剩余素数 p≤Y 的剩余类（相当于通过中国剩余定理挑一个“最坏的 N”）。

| Y | 素数个数 | 全部覆盖所需最大模 L | 所用模数个数 | L/√(2Y) |
|---|---|---|---|---|
| 10⁴ | 1227 | 443 | 85 | 3.1 |
| 10⁵ | 9590 | 2393 | 355 | 5.4 |
| 10⁶ | 78496 | 15083 | 1761 | 10.7 |
| 10⁷ | 664577 | 102607 | 9824 | 22.9 |
| 3×10⁷ | 1857857 | 264283 | 23172 | 34.1 |

拟合：L ∝ Y^0.80，模数个数 ∝ Y^0.70；而真实的 N≈2Y 只能使用 l ≤ √(2Y) ∝ Y^0.5。缺口以幂律扩大。在 l=√(2Y) 处，贪心对手只比“类被 N 强制”的情形少约 20% 的幸存者（Y=5×10⁶：25833 vs 32018），且图 `exp3_survivors.png` 显示真实纪录保持者的曲线几乎贴着贪心对手。

**解读**：用“每个小素数取一个剩余类”的同余方式覆盖所有 N−p，即使允许最坏情况的自由选择，也需要远超 √N 的模。这是“局部（同余）障碍不存在”的定量版本。但它不排除非局部的、全局性的阴谋（这正是证明的难点），所以只说明“覆盖”这条路要找反例，必须依赖与剩余类无关的结构。注意贪心不是最优覆盖，表中的 L 是上界，真正的最小值可能略小，但幂律缺口不太可能消失（每个模 l 至多覆盖约 1/(l−1) 的素数是硬约束）。

## 4. 总结：数据指向哪里

1. **密度层面已经“解决”**：HL/Bateman–Horn 在 10⁻³ 精度内成立，残差近高斯、量级 √N，剩余谱线由素数赛跑解释。在密度层面寻找新规律的空间很小。
2. **困难集中在两处**：次弧上 S(α)² 的相位相消（circle method 的视角），以及筛法的奇偶性障碍（覆盖视角中的 e^γ/2 常数）。这两处是同一障碍的两种表现。
3. **最有意思的数值线索**：(a) 真实素数的亚泊松刚性（Fano≈0.5 且缓慢上升）——可以和 Montgomery 对关联/GUE 做定量比较；(b) 和/差残差的弱负相关 −0.10——未解释，需要更大规模确认。
4. **对 ax+b 和量子类比的建议**：把它们落在次弧/对关联层面，而不是密度层面。
