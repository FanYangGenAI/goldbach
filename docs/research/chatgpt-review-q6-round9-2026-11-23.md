## 2. (a) 背景 v2：核心修补正确，两个实现边界要说明

令

\[
g(x)=\frac{x^{-0.45}}{\log x},\qquad
\widetilde\delta_z(x)=\delta_z(x)+zg(x).
\]

定义

\[
J_1=\int_2^{N-2}\delta_z(N-x)g(x)\,dx,\qquad
J_2=\int_2^{N-2}g(x)g(N-x)\,dx.
\]

则

\[
\int\widetilde\delta_z(x)\widetilde\delta_z(N-x)\,dx
=I_0+2zJ_1+z^2J_2.
\tag{1}
\]

脚本的 `corr_integrals()` 把区间分成两半，在第二半作 `x↔N-x`；随后用 `u=x/N=exp(v)`，Jacobian 为 `N u dv`。J1 两个半区间的加法、J2 的因子 2，以及 `I2=I0+2*z*J1+z*z*J2` 都正确，没有发现重复计数或漏掉 N 的问题。

局部因子的导数也正确。设对角局部因子为 `r_p(z)`，则

\[
T_N(z)=\sum_p\log p\;z\frac{r_p'(z)}{r_p(z)}.
\]

对 `p∤N`：

\[
z\frac{r_p'(z)}{r_p(z)}
=\frac{-2z(z-1)}{(p-1)^2-(z-1)^2}.
\tag{2}
\]

对 `p|N`，可从

\[
J_0(z)=\frac{p-2+z}{p-z},\quad J_0'(z)=\frac{2(p-1)}{(p-z)^2},
\]

\[
J_e=1-\frac1p+\frac{z^2}{p}J_{e-1},\quad
J_e'=\frac{2zJ_{e-1}+z^2J_{e-1}'}p
\]

直接递推，得到 `z J_e'/J_e−2z/(p−z)`。原脚本对这部分仍使用步长 `1e-6` 的中心差分，并不是整个 T 都用了闭式解析导数。复核使用了上述解析导数；结果与保存值一致到足以排除它解释本轮观测效应的精度。

背景的二次系数现在确实统一了：`[z]tilde_delta=1/log x`、`T_N(0)=0`，故

\[
[z^2]B_N(z)=\mathfrak S(N)
\int_2^{N-2}\frac{dx}{\log x\log(N-x)}.
\tag{3}
\]

例如，对两个代表 N，通过 z=0 的系数积分独立计算 (3) 及三次系数，再与 64 点圆周抽取比较，归一化到 N 后的差小于 `1.2e-15`。数学合同中的无限素数乘积与数值程序的有限截点仍须区分；这里是在同一有限素数实现下核对系数一致性。

两个需要保留的限定：

1. **I1 的选择是背景定义的一部分。** 目前 I1 只使用未修补的 δ，合同已写明，且不破坏 (3)。它不是把第八轮式 (10) 中的每个 δ 都换成 tilde_delta 后的完全同一表达。可以冻结现有版本，不必立即修改；若改成全部修补密度，应另命名、报告变化。
2. **数学上的可去奇点尚不等于代码能在该点求值。** `RT()` 仍算 `log r_p` 与 `r_p'/r_p`，最后才乘 R。在 `3∤N,z=-1` 处会出现 `log(0)`、无穷大与 `0*infinity`。指数化引入的本性奇点已经从数学表达中消失，但当前数值函数还没有实现那里所需的可去延拓。对本轮 `|z|=0.5` 没有影响；不能据此声称已经实现了可供 −1 邻域零点计算使用的函数。

还要注意，系数修补在远离原点处会改变零点结构：未修补的 `delta_{-1}=0`，而 `tilde_delta_{-1}=-g` 不为零。因此“背景现在全纯”不表示旧背景在 −1 的零点阶数也保留下来。当前不用这个邻域作机制解释是正确的。

## 3. 一处应立即修复的统计错误：复标准差不是两份标准误

源代码写成

```python
sem = E.std(0, ddof=1) / sqrt(n)
sem_re = sem.real
sem_im = sem.imag
```

NumPy 对复数的标准差是 `sqrt(sum(abs(E-mean)**2)/(n-1))`，结果是实数。因此这里的 `sem_im` 恒为零，`sem_re` 则合并了两个分量的波动，不能当作实部分量标准误。[文献 1]

应分别计算：

```python
sem_re = E.real.std(0, ddof=1) / sqrt(n)
sem_im = E.imag.std(0, ddof=1) / sqrt(n)
```

对相位本身则计算 `phi_N=arg(H_N/B_N)=arg(1+epsilon_N)`，报告其均值与标准误。小残差时虚部近似相位，但不是定义上的同一量。

独立复算 `z=0.5i` 的虚部均值：

| 样本 | 均值 | 正确的分量标准误 |
|---|---:|---:|
| Q4b 10^6 | −0.1165% | 0.0819% |
| Q4b 10^7 | −0.1855% | 0.0300% |
| Q4b 10^8 | −0.1465% | 0.0222% |
| Q5d 10^7 | −0.1086% | 0.0505% |
| Q5d 10^8 | −0.1332% | 0.0239% |
| Q5d 10^9 | −0.1618% | 0.0181% |

同号的小偏差确实存在；部分组的均值显著，但不是每组都超过 3 个正确标准误。实际相位的复算也与此量级相近。不能用原 JSON 中为零的虚部标准误支持结论。

Hermitian 协方差 `Xc.T @ Xc.conj()` 的共轭方向则正确，没有发现这部分矩阵算错。

## 4. (b) 16 点是混叠分解，但本轮主结论通过了 64 点复核

写

\[
\frac{E_N(z)}{z^2N}=\sum_{k\ge0}a_{k,N}z^k,
\qquad a_{k,N}=\frac{e_{k+2,N}}N.
\]

在半径 ρ 上做 M 点 FFT，得到的准确公式为

\[
\widehat d_{k,N}^{(M)}
=\sum_{\ell\ge0}a_{k+\ell M,N}\rho^{k+\ell M},
\quad 0\le k<M.
\tag{4}
\]

所以 M=16 时，Parseval 严格分解的是 **16 个离散 Fourier 模式的方差**，不是已经无混叠地分解了无限个 Taylor 扇区。直接把每一项叫成 e_m 需要数值收敛检查。

我用独立的素数级数计算密度、局部闭式导数与截断不完全 beta 积分，重算了全部 300 份多项式的 64 点背景。64 点结果在原 16 个角度上，与保存的 `D_N/N` 的最大绝对差约 `4.6e-12`。两个代表 N 的低阶系数另以 z=0 导数积分核对。

**主模态和 m=3 结论保留。** 在 10^9，64 点给出首特征值比例 `82.6835%`、m=3 方差份额 `41.2938%`、主成分振幅与该系数的相位不变相关约 `0.9762`，与 16 点相近。

混叠对很小的 Goldbach 残差系数仍应认真控制：该组 16→64 点的 `e_2/N` 最大变化约 `2.83e-8`，`e_3/N` 约 `6.88e-8`。它没有推翻本轮主模式，但不宜把 16 点系数当作精确值反复放大或做高精度均值判断。

六组样本的 64 点结果如下：

| 样本 | 首主成分方差比例 | m=3 方差份额 | 与 m=3 系数的相关绝对值 |
|---|---:|---:|---:|
| Q4b 10^6 | 67.04% | 50.94% | 0.9834 |
| Q4b 10^7 | 46.21% | 37.53% | 0.9833 |
| Q4b 10^8 | 68.74% | 50.63% | 0.9782 |
| Q5d 10^7 | 56.60% | 49.12% | 0.9864 |
| Q5d 10^8 | 73.31% | 57.66% | 0.9927 |
| Q5d 10^9 | 82.68% | 41.29% | 0.9762 |

因此“约 83%”应明确只指当前 10^9 组。各组并非都已近乎秩一；例如 Q4b 10^7 的首成分仅占 46%。m=3 的范围也应写成约 38%–58%，而不是遗漏其中一组后的 41%–58%。

原程序用 `amp.real` 和系数实部相关，依赖主特征向量的相位约定。复核改成相位不变的复相关，仍得到上述高相关；现有结果没有因此失效。建议以后显式固定相位或始终使用相位不变统计量。

## 5. 半径权重确有决定性作用，但不能把全部结构说成权重假象

在连续圆周、系数无混叠时，方差份额严格为

\[
S_m(\rho)=\frac{\rho^{2(m-2)}\operatorname{Var}(e_m/N)}
{\sum_{j\ge2}\rho^{2(j-2)}\operatorname{Var}(e_j/N)}.
\tag{5}
\]

因此“哪个扇区方差最大”本来就依赖半径。只要 `Var(e_2/N)>0`，当 `rho→0` 时必有 `S_2→1`；不可能把 m=3 的主导地位表述为任意接近原点都成立的性质。

从已收敛的 64 点系数向更小半径延拓，得到：

| 样本 | 半径 | m=2 份额 | m=3 份额 | 首主成分比例 |
|---|---:|---:|---:|---:|
| Q4b 10^6 | 0.10 | 87.87% | 11.94% | 93.16% |
| Q4b 10^6 | 0.25 | 51.50% | 43.73% | 79.35% |
| Q4b 10^6 | 0.50 | 15.00% | 50.94% | 67.04% |
| Q5d 10^9 | 0.10 | 25.99% | 72.44% | 79.16% |
| Q5d 10^9 | 0.25 | 4.70% | 81.92% | 92.43% |
| Q5d 10^9 | 0.50 | 0.59% | 41.29% | 82.68% |

这给出一个兼顾两面的回答：低规模的“m=3 占主导”确实会随合理的半径变化而翻转；但 10^9 组在 0.1、0.25、0.5 三个半径上都保留了很强的 m=3 成分，所以不能简单把该组结果全部归为 0.5 权重造成的假象。

还应区分两条证据的力度。即使各系数互不相关，只要加权后的 m=3 方差最大，PCA 首轴也可以就是该系数，相关系数等于 1；所以“主成分与 e3 高相关”本身不是发现共同源头的证据。另一方面，本轮 10^9 的最大单一方差份额约 41%，首特征值却占 83%，说明样本中的跨系数协方差确实有作用。需要解释的是这些协方差，不能只解释 PCA 轴为什么接近最大方差的坐标。

## 6. 低秩结构的一部分来自尚未去掉的分组均值

Q6b 把每个规模的全部 N 合在一起中心化，没有先扣除 mod 3 分组均值。对于两个分组，有精确分解

\[
\sum_i\|D_i-\bar D\|^2
=\sum_g\sum_{i\in g}\|D_i-\bar D_g\|^2
+\sum_g n_g\|\bar D_g-\bar D\|^2.
\tag{6}
\]

两组均值差贡献一个秩至多为 1 的协方差部分，它不需要任何新的随机共同源头。

在 10^9 组，**mod 3 组间均值差占总中心化方差迹的约 38.17%**。分别扣除两组均值后，剩余协方差的首成分占比约为 **76.16%**；各组内部的首成分比例约为 77.25% 和 84.13%。

所以低秩结构没有被分组均值完全解释，但其中相当一部分是已知算术分组的系统性差异。不能把 pooled 的 83% 整体都称为随机涨落的共同驱动。下一步至少同时报告 pooled、mod 3 内中心化，以及预先固定的 ν₂ 粗分层；不要为了追求秩一而事后选择分组。

另有两个术语应收窄：

- m=3 确实只能由 `(Omega(n),Omega(N-n))=(1,2),(2,1)` 组成，包括半素数为素数平方的情形。但它是 **计数减背景后的系数**，不是原始陈氏表示数；陈氏“素数加至多两个素因子的数”还包含 m=2 部分。这里没有建立关于这类表示的新定理。
- 对角多项式 H 只保留 `j+k=m` 的和。m=3 可明确识别，但 m=4 已把 `(1,3),(2,2),(3,1)` 混在一起；仅从 H 不能判定每个更高扇区的具体两侧来源。第九轮中列出的五个相关数应标成 e₂…e₆，而不是 e₂…e₅。

## 7. (c) 最直接的检验：先定义一个不拟合的线性预测器

取同一个、冻结的离散单系统背景

\[
f_z(n)=z^{\Omega(n)},\quad d_z(n)=\widetilde\delta_z(n),\quad
q_z(n)=f_z(n)-d_z(n),\qquad n\ge2,
\]

在 n<2 处置零。卷积指普通加性卷积。则恒等式为

\[
E_N(z)=C_N(z)+Q_N(z),
\tag{7}
\]

\[
C_N(z)=2(d_z*q_z)(N),\qquad
Q_N(z)=(q_z*q_z)(N)+(d_z*d_z)(N)-B_N(z).
\tag{8}
\]

这就是应先检验的“单系统交叉项”定义。C 只线性使用单系统误差，不需要 Goldbach 或素数+半素数的配对计数。其系数、符号与幅度已由定义固定，不应该再拟合一个系数后宣称它解释了残差。

特别要保留 Q 中的 `(d*d)-B`：现有 B 含有 p 进局部因子与 Mellin 修正，而 `d*d` 没有。`q*q` 自身包含大幅局部相关，可能与这项相消。不能单独把 `q*q` 大小叫作“新关联”，也不能省去这项声称进行了恒等分解。

### 7.1 不必先算整个复圆周，直接测试 m=3

写

\[
d_z(n)=\sum_{j\ge1}a_j(n)z^j,\quad
f_j(n)=\mathbf1_{\Omega(n)=j},\quad q_j=f_j-a_j.
\]

有 `a_1(n)=1/log n`，a₂ 是选定割线密度的二次系数；修补 `zg` 不改变 a₂。因此

\[
c_{2,N}=[z^2]C_N=2(a_1*q_1)(N),
\]

\[
c_{3,N}=[z^3]C_N
=2\{(a_1*q_2)(N)+(a_2*q_1)(N)\}.
\tag{9}
\]

等价地，

\[
c_{3,N}=2\{(a_1*f_2)(N)+(a_2*f_1)(N)-2(a_1*a_2)(N)\}.
\tag{10}
\]

这里没有 `f_1*f_2` 项。预测器只需素数、半素数的一维序列及平滑权重；而真实 h₃ 是 `2(f_1*f_2)(N)`。这是有区分力的预测，不是把待解释的配对计数换个名字。也能看出，“单系统误差”不仅包含素数计数误差 q₁，还包含半素数误差 q₂，不能只用 `psi(x)-x` 替代整项。

### 7.2 已做的小规模诊断：当前不支持这个来源解释

对现有 Q4b 的 60 个 N≈10^6，我独立重建 Ω 序列，计算 a₁、a₂，并用 FFT 卷积计算 (9)。背景 b₂、b₃ 以 z=0 的导数积分计算，不使用 16 点混叠系数。观察量是 `(h_m-b_m)/N`，预测量是 `c_m/N`。

对二者分别减去本组均值后，定义不拟合斜率的预测分数

\[
R^2_{\rm pred}
=1-\frac{\sum_i|(e_{m,i}/N_i-\overline{e_m/N})
-(c_{m,i}/N_i-\overline{c_m/N})|^2}
{\sum_i|e_{m,i}/N_i-\overline{e_m/N}|^2}.
\tag{11}
\]

| 扇区 | 相关系数 | 预测标准差 / 实测标准差 | 不拟合斜率的中心化 R² |
|---|---:|---:|---:|
| m=2 | 0.1676 | 3.71% | 0.0111 |
| m=3 | −0.0057 | 1.35% | −0.00034 |

m=3 在 3 倍数与非 3 倍数组内的相关也仅约为 −0.046 和 +0.044。结论不是由 pooled 的组间均值掩盖了一个明显的组内关系。

数值检查：a₂ 的对数插值网格从 8193 加密到 16385，预测量归一化到 N 后的最大变化约 `2.24e-11`；三个代表样本的直接点积与 FFT 计算 c₃ 相差不超过 `5e-11`（未除以 N），并独立重数核对了 h₂、h₃。这些数值误差远小于观察到的波动。

**此诊断只覆盖 10^6，不能代替 10^9 的源头判断。** 但它已经否定了“同一个全局交叉项显然解释整个已测范围的主模式”这种说法。C 的平均值可以与 E 同量级，仍不能解释中心化波动；要同时看相关和幅度。

### 7.3 如何推进到大 N 而避免重做二元配对计数

下一步可固定 (9)，计算一维累计误差

\[
Q_j(x)=\sum_{2\le n\le x}\{f_j(n)-a_j(n)\},\quad j=1,2.
\]

用分部求和把 `(a_k*q_j)(N)` 化为已知平滑核对 Q_j 的积分，或用分段 FFT 卷积。这样只需单系统素数/半素数信息，不需重建双变量配对。

同时报告：

1. `(e_3/N,c_3/N)` 的未中心化均值、组内相关、标准差比和 (11)。
2. 对 pooled 与固定 mod 3、ν₂ 分层分别计算；核对同一背景下的剩余 `E-C`。
3. 如低阶系数支持该解释，再比较 C 在复圆周上的预测协方差、相位及固定主成分载荷，不能只要求与一个事后选择的 PC 高相关。
4. 均值与所有斜率若需估计，训练和验证规则要冻结。300 份样本已经全部探索过，事后再切分不能称为新的盲确认；可先完成诊断，再在同一 N 范围内注册未使用的新随机样本。

若 C 的幅度仍远小于 E，就应如实转向 (8) 中的剩余二次关联与局部补偿项，而不是通过拟合巨大倍数或不断改背景把交叉项强行变成主解释。

## 8. 背景版本敏感度的正确用法

这里澄清第八轮的标准：A→v2 的差异不是 v2 的理论误差条。版本 A 已知漏了某些确定项；加入它们后，改变量大于新残差，并不证明新残差没有数学意义。

## 9. 这一步与群／量子主线的关系

本轮的“粒子数扇区”提供了清楚的系数分解；但 PCA 主成分是选定内积和概率空间下的协方差特征向量，不自动是某个量子 Hamiltonian 的本征态。半径对应的权重尚没有一个使其唯一的物理原则，因此必须把权重写进结论。

检验 (8) 可以直接用有限循环群上的卷积与 Fourier 变换：对序列零填充到足够长，`C_hat=2*d_hat*q_hat`，二次剩余则含 `q_hat^2` 及已知的背景补偿。这样把“单系统线性响应”和“二次关联”区分成可测的对象；本次小规模试算就是沿这个方向实现的。它没有引入筛法，也没有把换一种基底本身当作新定理。

当前应争取的成果是：哪一个精确定义的项解释了哪些扇区的哪些波动，或明确证明某个候选解释不够。这个问题比继续给同一个 PC 寻找物理名称更容易形成可审阅的进展。
