## 0. 声明的层级

审计时请按层级区分：
- **[R] 严格**：简单但严格的数学事实。
- **[N] 数值**：可复现的计算结果（脚本、随机种子、JSON 输出都在仓库里）。
- **[H] 启发式**：对数值的解释，未经证明。

## 1. 一句话结论

在 N ≤ 6.7×10⁷ 的范围内，数据支持一个完整的统计模型：**R(N) = N·𝔖(N) + G(N)**，其中 G(N) 是近高斯、方差 ≈ 0.05·N·log³N·𝔖(N)^γ（γ ≈ 0.84 → 1）的噪声。在这个模型下，“几乎所有 N” 到 “每一个 N” 之间缺失的信息可以精确定位为：**一个超过二阶、且损失不超过 x^{o(1)} 的矩估计**。二阶矩即使取其真实值，也有结构性的天花板（只能把例外压到约 log^{2.5~3}x 个）。

## 2. 主要发现

### 2.1 主项是完整奇异级数，次弧中的“结构”全部是算术尾项 [N]
- θ 加权的 R(N) 做精确的主弧/次弧分解（FFT 网格上是恒等式）。分母 ≤ 16 的主弧已使每个 N 的次弧贡献小于主项的一半（X = 2²⁴）。
- 次弧贡献原本高度非高斯（峰度 13.5）。把奇异级数尾项 N·(𝔖(N) − 𝔖_Q(N)) 作回归，系数 **a = 0.9998**（理论值 1），R² = 0.74。剩余部分按 𝔖(N)^{γ/2} 做异方差标准化后，峰度约 0.18，极值与高斯一致。
- 尾项几乎只朝正方向偏：负向最多 −2%（Q=256），光滑 N 处的大偏差全是正的。[N]
- [H] 圆法中“主弧/次弧”的划分在算术层面是人为的；真正的困难只在噪声部分 G(N)。

### 2.2 墙 A（次弧）的量化 [N]
- 证明只需要次弧比平凡界 ∫_𝔪|S|² 小约 6 倍（≈ log X 量级）；实际中位数小 417 倍，最差的 N 也小 24 倍（X=2²⁴，Q=256）。
- [H] 困难在于 **证明** 相位相消，而不是相消是否存在。

### 2.3 墙 B（奇偶性）的量化 [N]
- 取 z = N^{1/3}，粗糙的 N−p 只可能是素数或 P₂。用“筛法对 m 和 N−m 两侧都知道的全部信息”作基线，素数份额被预测到相对 5×10⁻⁵ 以内，没有任何 N 的算术记忆（45 个剩余类检验 max|t| = 2.66），涨落比独立抛硬币小（z 分数 sd 0.65–0.76）。离奇偶性反例最近的 N 也只低 0.3%（10⁸）。
- 方法论教训：单侧基线会把素数与 P₂ 的剩余类赛跑误判为“结构”（E1.1 因此失败，E1.2 修正）。
- [H] 墙 B 在数据上化归为：Liouville 函数在移位素数 N − p 上的二元 Chowla 型估计，对每个 N 一致成立。

### 2.4 矩阶梯 [R] + [N]
- [R] 在二进窗口 [x, 2x] 中，若 B_p := Σ_N |F(N)/(N𝔖(N))|^p < 1（F = R − N𝔖），则窗口内每个偶数都有 R(N) > 0。这是平凡的（每一项都 < 1）。
- [N] B₂ 随 x 增长（8 → 35，约 ∝ log^{2.5~3}x）；B₄ 下降（0.06 → 2.5×10⁻⁴，约 ∝ x^{−0.65}）。F 标准化后 m₄/m₂² ≈ 3.17，极值 max|z|/√(2 ln n) ≈ 1.0，且都不随 x 增长。
- [R]（简单计算）若 F 具有上述真实分布，则对任意 p > 2，B_p → 0。对照已知结果：Hardy–Littlewood 在 GRH 下得到 Σ_{n≤x}F(n)² ≪ x^{5/2+ε}，比真实的 x²·log³x 差 x^{1/2}；用二阶矩加平凡上确界去估四阶矩，结果也恰好差 x^{1/2}。
- [H] 因此：**二阶矩方法（包括 GRH 级别的信息）在结构上只能给出“几乎所有”；任何能把高阶矩控制到真实大小 x^{o(1)} 倍以内的方法，都会推出充分大 N 的哥德巴赫。**

### 2.5 素数的“刚性” [N]
- 未加权计数的 Fano 因子 Var/均值 ≈ 0.35 → 0.58（N 从 10³ 到 3×10⁷），远低于 Cramér 模型的 2，也低于先筛小素数再随机的 Granville 型模型。θ 加权方差的经验律为 σ² ≈ 0.05·x·log³x，介于 x·log²x 与 x·log³x 之间。
- [H] 这与 Montgomery–Soundararajan 关于短区间素数方差的现象同类；从 Hardy–Littlewood k 元组猜想推导 log³ 律是下一步的理论任务。

### 2.6 其他 [N]
- 10⁹ 以内最小哥德巴赫素数的纪录与 OEIS A025018/A025019 一致（最大 1789，N = 721013438）。
- 对抗性“同余覆盖”（每个模的剩余类可以自由挑选）要盖住 Y 以内的全部素数，最大模约需 Y^{0.80}，而真实的 N ≈ 2Y 只能用到 √(2Y) 以内的模。[H] 反例不可能来自剩余类层面的阴谋。
- 和/差去奇异级数后的残差有 −0.10 的弱相关，随规模减弱，原因未明（待用 GPU 在更大规模检查）。

## 3. 与已知文献的关系（请审计者重点核对）

- “几乎所有偶数是哥德巴赫数”（例外集 E(x) ≪ x^{1−δ}）由圆法加二阶矩得到（Montgomery–Vaughan 1975 等）。我们的 B₂ 曲线是这一事实的数值写照。
- GRH 下的二阶矩界 x^{5/2+ε} 出自 Hardy–Littlewood，见 Goldston–Suriajaya 的综述性引言。
- 奇偶性障碍（Selberg）、陈景润 1+2 定理对应我们的墙 B。
- 我们认为以下几点 **可能** 是新的表述或数值证据（需要审计者判断是否已有文献）：
  (i) 次弧非高斯性被完整奇异级数尾项以系数 0.9998 吸收，之后只剩异方差高斯噪声；
  (ii) 方差的经验律 σ² ≈ 0.05·x·log³x，以及 B₂ 随对数增长的结构性天花板；
  (iii) 双侧筛基线下，粗糙 N−p 中素数份额的亚二项涨落。

## 4. 已知局限

- 数值范围 ≤ 6.7×10⁷，对数因子的标度（log³x 等）在这么短的对数范围内很难与 log²x·log log x 之类区分。
- E3.1 的 P1、P2（六阶）、P4 按预注册阈值判为失败；失败原因已诊断（多一个对数因子、残余异方差），但这些诊断本身未经独立预注册检验。
- 我们使用 θ 加权（不含素数幂），主项附近有 O(√N) 量级的低阶项，表现为平均偏差 −3×10⁻⁴（x ≈ 3×10⁷）。

## 5. 下一步（按价值排序）

1. **理论**：从 Hardy–Littlewood k 元组猜想（四元组的奇异级数平均）推导 Var(F) 的渐近，检验 0.05·x·log³x 及其中的常数。若吻合，就得到一个完整的、有理论依据的二阶统计模型。
2. **数值（GPU）**：用 4090 上的 cuFFT 把 L2/L3 推到 10⁹–10¹⁰，区分对数因子的形式，并复查 −0.10 的和/差相关。
3. **高阶矩的结构**：Σ|F|⁴ 对应八元素素数加性关系的计数，研究它在主弧上的分解，看能否找到比“二阶矩加上确界”更好的、可证明的中间量。

## 附录 A（第二轮，2026-11-23）：GPU 扩展到 x = 4.3×10⁹（`gb/L3b-variance-law-gpu`，E3.2）

- 用 RTX 4090 的分块 FFT 卷积精确计算了 x = 2²³…2³² 处宽度 2²² 的窗口内全部偶数 N 的 R(N)。与 CPU 结果逐点一致（相对误差约 10⁻⁹）。[N]
- **方差律修正**：窄窗口下 σ² = Var(F/√𝔖) ≈ 0.13·x·log^{2.5}x（自由拟合指数 2.62），而不是第一轮写的 0.05·x·log³x。第一轮的数据来自二进宽窗口，混合了不同 N 处的方差。在此范围内，log^{2.5} 与 log²·(a+b·log x) 无法区分。σ² 约为 Cramér 对角项 2x·log²x 的 25–31%，比例随 x 缓慢上升。[N]
- **高斯性**：窄窗口下 m₄/m₂² = 3.00–3.07，m₆/m₂³ ≈ 15.1，极值与 √(2 ln n) 一致。第一轮的六阶矩超标同样来自宽窗口混合。[N]
- **矩阶梯保持**：外推到二进窗口的 B₂ 从 32 升到 90，B₄ 从 8×10⁻⁴ 降到 1.3×10⁻⁵。在 x = 4.3×10⁹ 处，反例需要偏离约 4300 个标准差。[N]
- 因此第 1 节的一句话结论应读作：G(N) 局部近高斯，方差 ≈ 0.13·N·log^{2.5}N·𝔖(N)^γ。
