# 自主线阶段性盘点（2026-11-27 17:15）

## 1. 与最终目标（哥德巴赫）的关系，如实说明

- **M1（Liouville 阶梯）**：结论是一个**障碍**。在第一级台阶上，"异类"刚性解恰好由哥德巴赫构型生成。所以这条阶梯没有绕开素数的廉价路径。
- **M2（反射递推）**：目标是在 GRH 下把 Mangerel 对 Corrádi–Kátai 型和式的界 |Σλ(n)λ(p−n)| < p − p·e^{−C(log log p)^6} 改进到 p − p/(log p)^{2+ε}。这是 Liouville 函数的**二元哥德巴赫类比**的定量改进，**不在**通往哥德巴赫本身的路径上：它依赖 λ 的完全积性，素数没有这种性质。

## 2. M2 的严格部分与剩余缺口

严格：
- 反射步、引理 R₀、引理 H（层级图约化）、引理 M（多重度 ≤ 2|D| + 2）；
- 命题 F（固定 Z/q 时覆盖率 → 0，依赖 Ford 2008），由此确定正确区间为 Z = q^{1+η}；
- 引理 E、E′、E″（几乎所有 n 都能逃离，且逃离顶点数 → ∞，用筛法，直接对真实 p 成立）；
- 缩放引理。

剩余：**猜想 G**（巨块的单点函数，以及在给定小模数余数条件下的去相关）。数值支持很强：E12–E17 中只有一个大块、且总含终点；η = 1/2 时 R 簇与终点 2 缩放簇的相交率达 99.5%–100%。但 E18 显示无条件独立性不成立，必须用条件形式。

## 3. 为什么不改做无条件版本

若存在 Siegel 零点，λ 在 [1, p) 上可能接近 Legendre 符号 (·/p)，此时 Σλ(n)λ(p−n) ≈ ±p。所以超出 Mangerel 无条件结果 |L| < p − 1 的改进，大概率要穿过例外特征这道经典障碍。GRH 在这里是自然的假设，M2 保持条件性的范围是合理的。

## 4. 决定

- 再用至多两小时推进猜想 G：先写出它的条件形式的精确陈述，再尝试在"截断到有界路径长度"的版本中，用线性型的局部因子计算协方差。
- 同时开一条新线 M3，回到素数问题。问题是：M2 中"缩放副本 + 相交 + 有界指示量的二阶矩"这套工具，能否用于哥德巴赫路径上的问题（例如例外集 E(X) 的估计，或 Chen 型的 P₂ 表示）。先做文献核对和一个小规模可行性实验。

## 更新（2026-11-28 02:30）：M3 的现状

- **已得到（待独立复核）**：定理 Q（GRH）：对充分大的素数 N，|L_λ(N)| ≤ N − N·exp(−C(log log N)²)。
  - 它把 Mangerel 命题 1.4 中的指数从 6 改进为 2。
  - 推论 Q′：每种符号模式的出现次数 ≫ N·exp(−C(log log N)²)。
  - 完整证明见 docs/research/M3_theorem_Q_full_proof.md。
- **严格的中间结果**：
  - 定理 W：对一切 N 成立的弱形式 L_q；
  - B = 0 时的刚性；
  - Thue 树证书；
  - 脊柱 + 毛毛虫结构（引理 SC）；
  - 松弛过程与命题 P1″；
  - 数字自动机（定理 D）。
- **两条改进路线，归结为同一类问题**：混合进制数字对模数的等分布。
  - 定理 Q⁺（指数 log log N·log log log N）只需要模 ≤ q² 的版本（引理 R）；
  - polylog 型节省 N − cN/(log N)^A 需要模数达到 q^{O(k)} 的版本。
- **定位**：这些都是 Corrádi–Kátai / Shusterman 型问题（哥德巴赫在 Liouville 函数上的类比）的有条件定量改进，**不是哥德巴赫猜想本身**。
