## 2. (a) 实现核对：没有发现大幅压低线性项的因素

### 2.1 预测公式、索引与素因子计数

代码的三项离散和分别是

\[
\sum_{\Omega(n)=1}a_1(N-n),\quad
\sum_{\Omega(n)=2}a_1(N-n),\quad
\sum_{\Omega(n)=1}a_2(N-n),
\]

范围均为 `2<=n<=N-2`，与第九轮公式一致。`elif o==2` 不会漏掉与素数分支重叠的整数，因为 Ω=1 与 Ω=2 本来互斥；素数平方已包含在 Ω=2 中。SPF 的整数范围和 Ω 的 int8 范围足够，未发现溢出、反射端点或多除一个 N 的问题。

### 2.2 a₂ 可以直接微分，不必依赖 FFT

令

\[
\ell(\sigma)=\log|\zeta(\sigma)|+
\sum_p\{\log(1-p^{-\sigma})+p^{-\sigma}\}.
\]

由于 `sin(pi z)/pi=z+O(z^3)`，严格按所选割线密度有

\[
a_2(t)=\int_{\sigma_0}^{1}\ell(\sigma)t^{\sigma-1}\,d\sigma.
\tag{1}
\]

有限素数实现中，还需对所用 E1 尾项求导，贡献为 `-E1/2`。审计按 (1) 直接取系数，再与原始素数对数运算得到的 32 点、半径 0.25 抽取比较：在完整 log 网格上，a₂ 的最大差约 **7.4e-13**；有限求积模型下，对所有 t≥2 的系数差绝对值上界约 **8.6e-13**。没有丢掉某个大的线性项。

对 `A(L)=a_2(exp L)`，线性插值误差满足

\[
|A(L)-A_{\rm interp}(L)|\le
\frac{(\Delta L)^2}{8}\sup|A''(L)|.
\]

用有限割线求积系数的绝对值和界定二阶导数，原 16385 点网格的统一绝对误差界约为 **2.44e-9**。这个界较保守，但已足以排除插值把主贡献压低两个数量级的解释。

### 2.3 离散和换成积分：可以很小，但恒等式需要记账

定义

\[
S_{12}(N)=\sum_{n=2}^{N-2}a_1(n)a_2(N-n),\qquad
I_{12}(N)=\int_2^{N-2}a_1(t)a_2(N-t)\,dt,
\]

并记 `eta_12=S_12-I_12`。则原程序的连续近似预测量满足

\[
\widehat c_{3,N}=c_{3,N}^{\rm discrete}+4\eta_{12}(N).
\tag{2}
\]

所以保存的 C 不是离散恒等式里的完全同一项。不能仅因误差相对 N 小，就不管它与待测涨落相比有多大。

这里可以直接控制它。对于 `h(t)=a_1(t)a_2(N-t)`，Euler–Maclaurin/一阶有界变差估计给出

\[
\left|\sum h(n)-\int h(t)dt\right|
\le\frac{|h(2)|+|h(N-2)|}{2}
+\frac12\int_2^{N-2}|h'(t)|dt.
\tag{3}
\]

用 a₂ 的有限 Laplace 和对其总变差作界，本批样本中，(2) 对 c₃ 的绝对影响上界不超过约 **2.87 个计数单位**。在 10^6 样本中，与第九轮完全离散卷积的直接比较，最大差约 **0.71 个计数单位**，符合这个量级。[1]

另外，我复算了六个代表 N 的连续卷积，改用按比例变量分段的高精度积分。原式 I12 与复算结果的最大差约 **0.023 个计数单位**。这不能构成全部 N 的区间误差证书，但没有显示出足以改变判定的求积问题。原代码丢弃了 `quad` 返回的误差估计，以后应保存；该估计本身也不是严格误差界。[2]

### 2.4 背景系数与总体误差尺度

对全部 300 个 N，我从 z=0 的系数积分独立计算 b₂、b₃，避免再用同一 FFT 抽取来验证自己。与保存值的最大差，除以 N 后分别约为 `2.1e-13`、`5.9e-13`。

把有限模型内的插值界、离散/连续差以及一个保守的浮点加法前向误差界相加，在 10^9 组中，它们相对实测组内中心化残差范数的界约为 **0.68%**。保存的线性项幅度约为 0.20%；即便把这些保守误差都往不利方向放大，仍远低于预注册“主要来源”所需的幅度。

限定必须说清：这些界针对已实现的有限密度模型，并非无限素数乘积/E1 尾项的严格区间证书；没有独立重数 10^9 的三个一维离散和。但结合直接低规模复核，没有证据表明某个数值错误掩盖了一个主导线性项。

## 3. (b) “主要波动在 Q 中”成立，但需要区分三个对象

冻结离散定义

\[
f_z(n)=z^{\Omega(n)},\quad d_z(n)=\widetilde\delta_z(n),\quad
q_z(n)=f_z(n)-d_z(n),\qquad n\ge2,
\]

在 n<2 处置零。则

\[
E_N=C_N+Q_N,\quad C_N=2(d_z*q_z)(N),\quad
Q_N=(q_z*q_z)(N)+(d_z*d_z)(N)-B_N.
\tag{4}
\]

前提是 E、C、Q 使用同一个背景、同一种离散化和同一个中心化算子；若 C 用连续近似，要把 (2) 的修正计入 Q。

令 e、c 是对同一分组中心化后的样本向量，`s=||c||/||e||`。由三角不等式，

\[
1-s\le\frac{\|e-c\|}{\|e\|}\le1+s.
\tag{5}
\]

因此 C 很小就已经足以推出 Q 保留了几乎全部波动，无需另算一次 `Q=E-C` 再当作独立确认。按保存数值，10^9 时 `s=0.002012`、`rho(e,c)=-0.1732`，得到

\[
\frac{\operatorname{sd}(Q)}{\operatorname{sd}(E)}
=\sqrt{1+s^2-2\rho s}\simeq1.00035,
\]

且两者相关约 `0.999998`。这是代数结果，不是发现了第二条独立证据。

在 m=3 上，应继续拆成

\[
Q_{3,N}=P_{3,N}+A_{3,N},
\]

\[
P_{3,N}=2(q_1*q_2)(N),\qquad
A_{3,N}=2(a_1*a_2)(N)-b_{3,N}.
\tag{6}
\]

P 是误差序列的配对项，A 是明确的局部/背景补偿。**Q 不是 P 本身。** “主要波动在 Q”不能自动变成“已经找到不由局部结构解释的配对涨落”。若使用“连通”，还应指定概率空间和所扣边际；固定平滑函数相减不自动是某个概率模型的条件协方差。

### 3.1 这次直接算了哪一部分

我独立算了 A 的平滑卷积和已固定的背景系数。10^9 组在 mod 3 内中心化后，A 的标准差约为 E 标准差的 **128 倍**；离散积分差相对此量级很小。

用恒等式代数重建的 P 与 A 的相关约为 **−0.999992**。这不是独立测得了一个新定律，而是说明两项有巨大的局部主量相消，不能只看原始 P 与局部奇异级数的高相关就声称解释了细小残差。

此外，在三个现有 N≈10^6 的样本上，我直接以误差序列点积计算 P、以离散点积计算 A，并独立核对 `E=C+P+A`。这些检查用于确认符号、因子 2 和离散约定；大规模 P 的上述数值仍明确标为代数重建。

### 3.2 还需要直接计算什么

不必为了证明 Q≈E 再重做全部二元计数。需要的是：

1. 保存一维原始和、平滑卷积及其误差，以便把连续近似 C 换成完全离散约定。
2. 单列 A 的均值、组内方差及其与 P 的抵消；用小规模直接点积或零填充 FFT 核对恒等式。
3. 在最终残差的尺度上，检验一个独立于实际配对计数的局部预测器。不能把对大数 P 的拟合优度替代对小量 Q 的预测能力。

本次的下一节已经给出一个这样的预测器及探索结果。

## 4. (c) 第一个正向预测：局部 Mellin 二阶项

沿用第八轮已明确的形式局部模型

\[
K_N(s,t;z,w)=\prod_p
\frac{J_p(zp^{1-s},wp^{1-t};\nu_p(N))}
{Z_p(zp^{1-s})Z_p(wp^{1-t})}.
\tag{7}
\]

以下只对这个形式模型求导，不假定它已被证明近似真实 G。

对偶数 N，定义

\[
\beta_{p,N}=\begin{cases}
-1/p,&p\mid N,\\
1/(p(p-2)),&p\nmid N.
\end{cases}
\qquad
\mathcal L_{r,N}=\sum_p\beta_{p,N}(\log p)^r.
\tag{8}
\]

由于 N 为偶数，第二种情形不会在 p=2 出现。固定 r 的和收敛；数值中使用与背景相同的素数截点，并补入 N 的所有实际素因子。

在 z=w 的对角上，直接展开每个局部因子，有

\[
K_N(s,t;z,z)=\mathfrak S(N)
\left[1+z\sum_p\beta_{p,N}
\{p^{1-s}+p^{1-t}\}+O(z^2)\right].
\tag{9}
\]

因此在 `(s,t)=(1,1)`：

\[
[z]K_{ss}=[z]K_{tt}=\mathfrak S(N)\mathcal L_{2,N},
\qquad [z]K_{st}=0.
\tag{10}
\]

源背景已经保留了 Mellin 一次项，但没有保留二次项。对 m=3，这给出一个很简单、没有自由参数的候选：

\[
\boxed{\ell_{3,N}^{(2)}
=\mathfrak S(N)\mathcal L_{2,N}
\int_2^{N-2}(D^2a_{1,\mathrm{cut}})(x)
a_{1,\mathrm{cut}}(N-x)\,dx},
\tag{11}
\]

其中 `D=d/d log x`，`a_1,cut=(1-x^{-0.45})/log x`。这里沿用现有 v2 局部导数项使用未修补 δ 的约定，没有事后改变背景。

写 `L=log x`，导数可直接计算：

\[
D^2a_{1,\mathrm{cut}}(x)
=-\frac{0.45^2x^{-0.45}}L
-\frac{0.9x^{-0.45}}{L^2}
+\frac{2(1-x^{-0.45})}{L^3}.
\tag{12}
\]

因子核对如下：Taylor 展开有 `K_ss/2` 与 `K_tt/2`；两边积分相同，合起来恰为 (11)，没有额外的 2。混合导数对 m=3 的该阶系数为零。单系统密度已有的对数项不再重复加入。

这个候选只使用 N 的素因子、单系统割线密度与冻结的局部模型。没有用 h₃ 拟合系数、符号、幅度或幂指数。它是所选形式模型中的 Mellin 二阶局部部分，不是已证的真实加性卷积余项展开。

## 7. 对本轮三问的简答
