## 2. M3 第一步（下一小时）

问题：在偶数 N 的奇数子纤维上，用"完整 GF(2) 闭包"（而不仅是反射）推出 T(t) 时，每个推导需要多少个刚性实例（证书大小）？证书大小的分布是否有界，或者随 N 只做多项式增长？

- 若证书大小有界，多重度仍是多项式，z = 2 台阶的推导链可以照搬 M2。
- 若证书随 N 无界增长，就说明 M1 的障碍（异类刚性解由哥德巴赫构型生成）在定量层面上同样存在，z = 2 台阶需要全新的输入。

做法：复用 M1 的 `certificate_search.py` 与 `T_closure.py`，在 N = 2^10 … 2^14 上抽样统计证书大小（最少需要的刚性方程个数）。按惯例先预注册。
