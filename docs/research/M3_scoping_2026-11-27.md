## 2. M3 第一步（下一小时）

问题：在偶数 N 的奇数子纤维上，用"完整 GF(2) 闭包"（而不仅是反射）推出 T(t) 时，每个推导需要多少个刚性实例（证书大小）？证书大小的分布是否有界，或者随 N 只做多项式增长？

- 若证书大小有界，多重度仍是多项式，z = 2 台阶的推导链可以照搬 M2。
- 若证书随 N 无界增长，就说明 M1 的障碍（异类刚性解由哥德巴赫构型生成）在定量层面上同样存在，z = 2 台阶需要全新的输入。

做法：复用 M1 的 `certificate_search.py` 与 `T_closure.py`，在 N = 2^10 … 2^14 上抽样统计证书大小（最少需要的刚性方程个数）。按惯例先预注册。

## 3. 第一步的结果与方向调整（2026-11-27 19:23）

详见分支 `gb/M1-liouville-ladder` 的 `research/M3_z2_rung/RESULTS.md` 第 1–9 节。

- **z = 2 台阶（奇数子纤维）**：完整 GF(2) 闭包对 T(qn) 的覆盖率约为 97%，与 q 无关，失败来自异类构型；反射只有 41%–67%。删行敏感度很低：每删一行约失去 1 个 n，最坏单行 ≤ 18，枢纽行完全冗余。
- **意外的收获在素数 N 的完整纤维上**：GF(2) 覆盖率恒为 100%（解空间只有 {1, χ_N}），最坏单行删除只失去 2 个 n。比值 |𝓔_q(g)|/|𝓔(g)| 的最大值约为 q + O(1)：翻转 g(q) 给出 q − 2，这是严格的下界例子；局部搜索至多 q + 5。
- 由此得到一个**确定性**的目标：引理 L_q，即 |𝓔_q(g)| ≤ (q + C)|𝓔(g)| 对一切完全积性 g 成立。配合 Mangerel 的 GRH 输入，它给出 M2 想要的定理，而且**不再需要覆盖率、随机模型或转移**。
- **决定**：M3 的下一步改为攻引理 L_q。先用线性规划在中等 N 上求"短证书系统的最优最大负载"，看它是否 ≈ q；再找证书的结构，以图证明。z = 2 台阶的原始目标暂缓：它多出一个异类构型带来的加性误差，本身就需要哥德巴赫型的输入。
