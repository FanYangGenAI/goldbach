# 失败与收获台账

> 每个实验一条。结论只能是：支持 / 否定 / 无信息。收获必须写出“下次不再做什么”或“下次该做什么”。

| 编号 | 线 | 假设 | 结果（关键数字） | 结论 | 收获 / 下一步 |
|---|---|---|---|---|---|
| E0.1 | L0 | HL 预测在 N≤3.4×10⁷ 精确到 1% 内 | 均值偏差 −5×10⁻⁴，std 1.7×10⁻³，最差比值 0.918 | 支持 | 密度层面没有新规律可挖；反例不会“慢慢接近”。不再做密度拟合类实验 |
| E0.2 | L0 | 修正奇异级数后残差无算术结构 | 残留谱线在 1/3、1/5…，由素数赛跑定量解释（mod 3：预测 ±4.2×10⁻⁴，实测 ±5.5×10⁻⁴） | 支持（带修正） | 残差的“结构”是有限规模的剩余类不平衡，不是新规律 |
| E0.3 | L0 | 真实素数的 r(N) 涨落与随机模型同级 | Fano 0.35→0.58，随机模型 1.3–2 | **否定** | 素数比随机更刚性 → 开 L3 做理论解释 |
| E0.4 | L0 | 和/差去奇异级数后的残差不相关 | 相关 −0.10（小规模 −0.16，随规模减弱） | 无信息（待确认） | 可能是有限规模效应 → L4 用 GPU 到 10¹⁰ 判定 |
| E0.5 | L0 | 仿射映射 ap+b 的计数只依赖奇异级数 | a∈{1,2,3,4,6}，比值都在 [0.986, 1.013] | 支持 | ax+b 在密度层面无额外信息；若有，在相位层面（L2） |
| E0.6 | L0 | 朴素“独立覆盖”估计在 z=√N 处成立 | 实测/预测 = 0.905–0.912，与 N 无关 | **否定**（符合理论） | 这是 Mertens/奇偶性障碍的常数 e^γ/2 → 开 L1 正面研究墙 B |
| E0.7 | L0 | 同余覆盖可在 √N 以内的模完成 | 贪心对手需要 L∝Y^0.80 ≫ √Y | 否定（对手自由选类时也不行） | 反例不可能来自剩余类阴谋；只能来自全局结构 → L5 低优先级 |
| E1.1 | L1 | 粗糙 N−p 中素数份额 f(N) 无 N 的算术记忆（单侧基线） | 均值偏差 ≤4×10⁻⁵，z sd 0.80–0.89；但 N mod 3 类均值 \|t\| 达 3.7，符号在窗口间翻转 | 否定（P2） | 基线只用了 m 一侧的筛信息，素数与 P₂ 的赛跑方向不同 → 设计 E1.2 |
| E1.2 | L1 | 用双侧筛基线 f_sieve 后类依赖消失 | 随机样本 45 个类检验 max\|t\|=2.66；相对偏差 ≤2×10⁻⁴；z sd 0.65–0.76；min f/f_sieve 0.981→0.997 | **支持** | 奇偶性信息像一枚无记忆、且比独立更稳的硬币；墙 B 化归为移位素数上的一致二元 Chowla 估计。方法论：残差分析一律用双侧筛基线 |
| E2.1 | L2 | 次弧贡献是随机相位噪声，量级远小于主项 | Q₀=16；Q=256 时所需相消 ≈5.9×，实际中位 417×、最差 24×；但峰度 13.5，按 X^{−0.18} 衰减 | 部分否定（P2、P4） | 次弧有确定性的重尾 → E2.2 |
| E2.2 | L2 | 重尾 = 奇异级数尾项（截断 K=2√X） | 系数 a=0.995，R²=0.74；残差按 X^{−0.36} 衰减；峰度 0.54、极值 1.78 略超阈值 | 部分支持（P2 ✗） | 怀疑截断漏掉光滑 N 的大分母 → E2.3 |
| E2.3 | L2 | 用完整奇异级数后残差高斯 | a=0.9998；峰度/极值几乎不变 | P2 否定（截断不是原因） | 探索性诊断：残差方差 ∝ 𝔖(N)^γ（γ→1），异方差标准化后通过 P2 阈值；尾项负向 ≤2%（Q=256）。结论：R(N)=N𝔖(N)+高斯噪声；墙 A 是“证明相消”的问题，不是“相消存在”的问题 |
| E3.1 | L3 | F(N)=R−N𝔖 经 √𝔖 标准化后高斯，σ²∝x^{1~1.25}，反例所需 σ 数上升，B₄≪1 | σ²≈0.05·x·log³x；m₄/m₂²≈3.17，m₆/m₂³≈17.5（不随 x 增长），极值≈高斯；K: 13→420；B₂: 8→35↑；B₄: 0.06→2.5×10⁻⁴↓ | P3 ✓；P1、P2(六阶)、P4 按阈值 ✗（方差多一个 log 因子、残余异方差） | **矩阶梯**：真实二阶矩也只能给出 ~log³x 个例外（结构性天花板）；任意 p>2 阶矩的真实大小即可推出大 N 的哥德巴赫。缺失信息 = 一个损失 x^{o(1)} 的高阶矩估计。下一步：从 k 元组猜想推导 σ² 的 log³ 律 |
| E3.2 | L3b | GPU 推到 x=4.3×10⁹：方差律 k∈[2.5,3.2]、窄窗口高斯、K≥2500、B₄<2×10⁻⁵ | k=2.62（σ²≈0.13·x·log^{2.5}x）；m₄/m₂²=3.00–3.07，m₆/m₂³≈15.1；K=4331；B₄=1.3×10⁻⁵↓，B₂=90↑ | **支持**（P1–P4 全过） | E3.1 的“log³”与六阶矩超标都是二进宽窗口混合不同方差造成的；窄窗口下误差项是近乎完美的高斯。矩阶梯在多两个数量级上保持。方法论：高阶矩一律用窄窗口 |
| E3.3 | L3c | 观测方差可由 HL 四元组主项 + 奇异级数平均（Gallagher/MS 型）定量解释 | 预测/观测 = 2.14→2.02（x=8×10⁶…7×10⁷）；对角项精确吻合（496x vs 496x），非对角项只抵消 38–40%（需要 ~70%） | **否定** | Goldbach 是 MS 意义下的“长区间”情形（h≍x），HL 主项启发式在此失效；V 是两个 N² 量之差，需要超出 HL 主项精度的信息。方差（刚性）应由 ζ/L 函数零点的对关联决定 → 新线：显式公式 + GUE 对关联预测 Var(F) |
| E3.4 | L3d | ζ 零点：Fujii 累积公式成立；局部平均跟随 2(ψ−x)；ζ 零点只解释 <5% 的逐点方差 | 相关 0.9997；残差/(x log x) ≤ 0.43；局部斜率 0.980（R²=0.66）；方差份额 0.19% / 0.18% | **支持**（P1–P3） | ζ 零点控制大尺度起伏，但刚性几乎全部来自 q≥2（L 函数族/次弧）。修正 E3.3 的结论：方差由 L 函数族的统计（Barban–Davenport–Halberstam / Montgomery–Hooley 型）决定，而非 ζ 的对关联 → E3.5 做按 q 的方差谱 |
| V1/V1b | R1 | L1 的 z sd<1 能否由条件抽样零模型解释 | 未分层：均值 −0.23→−0.89（位置效应）；分层后均值≈0，sd 1.17/1.22/1.32 | V1、V1b 均 ✗ | 撤回 L1“亚二项刚性”（是零模型选错）。正确零模型下反而是 **超** 超几何涨落，机制待查 |
| V2 | R1 | L3c 漏项修正；小 N 精确恒等式 | 比值 2.007–2.122；恒等式误差 7×10⁻¹⁶ | ✓ | 两倍偏差不是计数错误；撤回 GUE 结论 |
| V3 | R1 | 固定比例窗口的方差律；分层矩估计校准 | k 前半 2.98±0.12、后半 2.50±0.09；分层/完整 = 0.93–1.05 | 校准 ✓；对数律不可确定 | 撤回 log³ 与 log^{2.5} 两种律；B_p 以分层估计为准 |
