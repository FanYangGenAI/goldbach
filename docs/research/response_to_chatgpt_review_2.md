# 对 ChatGPT 第二轮审阅（R9–R14）的逐条反馈

> 审阅原文：`chatgpt-review-r1-v3-l3d-2026-11-23.md`（及 `research/review_20261123_validation.py`、`research/review_20261123_evidence.json`）。
> 总体判断：六条全部接受，没有实质反驳。审阅独立复算的数值与我们的结果一致；需要修正的是 **措辞强度** 和两处 **概念错误**（R9、R10）。修订已同步写入 `current_conclusions.md`。

| 编号 | 态度 | 反馈 |
|---|---|---|
| R9 短窗口二阶目标不能由分割自动获得 | **完全接受** | 我上次的说法“窗口短于 x/polylog 就够了”是错的。审阅给出的反例一针见血：如果某个 N₀ 是反例，它自己对 B₂ 的贡献就恰好是 1，无论怎么切，包含它的窗口都不可能满足 B₂<1。分割只能利用已有的、对 **每一个** 窗口都一致成立的局部界，不能凭空制造这种界。修订为条件性陈述：若对所有 t∈[x,2x] 有一致的 **未中心化** 短窗口二阶界，且常数可以使 B₂<1，则可排除反例；同时还需处理 Λ−θ 的差别。另外，Languasco–Perelli 型短区间例外集结果仍允许例外，不能补上“<1”这一步，这一点我也接受。 |
| R10 “0.2%”不是 q=1 的方差份额 | **完全接受** | 三处问题都成立：(1) 我先中心化再乘 𝔖，口径与声明的模板不一致（修正后为 0.206% / 0.198%）；(2) 方差比不等于解释率，需要报告协方差或 R²（审阅算得 R²≈0.20%，回归系数 0.99–1.00）；(3) 更重要的是，𝔖(N)·2(ψ(N)−N) 只是精确恒等式 R_Λ(N)=2ψ(N−1)−(N−1)+Σa(m)a(N−m) 中的 **线性项**，二次项 Σa(m)a(N−m) 同样可能由 ζ 零点控制（Goldston–Suriajaya 正是把累积余项与素数短区间方差、ζ 对关联联系起来）。所以“剩余方差来自 q≥2 / L 函数族”“否定 ζ 机制”都不成立，已撤回。现在的表述是：该线性模板在所测两个窗口的解释率约 0.2%。 |
| R11 V1b 只是“相对指定置换零模型的过度离散” | **完全接受** | 给定边际并不推出均匀随机配对，“正确零模型已建立”的说法撤回。审阅的探索性诊断（位置细分到 256 块、联合 mod 6/30/210 分层，sd 都停在 1.16–1.17）与我们同时完成的 V4（mod 210、2310 分层后 sd 不变）结论一致：小模数剩余类不能解释这个偏离。用语错误也接受：17–32% 是 **标准差** 的超出，**方差** 超出为 37%–75%。M_b=1 的均值问题：V1b 中设为 0 确有错误（当时没有此类单元，不影响结果）；V4 中已按观测值处理，与 r_bK_b 等价。 |
| R12 V3 的 ± 只是形式标准误；“约 3σ”无依据 | **完全接受** | 前后两半共享 j=26，不是独立拟合；残差里混有低阶项和模型失配，没有独立的测量误差估计。删去“约 3 个标准误”，± 一律标明为“模型内形式标准误”。审阅补充的单幅度纯幂比较（k=2、2.5、3 的 log 残差 rms 分别为 0.106、0.040、0.051）也记录进摘要。 |
| R13 局部公式应匹配窗口平滑；文献状态有误 | **完全接受** | 用同窗离散平均 L_I 代替中点代理后，斜率从 0.980 变为 0.9999，R² 为 0.68。这是更恰当的统计量，但仍有约 32% 的响应方差没有被解释，只能称“有限范围的平滑线性近似”。我把 RH 下 Fujii 余项 O(x log³x) 误称为“猜想”，这是文献错误，已改正：它在 RH 下是定理（Goldston–Suriajaya）。 |
| R14 8 窗校准不是全尺度 ±7% 的保证 | **完全接受** | j=22 时层宽 2¹⁹ 小于样本窗 2²⁰，窗口重叠且越出 [x,2x)，这是我没注意到的几何错误。更大的 j 退化为固定 8 点左端黎曼和，没有误差保证。摘要改为：“j=22…25 已测校准偏差 ≤6.8%；更大尺度无误差保证”。 |

## 对研究方向的影响

两轮审阅之后，项目的可靠资产是：一套可复现的计算基础设施（精确 FFT/GPU 卷积到 4.3×10⁹、条件零模型、预注册流程），以及一组带限定的数值观察。没有任何结论构成新的数学机制。

由此得到的方法论教训：
1. 每个“份额”或“解释率”必须先写出分解式与协方差。
2. 每个“足以排除反例”的论证必须检查一致性量词（对 **每个** 窗口还是平均窗口）。
3. 统计误差必须来自可辩护的误差模型，而不是拟合的形式标准误。

下一步只在需要提升结论时做确认实验（审阅 §10 第 3 条）。
