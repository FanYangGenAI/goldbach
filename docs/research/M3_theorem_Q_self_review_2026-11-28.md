## 逐条核对

**引理 1（Thue）**
- 对 w = 0, …, a − 1，a 个点 {wx/N} 落在长度为 1 的圆周上，必有两点的距离 ≤ 1/a。取 v 为它们下标之差，得 1 ≤ v ≤ a − 1，且 ‖vx/N‖ ≤ 1/a。
- 等号意味着 vx ≡ ±N/a (mod N)，需要 a | N；而 N 为素数、2 ≤ a < N，所以不可能。因此 y < N/a 严格成立，并且 y ≥ 1，因为 N ∤ vx。
- **应补的写法**：把"等号不可能"这一句写进证明。另外，"若 ax ≥ N"这个前提对引理本身不需要，只用于说明节点非平凡。

**引理 2（一步推导）**
- 记 r = ax mod N。由于 N 为素数且 1 ≤ x, a < N，r ≠ 0，所以 I(v, r) 是良定义的实例。**应补这一句。**
- 两种符号的推导逐式核对无误。关键是两处完全积性：g(v)g(ax) = g(a)g(vx)，以及 g(v)g(r) = g(vr)。ε = −1 时，两行的刚性 g(N − z) = ηg(z) 只用在 z = y 与 z = ay 上。由于 y < N/a ≤ N/2，pr(y) = y。
- 每一步 v < a，所以树是有限的；"树中各行都好 ⇒ n ∉ 𝓔_p"按树的高度归纳即得。

**引理 3、引理 4（连分数结构）**
- 引理 3 是第二类最佳逼近的标准事实。
- 引理 4(i) 用到三条标准不等式：‖q_{k−1}u‖ < 1/q_k；w < q_{k−1} 时 ‖wu‖ ≥ ‖q_{k−2}u‖；以及 ‖q_{k−2}u‖ > 1/(q_{k−1} + q_{k−2}) ≥ 1/q_k。
- 边界情形：u > 1/2 时 t₁ = 1，q₀ = q₁ = 1。此时 q_k = 1 的 A 型子节点平凡；k = 2 时 w < q₁ 的情形是空的，结论仍成立。
- 引理 4(ii) 中 δ_i < 1/q_{i−1} 的两种情形（i < k 与 i = k）都成立。i = k 时用到 q_{k−1} < q_k = v < a。
- 数值核对：约 29 万个节点，违反 0 次。

**引理 6（U′）、引理 7（V）**
- 半邻域不跨越 a 级端点：k/b < c/a < k/b + 1/(ab) 等价于 0 < cb − ka < 1，对整数不可能。
- 像为完整 b 级区间：(ak/b, ak/b + 1/b) 内部不含整数。下半邻域在 ak ≡ 0 (mod b) 时绕回到 ((b − 1)/b, 1)，仍是完整区间。
- 引理 7：I_c 的闭包至多含一个点 k/b；闭包外的点，其半邻域不可能落在 I_c 内。所以测度 ≤ 2/(ab)。

**命题 8（P1″）与推论 9**
- Φ_{ℓ+1} ≤ Φ_ℓ/2 的推导无误：Σ_{2≤b<a} (2/b)·b⁴ = 2Σ b³ ≤ a⁴/2。
- **差一（无害）**：实际脊柱的长度为 L 时，前 L − 1 步的 v ≥ 2，最后一步可能 v = 1，因为 v = 1 时下一节点乘数为 1，循环随即停止。所以"脊柱长度 ≥ ℓ"只推出存在长度为 ℓ − 1 的松弛路径，正确的界是
  μ(len ≥ ℓ) ≤ (p/2)⁴·2^{−(ℓ−1)}，比原文多一个因子 2。
- 第 6 节取 ℓ₀ = ⌈4 log₂ p + log₂(16/c)⌉，得到的余量是 c/256（原文所需为 c/8），乘以 2 之后仍 ≤ c/8。所以结论不变。**建议把原文的命题 8 改为"长度 ≥ ℓ + 1"，或者把 ℓ₀ 加 1。**
- 推论 9 的区间计数：交集的连通分支数 ≤ 各条件分支数之和，所以 ≤ ℓ·p^{ℓ+1}；松弛路径至多 p^ℓ 条。推导无误。

**引理 10（负载）**
- 用到行 ρ 的实例，按角色 (y = ρ；a′y = ρ；a′y = N − ρ) 与 (a′, v) 计数，x′ = −y·v^{−1} 唯一确定，共 ≤ 1.5p² 个。
- 父节点：对每个 a ∈ (b, p]，A 型父节点 w′ = w，B 型父节点 w′ = w·a^{−1}，至多 2 个，所以回溯路径 ≤ 2(2p)^k 条。
- 不同的 n 有不同的根，所以对应不同的路径。

**第 5 节（GRH 输入）**：对照 arXiv:2412.17199v1 原文。
- 命题 2.2（GRH，Dirichlet L 函数）：对 ε > 0 与 P ≥ (log N)²(log log N)^{2+ε}，存在素数 p ∈ (P, 2P]，使 (1/N)Σ_{a mod N} |S_λ(pa/N) − λ(p)S_λ(a/N)|² ≫ N。
- 引理 3.1：对 (d, N) = 1，上述均值 = 4|𝓔_d(N)|，其中 𝓔_d(N) = {n < N : λ(dn)λ(φ_d(n)) = −1}，φ_d(n) = N{dn/N} = dn mod N。这与本文的 𝓔_d(λ) 完全相同。
- 原文用它推出命题 1.4 时取的 P ≥ (log N)^{100}。本文取 P = (log N)²(log log N)³（ε = 1），在命题 2.2 允许的范围内，隐含常数是绝对的。

**第 6 节与推论 Q′**
