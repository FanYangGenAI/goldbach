## 0. 一句话总结（第十三轮审阅后修订）

我们没有接近哥德巴赫猜想的证明，也没有声称接近。本批实验的可靠产出是几项经新样本确认的 **预测**：
- 窗口平均漂移与剩余类之间的差，被素数计数与剩余类赛跑的一阶响应预测（O5、O9、O17、O18、O21）；
- 整数 χ 的跨 N 涨落约 60%–70% 被“大于 z 的素因子”局部因子预测（O6、O11）；
- 协方差核在新滞后上带有负 ω 项（O22）；
- Liouville 纤维和的跨尺度相关精确地服从 gcd 模型（R13-2）。

第一版摘要中的“局部结构已基本解释完，剩下的是与局部结构无关的噪声”**不成立，已撤回**：
- 低均值 R² 只说明所选特征没有线性均值预测力，不说明独立；
- 残差的条件方差与 N mod 3 有关（O13），协方差核依赖 h 的素因子（O16、O22）；
- Liouville 纤维和在共享公因子的 N 之间有精确的算术相关（R13-2）。

另外，强哥德巴赫等价于“残差 E(N) > −B(N)”（单侧阈值），而不是“|E| < B”（审阅式 13）。

详细勘误见第 8 节；第 1–7 节保留为历史记录，与第 8 节冲突时以第 8 节为准。

## 2. 目前站得住的正面结果（按证据强度）

1. **Q8（预注册新样本确认）**：在 [10⁹, 1.1×10⁹) 的 80 个新 N 上，第十轮审阅推导的二阶局部 Mellin 项 ℓ₃ = 𝔖(N)𝓛_{2,N}∫(D²a₁)a₁（其中 𝓛₂ = Σβ_p(log p)²）无参数地预测 m=3 扇区残差：ρ=0.957，标准差比 0.861，R²=0.907。
2. **Q1b**：零参数两变量欧拉乘积模型重现 j,k≤4 的整张扇区相关表（10⁸，log 误差 ≤0.030）。
3. **O2**：HL 背景系数的平均漂移到 8.6×10⁹ 仍在缩小，绝对值为 2×10⁻⁵。
4. **O1 的均值部分**：在 10⁹ 上，HL 型局部模型对 PP 配对数的预测误差为 1.5×10⁻⁴，对 χ 均值的误差约 7%。

这些都是已知启发式（HL、Selberg–Delange、局部因子）的精细数值确认和一个统一表述，不是新定理。

## 3. 通宵函数域实验 O3

分支 `gb/O3-function-field`（设计 d7d0b96，结果 6c774e1），探索性，无事前判据。对每个 n 次首一 F ∈ F_q[t]，数 r(F) = #{G：deg G < n，G 为常数乘首一不可约，F − G 为首一不可约}，用 (Z/q)ⁿ 上的 FFT 卷积一次算出全部 F，并与 HL 类比 r_pred = π_n·#{G}/qⁿ·𝔖(F) 比较，其中 𝔖(F) = ∏_{π∣F}|π|/(|π|−1)·∏_{π∤F}(1 − 1/(|π|−1)²)。范围：q=3 到 n=15（每个 n 有 3ⁿ 个 F，最大约 1400 万），q=5 到 n=10，q=7 到 n=8。q=3、n=3、4 的结果已用独立的试除程序逐个核对。

- **失败只出现在 F₃[t] 的 3 次（2 个）和 4 次（3 个）**；n ≥ 5 时全部 F 都有表示，最小 r/r_pred 单调趋向 1（q=3、n=15 时为 0.983）。
- **3 次失败的完整解释（事后）**：两个失败是 Artin–Schreier 多项式 t³ − t + c，它在全部平移 t → t + a 下不变，并在 F₃ 每一点取值 c。F − G 不可约 ⇔ G 在 F₃ 上处处不取值 c。但一次 G 取遍所有值，不可约二次 G 取到两个非零值，所以每个 G 都失败。这是 𝔖 看不见的 **值集障碍**，来自“次数相对 q 很小”。4 次失败的机制见第 7.4 节。
- **HL 类比极准**：r/r_pred 的均值以约 q^{−n} 的速度趋于 1，corr(r, 𝔖) → 0.99999。
- **涨落是平方根级、亚泊松的**：sd(r/r_pred) × √(平均 r) 在每个 q 上大致恒定（q=3 约 0.6，q=5 约 0.45，q=7 约 0.4）。
- 纠缠熵随 n 单调降到 0，与 E1 一致；(1,1) 格相关 / 𝔖 在 q=5、7 时约为 1，在 q=3 时升到 1.06（未查，候选为 Ω ≤ 3 的截断）。

意义：函数域是一个可以穷举的“试验田”，HL 在那里比在整数中准得多，唯一的反例来自 𝔖 之外的局部障碍。函数域中 χ 的对照（O4、O7）与大 q 极限（O10、O12）见第 7 节。

## 4. 负面结果与撤回（摘要）

- 撤回：L1 的“亚二项刚性”、GUE 解释、log³/log^{2.5} 方差律、贪心覆盖的不可能性、“均匀 √N 猜想”、B3 的 80%/42% 分解。
- **修正**：O1 的解读“χ 的 N 依赖完全不在局部结构中”，只对基础模型成立（O4、O6、O11）。
- 否定（预注册）：L3c（HL 首项解释方差）、Q7（单系统线性交叉项）、E1 的 H_local、O1 的波动判据、O4 的 H3（“非局部”）。O4 的 H2（D ∈ [0.5, 2]）在 q ≥ 11 时不成立。
- 方法教训：
  - 零模型必须保持被检验结构以外的一切。
  - 只修正到某一阶的模型，要同时预注册幅度判据。
  - 比较两个对象时，必须用同一种中心化。
  - 不改写预注册锚点。
  - 新教训（O1 → O6）：“局部模型给不出 N 依赖”，往往是模型漏掉了某类局部因子，而不是涨落真的非局部。下结论前，应先对 N 的局部特征做回归诊断（O4 的做法）。
  - 新教训（O9）：GPU 显存接近上限时，运行不会报错，但会极慢。应预留至少 4 GB 余量。

## 5. 主线判断（第十三轮审阅后修订）

- **有新样本确认的预测（保留）**：
  - Ω 扇区表（Q1b）、m=3 涨落（Q8）；
  - 窗口平均漂移与剩余类差（O5、O9、O17、O18、O21）。这些应表述为“与素数计数及赛跑的一阶响应一致”，属于局部因子重整化后的模型解释，不是严格展开后只剩 δ∗δ。实验输入的是实际素数计数，不是独立重建了 L 函数零点。
  - 整数 χ 的局部预测（O6、O11）；
  - 协方差核的 s(h) 形状与负 ω 项，限于所测窗口与 h ≤ 2000（O16、O22）；
  - Liouville 纤维和的 gcd 相关模型（R13-2）。
- **撤回或降级**：
  - “剩余噪声与局部结构无关”：撤回（见第 0 节）。
  - O12 的“两侧 Fourier 系数强烈反相关、由同一 L 函数决定”：撤回。比较的口径不一致，残差方差含背景的相干交叉项（审阅式 8）。
  - “函数域是唯一能把噪声算出来的地方”：撤回。它是一个可控试验场。
  - O20 的“精确分解”：对角公式漏掉了中点修正（审阅式 9）。余项还包含背景交叉项（审阅式 10），不能直接称为“四个不同素数的相关”。
- **难度判断**：在这个框架里，强哥德巴赫对应于残差的单侧阈值 E(N) > −B(N)。“至少与二元 Chowla 一样难”只是研究判断，不是已证明的归约；无粗糙限制的 C_λ、粗糙 P/S 的 χ 与哥德巴赫残差 E 也没有建立相互归约。

## 7. 通宵第二、三批实验（O4–O13）

这一批在 O1–O3 之后继续进行。分支：`gb/O4-ff-parity`、`gb/O5-drift-theta`、`gb/O6-chi-refined`、`gb/O7-ff-refined`、`gb/O8-variance-constant`、`gb/O9-gpu-2e10`、`gb/O10-ff-largeq`、`gb/O11-chi-gpu-1e10`、`gb/O12-ff-spectrum`、`gb/O13-int-noise-locality`。每个分支的 `research/<编号>_*/DESIGN.md` 中有设计、判据、运行前披露和结果。除 O8、O10、O12 为探索性外，都在运行前提交了设计与判据，运行前已知的信息都写在各自的 DESIGN.md 中。

### 7.1 漂移问题解决：O5、O9（GPU，预注册通过）
- 写 1_P = ρ + δ（ρ = 1/log，δ = d(π − li)），r(N) 的一阶项是 2Σδ(n)ρ(N−n)。由此得到无参数预测 rel_pred = 2[Σ_p 1/log(N−p) − I(N)]/I(N)。
- O5（96 个窗口，[2^30, 2^33)）：跨窗口相关 0.995，斜率 0.999，|残差|·√x 为 0.040（漂移本身为 2.18）。
- O9（j = 34、35，到 3.65×10¹⁰）：|残差|·√x 为 0.020、0.028。
- 结论：O2 的 1/√N 漂移就是 −½li(√t)（素数平方）加上 ζ 零点振荡项的一阶贡献。“HL + 一阶素数计数误差”把窗口平均解释到约 10⁻⁶ 的相对精度。剩下的只有二次项 Σδδ，也就是哥德巴赫本身的涨落。

### 7.2 χ 的 N 依赖大部分是局部的：O4、O6、O7、O11（修正 O1 的解读）
- O4（预注册）：在整数（10⁷–10⁹）和函数域（全部 F 穷举）中，χ 的跨 N 涨落都与“大于 z 的不同素因子个数 ω_big”强相关。R²_local 在整数中为 0.29–0.37，在函数域中为 0.32（q=3）到 0.93（q=31）。H3（“非局部”）全部被否定，H4（ω_big 主导）全部成立。
- 机制：若 p ∣ N 且 p > z，则 p ∣ n ⇔ p ∣ N − n。素数一侧几乎不会被 p 整除，半素数一侧会。O1 的基础模型对所有类都用同一个 𝔖(N)，漏掉了这一项。
- **O6（整数，预注册，新样本）**：把这一项写成无参数局部因子（PS：1 − w，SS：(p−1)w w′ + (1−w)(1−w′)）。10⁹ 上 ρ = 0.78，标准差比 0.70，R² = 0.60，判定为“支持”。
- **O11（GPU，预注册）**：用 FFT 对整个窗口精确计数，推到 10¹⁰：ρ = 0.83，R² = 0.69，判定为“支持”。
- **O7（函数域，预注册，穷举）**：每个 q 都“支持”，R² 为 0.45（q=3）到 0.93（q=31）。加入全部大次数不可约因子的版本（“all”）把 χ 的均值重现到所显示的全部位数。
- **剩余部分**：扣除精细局部预测后，随机标签离散度 D_after 在整数中为 1.16–1.26，在函数域中为 0.72–0.92。也就是说，剩下的就是随机标签尺度（或更小）的噪声。
- **对 O1 的修正**：O1 说“χ 的 N 依赖完全不在局部模型中”，这只对基础模型成立。加上大素因子的局部因子后，60%–70%（整数）到 93%（函数域大 q）的方差是局部的。这与第十二轮的“χ 与哥德巴赫计数代数等价”不矛盾：被预测的局部部分来自 SS/PS 配对，PP 配对（哥德巴赫计数）的涨落在剩余的噪声里。

### 7.3 哥德巴赫噪声本身：O8、O9、O10、O12、O13
- **O8（探索性）**：方差常数 c² = Var[(r − r_pred)/√r_pred]。
  - 整数：c² 从 0.47（7×10⁴）缓慢升到 0.68（10¹⁰），经验上 c² ≈ 1 − 7.2/log x（O9 在 3.6×10¹⁰ 以内外推成立，误差 < 0.01）。但补充拟合（O8 补充，j = 10…33）显示函数形式无法确定：按 AIC，最优的是 c² ≈ 0.135·(log x)^{0.51}，它与 L3/V3 中约 2.5 的有效对数指数一致；“1 − C/log x”排在第四。几种形式在 10¹⁰ 附近都吻合，外推到 10²⁰ 则相差很大。
  - 函数域：c² 也小于 1。它比“超几何”基线 (1−β)(1−α) 小 3–10 倍。
- **O10（探索性）**：函数域固定 n、q → ∞。n = 3 时 c² = 1/q（q·c² = 1.00 ± 0.01），残差约 80% 由 F 的分解型决定（局部的，且会消失）。n ≥ 4 时出现极限噪声：c² → 0.080（n=4）、约 0.14（n=5），它与 F 的分解型 **无关**（分解型解释的比例 → 0）。小 q、大 n 时也是如此：q = 3 时，分解型能解释的比例从 n = 4 的 0.16 降到 n = 14 的 1×10⁻⁴。
- **O12（探索性）**：按 Keating–Rudnick 的短区间分层，把 (Z/q)ⁿ 的加法特征分层。KR 的分层方差公式 |P̂|²/π_n ≈ (n−h−2)/n 在每一层都成立（大 q 时误差约 1%）。噪声几乎全部在最低层级 h = −1。若假设同一特征上 |L̂|² 与 |P̂|² 独立，会把 c² 高估 4–6 倍。所以两侧的 Fourier 系数强烈相关，候选解释是它们由同一个 L(u, ψ) 的零点决定。这给出了 c_∞(n) 的一个具体的随机矩阵问题。
- **O13（GPU，预注册）**：在 10⁹、10¹⁰ 的整个窗口（各约 210 万个 N）上，扣除 HL 与一阶项后的残差 z_N 对 N 的五个局部特征（ω_small、ω_big、最大素因子、v₂、log 𝔖）回归，R² 为 1.6×10⁻⁶ 和 2.0×10⁻⁶，与纯噪声水平一致（H1 ✓）。残差的方差有微弱局部结构：3∣N 时小约 9%（H2 ✓），z² 的 R² 约为 0.001。

### 7.4 函数域的小次数失败（O3 补充）
F₃[t] 的 3 个 4 次失败都在 F₃ 上恒等于 2。28 个候选 G 中有 26 个在某点取值 2，于是 F − G 有根。剩下的 2 个 G（t³ − t + 1 与 2(t³ − t + 2)）在 F₃ 上恒等于 1，此时 F − G 恰好分解为两个不可约二次式的乘积。全部 5 个函数域失败都是值集障碍。

### 7.5 第四批：刻画剩余噪声（O14、O15、O16）
- **O14（GPU，预注册）**：x = 10⁸、10⁹、10¹⁰、3×10¹⁰，每个窗口约 210 万个 N。残差 z_N 近乎完美高斯：|偏度| ≤ 0.005，超额峰度约 0.005，极值 ±5，与 √(2 ln n) 相符（H1 ✓）。跨 N 的相关有同余结构：N ≡ N′ (mod 3) 时约为 +0.02–0.03，否则约为 −0.01（H2 ✓）。滞后为 105、210 时相关最大，并随 x 缓慢减小。频谱集中在小分母有理数附近：0.4% 的频点承载 3%–7% 的功率。
- **O16（GPU，预注册）**：对 L = 1…400 的全部滞后，ρ(L) ≈ a + b·s(2L)，其中 s(h) = ∏_{p∣h, p>2}(p−1)/(p−2) 是孪生奇异级数比。新滞后上的 Pearson 相关为 0.96（10¹⁰）和 0.94（3×10¹⁰），R² 约 0.9（K1、K2 ✓）；b ≈ 0.022–0.027。所以噪声的协方差核本身是局部的，形状就是 HL 的二阶统计。若把三元奇异级数因子粗略取为 1，HL 对角项给出的斜率约为实测的 10 倍。所以与方差的情形一样，对角项很可能被大部分抵消；这一点没有严格计算。
- **O15（函数域，预注册）**：哥德巴赫纤维上的 Liouville 二点和 Λ(F) = Σ_G λ(G)λ(F−G)。n ≥ 4 的全部 (q, n) 上，sd·q^{n/2} = 1.00 ± 0.05，正是独立随机符号的尺度（H1 ✓）；与 F 的分解型无关，R² ≤ 0.002（H2 ✓）。小 q 时尾部比高斯更重（q = 3、n = 6…10，H3 ✗），但随 n 回落。n = 3 又是特例：涨落小约 √q 倍，且约一半由分解型决定。
- **关于方差常数的基线（更正 O8 的表述）**：整数的 r(N) 数的是有序对，所以独立模型下的泊松基线是 Var ≈ 2·E r。按这个基线，整数的 c²/2 在 10¹⁰ 上约为 0.34，与函数域 q = 3、n = 16 的 0.31 很接近。函数域的 r(F) 不对称，基线为 1。所以整数的亚泊松程度比第 7.3 节按基线 1 所写的更强；经验式 c² ≈ 1 − 7.2/log x 本身不受影响。
- **O17（GPU，预注册）**：按 N mod 3 拆分。N ≡ 1 (mod 3) 时，只有 p ≡ 2 (mod 3) 能与素数 N − p 配对；N ≡ 2 时只有 p ≡ 1。两类 N 的 r/b₂ 之差约为 +4.3/√x，这是 Chebyshev 偏差在哥德巴赫计数中的直接表现。在 [2^30, 2^34) 的 64 个窗口上，它随 x 的振荡（d·√x 从 1.2 到 7.3）被按类拆分的一阶素数计数项逐窗预测：相关 0.997，斜率 0.990，残差 0.08/√x（R1、R2 ✓）。这是 O5 从 ζ 零点到 L(s, χ₃) 零点的推广。窗口平均层面依赖于 N 的同余类的那部分，也被“局部密度 + 一阶素数计数误差”完全解释。
- **O18（GPU，预注册）**：O17 推广到模 4（零对照）、5、7、12，40 个窗口。类间差被一阶项预测：相关 0.9992（q=5）、0.9987（q=7）、0.9997（q=12），斜率 1.00 ± 0.01，残差约 0.02–0.03/√x（G1 ✓）。q = 4 的零对照类间差为 0.004/√x（G0 ✓）。O21 用同一代码把范围推到 1.2×10¹⁰–3.2×10¹⁰（12 个窗口）：相关 0.9995–0.9998，斜率 1.00 ± 0.01（G0、G1 ✓）。
- **O19（GPU，预注册）**：整数哥德巴赫纤维上的 Liouville 和 Λ(N) = Σ_{n<N} λ(n)λ(N−n)，在 10⁸、10⁹ 各约 210 万个 N 上计算。sd(Λ/√N)/√2 = 0.9997 / 1.0001，恰为独立随机符号尺度（对称性使每项出现两次）。它是高斯的（|偏度|、超额峰度 < 0.01），跨 N 自相关 ≤ 0.003，对局部特征的 R² 约为 10⁻⁵（C1–C3 ✓）。这是 O15 的整数对应。对照之下，哥德巴赫残差有亚泊松方差和由孪生奇异级数决定的协方差核。所以奇偶性在纤维上表现得像纯随机符号，而哥德巴赫噪声中的结构来自素数的局部相关。
- **O20（GPU，探索性）**：把 r(N)r(N+h) 精确拆成“对角”部分与“非对角”部分。对角部分是两对素数共用一个素数的项：h = 0 时为 2r，h > 0 时为 4(P∗Q_h)(N)，Q_h 是间距 h 的素数对。方差只有对角部分的 32%–33%（10⁹、10¹⁰；正好是 c²/2），即约 67% 被四个不同素数的相关抵消。h > 0 时，对角三元组被非对角部分抵消到 ±3% 以内，剩余的符号由 s(h) 决定。所以协方差核是两个大项之差的约 3% 余量。这与 L3c 中只算到 HL 主项的方差预测差一倍的现象相符（但 L3c 用的是 Λ 加权，未作直接对照）：二阶理论需要约 1% 的精度。

### 7.6 第六批：压力测试（O22、O23、O24）
- **O22（GPU，预注册；源于 O16 的事后发现）**：协方差核在 s(h) 之外还有一个稳定的负 ω(h) 项（ω 为 h 的不同奇素因子个数）。在新窗口 3×10⁹、2×10¹⁰ 和新滞后 L = 401…1000（h 到 2000）上，系数为 −0.0031、−0.0046，R² 提高 0.013，线性残差与 ω 的相关为 −0.33、−0.29（W1–W3 ✓）。核对 s(h) 的 Pearson 相关在这些大滞后上仍为 0.97。
- **O23（预注册）**：O15 推到更大的 q 与次数（q=3、n=16；q=5、n=11；q=7、n=9；q=11…19、n=6–7；q=37、n=5；q=53…61、n=4；每个情形 1.8×10⁶ 到 6.9×10⁷ 个 F）。sd·q^{n/2} = 0.999–1.018（H1 ✓），R²_type ≤ 0.0007（H2 ✓）；极值只在 q = 11、n = 6 时超出一次（H3 ✗）。
- **O24（GPU，预注册）**：c² 的函数形式。每个尺度 4 个新窗口，j = 14…34，共 84 个窗口；用 O8 冻结的参数比较。两种 √log 型形式（a·(log x)^{0.51}，A(1 − C/√log x)）的均方误差约为 2×10⁻⁴，明显优于 1 − 7.26/log x 的 2.8×10⁻³（F1 ✓）。但所有形式的 χ² 都远大于点数，函数形式仍然无法确定。
