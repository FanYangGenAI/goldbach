# 阶段性总报告（截至 2026-11-24，含通宵实验 O1–O3）

> 这份报告面向外部审阅者，力求自包含。逐条证据见 `lessons_ledger.md`。当前有效的“结论/勘误”表见 `current_conclusions.md`；两者冲突时，以本报告和台账的最新行为准。所有实验分支都在 GitHub 仓库 FanYangGenAI/goldbach 中，命名为 `gb/<编号>-…`。除特别注明外，每个检验都在运行前提交了设计和判据。

## 0. 一句话总结

我们没有接近哥德巴赫猜想的证明，也没有声称接近。有价值的产出是一张越来越清楚的“地图”：哪些涨落可以由 N 的素因子结构（局部信息）完全决定，哪些不能。迄今所有“不能”的部分都落在奇偶性方向上。

## 2. 目前站得住的正面结果（按证据强度）

1. **Q8（预注册新样本确认）**：在 [10⁹, 1.1×10⁹) 的 80 个新 N 上，第十轮审阅推导的二阶局部 Mellin 项 ℓ₃ = 𝔖(N)𝓛_{2,N}∫(D²a₁)a₁（其中 𝓛₂ = Σβ_p(log p)²）无参数地预测 m=3 扇区残差：ρ=0.957，标准差比 0.861，R²=0.907。
2. **Q1b**：零参数两变量欧拉乘积模型重现 j,k≤4 的整张扇区相关表（10⁸，log 误差 ≤0.030）。
3. **O2**：HL 背景系数的平均漂移到 8.6×10⁹ 仍在缩小，绝对值为 2×10⁻⁵。
4. **O1 的均值部分**：在 10⁹ 上，HL 型局部模型对 PP 配对数的预测误差为 1.5×10⁻⁴，对 χ 均值的误差约 7%。

这些都是已知启发式（HL、Selberg–Delange、局部因子）的精细数值确认和一个统一表述，不是新定理。

## 3. 通宵函数域实验 O3

分支 `gb/O3-function-field`（设计 d7d0b96，结果 6c774e1），探索性，无事前判据。对每个 n 次首一 F ∈ F_q[t]，数 r(F) = #{G：deg G < n，G 为常数乘首一不可约，F − G 为首一不可约}，用 (Z/q)ⁿ 上的 FFT 卷积一次算出全部 F，并与 HL 类比 r_pred = π_n·#{G}/qⁿ·𝔖(F) 比较，其中 𝔖(F) = ∏_{π∣F}|π|/(|π|−1)·∏_{π∤F}(1 − 1/(|π|−1)²)。范围：q=3 到 n=15（每个 n 有 3ⁿ 个 F，最大约 1400 万），q=5 到 n=10，q=7 到 n=8。q=3、n=3、4 的结果已用独立的试除程序逐个核对。

- **失败只出现在 F₃[t] 的 3 次（2 个）和 4 次（3 个）**；n ≥ 5 时全部 F 都有表示，最小 r/r_pred 单调趋向 1（q=3、n=15 时为 0.983）。
- **3 次失败的完整解释（事后）**：两个失败是 Artin–Schreier 多项式 t³ − t + c，它在全部平移 t → t + a 下不变，并在 F₃ 每一点取值 c。F − G 不可约 ⇔ G 在 F₃ 上处处不取值 c。但一次 G 取遍所有值，不可约二次 G 取到两个非零值，所以每个 G 都失败。这是 𝔖 看不见的 **值集障碍**，来自“次数相对 q 很小”。4 次失败的机制未分析。
- **HL 类比极准**：r/r_pred 的均值以约 q^{−n} 的速度趋于 1，corr(r, 𝔖) → 0.99999。
- **涨落是平方根级、亚泊松的**：sd(r/r_pred) × √(平均 r) 在每个 q 上大致恒定（q=3 约 0.6，q=5 约 0.45，q=7 约 0.4）。
- 纠缠熵随 n 单调降到 0，与 E1 一致；(1,1) 格相关 / 𝔖 在 q=5、7 时约为 1，在 q=3 时升到 1.06（未查，候选为 Ω ≤ 3 的截断）。

意义：函数域是一个可以穷举的“试验田”，HL 在那里比在整数中准得多，唯一的反例来自 𝔖 之外的局部障碍。它还没有触及奇偶性问题：下一步若继续，应在函数域里做 O1 的对照（带 Liouville 符号的 χ 能否被局部模型预测），因为函数域中的 Chowla 型问题在大 q 极限下有已知结果。

## 4. 负面结果与撤回（摘要）

- 撤回：L1 的“亚二项刚性”、GUE 解释、log³/log^{2.5} 方差律、贪心覆盖的不可能性、“均匀 √N 猜想”、B3 的 80%/42% 分解。
- 否定（预注册）：L3c（HL 首项解释方差）、Q7（单系统线性交叉项）、E1 的 H_local、O1 的波动判据。
- 方法教训：零模型必须保持被检验结构以外的一切；只修正到某一阶的模型要同时预注册幅度判据；比较两个对象时必须用同一种中心化；不改写预注册锚点。

## 5. 主线判断：统一的“局部/奇偶性”二分

把所有线放在一起，图景是一致的：

- 正逸度方向（Ω 计数、扇区表、m=3 涨落、E1 纠缠、B1 的拒绝）：**N 的素因子结构几乎决定一切**，可以用局部欧拉因子逐阶预测，而且预测在新样本上成立（Q8）。
- 奇偶性方向（arg z≈π、Liouville 带符号的 χ、B2/B3 的剩余刚性）：**局部模型给出正确的均值，却给不出任何 N 依赖**（O1），误差呈近平方根抵消（Q4）。B3 勘误显示，这方面任何“超出筛结构”的统计量，在 z³≥M 时都与哥德巴赫计数本身代数等价。

因此我们目前的判断是：在这个框架里，强哥德巴赫等价于控制奇偶性方向上的涨落，它至少和二元 Chowla 型估计一样难。框架的作用是把这一点精确地局部化，而不是绕过它。
