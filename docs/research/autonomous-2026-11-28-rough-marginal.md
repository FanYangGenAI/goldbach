# Rough-pair marginal criterion (2026-11-28)
Read gb/hub current_conclusions and scale-perturbation; previous run derived G=(S-2L+T)/4 for mirror-symmetric rough set C, z=floor(cuberoot N), both entries >1, least prime factors >z. Every entry is prime or semiprime. Let A count prime entries and B semiprime entries, so S=A+B and L=B-A. Inclusion-exclusion on C gives G>=max(0,2A-S)=max(0,-L). Thus a strict prime majority among rough-pair candidates suffices without estimating T. This is sharp given only marginal counts: an involution with no fixed points can pair opposite labels as much as possible (subject to parity); no general stronger bound from marginals alone. The actual fixed point N/2, if prime, already proves Goldbach. This is an elementary sufficient condition, not a proof of its uniform validity.
