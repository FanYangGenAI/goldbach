# 策略状态（2026-11-28 早晨，接续 strategy_status_2026-11-27.md）

## 1. 没有变化的部分

- 定理 Q（GRH）：|L_λ(N)| ≤ N − N·exp(−C(log log N)²)，对充分大的素数 N 成立，**仍待独立复核**。完整证明见 M3_theorem_Q_full_proof.md。
- 定位不变：这是 Corrádi–Kátai / Shusterman 型问题（哥德巴赫在 Liouville 函数上的类比）的有条件定量结果，不是哥德巴赫猜想本身。

## 2. 今早新增的严格结果（gb/M1-liouville-ladder 上 RESULTS.md 第 57–63 节，都待复核）

- **引理 L / L*（Kraft 型预算截断）**：给"父 → 子"边一个代价，只要求对每个节点满足 Σ_{脊柱父节点} e^{−代价} ≤ 1。在这个条件下，已覆盖的祖先数 ≤ e^T，负载 ≤ p^{O(1)}·e^T，不再随截断深度指数增长。
  - 两个特例：代价取 log indeg* 时，得到对数负担 Λ*；代价取熵时，得到终点祖先数 Ā，即二阶矩路线。
- **引理 I**：根乘数 p 是素数时，相邻两个 Thue 条件**精确独立**。400 组有理数精确核对，0 次失败。
- **引理 S**：深度 1、2 的节点对 Λ* 只贡献 O(log log p)。
- **一处更正**：截断必须取在实际脊柱上。松弛过程的总质量约为 p 倍（启发式估计），会抵消全部收益。

## 3. 有条件的定理

在 GRH 下，以下任一条件都推出 polylog 型节省 |L_λ(N)| ≤ N − N/(log N)^A：
- (i) Λ* ≤ C·log p；
- (ii) 命题 D′：深度 ≥ 3 的节点 Σ_t E[log indeg*] ≤ C·log p；
- (iii) Ā = E_n[anc(σ_L(n))] ≤ p^C。这个条件最弱。

若只能把它们证明到差一个 log log 因子，得到的是定理 Q⁺。

## 4. 数值证据（1024 位 N，即定理所需的区域；只是证据，不是证明）

- Λ*/ln p ∈ [0.16, 0.21]，p = 31…4093。
- 深度 ≥ 3 的部分约为 0.06·ln p。
- Ā = 2.8、4.5、6.0、7.6（p = 61、251、1021、4093），约为 0.9·ln p，或 p^{0.25}。
- 小 N（≤ 2²⁰）的数值系统性地高估了合并。此前 E42 看到的"祖先数与 q 成正比"是有限 N 效应。

## 5. 被否定的设想

命题 D（与 n 相关的候选父节点在脊柱上的概率 ≲ C/a′）在数值上不成立，比值最高为 125 倍。真实的机制是"末位替换"：n′ = (a_{t−1}/a′)·n 继承了 n 的 Thue 条件，这在深度 2 处概率约为 0.65。

## 6. 剩下的核心困难

三个条件最终都需要混合进制数字模**小素数幂**的相容性。粗略处理小素数只能给出定理 Q⁺（见第 63 节的分析）。
