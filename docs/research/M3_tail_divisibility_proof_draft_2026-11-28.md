# 尾数整除的两段式证明稿（松弛″测度、相邻互素）——待独立复核

2026-11-28 10:56。对应分支 gb/M1-liouville-ladder 的 `research/M3_z2_rung/RESULTS.md` 第 71 节。本稿只覆盖定理 Q⁺ 路线图（第 64.4 节）的第 2 步。第 3 步（相邻不互素）与第 4 步（松弛 → 实际）**不在本稿范围内**。

## 0. 记号

- 乘数 a_0 = p > a_1 > ⋯ > a_t，相邻互素；ε ∈ {0, 1}^t；数字 c_i ∈ [0, a_i)。
- 自动机关系：a_{i+1}c_i + c_{i+1} + ε_i = K_ia_i。
- T_i = a_{i+1}⋯a_t，M = Σ_i c_iT_i，M^{(i)} = Σ_{k≥i} c_kT_k，S_i = T_{i+1}。
- 松弛″：所有 c_i ∈ [1, a_i − 2]，在合法串上取均匀测度。序列的权重为 Π_{i<t} 2/a_i（引理 I*）。
- 目标量：X_t := Ω(gcd(M(M + 1), P_t))，P_t = a_0⋯a_t。

## 1. 引理 B′（合法性只由 c_t 决定）

**陈述**：c_i = 0 当且仅当 (c_{i+1}, ε_i) = (0, 0)；c_i = a_i − 1 当且仅当 (c_{i+1}, ε_i) = (a_{i+1} − 1, 1)。因此每个 ε 恰有 a_t − 2 个合法串，它们与 c_t ∈ [1, a_t − 2] 一一对应。

**证明**：由关系式，c_i ≡ −(c_{i+1} + ε_i)·a_{i+1}^{−1} (mod a_i)，且 0 ≤ c_{i+1} + ε_i ≤ a_{i+1} < a_i，逐一比较即得。∎

## 2. 引理 X（尾部约化）

**陈述**：对 j ≤ t − 2，令 X_j = M^{(j+2)} − ε_jT_{j+1}。
- (a) M ≡ X_j (mod a_j)。
- (b) X_j 只依赖 a_{j+2}, …, a_t、c_t 与 ε，与 a_j、a_{j+1} 无关。
- (c) 0 < |X_j(X_j + 1)| < 2a_{j+1}^{2ℓ+2}，其中 ℓ = t − 2 − j。
- (d) 更一般地，对素数 q 与 k ≥ 1，令 i₀ = 满足 v_q(a_i⋯a_t) ≥ k 的最大 i。若 i₀ ≤ t − 2，则 M ≡ X_{i₀} (mod q^k)。

**证明**：
- (a)：a_j | T_k（k < j），且 c_jT_j + c_{j+1}T_{j+1} = (K_ja_j − ε_j)T_{j+1}。
- (b)：由反向确定性。
- (c)：由引理 B′，0 < M^{(j+2)} < T_{j+1}，且数字不取最大值。
- (d)：q | a_{i₀}，由相邻互素 q ∤ a_{i₀+1}，所以 v_q(a_{i₀}T_{i₀+1}) ≥ k，再用 M ≡ M^{(i₀)} (mod T_{i₀−1})。∎

**计数约定**：每个 q^k | gcd(M(M + 1), P_t) 归到唯一的位置 i₀(q, k)。
- j = t − 1 时 X_{t−1} = −ε_{t−1}，所以 a_{t−1} | M(M + 1) 恒成立，贡献确定性的 Ω(a_{t−1})。
- j = t 时 M ≡ c_t (mod a_t)。

## 3. 引理 H / H′（大素数幂，对 a_j 平均）

**陈述**：固定 a_{j−1} 与 a_{j+1}, …, a_t，令 a_j 取遍可容许集 A_j ⊂ (a_{j+1}, a_{j−1})，权重 1/a_j，W_j = Σ_{A_j} 1/n，Y = √a_{j+1}。则
  E_{a_j}[#{(q, k) : i₀ = j，q^k > Y，q^k | M(M + 1)}] ≤ W_j^{−1}·Σ_{(q,k) : q^k | X_j(X_j+1), Y < q^k < a_{j−1}} (log(a_{j−1}/a_{j+1})/q^k + 1/a_{j+1})
  ≲ W_j^{−1}·(ℓ + 1)·log a_{j+1}·(log(a_{j−1}/a_{j+1})/√a_{j+1} + 1/a_{j+1})。

**证明**：
- 由引理 B′，对每个 a_j，合法串都与 (ε, c_t) 一一对应。
- 由引理 X(b)，X_j 不随 a_j 变化。
- 交换求和次序，并用 Σ_{a<n<b, d|n} 1/n ≤ log(b/a)/d + 1/a，以及 (c) 给出的素因子个数界。∎

## 4. 引理 W（小素数幂，对 b = a_{j+2} 平均）

**设定**：q^k ≤ √a_{j+1}，i₀(q, k) = j，q 只在 j 处出现，ℓ ≥ 1。记 m = a_{j+3}，Q = q^k·m，S = S_{j+2}，I = −ε_{j+2}S + M^{(j+4)}。

**约化**：q^k | M 当且仅当 bK′ ≡ w (mod Q)，其中
- K′ = K_{j+2} − ε_jm ∈ J（J 为 m + 1 个连续整数）；
- w = CRT(c_{j+3} + ε_{j+2} mod m；−I·S^{−1} mod q^k)，只依赖 y = c_{j+3}、ε 与内层乘数。

**界**：设 I* 为长度 L 的区间中与 a_{j+1}·Q 互素的 b。则
  Σ_{b∈I*} N_{q^k,ε}(b) ≤ (a_t − 2)·|I*|·(m + 1)/Q·(1 + O(τ(Q)·g·log Q/m)) + (a_t − 2)·τ(Q)σ_{−1/2}(Q)(2 + log Q)²·max_y √(Q·g_y)，
其中 g_y = gcd(w_y, Q)。

**证明**：
- 由 y 的单射性，计数化为 Σ_y #{b ∈ I* : w_yb̄ mod Q ∈ J}。
- 把 1_J 在 Z/Q 上作 Fourier 展开。k = 0 项给出主项。
- 完整周期给 Ramanujan 和，|c_Q(α)| ≤ gcd(α, Q)。
- 不完整的部分用 Weil–Estermann 界 |S(α, β; Q)| ≤ τ(Q)(α, β, Q)^{1/2}Q^{1/2} 补全（Iwaniec–Kowalski，推论 11.12）。
- 最后用 Σ_{k≤Q/2} √gcd(k, Q)/k ≤ σ_{−1/2}(Q)(1 + log Q)。∎

**推论**：E_b[P(q^k | M)] ≤ (1 + o(1))/q^k + O(√(q^k·m)·polylog/|I*|)。

**条件版本（情形 B1）**：设 q 也整除更后面的乘数，但 q ∤ a_{j+2}a_{j+3}，并令 e = v_q(S)。则 q^k | M 当且仅当 [q^e | M] 且 [bK′ ≡ −(I/q^e)(S/q^e)^{−1} (mod q^{k−e})]。第一个条件与 b 无关。由此 E_b[P(q^k | M)] ≤ P(q^e | M)·((1 + o(1))q^{−(k−e)} + Err)，再对 k 归纳。

## 5. 合成

**每步的界**：
  E[X_t] ≤ E[Ω(a_{t−1})] + 2(1 + o(1))·Σ_{q|P_t} 1/q + O(1)。
其中 O(1) 包括：
- a_{j+1} ≤ A₀ 的有限多个位置（用平凡界）；
- 引理 H/H′ 的总和；
- 引理 W 的误差总和 O(a^{−1/4+o(1)})；
- 素数幂 Σ O(q^{−k})。

**总量**：对 t 求和，E[Σ_t X_t] = O(log p·log log p)，即引理 R′ 的形式（在松弛″、相邻互素的模型中）。

## 6. 缺口（必须在复核时重点检查）

1. **G2（窗口）**：引理 H、W 都是"给定邻居时对一个乘数平均"。合成时须用"期望之比"处理短窗口，并要求松弛森林中后续质量 ≍ a^c。目前是草稿（第 71.8 节）。
2. **G3-B2**：q | a_{j+2} 或 q | a_{j+3} 的素数幂配置，需单独记账。
3. **第 3 步（相邻不互素）与第 4 步（松弛 → 实际）**：完全未处理。实际脊柱上约 16–19% 的步不互素。
4. **常数**：Weil 误差项要到 a ≳ 10^{10} 才小于主项，所以这纯粹是渐近论证。
5. **引用**：Weil–Estermann 界对一切模数 Q 成立。数值上常数 1 是紧的：E53c 中 1,600 例的最大比值为 0.971。
