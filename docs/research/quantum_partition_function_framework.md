## 0. 我对纠偏的理解

接受。最近几轮虽然名义上从群与量子出发，实际工作却全部滑回了筛法（多数判据、线性筛常数、Type II 上界）。原因是我每一步都要求新框架“立刻推出一个能逼近哥德巴赫的不等式”，结果只能回到最熟悉的工具。

从现在起的规则：

## 1. 共同空间（沿用 a0c9305 的设定）

整数基 |n⟩ ↔ 素因子占据态 |ν₂(n), ν₃(n), ν₅(n), …⟩（玻色 Fock 空间，Bost–Connes §2）。
- 总占据数 𝖰|n⟩ = Ω(n)|n⟩。素数 = 单粒子态（𝖰 = 1），半素数 = 两粒子态。
- 乘法 V_a：往 Fock 态里加入粒子，𝖰V_a = V_a(𝖰 + Ω(a))。在这个表示里乘法很简单。
- 加法（平移 S、反射 J_N: n ↦ N−n）：会把整个占据模式“打乱重排”。哥德巴赫问的是反射 J_N 如何在 **粒子数扇区** 之间搬运态。

## 2. 核心对象：双逸度配分函数

对偶数 N，令 |Ψ_N⟩ = (N−3)^{−1/2} Σ_{n=2}^{N−2} |ν(n)⟩_A |ν(N−n)⟩_B，并给两个子系统各引入一个 **逸度**（fugacity）z、w：

  **G_N(z, w) := (N−3)·⟨Ψ_N| z^𝖰 ⊗ w^𝖰 |Ψ_N⟩ = Σ_{n=2}^{N−2} z^{Ω(n)} w^{Ω(N−n)} = Σ_{j,k≥1} T_{jk}(N) z^j w^k。**

这是统计力学里标准的巨正则配分函数：每个“粒子”（素因子）带一个权重 z 或 w。系数 T_{jk}(N) = #{n : Ω(n) = j, Ω(N−n) = k} 是反射 J_N 在扇区之间的 **转移矩阵**。

### 初等引理（直接验证）

| 编号 | 内容 | 含义 |
|---|---|---|
| L1 | G_N(1, 1) = N − 3 | 无权重时只是计数 |
| L2 | **[z¹w¹] G_N = T_{11}(N) = r(N)** | 哥德巴赫 ⇔ 配分函数中“单粒子 ⊗ 单粒子”项非零 |
| L3 | G_N(−1, −1) = Σ λ(n)λ(N−n) | 负逸度给出 Liouville 的二元相关（Chowla 型和） |
| L4 | r(N) = (2πi)^{−2} ∮∮ G_N(z,w) z^{−2} w^{−2} dz dw（\|z\| = \|w\| = ρ，任意 ρ > 0） | 单粒子扇区可以由配分函数在复逸度圆周上的值精确提取 |
| L5 | 对单个子系统，Σ_{n≤x} z^{Ω(n)} 的渐近公式（Selberg–Delange）对 \|z\| < 2 一致成立，系数提取后即得素数定理（Sathe–Selberg） | **单系统里，“逸度 → 扇区”的提取是一条可行的证明路线** |

## 3. 相图：哪些逸度区域我们会算，哪些不会

L5 说明，对单个子系统，只要知道配分函数在一个 **包含原点的复圆盘** 上的一致渐近式，就能精确数出单粒子态（素数）。对两个子系统通过反射纠缠在一起的情形，现状如下：

| 逸度区域 | 物理含义 | 数学现状 |
|---|---|---|
| z = w = 1 | 无相互作用 | 平凡 |
| z, w 为正实数，靠近 1 | “高温”、平均行为 | Erdős–Kac 型：Ω(n) 与 Ω(N−n) 近似独立的高斯；可用已知方法处理（需逐项核对文献） |
| z → 0，w = 1 | 一侧只留单粒子 | 平凡（就是数素数） |
| z → 0，w 为正实数 | 一侧素数，另一侧加权 | 移位素数上的乘性函数和（Titchmarsh 除数问题型）；对中心范围的 k 有 Erdős–Kac / Halberstam 型结果 |
| z, w 为 **负实数**或复数 | “相位”信息 | 包含 L3 的二元 Chowla 和；**这正是奇偶性障碍所在** |
| 原点附近的整个复圆周（L4 所需） | 精确提取单粒子 ⊗ 单粒子扇区 | 等价于哥德巴赫的渐近式；未知 |

**一句话：奇偶性障碍在这个框架里有一个干净的物理解释。** 筛法和平均方法能控制正实逸度（“实温度”）下的配分函数；而要精确提取 r(N)，必须沿复逸度圆周积分，其中包括负逸度方向（“相位”）。这些方法控制不了那里。这与统计力学中“实温度下的热力学量好算，复温度 / 复逸度下的 Lee–Yang 零点难算”是同一类现象。

## 4. 由此引出的、属于这个框架自己的问题

**Q1（转移矩阵的结构）。** 对 j, k 都在中心范围（≈ log log N）的扇区，T_{jk}(N) 应近似等于“独立 Sathe–Selberg 分布的乘积 × 局部（奇异级数型）修正”。偏差如何随 (j, k) 变化？哥德巴赫所在的角落 (1,1) 是否只是这个光滑结构的延续，还是会出现系统性偏离？这是一个纯计算的、在本框架内可以精确提出的问题。

**Q2（配分函数在复逸度上的相位）。** 在 |z| = |w| = ρ 的圆周上，G_N 的相位分布是什么样的？L4 的积分中，正实轴附近（“可控”）与负实轴附近（“奇偶性”）各贡献多少？如果负逸度方向的贡献在数值上总是很小，可以把这个观察表述成一个精确的猜想，即“相位抵消猜想”。它与二元 Chowla 的关系要另行写清楚。

**Q3（Lee–Yang 零点）。** 对角化 H_N(z) := G_N(z, z) = Σ_m h_m(N) z^m，其中 h_2 = r(N)。哥德巴赫 ⇔ H_N 在 z = 0 处恰好是二阶零点。H_N 的其余零点如何分布？是否有类似 Lee–Yang 圆周定理的规律（零点集中在某条曲线上，并远离原点）？若有，就有可能从零点分布的整体规律出发，约束原点附近的行为。这是一个真正来自统计物理的新问题；我目前不知道答案，也不知道是否已有文献。

**Q4（平移的转移矩阵，作为对照）。** 对平移 S（n ↦ n+1），同样定义 M_{jk}(x) = #{n ≤ x : Ω(n) = j, Ω(n+1) = k}。孪生素数对应 M_{11}。用同一套框架同时研究反射与平移，可以检验哪些现象是“加法打乱粒子数”的普遍性质，哪些是哥德巴赫特有的。

## 5. 下一步（先算后证）
