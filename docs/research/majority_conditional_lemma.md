## 1. 设定

偶数 N，z = N^{1/u}，2 < u ≤ 3。
- A_N = {2 ≤ n ≤ N−2 : n 与 N−n 都没有 ≤ z 的素因子}，它在 n ↦ N−n 下不变。
- 因为 u ≤ 3，A_N 中每个数都是素数或恰有两个素因子（含 p²，p > z）。
- P_N = #{n ∈ A_N : n 为素数}，S_N = #{n ∈ A_N : n 非素数}，T_N = P_N + S_N。

**多数判据（初等，原备忘录已给出）**：若 P_N > S_N，则由 R − S = P_N − S_N（R、S 分别为素数–素数、合数–合数的有序对数）得 R > 0，所以 N 是两个大于 z 的素数之和。

## 2. 关键观察：P_N 与 S_N 是“同一个筛”

把 P_N 和 S_N 都看成“在一个基础序列上，筛 N − n 是否 z-粗糙”：

| | 基础序列 | 质量 X | 对奇素数 ℓ ≤ z 的排除密度 |
|---|---|---|---|
| P_N | z < p ≤ N−2 的素数 | X_P ≈ N/log N | ℓ ∤ N 时 1/(ℓ−1)；ℓ ∣ N 时 0 |
| S_N | 两个素因子都 > z 的合数 n ≤ N−2 | X_S ≈ log(u−1)·N/log N | **相同**：这些数模 ℓ 都是单位，并在单位类中均匀分布 |

因此两者有 **相同的筛维数（1）和相同的局部因子** V₁ = ∏_{3≤ℓ≤z, ℓ∤N}(1 − 1/(ℓ−1))。记 M_P = V₁X_P，M_S = V₁X_S。若两个基础序列在算术级数（剩余类 N mod d）中都有分布水平 N^θ，则线性筛定理（Rosser–Iwaniec；见 Tao 254A Supplement 5, Theorem 2）给出，其中 s = θu：

  P_N ≥ (f(s) − o(1))·M_P，  S_N ≤ (F(s) + o(1))·M_S。

对 2 ≤ s ≤ 3，f(s) = 2e^γ·log(s−1)/s，F(s) = 2e^γ/s，所以 f(s)/F(s) = log(s−1)。

### 引理 1（这一具体方法的天花板）

用上述两个线性筛界去推出 P_N > S_N，需要 f(θu)·X_P > F(θu)·X_S，即（取主项 X_S/X_P → log(u−1)）

  **log(θu − 1) > log(u − 1)，等价于 θ > 1。**

由于分布水平 θ ≤ 1，**对任何 u ∈ (2, 3]，这条路都不通；在 θ = 1（Elliott–Halberstam 型）时两边恰好相等。**

*证明*：直接代入。当 θ ≤ 1、u ≤ 3 时 s = θu ≤ 3，公式适用。若 θu ≤ 2，则 f(s) = 0，下界平凡。∎

**含义**：这是奇偶性障碍在本问题中的一个精确的数值形态。素数与“两个大素数之积”的质量之比，恰好等于线性筛上下界之比。这说明 TR3 指出的错误比较之所以“差一点就对”，是因为正确的比较给出的是 **精确相等**。
**限定（回应 TR2）**：引理 1 只说明“组合这两个线性筛界”这一具体方法不够，不是对所有方法的不可能性定理。要得到后者，需要构造同时满足两个序列全部输入的带权反例，本文没有做。

2. 真实值（≈1.005）与筛法界（0.823 / 1.187）之间有很大空隙。多数判据成立靠的是真实值，而不是筛法能证明的值。

## 4. 条件性引理：需要的新信息是什么

### 引理 2（充分条件）

固定 u = 3（z = N^{1/3}）。假设对所有充分大的偶数 N：

- **(A) 素数的分布水平 θ > 2/3**（Elliott–Halberstam 型的 Type I 信息）：对剩余类 N mod d、模 d ≤ N^θ 的素数分布，满足线性筛所需的余项界。由此 P_N ≥ (f(3θ) − o(1))·M_P，且 f(3θ) > 0。
- **(B) 半素数序列的“破奇偶”上界**：存在固定的 η > 0，使得

    S_N ≤ (f(3θ) − η)·M_P。

那么对所有充分大的偶数 N，都有 P_N > S_N，从而 N 是两个大于 N^{1/3} 的素数之和。

*证明*：由 (A)，P_N − S_N ≥ (η − o(1))·M_P。而 M_P = V₁X_P ≫ N/(log N)²，所以对充分大的 N，P_N − S_N > 0。再由 §1 的多数判据得 R ≥ P_N − S_N > 0。∎

### 这不是换名字（回应“仅改写 L_N<0 不算引理”）

- (B) 只涉及 **一侧是半素数** 的计数，形状是双线性的：S_N ≈ Σ_{z<p≤q} 1[N − pq 为 z-粗糙]。这是关于双线性族 {N − pq} 的一个 **上界**，不涉及素数对 R。
- 取 θ = 1 时，(B) 要求 S_N/M_S ≤ (1−δ)·F(3)，即比线性筛上界好一个固定比例 δ > 0。数据中的真实值约为 1.005 = (1 − 0.153)·F(3)，所以 (B) 在数值上有约 15% 的余量。
- 由引理 1，(B) **不能** 只由分布水平（Type I）信息推出（至少不能由线性筛推出）。它需要某种能感知 N − pq 是素数还是半素数的信息。一个自然的候选形式（启发式对应，未证明等价）是双线性族上的 Liouville 估计：

    Σ_{z<p≤q, pq<N, N−pq z-粗糙} λ(N − pq) ≥ −(1 − δ')·S_N。

  直观上，这说明 N − pq 这些值 **不会几乎全是素数**。

### 与已知工作的关系（诚实评估）

- Friedlander–Iwaniec（x² + y⁴）与 Heath-Brown（x³ + 2y³）都是在“两个变量的多项式取值”上打破奇偶性。{N − pq} 也是两个变量的族，形状相近；但这里的变量 p、q 本身限制为素数（非常稀疏），已知方法无法直接处理。
- 陈景润的“交换原理”能给出某些合数计数的非平凡上界，但它不打破奇偶性，不能单独推出 (B)。
- 所以 (B) 是一个 **明确、可审阅、数值上有余量、但目前没有已知方法能证明** 的目标。它的价值在于把“缺少的新信息”压缩成一个具体对象：在双线性族 N − pq 上，Liouville 函数不能几乎全取 −1。
