## 1. 仍然成立的结论

| 结论 | 证据层级 | 范围与限定 |
|---|---|---|
| R(N) 与 Hardy–Littlewood 预测在窗口均值意义上吻合到 10⁻³ 量级；单个 N 的比值最差为 0.918（N=144128，N>10⁵） | 数值 | N ≤ 3.4×10⁷。L0 台账中“全范围 1% 内”的说法错误，应改为窗口均值 |
| 次弧的重尾主要由奇异级数尾项 N(𝔖−𝔖_Q) 解释（斜率 0.9998，R²=0.74） | 数值 | X=2²⁴，Q=256。预注册的高斯检验 P2 **未通过**；之后的异方差标准化是探索性的。拟合残差 e_N 与 F(N) 不是同一个对象 |
| 定义 F=R−N𝔖、B_p=Σ_{N∈窗口}|F/(N𝔖)|^p。若 B_p<1，则窗口内没有反例 | 严格（标准的矩/Markov 充分条件） | 不是新发现，也不是必要条件。条件性目标：若对 **所有** t∈[x,2x] 有一致的未中心化短窗口二阶界、并能使每个窗口 B₂<1，则可排除反例（R9）；分割本身不会产生这种一致界；回到强哥德巴赫还需处理 Λ−θ |
| 窄窗口内 F/√𝔖 的四阶矩比接近 3，极值接近 √(2 ln n) | 数值（有限样本的形状证据） | x 到 4.3×10⁹。不能认证尾部一直到反例阈值；相邻 N 有相关，不是独立样本 |
| 分层估计的二进窗口 B₂ 随 x 上升（24→61），B₄ 下降（9.7×10⁻⁴→1.2×10⁻⁵） | 数值估计 | j=22…31。j=22…25 已测校准偏差 ≤6.8%；更大尺度没有误差保证（R14；j=22 的窗口还重叠并越界）。不是全窗口测量，也不是上界 |

| 线性模板 2𝔖(N)(ψ(N)−N) 对偶数 N 上 F_Λ 的带截距回归 R² 约 0.20%（系数 0.99–1.00） | 数值 | 两个窗口（≈1.7×10⁷、6.7×10⁷）。这 **不是** ζ 零点总贡献的上界：二次项 Σa(m)a(N−m) 同样可能由 ζ 零点控制；也不能把剩余方差归因于 q≥2 或 L 函数族（R10） |

## 4. 开放问题（按价值排序）

1. **L1 的过度离散**（V1b/V4）：相对位置分层置换零模型，联合素数计数的方差超出 37%–75% 并随 N 增大，且不是小模数剩余类效应。候选（未检验）：它是 L3 方差超出在条件抽样语言下的重现。提升结论前需要独立区间的确认实验。
2. **方差的理论形式**：固定窗口口径下有效对数指数从约 3 降到约 2.5。需要一个控制均值项、θ/Λ 差异和累计误差的理论候选，再做预测检验。
3. **按分母 q 的方差分解**：必须先定义分量和协方差（局部偶数窗口上各分量一般不正交），再谈“份额”；之后才考虑与 Barban–Davenport–Halberstam / Montgomery–Hooley 型结果的联系。
