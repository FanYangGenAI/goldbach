## 3. 我的补充：目标 A 的难点到底在哪

备忘录的核心新落点是：

> **目标 A：若在 A_N 中素数占多数（ρ_N > 1/2，等价于 L_N < 0），则 r_>(N) ≥ −L_N > 0，哥德巴赫对该 N 成立。**

这是一个“鸽巢原理”式的判据：反射 n ↦ N−n 是 A_N 上的双射，素数占一半以上时，素数不可能全部被映到非素数上。

### 3.1 数值上，目标 A 有相当的余量（探索性核对）

| N 的量级 | ρ_N 均值 | ρ_N 最小值 | r_>/T 最小值 |
|---|---|---|---|
| 10³ | 0.720 | 0.663 | 0.395 |
| 10⁵ | 0.680 | 0.660 | 0.426 |
| 10⁶ | 0.653 | 0.646 | 0.413 |
| 10⁷ | 0.637 | 0.635 | 0.401 |
| 10⁸ | 0.632 | 0.630 | 0.396 |

（10³–10⁵ 是连续全部偶数，10⁶ 起每个量级随机 200 个；另外 6 ≤ N ≤ 20000 的全部偶数都满足 ρ_N > 1/2。）

启发式极限：在 A_N 中，半素数必须两个素因子都大于 N^{1/3}，所以只在 n > N^{2/3} 时出现。按素数定理估算，半素数与素数的个数之比约为 ∫_{1/3}^{1/2} dα/(α(1−α)) = log 2，故 ρ_N → 1/(1+log 2) ≈ **0.591**。数据从 0.72 缓慢降向这个值。余量约为 0.09，不会趋于 0。另外 r_>/T ≈ ρ_N²，说明两侧素性近似独立（κ_N ≈ 0）。

### 3.2 但目标 A 正好被奇偶性障碍挡住（这一点比备忘录说得更具体）

#A_N∩ℙ = #{p > z：N−p 没有 ≤ z 的素因子}。这是一个标准的筛法量，计数时并不区分 N−p 是素数还是半素数，所以它 **本身** 不是奇偶性敏感的。但要证明 ρ_N > 1/2，必须把它与 T_N 的一半作比较，这一步被奇偶性障碍挡住，理由如下：

- **替身论证。** 把“素数”换成“两个大素数之积”（半素数）。两者在算术级数中的分布性质（筛法的全部输入）相同，但替身的 ρ' = 1 − ρ ≈ 0.41 < 1/2。所以任何只依赖筛法输入的论证都无法区分 ρ ≈ 0.59 与 ρ' ≈ 0.41，也就证明不了 ρ > 1/2。这正是备忘录 §7 删点检验的一个具体实例。
- **分布水平。** 即使不考虑奇偶性，用线性筛给 #{p：N−p 为 N^{1/3}-粗糙} 一个正的下界，需要筛参数 s = (分布水平)/(1/3) > 2，即素数在算术级数中的分布水平大于 2/3。Bombieri–Vinogradov 只给出 1/2（s = 1.5，下界函数 f(1.5) = 0），所以无条件连非平凡下界都没有。在 Elliott–Halberstam 猜想下 s = 3，下界函数为 f(3)/F(3) = log 2 ≈ 0.69 倍于上界，损失仍大于 0.59 对 0.5 的余量。

**结论：** 目标 A 是 Goldbach 的一个漂亮的 **充分条件重述**，在数据上余量稳定（约 0.09）。但证明它需要的恰好就是筛法之外的 Type II（双线性）信息。它把“需要什么”说得更清楚了，却没有降低难度。这与备忘录 §4.3 的判断一致，只是更具体：障碍的位置是“比较素数与半素数的个数”，而不是“计数粗糙数”。

## 4. 对研究计划的意见

同意备忘录 §8 的两项任务，并建议补一个零号任务：

- **任务零（便宜、可预注册）：** 系统测量 ρ_N 与 1/(1+log 2) 的偏差、ρ_N 的最小值随 N 的变化，以及 κ_N 的大小。这是给目标 A 建立“现实余量”的数值档案，计算量很小（10⁸ 规模几分钟）。
- **任务一（双侧粗糙模型的条件性引理）：** 按 3.2 节，最自然的条件形式是“若对 {N−p} 有某种 Type II 估计，则 L_N < 0”。需要写清楚哪一个双线性和、需要什么强度。
- **任务二（函数域证明依赖表）：** 同意先读 Pellet 公式 μ(f) = (−1)^{deg f}χ₂(disc f) 这条路线。它恰好是“乘法分解的符号被转化为可估计的特征和”，也就是函数域中目标 A 那类量为什么可以被控制的根本原因。

## 5. 小的保留意见

- 备忘录把“目标 A”排在第一位，理由是“有清楚的数学任务”。我同意，但要强调：它的余量不随 N 消失（≈0.09），这一点有好有坏。好处是它不是一个“擦边”命题；坏处是 3.2 节的替身论证说明，这个余量恰好落在奇偶性的盲区里，所以余量大小本身帮不上证明。
- §6.2（进位自动机 / 张量网络）作为思想实验有意思，但目前看不到它如何越过 3.2 节的替身论证。在找到能区分素数与半素数的压缩之前，建议列为低优先级。
