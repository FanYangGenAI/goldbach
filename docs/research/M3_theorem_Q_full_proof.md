# 定理 Q 的完整证明（供独立复核）

**状态**：本会话给出的证明，每个引理都附有数值核对，但**尚未经独立复核**。数值核对的代码与数据见分支 gb/M1-liouville-ladder 下的 `research/M3_z2_rung/`，对应的节号在各处注明。

**定理 Q（GRH）**：存在绝对常数 C，使对一切充分大的素数 N，
  |L_λ(N)| := |Σ_{n<N} λ(n)λ(N − n)| ≤ N − N·exp(−C(log log N)²)。

**推论 Q′**：在 GRH 下，对充分大的素数 N 和每个 (η₁, η₂) ∈ {±1}²，
  #{n < N : λ(n) = η₁, λ(N − n) = η₂} ≫ N·exp(−C(log log N)²)。

**对比**：Mangerel（arXiv:2412.17199，命题 1.4）在同样的假设下给出 N − N·exp(−C(log log N)⁶)。

---

## 0. 记号

- N 为大素数。g: ℕ → {±1} 为完全积性函数，η ∈ {±1}。
- 对 x ∈ [1, N−1]，记 pr(x) = min(x, N − x)。"行" ρ ∈ [1, (N−1)/2] 指配对 {ρ, N − ρ}。若 g(ρ)g(N − ρ) ≠ η，称它为坏行，坏行数记为 B。
- 实例 I(a, x)（2 ≤ a，1 ≤ x ≤ N − 1）表示断言 g(ax) = g(ax mod N)。当 ax < N 时它平凡成立。
- 𝓔_a(g) = {x : I(a, x) 不成立}。
- ‖t‖ 表示 t 到最近整数的距离。

## 1. Thue 树证书

**引理 1（Thue）**：若 ax ≥ N，则存在 1 ≤ v ≤ a − 1、ε ∈ {±1} 和 1 ≤ y < N/a，使 xv ≡ εy (mod N)。取最小的这样的 v，记为 v(a, x)。

证明：对 (u, w) ∈ [0, ⌊N/a⌋] × [0, a − 1] 用鸽笼原理，因为 (⌊N/a⌋ + 1)·a > N。∎

**引理 2（一步推导）**：令 r = ax mod N，v = v(a, x)。则
- ε = +1 时：I(v, x) 与 I(v, r) 合起来推出 I(a, x)；
- ε = −1 时：还需行 pr(y) 与 pr(ay) 都是好行。

证明：
- vr ≡ εay (mod N)，且 ay < N。
- 由完全积性，g(v)g(ax) = g(a)g(vx)。由 I(v, x)，g(vx) = g(vx mod N)；而 vx mod N 等于 y（ε = +1）或 N − y（ε = −1）。
- 同理，由 I(v, r)，g(v)g(r) = g(vr mod N)，它等于 g(ay) 或 g(N − ay)。
- ε = +1 时，两边都等于 g(a)g(y)。ε = −1 时，用两行的刚性 g(N − z) = ηg(z) 把两边都化成 ηg(a)g(y)。∎

v < a，所以递归终止，得到 n 的树 tree(n)，根为 I(p, n)。**若树中用到的行都是好行，则 n ∉ 𝓔_p。**

## 2. 结构

**引理 3（Lagrange）**：v(a, x) 是 u = x/N 的某个连分数渐近分母 q_k。并且 ‖q_k u‖ < 1/a ≤ ‖q_{k−1}u‖。

证明：v 是使 ‖vu‖ < 1/a 的最小正整数，所以对 w < v 有 ‖wu‖ ≥ 1/a > ‖vu‖。这说明 v 是第二类最佳逼近，因而是渐近分母。∎

**引理 4（脊柱 + 毛毛虫）**：
- (i) A 型子节点 I(q_k, x) 的 Thue 选择为 q_{k−1}。
- (ii) 对 i ≤ k，节点 I(q_i, x) 的 B 型子节点 I(q_{i−1}, q_i x mod N) 要么平凡，要么 Thue 选择为 1。Thue 选择为 1 时，两个子节点的乘数都是 1，不再展开。

证明：
- (i) 由连分数的标准性质，‖q_{k−1}u‖ < 1/q_k；又对 w < q_{k−1}，‖wu‖ ≥ ‖q_{k−2}u‖ > 1/(q_{k−1} + q_{k−2}) ≥ 1/q_k。
- (ii) 记 δ_i = ‖q_i u‖，则 {q_i u} ∈ {δ_i, 1 − δ_i}。i < k 时 δ_i < 1/q_{i+1}；i = k 时 δ_k < 1/a；两种情形都有 δ_i < 1/q_{i−1}。
  - 若 {q_i u} = δ_i，则 q_{i−1}δ_i < 1，节点平凡；
  - 若 {q_i u} = 1 − δ_i，则 ‖1·(1 − δ_i)‖ = δ_i < 1/q_{i−1}，所以 v = 1。∎
- 数值核对：约 29 万个节点，违反 0 次（第 44 节）。

**推论 5**：每棵树由两部分组成：
- 一条**脊柱** (a₀, x₀) = (p, n)，规则为 a_{j+1} = v(a_j, x_j)，x_{j+1} = a_j x_j mod N；
- 脊柱的每个节点上挂一条 A 型链（"毛毛虫"）。由于渐近分母按 Fibonacci 速度增长，链长 ≤ log_φ p + 2。

因此**树的深度 ≤ 脊柱长度 + log_φ p + 3**。

## 3. 脊柱长度的尾部

**松弛路径**：从 (a₀, u₀) = (p, θ) 出发，每一步任取 b ∈ [2, a − 1] 使 ‖bu‖ < 1/a，然后 (a, u) ↦ (b, {au})。实际脊柱是其中一条松弛路径。

**引理 6（U′）**：若 u 的分布是若干完整 a 级区间 I_c = (c/a, (c+1)/a) 上均匀分布的混合，那么在条件 ‖bu‖ < 1/a（b < a）下，{au} 的分布是若干完整 b 级区间上均匀分布的混合。

证明：
- 满足条件的集合是半邻域 (k/b, k/b + 1/(ab)) 与 (k/b − 1/(ab), k/b) 之并。
- 若 k/b ≠ c/a，则 |k/b − c/a| = |kb′ …| ≥ 1/(ab)，所以每个半邻域整个落在某一个 I_c 内。
- 在半邻域 (k/b, k/b + 1/(ab)) 上，u ↦ {au} 是斜率为 a 的仿射映射，把它一一地映满 b 级区间 ((ak mod b)/b, (ak mod b + 1)/b)。另一半同理。∎
- 数值核对：按 θ 聚类的检验，深度 1–4 上均一致（第 47 节）。

**引理 7（V）**：u 在 I_c 上均匀时，P(‖bu‖ < 1/a) ≤ 2/b。

证明：I_c 的闭包长度为 1/a < 1/b，至多含一个点 k/b。由引理 6 的证明，只有这个点的半邻域能与 I_c 相交，贡献的测度 ≤ 2/(ab)。∎

**命题 8（P1″）**：
  μ{θ ∈ (1/p, 1) : 脊柱长度 ≥ ℓ} ≤ (p/2)⁴·2^{−ℓ}。

证明：令 Φ_ℓ = E_θ[Σ_{长度为 ℓ 的松弛路径} a_ℓ⁴]。根的分布 θ ~ U(1/p, 1) 是完整 p 级区间之并。由引理 6 对 ℓ 归纳，给定路径时 u_ℓ 的条件分布是完整区间上均匀分布的混合。再由引理 7，
  E[Σ_{b 合法} b⁴] ≤ Σ_{b<a} (2/b)·b⁴ ≤ a⁴/2，
所以 Φ_{ℓ+1} ≤ Φ_ℓ/2，Φ_ℓ ≤ p⁴·2^{−ℓ}。又因为 a_ℓ ≥ 2，长度为 ℓ 的路径数 ≤ Φ_ℓ/16。∎

**整数版本（推论 9）**：每条松弛路径的合法集合是 θ 的至多 ℓ·p^{ℓ+1} 个区间之并。第 i 个条件 ‖a_{i+1}{P_iθ}‖ < 1/a_i 本身是 P_i·a_{i+1} 个区间之并。所以
  #{n ∈ [1, N) : 脊柱长度 ≥ ℓ} ≤ N(p/2)⁴·2^{−ℓ} + ℓ·p^{2ℓ+1}。

## 4. 截断后的负载

**引理 10**：对任意行 ρ 和 k，
  #{n : 树深度 ≤ k，且 tree(n) 用到 ρ} ≤ 3p²(2p)^k。

证明：
- 用到 ρ 的实例 I(a′, x′) 都满足 ε = −1，且 ρ ∈ {pr(y), pr(a′y)}。给定 (a′, v) 和角色（y、a′y = ρ、a′y = N − ρ），x′ = −y·v⁻¹ 唯一确定。所以这样的实例至多 3·Σ_{a′≤p}(a′ − 1) ≤ 1.5p² 个。
- 实例 I 的"父节点"是满足 v(a, w) = b 且 I ∈ {I(b, w), I(b, aw mod N)} 的 I(a, w)。对每个 a ∈ (b, p]，父节点至多 2 个。所以从 I 回溯到根、长度 ≤ k 的路径至多 2(2p)^k 条。
- 每个满足条件的 n 对应其中一条路径，不同的 n 对应不同的路径。∎

## 5. GRH 的输入（Mangerel，arXiv:2412.17199）

- 引理 3.1：E_d(N) = {n < N : λ(dn)λ(dn mod N) = −1}，与 𝓔_d(λ) 完全相同，并且
  (1/N)·Σ_{a mod N} |S_λ(da/N) − λ(d)S_λ(a/N)|² = 4|E_d(N)|。这也可以直接由 Parseval 等式验证。
- 命题 2.2（GRH）：对 P ≥ (log N)²(log log N)^{2+ε}，存在素数 p ∈ (P, 2P]，使上面的均值 ≫ N。

由此 |𝓔_p(λ)| ≥ cN。

## 6. 证明的完成

1. 取 P = (log N)²(log log N)³，并取上面的 p。令 η 为 L_λ(N) 的符号，B 为 λ 的坏行数。由 Mangerel 的恒等式 N − 1 + ηL = 2#{n : λ(n)λ(N − n) = η}，有 |L_λ(N)| = N − 1 − 4B。
2. 取 ℓ₀ = ⌈4 log₂ p + log₂(16/c)⌉，k = ℓ₀ + ⌈log_φ p⌉ + 3。
3. 每个 n ∈ 𝓔_p 要么树深度 > k，要么由第 1 节，其树中含有坏行。所以
   cN ≤ |𝓔_p| ≤ #{n : 脊柱长度 > ℓ₀} + Σ_{坏行 ρ} 3p²(2p)^k ≤ cN/8 + ℓ₀p^{2ℓ₀+1} + 3p²(2p)^k·B。
4. 因为 k = O(log p)、log p ≍ log log N，所以 p^{O(k)} = exp(O((log log N)²)) = N^{o(1)}。由此 B ≥ N·exp(−O((log log N)²))。代入第 1 步即得定理 Q。∎
5. 推论 Q′：该计数 = (1/4)[(N − 1) + η₁Σλ(n) + η₂Σλ(N − n) + η₁η₂L]。由素数定理 Σ_{n<N} λ(n) = O(N e^{−c√log N})，再用定理 Q 即得。∎
