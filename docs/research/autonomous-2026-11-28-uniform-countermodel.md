# Uniform countermodel to binary positivity
2026-11-28. Read hub current_conclusions and previous local-marginal obstruction. Let W be fixed even, M=4KW, b(n)=1_{gcd(n,W)=1} on Z/M. Partition into 2K blocks of length 2W. Reflection T(n)=-n mod M pairs blocks j and 2K-1-j on supported points (block endpoints are unsupported). In each of the first K blocks independently for each unit residue r mod W choose one of the two positions r,r+W uniformly, assigning f=2 there and 0 at the other. In the reflected block set f(Tn)=2b(n)-f(n). Elsewhere f=0. Then every block has exact b mass in each residue mod W; every interval I and every class modulo d|W has discrepancy |sum_{I,n=r mod d}(f-b)|<=4W, since only two incomplete blocks contribute. Yet (f*f)(0)=0, whereas (b*b)(0)=M phi(W)/W. This holds also for ordinary sum M. For a=f-b, a(Tn)=-a(n), so (a*a)(0)=-sum a(n)^2=-M phi(W)/W; b*a(0)=0. Each unnormalized Fourier coefficient is a sum of K phi(W) independent Rademacher terms with complex coefficients of modulus <=4 (four positions per choice). Hoeffding on real and imaginary parts gives P(|hat a(k)|>=t)<=4 exp(-t^2/(64 K phi(W))). Union bound gives existence with max <=sqrt(64 K phi(W) log(8M)), hence O(sqrt(M log M)). Thus even exact local marginals, bounded interval discrepancy, and normalized Fourier sup tending to zero do not imply binary positivity. Fixed W or W growing sufficiently slowly; interval discrepancy bound is absolute O(W), not a claim about all prime-scale short intervals. Fourier bound is on residual, not on actual primes. This is a countermodel, not a Goldbach counterexample. No novelty claim. Reference checked: Green–Tao, Annals 171 (2010), abstract https://annals.math.princeton.edu/2010/171-3/p08 excludes binary cases.
