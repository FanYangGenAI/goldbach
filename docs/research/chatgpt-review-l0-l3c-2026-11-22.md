## 3. R1：L1 基线含有素数标签，且“未显著”不等于“无记忆”

证据：[E1.2 代码](https://github.com/FanYangGenAI/goldbach/blob/c06d8f8e701cf65810e37510db92d1e5cccf1525/research/L1_parity/e1_2_sieve_baseline.py#L97)，尤其第 110 行的 `if f == m`。这里 f=lpf[m]，该条件就是“m 是真素数”。

基线实际上为

\[
f_{\rm sieve}(N)=
\frac{\sum_{m\in A_N} w_N(m)\,1_{\mathbb P}(m)}
     {\sum_{m\in A_N} w_N(m)},\qquad
A_N=\{m:N/2\le m<N,\ m,N-m\text{ 均为 }z\text{-粗糙}\}.
\]

分母来自双侧筛条件，**分子额外使用了完整的素数判定**。它是“含真实素数标签的双侧粗糙集合条件基线”，不是只用 ≤z 整除信息得到的预测。这不会使描述性比较失效，但会改变它对奇偶性障碍的解释。

还有一个重要的统计原因：实际 f(N) 使用的样本与构造基线的总体重叠，二项独立抽样并非自然的零模型。最简单的等权、固定样本量零模型中，若从大小 M、带素数标签的总体中无放回抽取 r 个元素，则

\[
\operatorname{Var}(\widehat f)
=\frac{f_0(1-f_0)}r\frac{M-r}{M-1}.
\]

因此，除以二项标准差得到的 z 分数，其标准差本来就可以小于 1，无需引入额外“刚性”。独立小计算在 N=10⁶、z=100 时得到双侧粗糙总体 M=12837，其中 N−m 为素数的 r=8818；这个简化零模型的标准差修正因子约为 **0.560**。这不是对实际加权、非均匀抽样的完整预测，但足以说明 **0.65–0.76 不能直接解释为超出条件抽样效应的素数刚性**。

其他需要修正的表述：

- 随机样本的三个窗口均值相对偏差分别为 −2.2217×10⁻⁴、−4.8703×10⁻⁵、−3.3005×10⁻⁵。“全部预测到相对 5×10⁻⁵ 以内”不成立；这些还是窗口均值误差，不是逐 N 误差。
- 45 个类检验未超过阈值，只能说明在所选模数、规模和检验能力下未检出。不能推出没有算术依赖，更不能推出对每个 N 一致成立。
- 代码中的类统计量是“该类均值相对零”的标准化量，并非直接检验各类均值相等的联合检验；同时涉及重叠样本、异方差与多重比较。随机 Ns 还是有放回抽取，需考虑重复值。
- E1.1 与 E1.2 同时改变了基线、抽样方式和显著性阈值，不能据此断言旧失败“完全由单侧基线造成”。

**最小处理**：准确重命名基线；保留现有描述性结果；增加匹配权重与抽样比例的条件随机化或置换零模型，报告效应量和区间；若研究目标确实是“筛法之外的信息”，另设不使用目标素数标签的基线或明确写出所使用的额外算术输入。新窗口冻结规则后再检验。

## 4. R2：E3.2 的 2.62 可以复现，但需要更改窗口代表坐标

证据：[E3.2 预注册及结果](https://github.com/FanYangGenAI/goldbach/blob/4619d18cd3aeab7e711f85993e5a47eb851582a1/research/L3b_gpu/DESIGN.md)。预注册以窗口起点 x=2^j 为坐标，要求在 j=14…32 的合并数据上拟合

\[
\log\sigma^2=\log c+\log x+k\log\log x.
\]

代码保存窗口统计，却没有提交产生对数律结论的拟合脚本。本次对冻结 JSON 使用无权普通最小二乘，独立得到：

| 数据选择 | 代表坐标 | 拟合 k |
|---|---|---:|
| GPU j=23…32 | JSON 中的起点 x | 1.987034 |
| GPU j=23…32 | 中点 x+H/2 | **2.618617** |
| CPU j=14…25 + GPU j=22…32 | 各自起点 x | **2.020642** |
| 同一合并数据 | CPU 用 1.5x、GPU 用 x+H/2 | 2.824138 |

这说明报告中的 2.62 有一个自然、可复现的来源：使用 GPU 窗口中点。**中点是合理的分析坐标，但不是原文写明的预注册起点 x，也不是预注册规定的合并数据集。** 按字面约定、上述直接拟合，P1 的 k 不在 [2.5,3.2] 内；中点分析应列为方法修订后的结果。

这里固定 H=2²²，使 H/x 从 j=22 时的 1 降到 j=32 时的 1/1024。相当一部分“指数变化”可能是窗口几何与代表坐标变化，不能直接解释为渐近对数因子被识别。

还应区分：`0.13·x·log^{2.5}x` 是固定指数的有限区间近似；中点坐标下自由指数 2.6186 对应的拟合系数约为 0.0901。二者不是同一个拟合式。

**最小处理**：

1. 提交完整拟合脚本，明确坐标、纳入窗口、权重与损失函数。
2. 原预注册结果与中点修订分析并列报告，不再写“P1–P4 全部按原判据通过”。
3. 优先拟合窗口积分，如 \(\frac1H\int_x^{x+H}ct(\log t)^k\,dt\)，或固定 H/x，而不是混用不同宽度窗口的起点。
4. 在更多位置与相同窗口口径下做留出比较，再讨论 log²、log²·loglog、log³ 和带低阶修正模型。

目前可以保留“局部方差约为 N 乘缓慢变化的对数因子”；**不能宣布 log³ 渐近律已经被否定、log^{2.5±0.2} 已经确立**。±0.2 也不是当前材料中有方法支持的置信区间。

## 5. R3：GPU 窗口不是从小到大的连续覆盖，矩外推存在已知偏差

[E3.2 代码第 113 行](https://github.com/FanYangGenAI/goldbach/blob/4619d18cd3aeab7e711f85993e5a47eb851582a1/research/L3b_gpu/e3_2_gpu_windows.py#L113) 定义

\[
\widehat B_p([x,2x))=\frac{x}{H}B_p([x,x+H)).
\]

这是用左端局部窗口外推整段的估计，不是上界。两个大尺度采样窗口之间仍有很大的未计算区间。

利用已提交 CPU 完整二进窗口数据，可以直接评估同一外推的误差：

| j | GPU 外推 B₂ / CPU 完整 B₂ | GPU 外推 B₄ / CPU 完整 B₄ |
|---|---:|---:|
| 22 | 1.000 | 1.000 |
| 23 | 1.127 | 1.252 |
| 24 | 1.247 | 1.515 |
| 25 | **1.370** | **1.813** |

偏差有清晰来源：若局部 F 的典型大小约为 √N·polylog，归一化后的二阶和四阶矩密度分别大致含 1/N 和 1/N²，沿 [x,2x) 并不恒定。即使完全相信同一个高斯模型，左端密度乘区间长度也不等于区间积分。

因此，在 j=32：

- 直接测得的局部 B₄ 为 **1.22327×10⁻⁸**；
- 1.25263×10⁻⁵ 是乘 1024 后的外推；
- 直接测得的局部 B₂ 为 **0.0875125**；
- 89.6128 是相同方式的外推。

这些数值都可保留，但必须标清定义。局部 B₂ 已经小于 1，也说明“二阶矩到底能否排除例外”必须注明窗口长度；全二进窗口结论不能不加限定地推广到所有尺度。

“4300σ”同样应限定为：**按所测局部窗口经验标准差归一化后，R=0 阈值对应的尺度比**。它不是已验证到 4300σ 的高斯尾概率，更不是未采样 N 的统一界。代码使用中心化 Z 的方差，而 K 采用未扣均值的主项阈值；若要作严格的“距局部均值多少标准差”表述，还应纳入局部均值修正。

**最小处理**：保留 window 与 dyadic_est 两类字段；增加分层、多个位置的窗口和对已知完整区间的校准；没有覆盖或严格上界前，不把外推用于 B_p<1 的全窗口证书。

## 6. R4：L3c 有确定的遗漏项；“需要精细误差控制”成立，“因此必须 GUE”尚未成立

### 6.1 设计公式与实现不一致

设计写的是

\[
V_{\rm HL}(N)=D(N)-N\mathfrak S(N)^2+
\sum_{0<|h|<N}
\left(\mathfrak S_4(h,N)-\mathfrak S(N)^2\right)(N-|h|).
\]

但 [代码第 152 行](https://github.com/FanYangGenAI/goldbach/blob/b0e8c5603dea7c54d288a1b8c9022fb2225a9911/research/L3c_4tuples/e3_3_hl_variance.py#L152) 实际使用 `(d+o)/S`，漏掉了 `−N*S*S`，即除以 S 后漏减 N*S。

使用原 JSON 中同一批 48 个 N，无需重跑四元组求和即可修正：

| j | 原报告比值（约） | 补减 N𝔖² 后的比值 |
|---|---:|---:|
| 23 | 2.14 | 2.12250 |
| 24 | 2.07 | 2.05408 |
| 25 | 2.04 | 2.03375 |
| 26 | 2.02 | 2.00727 |

**这个 bug 不足以解释两倍偏差，P1 仍失败。** 但必须先修正文码一致性，才能讨论常数因子的意义。

### 6.2 还需统一“二阶展开”“均方误差”和“中心方差”

令 M(N)=N𝔖(N)、F=R−M，则严格有

\[
R^2-M^2=2MF+F^2,
\]

因此窗口上的目标为

\[
\operatorname{Var}\!\left(\frac F{\sqrt{\mathfrak S}}\right)
=
\left\langle\frac{R^2-M^2}{\mathfrak S}\right\rangle
-2\langle NF\rangle
-\left\langle\frac F{\sqrt{\mathfrak S}}\right\rangle^2.
\]

仅用 R² 的首项近似，不能自动得到已中心化的方差。低阶均值、θ/Λ 差异、非对角累计误差都要放进同一公式。固定参数的 k 元组主项，也不自动提供对随 N 变化的反射线性型族和所有 h 一致、且足以在相减后保留方差的误差控制。

对角两条线 a'=a、a'=N−a 在 a=a'=N/2 处重叠，精确恒等式还需减去 \((\theta(N/2)^2)^2\)。这通常很小，不能解释两倍误差，但独立的小 N 验证应包含它，避免把“约等于两倍”直接归因于有序/无序重复计数。

### 6.3 负结果能支持的理论判断

可以支持：

> 当前“HL 首项 + 所用奇异级数平均”的实现和启发式，尚不能定量重现所测中心方差；需要更强的均值、低阶项与累计误差分析。

不能直接支持：

> HL/k 元组路线在本问题上已经失效；方差只能由 ζ/L 零点的对关联解释；当前两倍偏差证明了长区间机制。

MS 的 H 是“素数计数区间长度”；本实验的 h=a'−a 是展开卷积二阶量时的位移。两者不是同一个变量，不能只因 h 可达 N 就直接套用 MS 的长区间分类。HL 和零点统计也不是互斥理论框架。

Gallagher 型首项平均通过到 10⁻⁵，不代表决定方差的加权次项也准确到所需精度。下一步从显式公式探索是合理的，但应写成**候选解释**，在明确统计量、平滑核、截断与所需零点相关假设后再检验。不要预先指定必须得到 2.5 这个尚未确立的指数。

## 7. R5：贪心失败不能排除其他同余覆盖

证据：[L0 greedy_cover](https://github.com/FanYangGenAI/goldbach/blob/86c00f23db6d719b2f7d3bcb996843e33f0a61cc/research/goldbach_explore/exp3_covering.py) 每步选择当前覆盖最多的剩余类，输出某一个具体覆盖的完成模数 L_greedy。

若 L_min 为所有合法类选择下的最小完成模数，只能推出

\[
L_{\min}\le L_{\rm greedy}.
\]

观测到 \(L_{\rm greedy}\gg\sqrt{2Y}\)，**不能推出** \(L_{\min}>\sqrt{2Y}\)。原笔记虽承认贪心给出上界，随后“最小值可能略小、幂律缺口不太可能消失”的判断没有下界证据。hub 台账把它进一步写成否定或排除，属于推理方向错误。

**最小处理**：改为“所测试贪心策略未在 √(2Y) 的模数预算内完成覆盖”。若要否定所有自由选类覆盖，必须提供覆盖整数规划的不可行证书、严格组合下界或可核验的松弛下界；一次贪心失败不能替代。即便自由选类覆盖成功，CRT 给出的 N 大小还需另行满足 N≈2Y 的自洽约束。

## 8. R6：矩阶梯的严格部分正确，但不是完整证明路线的新发现

定义偶数窗口 W_x=[x,2x)∩2ℕ，a_N=|F(N)/(N𝔖(N))|。若存在 R(N)=0，则对应 a_N=1，因此

\[
\#\{N\in W_x:R(N)=0\}\le \sum_{N\in W_x}a_N^p=B_p(x).
\]

所以 B_p<1 确实排除该窗口的反例；这不要求独立性或高斯性，是标准的矩/Markov 充分条件。

严谨的条件性目标可以写成：对某个**固定** p>2，若

\[
\sum_{N\in W_x}|F(N)|^p\ll x^{1+p/2+o(1)},
\]

利用偶数 N 上 𝔖(N)≥2C₂>0，可得

\[
B_p(x)\ll x^{1-p/2+o(1)}\to0.
\]

这是一个充分条件，不是必要条件，也不能因为低阶经验矩看似高斯，就声称这种统一上界已经获得支持到任意固定 p。还可以容许一定固定幂次损失：若额外损失为 x^δ，只要 δ<p/2−1，仍能收敛；“必须不超过 x^{o(1)}”是方便而偏强的目标。

“真实 B₂ 随对数增长”的数据说明：**在完整二进窗口上，只知道一个 B₂ 总量上界再直接套 Markov，不足以推出例外数为零。** 它不证明所有利用二阶信息的方法都存在普遍不可突破的天花板。加局部化、单侧结构或其他信息的二阶方法并未被排除。R3 中局部 B₂<1 已是窗口口径重要性的直接例子。

同样需要区分：

- 定义 F=R−N𝔖 后，R=N𝔖+F 本身是恒等式，不是统计模型的验证。
- 四阶、六阶矩和所见极值接近高斯，是有限样本形状证据；它们不能认证高斯尾部直到反例阈值，也不能排除未观测的大偏差。
- 相邻 N 共用素数，有显著相关。√(2log n) 可作启发式参照，但不是独立样本极值检验的有效性证明。
- 有限范围数据不能单独确定渐近标度或任意大 x 的一致性。

## 9. R7：L2 提供了有价值的数值解释，但现有措辞超出了检验对象

E2.3 冻结 JSON 在 X=2²⁴ 给出 a=0.9997635、R²=0.7367358；扣除拟合尾项后的超额峰度约 **0.53403**，极值比约 **1.78755**，`P2=false`。这点在分支设计中如实记录，值得保留。

之后利用同一批数据拟合 γ，再用 𝔖^{γ/2} 标准化，是**探索性诊断**，不能把原预注册 P2 改判为通过。回归斜率近 1 表明尾项幅度吻合；R²≈0.74 表明解释了约 74% 的次弧方差，不是“全部结构都已吸收”的证明。

还应分清不同残差。令 T_N=N(𝔖−𝔖_Q)，代码分析的是

\[
e_N=R_{\min}(N)-aT_N-b.
\]

它与全误差 F 的关系为

\[
e_N=F(N)+\bigl(N\mathfrak S_Q(N)-R_{\rm maj}(N)\bigr)
 +(1-a)T_N-b.
\]

所以，e_N 近高斯不能不经主弧误差检查就转述为 F(N) 的同一分布定律。L3 对 F 的直接分析是额外证据，但也不能把各自的方差常数与拟合指数混为同一对象。

另有两项数值口径：

1. FFT 掩膜分解在固定离散网格上是代数恒等式；浮点 FFT 仍有舍入误差，连续主/次弧积分不因此成为精确计算。
2. `major_mask` 用 floor(左端)、ceil(右端) 后填满整数索引，会把理想不等式之外的边缘格点纳入。它是略扩张的网格掩膜，须写明；如果要对应原连续弧定义，应检查格点不等式，并做 L/X、端点取整方式与 Q 的敏感性分析。

此外，T/mean(R_maj)≈5.9 是平均主项口径；逐 N 的足够相消需要 R_maj(N)>0 及相应的逐点比值。尾项负向最多 −2% 也只对已计算的范围和 Q 成立，不能推广为统一界。

**最小处理**：保留“尾项解释主要次弧波动”；冻结 a=1 与 γ 的新检验规则，在独立窗口检查；分别报告 F、主弧误差、拟合残差；避免使用“真随机”“没有新结构”等不可由当前检验推出的词。

### 11.1 无需重跑大实验即可复现关键再分析

以下脚本在仓库根目录执行；读取固定提交，避免分支切换影响。需要 Python 和 NumPy。

~~~python
import json
import subprocess
import numpy as np

def load(ref, path):
    raw = subprocess.check_output(["git", "show", f"{ref}:{path}"])
    return json.loads(raw.decode("utf-8"))

cpu = load("4b47b17", "research/L3_moments/out/e3_1_summary.json")["rows"]
gpu = load("4619d18", "research/L3b_gpu/out/e3_2_rows_22_32.json")

def fit(rows, midpoint=False):
    x = np.array([
        r["x"] + (r.get("H", r["x"]) / 2 if midpoint else 0)
        for r in rows
    ])
    v = np.array([r["sigma2"] for r in rows])
    k, logc = np.polyfit(np.log(np.log(x)), np.log(v / x), 1)
    return float(k), float(np.exp(logc))

combined = [r for r in cpu if r["j"] >= 14] + gpu
print("GPU start:", fit(gpu[1:]))
print("GPU midpoint:", fit(gpu[1:], True))
print("Combined start:", fit(combined))
print("Combined midpoint:", fit(combined, True))

for j in (22, 23, 24, 25):
    a = next(r for r in cpu if r["j"] == j)
    b = next(r for r in gpu if r["j"] == j)
    print(j, {
        k: b[k + "_dyadic_est"] / a[k]
        for k in ("B2", "B4")
    })

hl = load("b0e8c56", "research/L3c_4tuples/out/e3_3_rows.json")
for r in hl["rows"]:
    missing = np.mean([N * S for N, S, *_ in r["samples"]])
    corrected = (r["sigma2_HL"] - missing) / r["sigma2_obs"]
    print("Corrected HL ratio:", r["j"], corrected)
~~~

## 12. 与文献的关系：能援引什么，尚不能声称什么

这是一轮针对论证边界的文献核查，不是证明不存在先行工作的穷尽性检索。

1. **Bhowmik–Halupczok, Asymptotics of Goldbach representations**，[arXiv:1809.06920](https://arxiv.org/pdf/1809.06920)，§2.1–2.2。明确使用含素数幂的 Λ 卷积，综述 Hardy–Littlewood 在 GRH 下的二阶误差界。仓库引用的 x^{5/2+ε} 有依据；但应注明权重差异，并单独说明 θ 版本的转换，不要把综述量直接标成自身统计量的新定理。

2. **Montgomery–Soundararajan, Primes in short intervals**，[arXiv:math/0409258](https://arxiv.org/pdf/math/0409258)，Theorem 3、Corollary 1 与 Conjectures 1–2。论文明确区分带统一误差的 k 元组假设、可证明的矩范围、较长区间的猜测，以及 H≈N 时不能直接保留同一高斯结论。因此不能把“HL 首项足够”和“Goldbach 的 h 就是 MS 的 H”当成现成定理。

3. **Goldston–Suriajaya, On an Average Goldbach Representation Formula of Fujii**，[arXiv:2110.14250v2](https://arxiv.org/html/2110.14250v2)，§1，定义 (1)、公式 (2)、(5) 与 Theorem 1。它研究 Λ 加权 Goldbach 表示数的**累加平均**及零点项，并将其误差与素数短区间方差联系。它没有直接给出本项目局部 Var((Rθ−N𝔖)/√𝔖)≈cNlog^{2.5}N 的结论。不能未经新的误差分析就对累加显式公式作形式差分，得到单点随机模型。

4. **Goldston–Suriajaya, On a smoothed average of the number of Goldbach representations**，[arXiv:2306.04807](https://arxiv.org/abs/2306.04807)。研究 GRH 下 q 的倍数上的平滑平均；适合后续研究对接，但不能替代本实验的局部方差推导。

矩充分条件和奇异级数主项属于标准理论框架。项目可能贡献的是**定义明确、控制误差、能够复现的数值诊断与候选模型比较**。当前证据还不足以确认“发现了新的渐近方差律”或“首次定位了猜想证明唯一缺失的信息”。
