# 定理 Q（GRH）：对素数 N，|L_λ(N)| ≤ N − N·exp(−C(log log N)²)

状态：本会话给出的证明，**待独立复核**。数值核对与推导细节见分支 gb/M1-liouville-ladder 上 `research/M3_z2_rung/RESULTS.md` 第 21、32、43–47 节。

## 记号

- N 是大素数。g: ℕ → {±1} 是完全积性函数，η ∈ {±1}。
- "行" x ∈ [1, (N−1)/2] 指配对 {x, N − x}。若 g(x)g(N − x) ≠ η，称这一行为坏行。B 为坏行数。
- 𝓔_p = {n ∈ [1, N−1] : g(pn) ≠ g(pn mod N)}。
- 实例 I(a, x) 表示断言 g(ax) = g(ax mod N)。当 ax < N 或 a = 1 时它是平凡的。

## 1. Thue 树证书

设 ax ≥ N。取最小的 v ∈ [1, a−1]，使 xv ≡ εy (mod N)，其中 ε = ±1，1 ≤ y < N/a。由 Thue 引理（鸽笼原理），这样的 v 存在。令 r = ax mod N，则
  I(a, x) ⇐ I(v, x) ∧ I(v, r) ∧ [当 ε = −1 时，行 y 与行 ay 都是好行]。

推导：
- vr ≡ εay (mod N)，且 ay < N；
- g(v)g(ax) = g(a)·g(vx mod N)，g(v)g(r) = g(vr mod N)；
- 分 ε = ±1 两种情况，用两行的刚性即得 g(ax) = g(r)。

乘数严格下降，所以递归终止。若树中所有行都是好行，则 n ∉ 𝓔_p。

## 2. 结构（引理 SC）

由 Lagrange 定理，v = v(a, u)（u = x/N）是 u 的某个连分数渐近分母 q_k。由此：
- A 型子节点 (q_k, u) 的 Thue 选择为 q_{k−1}；
- A 型链上每个节点 (q_i, u) 的 B 型子节点 (q_{i−1}, {q_i u}) 要么平凡，要么 Thue 选择为 1。证明的关键是 ‖q_i u‖ < 1/q_{i+1}。

所以树由两部分组成：一条脊柱 (a, u) ↦ (v(a, u), {au})，以及每个脊柱节点上一条长度 ≤ log_φ a + 2 的"毛毛虫"。由此，深度 ≤ 脊柱长度 + log_φ p + 3。

## 3. 脊柱尾部（命题 P1″）

**松弛路径**：每一步取任意满足 ‖bu‖ < 1/a 的 b ∈ [2, a−1]，然后 (a, u) ↦ (b, {au})。实际脊柱是其中一条。

- **引理 U′**：若 u 的分布是若干完整 a 级区间 (c/a, (c+1)/a) 上均匀分布的混合，那么在条件 ‖bu‖ < 1/a 下，{au} 的分布是若干完整 b 级区间上均匀分布的混合。理由：若 k/b ≠ c/a，则 |k/b − c/a| ≥ 1/(ab)，所以每个半邻域都完整地落在某个 a 级区间里，并被 u ↦ {au} 仿射地映满一个 b 级区间。
- **引理 V**：在一个完整的 a 级区间上，P(‖bu‖ < 1/a) ≤ 2/b，所以 E[Σ_b 1(合法)·b⁴] ≤ 2Σ_{b<a} b³ ≤ a⁴/2。
- 根 θ 在 (1/p, 1) 上均匀。令 Φ_ℓ = E[Σ_{长度为 ℓ 的路径} a_ℓ⁴]，则 Φ_ℓ ≤ p⁴·2^{−ℓ}。所以
  **μ(脊柱长度 ≥ ℓ) ≤ (p/2)⁴·2^{−ℓ}**。
- 整数版本：每条路径的合法集合至多是 ℓ·p^{ℓ+1} 个区间之并，所以
  #{n : 脊柱长度 ≥ ℓ} ≤ N(p/2)⁴·2^{−ℓ} + ℓ·p^{2ℓ+1}。

## 4. 截断后的负载

使用某一给定行的实例至多 1.5p² 个：按 (a′, v, 角色) 分类，x′ 由行唯一确定。每个实例回溯到根、长度 ≤ k 的路径至多 2(2p)^k 条：每一步父节点的乘数至多 p 种，类型 A/B 两种，父节点的点随之确定。所以对深度 ≤ k 的 n，每一行的负载 ≤ 3p²(2p)^k。

## 5. 结论

**GRH 的输入**：Mangerel，arXiv:2412.17199，命题 2.2 与引理 3.1。对 P = (log N)²(log log N)³，存在素数 p ∈ (P, 2P]，使
  (1/N)·Σ_a |S_λ(pa/N) − λ(p)S_λ(a/N)|² ≫ N。
由 Parseval 等式，左边恰为 4·#{n : λ(pn) ≠ λ(pn mod N)}，所以 |𝓔_p(λ)| ≥ cN。

**证明**：取 ℓ₀ = ⌈4 log₂ p + log₂(16/c)⌉，k = ℓ₀ + log_φ p + 3。则
  cN ≤ |𝓔_p| ≤ #{n : 深度 > k} + 3p²(2p)^k·B ≤ cN/8 + exp(O(log² p)) + exp(O(log² p))·B，
所以 B ≥ N·exp(−O((log log N)²))。再由 Mangerel 的恒等式 N − 1 + ηL = 2#{n : λ(n)λ(N − n) = η}，取 η 为 L 的符号，得 |L_λ(N)| = N − 1 − 4B。∎

## 定位

- 这把 Mangerel 命题 1.4（GRH，对素数 N）中的 e^{−C(log log N)⁶} 改进为 e^{−C(log log N)²}。
- 它不是哥德巴赫猜想，也不是通往哥德巴赫的关键步骤。
- 下一步的方向：用二阶矩证明（P2），进一步得到 N − cN/(log N)^A。
