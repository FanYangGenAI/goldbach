## A. 截断与负载

**引理 L（对数预算，第 57 节）**：给每个非源脊柱节点 σ 一个入度上界 indeg(σ)。若源 n 满足 len(n) ≤ k 且 Σ_t log(1 + indeg(σ_t(n))) ≤ T，称它已覆盖。则任一节点上已覆盖的祖先数 ≤ e^T，负载 ≤ 1.5p²(p² + p + 1)·e^T。
- 证明：对 f(τ, Y) 作预算归纳。

**引理 L*（Kraft 型预算，第 58 节）**：只要求对每个非源节点满足 Σ_{π ∈ par*(σ)} e^{−c(σ,π)} ≤ 1，其中 par*(σ) 只含本身在某条脊柱上的父节点。同样的结论成立。
- 两个特例：c = log indeg*，得到对数负担 Λ*；熵代价，截断变成"终点祖先数 ≤ e^T"，即二阶矩路线。

**一处更正（第 57 节）**：截断与期望必须取在实际脊柱上。松弛过程的总质量约为 p 倍（启发式估计）。

## C. 关于 Thue 条件与数字自动机的严格引理

- **引理 I（第 62 节）**：b < a < p、p 为素数时，μ{‖aθ‖ < 1/p, ‖bpθ‖ < 1/a} = 4/(pa) 精确成立。400 组有理数精确核对，0 次失败。
- **引理 I*（第 64 节）**：相邻乘数互素时，任意深度的 Bohr 条件交集测度恰为 Π_{i<t}(2/a_i)。有组合与 Fourier 消元两种证明；精确核对为计数 400/400、深度 4 区间计算 82/82。
- **引理 B（第 64 节）**：相邻互素时，数字自动机向后确定；合法串 ↔ (ε 串, 末位)，松弛″下每个 ε 串至多排除 2t 个末位。
- **引理 S（第 62 节）**：深度 1、2 的节点满足 E[log indeg*(σ_t)] ≤ log(6 + 4 ln p) + log 2·E[Ω(a₁) + Ω(a₂)] = O(log log p)。证明用到引理 I、剩余类公式与 Jensen 不等式。
- **剩余类公式与 Gronwall 界（第 60 节，严格的部分）**：E[Σ_{a′ | w^±} 1/a′ | 历史] ≤ ζ(2)·(σ(g)/g + σ(g′)/g′) = O(log log p)，对一切 M 一致成立。
- **引理 T（第 64 节）**：相邻互素、q | a_j、gcd(q, a_{j+1}⋯a_t) = 1。尾数长度 ℓ = t − j − 2 ∈ {0, 1} 时，P(q | M(M+1)) ≤ 2((a_t + 1)/q + 1)/(a_t − 2 − 2t)。
- **引理 T″₂（第 64.5 节）**：对斜率 A 在 Z_m 上平均，纤维 ≤ X/q + τ(m) + σ(m)/m。证明对任意单射 y 与任意加项 F 成立。182 组精确核对。
- **反例族（第 64.3 节）**：ℓ = 2 且 a_t·a_{t−2} ≡ 1 (mod a_{t−1})、q | a_ta_{t−2} − 1 时，M mod q 每个 ε 串只取两个值。实例 [397, 394, 393, 199, 100, 99] 中 P(197 | M(M+1)) = 0.5，而一致界为 0.061。所以 ℓ ≥ 2 时只可能有平均意义的界。

- **引理 F（第 66 节）**：相邻互素、q | a_j 时，P(q | M(M+1)) = 2/q + 一个 (ℓ+1) 维格上的 sinc 乘积和（精确公式）。ℓ = 0 的 289 个、ℓ = 1 的 25 个情形与精确枚举吻合，ℓ = 2 做了粗核对（8 个，差 ≤ 0.0053）。消元推导严格，级数交换的收敛性待补写。乘法巧合对应这个格的短向量。

## D. 定理 Q⁺ 的剩余缺口（第 64.4–64.5 节）

1. 对大素数 q 的尾数等分布：只对一个乘数平均不够，问题化为 Kloosterman 型的不完全和。
2. 相邻不互素的修正：实际脊柱上约 16–19% 的步不互素，每步 E[log gcd] ≈ 0.25。
3. 从松弛测度转到实际测度：约化条件化为逐层的互素条件，慢下降步另有极小性排除。

## E. 定位

以上全部是 Corrádi–Kátai / Shusterman 问题（哥德巴赫在 Liouville 函数上的类比）的有条件定量结果，**不是哥德巴赫猜想本身**。有条件的部分在条件被证明之前不构成定理。
