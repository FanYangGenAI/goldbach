# O12（通宵，探索性）函数域哥德巴赫噪声的 Fourier 分层谱

> 分支 `gb/O12-ff-spectrum`（从 `gb/O10-ff-largeq` 分出）。**探索性，没有事前判据。** 冒烟结果在下文披露。

## 动机
O8、O10 给出函数域中 HL 残差的方差常数 c²。按 Parseval，Var(r) = q^{−2n}Σ_{ψ≠1}|L̂(ψ)|²|P̂(ψ)|²，其中 L 是低次（< n）“常数×首一不可约”的集合，P 是 n 次首一不可约的集合，ψ 跑遍低 n 个系数构成的加法群的特征。按 Keating–Rudnick（KR）的短区间分层，把特征按层级 h(k) = min{i : k_i ≠ 0} − 1 分组（h = −1, …, n−2）。层级 h 的特征对次数 ≤ h 的多项式是平凡的。KR 的方差定理给出启发式：在层级 h 上，|P̂|² 的平均值 ≈ π_n·(n−h−2)/n。

## 输出（每个 (q, n)）
- 每个层级 h：|P̂|²/π_n 的平均值与 KR 值 (n−h−2)/n 的比较；|L̂|² 在该层级上的权重（占 Parseval 总量的比例）；HL 残差 e = r − r_pred 的能量在该层级上的份额。
- c²_hl、c²_raw = Var(r)/E r，以及“独立”启发式 c²_indep = (1 − α)·Σ_h f(h)·w_L(h)（α = |L|/qⁿ，f 取 KR 值或实测值）。这个启发式假设在每个层级内 |P̂|² 与 |L̂|² 不相关。

## 计划
q=3，n=6…15；q=5，n=4…9；q=7，n=4…7；q=13、23、31，n=4、5；q=43，n=4。

## 冒烟（已运行）
q=5、n=4 与 q=3、n=8：每层 |P̂|²/π_n 与 KR 值大致相符（例如 0.85 对 0.75，0.47 对 0.50，0.79 对 0.75，0.62 对 0.625）。层级 n−2 上 |P̂|² 恰为 0：平移 t → t + c 保持不可约性，并且是 a_{n−1} 的双射。HL 残差能量的 66%–73% 在层级 −1（涉及常数项系数的特征）。独立启发式给出 c² ≈ 0.45 / 0.70，而实测 c²_hl 为 0.14 / 0.21，c²_raw 为 3.6 / 54。这说明“层内不相关”的假设不成立，或者需要先扣除 𝔖 的部分。

**观察（探索性）**：
1. **KR 的分层方差公式在每一层都成立**：大 q 时实测 |P̂|²/π_n 与 (n−h−2)/n 相差约 1%（q=43、n=4：0.756 对 0.750，0.494 对 0.500）。小 q 时偏高几个百分点。层级 n−2 上 |P̂|² 恰为 0。
2. **噪声几乎全部在最低层级 h = −1**（涉及常数项系数的特征）：q=31 时为 96%，q=43 时为 98%。
3. **“层内独立”的启发式高估 c² 4–6 倍**：大 q 时为 0.59 对 0.14、0.49 对 0.08。所以在同一个特征 ψ 上，|L̂(ψ)|² 与 |P̂(ψ)|² 必须强烈地反相关；或者说，HL 预测扣掉的 𝔖 部分恰好吃掉了大部分。一个自然的解释是：在函数域中，L̂(ψ) 与 P̂(ψ) 由 **同一个** L 函数 L(u, ψ) 的零点（同一个 Frobenius 共轭类）决定，所以并不独立。我们没有做这个计算。这正是第 6 节问题 (a) 的具体形式：c_∞(n) 应当等于某个关于 tr U^d 的随机矩阵积分。
