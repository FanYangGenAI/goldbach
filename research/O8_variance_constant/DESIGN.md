# O8（通宵，探索性）哥德巴赫的“方差常数”：整数与函数域对照

> 分支 `gb/O8-variance-constant`。**探索性，没有事前判据。** 冒烟结果已在下文披露。

## 动机
O3 发现，函数域中 sd(r/r_pred)·√r 在每个 q 上大致恒定，并且小于 1，即涨落是亚泊松的。O2 中的整数窗口也显示出相似的量级。O6、O7 显示，χ 扣除局部部分后剩下的大约是随机标签尺度的噪声。这里直接测量两种情形下的方差常数
c² = Var[(r − r_pred)/√r_pred]，
看它如何依赖于 q、n（函数域）和 N（整数）。目标是为一个理论公式（Montgomery–Soundararajan 或 Keating–Rudnick 型的亚泊松修正）提供数据。

## 对象
- **函数域**（`o8_ff.py`）：r_pred 同 O3。对每个 (q, n) 穷举全部 F，并按 F 是否不可约分组报告。计划：q=3，n=5…16；q=5，n=4…10；q=7，n=3…8；q=11、13，n=3…6；q=17、19、23、29、31，n=3…5。
- **整数**（`o8_int.py`，RTX 4090）：对 j = 16…33，每个 j 取一个窗口，起点 2^j + 2^{j−3}，宽 H = 2^{min(22, j−4)}，窗口内全部偶数都计入。r_pred = b₂（同 O2），并按 N mod 3 分组报告。

## 冒烟（已运行）
- 函数域：q=3，n=5…7 时 c² = 0.28、0.26、0.18；q=5，n=4、5 时为 0.14、0.14。不可约 F 与可约 F 的 c² 相差很大（q=3、n=5 时为 0.59 对 0.19）。
- 整数：j=16、18、20 时 c² = 0.47、0.48、0.50（mod 3 分组为 0.39–0.46 对 0.50–0.52）。注意，c² 中包含窗口内均值偏差（mean_z ≈ −0.2…−0.4）。下面的 c² 都是去均值的方差，所以均值偏差不进入 c²。

**观察（探索性）**：
1. **两种情形都是亚泊松的**：c² < 1。整数中 c² 从 0.47（x ≈ 7×10⁴）缓慢上升到 0.68（x ≈ 10¹⁰），(1 − c²)·log x 在 j ≥ 18 时大约稳定在 6.6–7.5。也就是说，经验上 c² ≈ 1 − 7/log x，这与 Montgomery–Soundararajan 对短区间素数个数的“1 − log h/log x”形状相似。这只是一个经验拟合，没有理论推导。3 ∣ N 的 c² 系统性地更小（0.64 对 0.70，j = 33）。
2. **函数域的大 q 极限非常干净**：固定 n，q → ∞ 时 c² 趋于一个只依赖 n 的极限。n = 3 时 c² ≈ 1/q（q = 11…31 时 q·c² = 1.00 ± 0.01），所以极限是 0。n = 4 时极限约为 0.080（q ≥ 17），n = 5 时约为 0.14，n = 6 时约为 0.175。这正是 Katz 型等分布（Galois 群为 S_n 的大 q 极限）能够精确计算的情形。
3. 在固定 n 下，不同 q 的 c² 很接近（例如 n = 10 时 q = 3 为 0.24，q = 5 为 0.25）。这提示 c² 主要依赖于次数 n，而在整数中对应于 log x。但整数的 c² 在 log x ≈ 11 时已经是 0.47，比函数域任何测到的值都大，所以“n ↔ log x”的简单对应不成立。
4. **待理论回答**：(a) 大 q 极限下 c²(n) 的精确值（0、0.080、0.14、0.175，…）能否由置换群 S_n 上的计算给出？(b) 整数中 c² ≈ 1 − C/log x 的常数 C ≈ 7 是否有理论来源？

**补充（探索性，夜间后段）**：`python o8_int.py --smallj`（`.venv`）补算了 j = 10…15（窗口宽 2^{j−2}），结果在 `out/o8_int_smallj.json`。对 j = 10…33 的全部 c² 拟合五种函数形式，见 `out/o8_fits.json`。标准误取 1.5·√(2/n)·c²，以粗略考虑窗口内的相关。
- 所有形式的 χ² 都远大于自由度（377–1309，自由度 22）。窗口间的散布远大于名义抽样误差，所以没有一种形式在统计上“通过”。
- 按 AIC 由好到差：a·(log x)^b（a = 0.135，b = 0.51）、A(1 − C/√log x)、A − C/log x（A = 0.93，C = 5.8）、1 − C/log x（C = 7.26）、A − C/log² x。
- 这些形式在 3.4×10¹⁰ 上都给出 0.68–0.70，与 O9 的实测 0.692–0.700 相符。但外推到 10²⁰ 时差别很大（0.74–0.97）。
- 结论：在 10³–10¹⁰ 范围内，c² 的函数形式无法确定。O9 预注册所用的“1 − 7.2/log x”只是在小外推范围内成立的经验式。值得注意的是，最优的 c² ∝ (log x)^{0.51}，相当于 Λ 加权方差 ∝ x·log^{2.5}x，与 L3/V3 中有效对数指数约 2.5 的结果一致。不过 L3/V3 已经说明，那个指数本身也依赖窗口口径。
