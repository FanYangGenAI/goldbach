# O11（通宵，GPU）O6 的精细局部模型推到 N ≈ 10¹⁰ — 预注册

> 分支 `gb/O11-chi-gpu-1e10`（从 `gb/O6-chi-refined` 分出）。设计与运行器 `o11_chi_gpu.py` 在全量运行前一同提交。

## 方法
- 当 N < z³（z = ⌊N^{1/3}⌋）时，(z, N−z) 中的 z-粗糙数最多有两个素因子，所以 S = 粗糙数 − 素数。
- 在 RTX 4090 上用只筛奇数的数组表示素数和 z-粗糙数，用分块 FFT 对窗口内 **每个** 偶数 N 精确计算 PP、PS、SP、SS。
- 每个窗口只用一个 z：窗口选在 z 不变的区间里，窗口宽 H = 2²¹。
- 规模：X = 10⁹、3×10⁹、10¹⁰，每个规模一个窗口，从 X 起（若跨越立方数则后移 H）。
- 每个窗口中随机抽 300 个 N（种子 2026112414），计算 O6 的精细预测；预测函数逐字复制自 O6。另外在整个窗口（约 10⁶ 个 N）上计算 χ 的随机标签离散度 D。

## 预注册判据（与 O1、O6 相同，取 10¹⁰，按 mod 3 组内中心化）
- 支持：相关 > 0.5、标准差比 ∈ [0.5, 2]、R²_pred > 0.25。
- 否定：相关 < 0.2 或标准差比 < 0.1。
- 其余为“部分”。
- 另报告：扣除精细预测前后的 D（样本内），以及整个窗口的 D。

## 运行前已知的信息（如实披露）
- 冒烟（X = 10⁶、10⁷，H = 2^14，每个 40 个 N）：每个窗口随机抽 3 个 N，四类计数与 CPU 暴力计数一致。冒烟中修正了两个错误：粗糙数表的下界差一，以及 P 类没有排除 ≤ z 的素数（暴力核对发现的）。修正后，相关 0.63 / 0.66，标准差比 0.72 / 0.52，R² 0.39 / 0.41（“支持”）；扣除精细预测后 D 从 1.40 降到 1.05–1.07。
- O6（10⁸、10⁹）的结果已知：10⁹ 上相关 0.78、R² 0.60。

**预注册判定（10¹⁰）：支持。**

**解读**：
- O6 的精细局部模型在 10¹⁰ 上继续成立，而且略有改善（R² 为 0.60 → 0.54 → 0.69，有样本噪声）。10⁹ 的结果与 O6 的独立样本（ρ = 0.778，R² = 0.599）几乎相同。注意：两者的抽样区间不同，O11 用的是窗口 [10⁹, 10⁹+2²¹)。
- 整个窗口上，扣除前的 D 随 N 增大（1.92 → 2.17），因为局部部分的方差在增大。扣除精细预测后，样本内的 D 稳定在 1.16–1.26，即剩余部分比随机标签噪声大约 15%–25%。
