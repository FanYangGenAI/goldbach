# L3b 方差律的 GPU 扩展 — 实验 E3.2 预注册

> 分支 `gb/L3b-variance-law-gpu`（从 L3 切出）。运行前提交。

## 目的

E3.1（x ≤ 3.4×10⁷）得到 σ² = Var(F/√𝔖) ≈ 0.05·x·log³x，但对数范围太短，分不清 log²、log²·loglog 与 log³。本实验用 RTX 4090 把 x 推到 2³² ≈ 4.3×10⁹，并检验矩阶梯在更大规模是否保持。

## 方法

- GPU 上整体筛出 [0, 2³² + 2²²] 的素数（uint8，约 4.3 GB 显存）。
- 窗口 N ∈ [x, x+H)，H = 2²²（2²¹ 个偶数），x = 2^j，j = 22…32。
- R(N) 用分块卷积精确计算：把 p 分成长度 H 的块，每块与对应的长度 2H 的段做 float64 FFT 卷积，在窗口上累加。代价约为 (x/H) 次长度 2²⁴ 的 FFT。
- 𝔖(N) 在 CPU 上用分段因子筛精确计算。
- 校验：j = 22–25 的窗口结果与 E3.1 的 CPU 结果（同一 x 附近）相对差 < 1%。

## 预测

- **P1（对数律）**：在 j = 14…32 的合并数据上（E3.1 的二进窗口 + 本实验窗口，分别标注），自由拟合 log σ² = log c + log x + k·log log x，得到 k ∈ [2.5, 3.2]。
- **P2（高斯性）**：所有 GPU 窗口 m₄/m₂² ∈ [2.9, 3.3]，max|z|/√(2 ln n) ∈ [0.8, 1.25]。
- **P3（离反例的距离）**：K = min_N N𝔖(N)/(σ√𝔖(N)) 单调上升，K(2³²) ≥ 2500。
- **P4（矩阶梯）**：外推到整个二进窗口的 B₄ ≈ (x/H)·Σ_窗口 (F/N𝔖)⁴ 在 j=32 时 < 2×10⁻⁵；外推的 B₂ 继续上升。

## 判据

P1 判定对数律；P2–P4 检验 E3.1 的结论能否外推两个数量级。任何一条失败都要诊断并记入台账。
