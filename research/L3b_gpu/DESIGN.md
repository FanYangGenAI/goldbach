# L3b 方差律的 GPU 扩展 — 实验 E3.2 预注册

> 分支 `gb/L3b-variance-law-gpu`（从 L3 切出）。运行前提交。

## 目的

E3.1（x ≤ 3.4×10⁷）得到 σ² = Var(F/√𝔖) ≈ 0.05·x·log³x，但对数范围太短，分不清 log²、log²·loglog 与 log³。本实验用 RTX 4090 把 x 推到 2³² ≈ 4.3×10⁹，并检验矩阶梯在更大规模是否保持。

## 方法

- GPU 上整体筛出 [0, 2³² + 2²²] 的素数（uint8，约 4.3 GB 显存）。
- 窗口 N ∈ [x, x+H)，H = 2²²（2²¹ 个偶数），x = 2^j，j = 22…32。
- R(N) 用分块卷积精确计算：把 p 分成长度 H 的块，每块与对应的长度 2H 的段做 float64 FFT 卷积，在窗口上累加。代价约为 (x/H) 次长度 2²⁴ 的 FFT。
- 𝔖(N) 在 CPU 上用分段因子筛精确计算。
- 校验：j = 22–25 的窗口结果与 E3.1 的 CPU 结果（同一 x 附近）相对差 < 1%。

## 预测

- **P1（对数律）**：在 j = 14…32 的合并数据上（E3.1 的二进窗口 + 本实验窗口，分别标注），自由拟合 log σ² = log c + log x + k·log log x，得到 k ∈ [2.5, 3.2]。
- **P2（高斯性）**：所有 GPU 窗口 m₄/m₂² ∈ [2.9, 3.3]，max|z|/√(2 ln n) ∈ [0.8, 1.25]。
- **P3（离反例的距离）**：K = min_N N𝔖(N)/(σ√𝔖(N)) 单调上升，K(2³²) ≥ 2500。
- **P4（矩阶梯）**：外推到整个二进窗口的 B₄ ≈ (x/H)·Σ_窗口 (F/N𝔖)⁴ 在 j=32 时 < 2×10⁻⁵；外推的 B₂ 继续上升。

## 判据

P1 判定对数律；P2–P4 检验 E3.1 的结论能否外推两个数量级。任何一条失败都要诊断并记入台账。

---

## E3.2 结果（RTX 4090，总耗时 94 秒）

校验：j = 22 窗口恰好等于 E3.1 的二进窗口，σ² 完全一致（755982832.17）；随机抽查的 R(N) 与 CPU 暴力求和一致到 10⁻⁹。

| x | K（σ 数） | m₄/m₂² | m₆/m₂³ | max\|z\|/√(2ln n) | σ²/(x·log^{2.5}x) | B₂（二进外推） | B₄（二进外推） |
|---|---|---|---|---|---|---|---|
| 8.4×10⁶ | 262 | 3.07 | 16.1 | 0.99 | 0.123 | 32 | 8.2×10⁻⁴ |
| 6.7×10⁷ | 694 | 3.01 | 15.08 | 0.96 | 0.129 | 52 | 2.7×10⁻⁴ |
| 5.4×10⁸ | 1737 | 3.01 | 15.16 | 0.97 | 0.125 | 70 | 6.1×10⁻⁵ |
| 4.3×10⁹ | **4331** | 3.01 | 15.14 | 1.12 | 0.130 | 90 | **1.3×10⁻⁵** |

- **P1 ✓**：自由拟合 k = 2.62（j = 23…32；前后半段分别为 2.73、2.76）。σ²/(x·log^{2.5}x) 在 0.123–0.130 之间几乎不变；σ²/(x·log²x) = a + b·log x（a = 0.21，b = 0.018）也同样贴合，两者在这个范围内无法区分。**E3.1 的“log³”被否定，修正为 log^{2.5±0.2}**。
- **P2 ✓**：窄窗口下 m₄/m₂² = 3.00–3.07，m₆/m₂³ = 15.1–16.1，极值 0.90–1.12。**几乎完美的高斯。** 这同时诊断了 E3.1 的 P2 失败：二进窗口 [x, 2x] 内方差随 N 变化，把不同方差的高斯混在一起，抬高了高阶矩比。窄窗口里这种效应消失。
- **P3 ✓**：K 单调上升到 4331（x = 4.3×10⁹）。
- **P4 ✓**：B₄（外推）= 1.3×10⁻⁵ < 2×10⁻⁵，继续下降；B₂ 从 32 升到 90，继续上升。

**结论**：在 x 达 4.3×10⁹ 的范围内，F(N)/√𝔖(N) 在局部窗口内是方差约 0.13·x·log^{2.5}x 的高斯变量（与 Cramér 对角项 2x·log²x 相比只占约 25–31%，且比例随 x 缓慢上升）。矩阶梯的两条结论（B₂ 上升、B₄ 下降）在多两个数量级的范围内保持。

**方法论收获**：高阶矩比必须在窄窗口里测；宽窗口会把方差的缓慢变化误读成重尾。
