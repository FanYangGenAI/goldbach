# O1（通宵，CPU）带符号奇偶性二点量 χ 的局部模型预测 — 预注册

> 分支 `gb/O1-chi-local`。设计与运行器 `o1_chi_local.py` 在运行前一同提交。

## 对象（第十二轮审阅式 (3)–(5)）
z = ⌊N^{1/3}⌋。在“两侧都 z-粗糙、和为 N”的有序配对中，按两侧素因子个数分为四类：PP、PS、SP、SS（P 为素数，S 为两个大于 z 的素数之积，含平方）。令 A = PP+PS+SP+SS，B = −PP+SS+(PS−SP)，C = PP−PS−SP+SS，μ = B/A，χ = C/A − μ²。

## 局部（HL 型）预测，无拟合参数
- PP_pred = 𝔖(N)∫ρ₁(t)ρ₁(N−t)dt，PS_pred = SP_pred = 𝔖(N)∫ρ₁(t)ρ₂(N−t)dt，SS_pred = 𝔖(N)∫ρ₂ρ₂，积分区间为 [z+1, N−z−1]。
- ρ₁(t) = 1/log t；ρ₂(t) = log((log t − log z)/log z)/log t（t > z² 时；否则为 0），即两个素因子都大于 z 的半素数的密度。
- 对三类配对都用同一个 𝔖(N)（理由：素数和这类半素数模 p ≤ z 时都是单位）。这是一个近似：对 p > z 的局部因子，素数与半素数的行为不同，此处未建模。

## 样本
N ≈ 10⁶、10⁷、10⁸、10⁹，每个规模在 [X, 1.1X) 中取 3∣N 与 3∤N 各 20 个（种子 2026112411）。

## 判据（10⁹，按 mod 3 组内中心化）
支持：相关 > 0.5、标准差比 ∈ [0.5, 2]、R²_pred > 0.25；否定：相关 < 0.2 或标准差比 < 0.1；其余为“部分”。另报告 χ、μ 的均值，以及 PP、A 的观测/预测比。

## 运行前已知的信息（如实披露）
小规模冒烟测试（10⁵、10⁶ 各 20 个 N）已经显示：预测的 χ 几乎不随 N 变化（标准差比约 0.007）。原因是在这个模型里 𝔖(N) 在 C/A 和 B/A 中被约掉了，χ_pred 只通过 z 平滑地依赖于 N。因此本检验在“波动”判据上 **预计会被否定**。我们保留这个判据，因为它回答一个有意义的问题：χ 的跨 N 波动是否超出了局部结构？这与 Q8 中 m=3 扇区的波动由局部项主导形成对照。均值层面的比较另行报告。

**预注册判定：否定**（与运行前披露的预期一致）。

**解读**：
- **均值层面，局部（HL 型）模型很好**：χ 的均值在 10⁸、10⁹ 上相差不到 7%；素数+素数配对数（PP）的观测/预测比为 0.9998–0.99985，即 HL 公式本身极准。
- **波动层面，局部模型完全无能为力**：χ 的跨 N 波动，模型只给出约 1%–2% 的幅度，相关接近 0。原因是在这个模型里 𝔖(N) 在 χ 中被约掉了。
- **与 Q8 形成对照**：Q8 中 m=3 扇区系数的跨 N 波动，约 91% 可由局部（Mellin 二阶）项预测；而这里带 Liouville 符号的二点量 χ 的跨 N 波动，几乎完全不是局部结构造成的。也就是说，**奇偶性方向上的 N 依赖，恰恰是局部模型看不见的部分**。这与奇偶性障碍的直觉一致，但不是它的证明。
