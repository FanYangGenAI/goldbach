# E1 固定和约束下的“纠缠”：二分态的纠缠熵与互信息 — 预注册

> 分支 `gb/E1-entanglement`（从 gb/hub 切出）。回应 Fan 的直觉：“若 N = p + q，两个素数是基于 N 的纠缠态”。运行器 `e1_entanglement.py` 与本文件 **同时** 在运行前提交（第十一轮审阅的冻结要求）；模型代码固定到提交 32f5fc0。**这是相关性度量，不是物理主张。**

## 1. 对象

对偶数 N，扇区表 T_jk(N) = #{2 ≤ n ≤ N−2 : Ω(n) = j, Ω(N−n) = k}，j, k ≤ 20。

- **二分态（振幅编码）**：|Φ_N⟩ = Σ_{j,k} √(T_jk/(N−3)) |j⟩_A|k⟩_B。它是乘积态（无纠缠）⇔ 振幅矩阵秩为 1 ⇔ T_jk ∝ 行边际 × 列边际（两侧独立）。纠缠熵 S_N = −Σ σ_i² log σ_i²，σ_i 为振幅矩阵 √(T/(N−3)) 的奇异值。
- **经典互信息**：I_N = H(J) + H(K) − H(J,K)，按联合分布 T/(N−3) 计算。
- 背景事实：解除固定和约束后，配分函数精确分解为两个单系统的乘积（第七轮审阅的生成函数恒等式），对应“乘积态”。所以 S_N、I_N 度量的正是 **固定和约束带来的关联**。
- 振幅编码是一种选择；纠缠熵在两侧各自重新标记扇区（局部幺正）下不变，所以单纯交换“素数/半素数”的标签不会改变它。

## 2. 三个参照
1. **局部模型**：Q1b 的零参数欧拉乘积模型给出 T^model_jk（提交 32f5fc0，j, k ≤ 20，负值截为 0），只包含每个素数 p 的局部（p 进）关联。
2. **局部保持打乱（替身）**：把 Ω(n) 在“同一剩余类 n mod 210、同一长度 2¹⁶ 的区块”内随机打乱（种子 20261124），保持小模数结构与大小趋势，破坏更细的算术配对。
3. **(1,1) 格的贡献**：ΔS_11 = S(T) − S(T′)，其中 T′ 只把 T_11 替换为独立值（行边际 × 列边际 / 总数），其余不变。

## 3. 样本
N ≈ 10⁶、10⁷、10⁸，每个规模 30 个随机偶数，N ∈ [X, 1.1X)，种子 20261125。保存每个 N 的完整 T_jk。

## 4. 预测与判据
- **H_local（纠缠完全由局部结构决定）**：在 10⁸ 上，|S_real − S_model|/S_real 的中位数 < 5%，且 S_null/S_real 的中位数 > 0.8。
  - 若成立：固定和“纠缠”在这一粗粒化层面由局部（p 进）结构决定，没有额外的非局部纠缠。
  - 若不成立：存在局部模型与替身都不能解释的纠缠，记录其大小和随 N 的变化。
- **描述性输出（不设判据）**：S_N、I_N 随 N 的变化；ΔS_11 及其占 S_N 的比例；S 对 j, k 截断（12 与 20）的敏感度。

> 实现修正（运行前，尚未得到任何结果）：运行器对冻结模型代码做字符串替换时，把模型代码内部的 `src.replace("cache=True", "cache=False")` 也替换成了无效操作，导致 numba 缓存报错，程序没有跑起来。现改为只替换装饰器中的 `cache=True)`。分析方法、样本与判据均未改变。

## 结果（运行 167 秒，每个规模 30 个 N）

| 规模 | 纠缠熵 S（中位数） | 互信息 I | 局部模型 S_model | 替身 S_null | \|S−S_model\|/S | S_null/S | (1,1) 格贡献 ΔS₁₁/S |
|---|---|---|---|---|---|---|---|
| 10⁶ | 0.197 | 0.075 | 0.222 | 0.106 | 21.6% | 0.91 | 2.0% |
| 10⁷ | 0.105 | 0.034 | 0.125 | 0.116 | 18.3% | 0.98 | 1.8% |
| 10⁸ | 0.150 | 0.056 | 0.166 | 0.109 | 15.6% | 0.81 | 1.0% |

截断敏感度（j, k ≤ 12 对比 ≤ 20）约 1%。

**预注册判定：H_local 不成立**（10⁸ 上模型相对误差 15.6% > 5%）。

### 进一步描述（探索性）
- **随 N 的变化完全被局部模型跟踪**：每个规模内，跨 N 的 S_real 与 S_model 的相关为 0.989、0.998、0.996；与替身的相关只有 0.75–0.79。
- **差别只在整体水平**：模型系统性高估，模型/实测比为 1.29 → 1.19 → 1.17（3∣N）、1.21 → 1.18 → 1.14（3∤N），并随 N 缓慢减小。这与 Q1b 模型缺少的次级局部项（Q5c 的尺度平移等）的方向和大小一致，但本实验没有检验这一点。
- **纠缠主要来自共享的小素数整除性**：3∣N 时 S 约为 0.25–0.28，3∤N 时约为 0.11–0.14。
- **哥德巴赫格 (1,1) 的贡献很小，并且在缩小**：ΔS₁₁ 占纠缠熵的 2.0% → 1.8% → 1.0%（最大值 0.014 → 0.008 → 0.005）。

### 解读（限定）
固定和约束确实把两侧“纠缠”在一起（乘积态的 S 为 0，这里 S > 0）。但在“Ω 扇区”这个粗粒化层面，这种纠缠的 N 依赖几乎完全由局部（p 进）结构决定：n 与 N−n 同时被同一个小素数整除。素数+素数那一格只占纠缠的 1%–2%，而且随 N 下降。没有看到一个“两个素数因 N 而相互依存”的、独立于局部结构的全局纠缠信号。这是相关性度量，不是物理结论；振幅编码和粗粒化方式都是选择，换一种编码可能得到不同的数值。
