## 1. M3-E1 预注册（19:08）

对 N = 2^k 的奇数子纤维刚性（变量为 g(p)，p 为 < N 的奇素数，以及 η），T(t)：g(t mod N) = g(t)。对奇素数 q 与奇数 n < N，若 qn 与 qn mod N 的素因子都 < N，问 T(qn) 是否属于刚性方程组的 GF(2) 行空间（"GF(2) 覆盖"）。对照：只用奇数乘数（d ≤ 6q 或 d = q·a，a ≤ 6q）的反射路径覆盖（M2 的层级图，"反射覆盖"）。
- **H1**：对每个 q ∈ {3, 5, 7, 11, 13}，GF(2) 覆盖率随 k（10 → 13）上升。
- **H2**：k = 13 时，所有 q ≤ 13 的 GF(2) 覆盖率 ≥ 95%（在素因子 < N 的 n 中）。
- **H3**：反射覆盖率比 GF(2) 覆盖率至少低 20 个百分点（说明 z = 2 台阶上反射机制远不够，需要完整闭包）。
- 用意：若 GF(2) 覆盖率 → 1，z = 2 台阶的 M2 式推导链只差"多重度"的控制；若不 → 1，障碍是定性的。

## 2. M3-E1 结果（见 RESULTS.md 第 1 节）与 M3-E2 预注册（19:10）

M2 式推导链需要：若刚性只在少数配对上失败（坏配对集合 B），则只有少数 n 失去 T(qn)。用"删去 B 中的行之后 T(qn) 是否仍在行空间中"来度量：killed(B) = 删前可推出、删后不可推出的 n 的个数，比值 killed(B)/|B| 就是多重度的 GF(2) 类比。
- 随机删除：k ∈ {10, 11, 12}，q = 3，|B| = r ∈ {1, 4, 16, 64}，每种 10 次。
- 结构化删除：删去所有含某个素数 p 的行（p 取 N^{1/2} 附近的 3 个素数）。
- **H1**：k = 12 时随机删除的 killed/r ≤ 10（r ≤ 16）。
- **H2**：随机删除的 killed/r 从 k = 10 到 12 增长不超过 2 倍。
- **H3**：结构化删除时 killed/|B| ≤ 10。

## 3. M3-E2 结果（见 RESULTS.md 第 2 节）与 M3-E3 预注册（19:10）

E2 只测了随机与"含某素数"两种删除。推导链需要的是对**任意**坏集合的稳健性，所以先看最坏的单行删除。
- **M3-E3**：k ∈ {10, 11, 12}，q = 3，对每一行 b 计算 killed({b})。
- **H1**：k = 12 时 max_b killed({b}) ≤ 20。
- **H2**：max_b killed({b}) 从 k = 10 到 12 的增长不超过 log N 的增长比例（12/10）的 2 倍。
- 同时报告 killed({b}) 的分布（0 的比例、均值），以及被删后杀死最多 n 的那一行的结构（n、N − n 的分解）。
