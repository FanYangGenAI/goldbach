## 1. M3-E1 预注册（19:08）

对 N = 2^k 的奇数子纤维刚性（变量为 g(p)，p 为 < N 的奇素数，以及 η），T(t)：g(t mod N) = g(t)。对奇素数 q 与奇数 n < N，若 qn 与 qn mod N 的素因子都 < N，问 T(qn) 是否属于刚性方程组的 GF(2) 行空间（"GF(2) 覆盖"）。对照：只用奇数乘数（d ≤ 6q 或 d = q·a，a ≤ 6q）的反射路径覆盖（M2 的层级图，"反射覆盖"）。
- **H1**：对每个 q ∈ {3, 5, 7, 11, 13}，GF(2) 覆盖率随 k（10 → 13）上升。
- **H2**：k = 13 时，所有 q ≤ 13 的 GF(2) 覆盖率 ≥ 95%（在素因子 < N 的 n 中）。
- **H3**：反射覆盖率比 GF(2) 覆盖率至少低 20 个百分点（说明 z = 2 台阶上反射机制远不够，需要完整闭包）。
- 用意：若 GF(2) 覆盖率 → 1，z = 2 台阶的 M2 式推导链只差"多重度"的控制；若不 → 1，障碍是定性的。

## 12. M3-E14：线性规划界的有理数复核，以及用平方类做独立的证书检验（2026-11-27 20:20 预注册）

**严格的重新表述（引理 Q，已证）**：令 V = ℚ_{>0}^× / (ℚ_{>0}^×)²，它是以素数为基的 𝔽₂ 向量空间。行 x 对应 v_x = [x(N − x)]，目标 n 对应 w_n = [qn · r]，其中 r = qn mod N。若行集合 S 满足 (a) |S| 为偶数，并且 (b) qn·r·∏_{x∈S} x(N − x) 是完全平方数，那么对任何完全积性 g: ℕ → {±1} 和任何 η ∈ {±1}：只要 S 中各行都满足 g(x)g(N − x) = η，就有 g(qn) = g(r)，即 n ∉ 𝓔_q(g)。
证明：由 (b)，g(qn)g(r)∏_{x∈S} g(x)g(N − x) = 1；再由 (a)，g(qn)g(r) = η^{|S|} = 1。∎
反射路径是它的特例。两步时的显式形式（**引理 R2**）：设 qn = jN + r。若存在 e ≥ 1 使 e | r 且 (j + e) | qn，记 x = qn/(j + e)、y = r/e，则 (j + e)(N − x) = e(N − y)。于是行集合 {x, y} 是一张证书，因为 qn·r·x(N − x)·y(N − y) = [(j + e)·e·x·(N − y)]² 是平方数。e = 1 时就是"免费"的一步。

**检验内容**：用 E12 的方法（K = 4，每个 n 至多 200 张证书）生成证书和线性规划解。
- 先用引理 Q 的平方检验独立验证每一张证书。
- 再把权重化为有理数：截成分母 10⁶ 的分数，去掉负值，每个 n 内归一化到恰好为 1。
- 用 Fraction 精确计算每行负载的最大值 t_exact。

**假设**：
- **H1**：在 (211, {3, 7, 13}) 和 (401, {3, 7}) 上，平方检验的失败数为 0。注意：E12 代码在 pr(t/d) = pr(t) 时用集合字面量做对称差，可能出错，本检验正好能查出这种情况。
- **H2**：t_exact ≤ t*_float + 0.05。

**产出**：对每个完全覆盖的 (N, q)，得到一条计算机严格验证的定理：对一切完全积性 g 和任一 η，|𝓔_q(g)| ≤ t_exact·#(坏行)。
