## 12. M3-E14：线性规划界的有理数复核，以及用平方类做独立的证书检验（2026-11-27 20:20 预注册）

**严格的重新表述（引理 Q，已证）**：令 V = ℚ_{>0}^× / (ℚ_{>0}^×)²，它是以素数为基的 𝔽₂ 向量空间。行 x 对应 v_x = [x(N − x)]，目标 n 对应 w_n = [qn · r]，其中 r = qn mod N。若行集合 S 满足 (a) |S| 为偶数，并且 (b) qn·r·∏_{x∈S} x(N − x) 是完全平方数，那么对任何完全积性 g: ℕ → {±1} 和任何 η ∈ {±1}：只要 S 中各行都满足 g(x)g(N − x) = η，就有 g(qn) = g(r)，即 n ∉ 𝓔_q(g)。
证明：由 (b)，g(qn)g(r)∏_{x∈S} g(x)g(N − x) = 1；再由 (a)，g(qn)g(r) = η^{|S|} = 1。∎
反射路径是它的特例。两步时的显式形式（**引理 R2**）：设 qn = jN + r。若存在 e ≥ 1 使 e | r 且 (j + e) | qn，记 x = qn/(j + e)、y = r/e，则 (j + e)(N − x) = e(N − y)。于是行集合 {x, y} 是一张证书，因为 qn·r·x(N − x)·y(N − y) = [e·x·y·(N − y)]² 是平方数（提交后更正：原写成 [(j + e)·e·x·(N − y)]²，是笔误；推导：(j + e)·e·(N − x)(N − y) = e²(N − y)²）。e = 1 时就是"免费"的一步。

## 15. 定理 W（对一切素数 N 成立的弱形式引理 L_q）及其数值核对（2026-11-27 21:12 预注册）

**记号**：N 为奇素数，G 是完全可加函数 ℕ → 𝔽₂（即 g = (−1)^G），f = G|_{[1,N−1]}，看作 (ℤ/N)^× 上的函数。
- 对 𝔽₂ 中的"字" s（由 −1、素数 ℓ < N 及它们的逆组成），定义 κ(s)：κ(−1) = η′，κ(ℓ) = G(ℓ)，并且可加、κ(s⁻¹) = κ(s)。这里 η′ 对应 η，即 η = (−1)^{η′}。
- 定义 E_s = {z ∈ (ℤ/N)^× : f(sz) ≠ f(z) + κ(s)}。

**事实**：
- (a) E_ℓ = 𝓔_ℓ，E_{−1} = 𝓔（按 n 计，大小为 2B）。
- (b) E_{ab} ⊆ E_b ∪ b⁻¹E_a。
- (c) |E_{s⁻¹}| = |E_s|。

**定理 W**：对素数 p < N，|𝓔_p| ≤ 4(p − 1)B + 4·Σ_{v=2}^{p−1} |E_v|，其中 |E_v| ≤ Σ_{ℓ^a ∥ v} a·|𝓔_ℓ|。由此递推得到 |𝓔_q| ≤ C_q·B，C_q = exp(O(q/log q))，**对一切素数 N > q 一致成立**。

**证明**：
1. 由 Thue 引理（鸽笼原理，A = ⌊N/p⌋ + 1，B = p，AB > N），每个 x ∈ (ℤ/N)^× 都可写成 x ≡ ε·y·v⁻¹，其中 ε = ±1，1 ≤ v ≤ p − 1，1 ≤ y < N/p。
2. 取 s = εv⁻¹。因为 py < N，f(py) = G(p) + f(y) 精确成立。
3. 若 y ∉ E_s 且 py ∉ E_s，则 f(px) = f(s·py) = f(py) + κ(s) = f(y) + κ(s) + G(p) = f(x) + G(p)，即 x ∉ 𝓔_p。
4. 对固定的 s，映射 x ↦ y 是单射。所以 |𝓔_p| ≤ Σ_s 2|E_s| ≤ 2Σ_ε Σ_v ([ε = −1]·2B + |E_v|)。∎

**推论（B = 0 时的刚性，严格）**：若对一切 1 ≤ n ≤ N − 1 都有 g(n)g(N − n) = η，则 g 在 [1, N − 1] 上等于平凡特征或 Legendre 符号 χ_N。证明：对素数 p 归纳，由定理 W 得一切 𝓔_p = ∅，于是 f(px) = f(x) + G(p)，故 f 是同态。

**数值核对（检验证明，不是证据）**：
- 在 N ∈ {1009, 4093} 上取三类 g：随机 g、χ_N 翻转 1/3/10 个素数、χ_N 只翻转 q。
- 对素数 p ≤ 31 检验三件事：(i) Thue 表示对一切 x 存在；(ii) 证明第 4 步的不等式 |𝓔_p| ≤ Σ_s 2|E_s|（用实际计算的 E_s）；(iii) 定理 W 的递推不等式。
- **H**：违反次数为 0。任何违反都说明证明有错。

## 16. M3-E19："Thue 树"证书，一个对一切 N 明确定义的纯行证书族（2026-11-27 21:17 预注册）

**构造（严格，已证）**：实例 I(a, x) 表示断言 g(ax) = g(ax mod N)。
- 若 ax < N，则 I(a, x) 平凡成立。
- 否则取最小的 v ∈ [1, a − 1]，使 u = xv mod N 满足 u < N/a（令 ε = +1，y = u）或 N − u < N/a（令 ε = −1，y = N − u）。Thue 引理保证这样的 v 存在。
- 令 r = ax mod N。则 I(a, x) ⇐ I(v, x) ∧ I(v, r) ∧ [ε = −1 时，行 y 和行 ay 都是好行]。

推导：
- I(v, x) 给出 g(vx) = g(εy mod N)；
- I(v, r) 给出 g(vr) = g(εay mod N)，因为 vr ≡ εay (mod N)，且 ay < N；
- 再用两行的刚性即得 g(ax) = g(r)。

乘数严格下降，所以递归必然终止。证书取树中各行（按重数）的对称差，它满足引理 Q。
- 特点：**完全不用模 N 乘以 v⁻¹，也不付出 𝓔_ℓ 的代价**，只用到行。
- 若最大行负载 ≤ poly(q) 且与 N 无关，就能把定理 W 的指数常数改进为多项式常数。

**实验**：q ∈ {3, 5, 7, 13, 31}，N ∈ {1009, 4093, 16381}（都是素数）。对每个 n ∈ [N/q, N) 构造证书，然后：
- 用引理 Q 的平方检验验证证书；
- 记录证书大小（平均与最大）、最大行负载、平均行负载。

**假设**：
- **H1**：平方检验失败数为 0（这是对构造的核对）。
- **H2**：最大行负载 ≤ 3q。
- **H3**：从 N = 1009 到 16381，最大行负载的增长不超过 20%。
