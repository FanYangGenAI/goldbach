**解读与严格的一点**：
- **（严格）** 若 T(qn) 的向量落在"不在 𝓔 中的那些行"张成的空间里，那么对任何在这些行上刚性的 g，T(qn) 都成立：行的组合给出 Π g(n_i)g(N − n_i) = η^{|S|}，而 η 分量为 0 推出 |S| 为偶数。所以 |𝓔_q| ≤ #{n：T(qn) 不在 span(行 ∉ 𝓔) 中}，这是 M2 引理 R₀ 在 z = 2 台阶上的精确 GF(2) 版本。
- 数值上，随机或"含某素数"的坏行集合每删一行只杀死约 1 个 n，比值不随 N 增长。这正是 M2 推导链需要的"多重度 O(1)"。
- 机制推测：大于 N/3 的素数 p 只出现在一行里，这一行"钉住"g(p)；删去它只放开 g(p)，只影响 n = p。
- 但这只是随机或结构化删除，**不是任意集合**。最坏情形见 M3-E3。

**一个等价的重述（严格）**：删去行集 B 后失去的目标，恰是某个"在 B 之外处处刚性"的完全积性 g 使 T(qn) 失败的那些 n（失去的方向对应商空间上的线性泛函）。所以"对一切 B，killed(B) ≤ C|B| + uN"**等价于** M1 第 5 节的目标引理 L 的 GF(2) 版：对一切完全积性 g，|𝓔_q(g)| ≤ C·|𝓔(g)| + u·N。这是一个**确定性的线性代数命题**（不涉及概率），数据目前支持 C ≈ 4 量级（单行最坏为 8，而每个坏配对对应两行中的一行）。

所以在能由 GF(2) 推出、但反射推不出的 n 中，除了每个 k 约 1 个之外，都有**至多 6 行**的证书，典型为 4 行。

> 对一切完全积性 g：|𝓔_q(g)| ≤ C·|𝓔(g)| + u_q(N)·N，C 为绝对常数，u_q(N) = 推不出的 n 的比例（→ 0？）。

|---|---|---|---|---|---|
| 4096 | 31 | 奇数 | 96.97% | 0.756 | 18 |
| 4096 | 67 | 奇数 | 96.88% | 0.994 | 16 |
| 4093（素数） | 3 | 完整 | **100%** | 0.300 | **2** |
| 4093 | 31 | 完整 | **100%** | 0.225 | **2** |
| 4093 | 67 | 完整 | **100%** | 0.312 | **2** |

判定：H1（大 q 的奇数纤维覆盖率与 q = 3 时相差 ≤ 2 个百分点）**支持**；H2（最坏单行 ≤ 20、随机 ≤ 10）**支持**；H3（完整纤维覆盖率 ≥ 99%）**支持**，实际为 100%。

**解读**：
- 完整纤维上 100% 覆盖是必然的：解空间只有 {1, χ_N}，而 χ_N 对乘以 q 等变。
- 新的事实是：删去任何一行至多让 **2** 个 n 失去推导，并且这一点**与 q 无关**（q = 3、31、67）。若推广为对一切坏行集合成立的线性界，即

> **引理 L（完整纤维、GF(2)，猜想）**：存在绝对常数 C，使对一切素数 N、一切 q ≤ (log N)^3、一切完全积性 g: ℕ → {±1}，|𝓔_q(g)| ≤ C·|𝓔(g)|，

  那么配合 Mangerel 的 Prop. 2.2（GRH：存在 q ∈ (P, 2P] 使 |𝓔_q(λ)| ≫ N），立即得到 |𝓔(λ)| ≫ N/C，即

  **GRH ⟹ |Σ_{n<N} λ(n)λ(N − n)| ≤ (1 − c)·N**（N 为大素数）。

- 这远强于 Mangerel 的 N − N·e^{−C(log log N)^6}，也强于 M2 的目标 N − N/(log N)^{2+ε}；但仍不是 Corrádi–Kátai 猜想要求的 o(N)。它也比 M2 简单得多：引理 L 是一个**确定性的线性代数命题**，不涉及任何随机模型或覆盖率。
- M2 的反射证书给出的多重度是 2|D| + 2，随 q 增长；完整 GF(2) 闭包显然有好得多的证书。
- **这只是数值线索，不是证明**；"单行删除 ≤ 2"也不推出"一切集合"的线性界。下一步（M3-E8）直接对大量 g（随机、接近特征、局部搜索构造的最坏情形，以及 λ 本身）计算比值 |𝓔_q(g)|/|𝓔(g)|。

## 8. M3-E8：引理 L 的常数必须随 q 增长；正确的形式是 |𝓔_q| ≲ q·|𝓔|（2026-11-27 19:20）

设计：DESIGN.md 第 7 节（提交 d115704）。数据：`m3_e8_out.txt`。ρ(g) = |𝓔_q(g)|/|𝓔(g)|（完整纤维，素数 N）。

| N | q | λ：ρ（|𝓔|, |𝓔_q|） | 随机 g 最大 | 接近特征（翻转 k = 1 / 3 / 10 / 30 个素数）最大 | 局部搜索最大 |
|---|---|---|---|---|---|
| 1009 | 3 | 1.40（242, 338） | 1.56 | 2.0 / 2.0 / 1.88 / 1.79 | 2.31 |
| 1009 | 31 | 1.92（242, 464） | 2.31 | 2.0 / 2.56 / 18.9 / 5.95 | 24.2 |
| 1009 | 67 | 2.02（242, 488） | 2.41 | 2.0 / 2.5 / 27.6 / 5.94 | 57.3 |
| 4093 | 3 | 1.37（995, 1358） | 1.44 | 2.0 / 2.0 / 1.77 / 1.81 | 2.20 |
| 4093 | 31 | 2.02（995, 2006） | 2.13 | 2.0 / 25.6 / 2.05 / 3.58 | 21.8 |
| 4093 | 67 | 1.92（995, 1908） | 2.21 | 2.0 / 2.0 / 2.59 / 17.9 | 38.8 |

判定：H1（(i)–(iii) 中 ρ ≤ 10）**否定**：接近特征的 g 在 q = 31、67 时达到 17.9–27.6；H2（局部搜索最大 ≤ 20）**否定**：达到 21.8–57.3。但从 N = 1009 到 4093 并不增长（24.2 → 21.8，57.3 → 38.8）。

**原因（严格的例子）**：取 g = χ_N，只翻转 g(q)。被影响的行是 n(N − n) 中 q 出现奇数次的那些，约占 2/q，所以 |𝓔| ≈ N/q；而 T(qn) 中 g(qn) = g(q)g(n) 对**几乎所有** n 都改变了符号，所以 |𝓔_q| ≈ N。于是 ρ ≈ q − 2。**引理 L 不可能有绝对常数**，最好也只能是 C·q。局部搜索找到的最大值 0.58q–0.86q 都在 q 以内。

**修正后的猜想（确定性）**：

> **引理 L_q**：存在绝对常数 C，使对一切素数 N、一切素数 q ≤ (log N)^3、一切完全积性 g: ℕ → {±1}，|𝓔_q(g)| ≤ C·q·|𝓔(g)|。

**它的意义**：
- 配合 Mangerel 的 Prop. 2.2（GRH）与 Lemma 3.1，引理 L_q 给出 |𝓔(λ)| ≫ N/q，即 GRH ⟹ |Σ_{n<N} λ(n)λ(N − n)| ≤ N − cN/((log N)²(log log N)^{2+ε})。这与 M2 的目标同阶，而且推导更短：**不需要任何覆盖率、随机模型或转移**。原因是在素数 N 的完整纤维上，解空间只有 {1, χ_N}，GF(2) 闭包对 T(qn) 的覆盖率恒为 100%（第 7 节）。
- 引理 L_q 正是"把 Mangerel 的无条件递推 |𝓔_q| ≤ 2^{(1+o(1))q²}|𝓔|（他的 Prop. 2.1 一类）改进到多项式"这件事的 GF(2) 表述。M2 的反射路径给出多重度 2|D| + 2，但需要覆盖；GF(2) 闭包自动覆盖，剩下的只是**证书的负载**能否压到 O(q)。
- 不能得到 (1 − c)N 的原因是"翻转 q 本身"这个例子，与 M2-E1 中测到的 M_q ≈ 3.5q 一致。

**小结（第 7–9 节）**：在素数 N 的完整纤维上，数值支持

> **引理 L_q（猜想，确定性）**：|𝓔_q(g)| ≤ (q + C)·|𝓔(g)|，对一切完全积性 g: ℕ → {±1}、一切素数 q ≤ (log N)^3 成立，C 为绝对常数。

"翻转 q"的例子说明系数 q 不能再改小。

**负载的下界（严格的观察）**：设 g = χ_N·[翻转 q]。对几乎所有 n，T(qn) 的向量在坐标 e_q 上为 1，所以任何证书都必须含奇数条"q 出现奇数次"的行。这样的行只有约 N/q 条，而 n 有 N 个，所以任何证书系统中这些行的平均负载 ≥ q。引理 L_q 等价于说：**这是唯一的瓶颈**，即存在一族证书（可以随机选取），使每一行的期望负载 ≤ (q + C)。

**与 M1、M2 的关系**：
- M2 的反射证书负载为 2|D| + 2，但覆盖率在固定 Z/q 时趋于 0（命题 F）。
- GF(2) 证书的覆盖率恒为 100%，因为素数 N 时解空间只有 {1, χ_N}。剩下的问题只是负载。
- 典型的非反射证书由"算术巧合"给出，例如含平方数的行（第 4 节）。它们像因数分解算法中的"光滑关系"。证明引理 L_q 需要理解这些关系的分布，这是下一步的目标。

## 17. 计算机验证的有限定理（2026-11-27 20:33）

证书与有理权重保存在 `certs/cert_N{N}_q{q}.json`。独立检验器 `m3_verify_cert.py` 只用整数和 Fraction 运算，不依赖线性规划，输出见 `m3_verify_out.txt`。它检查四件事：
- 每张证书满足引理 Q：行数为偶数，且 qn·r·∏x(N − x) 是平方数；
- 每个 qn ≥ N 的 n 都有证书；
- 每个 n 的权重为正，且和恰为 1；
- 精确计算最大行负载 T。

**定理（计算机验证）**：对下表中的每个 (N, q)，对一切完全积性 g: ℕ → {±1} 和任一 η ∈ {±1}，有

  |{n ∈ [1, N − 1] : g(qn) ≠ g(qn mod N)}| ≤ T · |{x ∈ [1, (N − 1)/2] : g(x)g(N − x) ≠ η}|。

| (N, q) | T |
|---|---|
| (211, 3) | 3.098470 |
| (211, 7) | 6.800001 |
| (211, 13) | 12.875001 |
| (401, 3) | 3.156982 |
| (401, 7) | 6.622223 |
| (809, 3) | 3.262179 |
| (809, 7) | 6.748049 |

证明：对每个 n，按权重随机取一张证书。由引理 Q，若 n 属于左边的集合，则所取证书中至少有一行是坏行。所以左边 ≤ Σ_{坏行} 负载 ≤ T·#坏行。∎

**意义与局限**：
- 这些是引理 L_q 在个别 N 上的严格实例，常数约为 q + O(1)，与"翻转 g(q)"给出的下界 ρ ≈ q − 2 只差 O(1)。
- 它们**不是**引理 L_q 本身。L_q 要求对一切素数 N 成立，而这需要一个可以对一般 N 分析的证书构造。

**补充（严格计算，20:40）：翻转例子的精确值。** 令 g = χ_N·(−1)^{v_q(·)}，A = #{1 ≤ x < N : v_q(x) 为奇数}。
- **坏行**：q 不可能同时整除 x 和 N − x，所以行 x 是坏行，当且仅当 v_q(x) 或 v_q(N − x) 中有一个为奇数。因此 #坏行 = A。
- **𝓔_q**：若 qn ≥ N，则 j = ⌊qn/N⌋ ∈ [1, q − 1]，所以 q ∤ r = qn − jN。此时 n ∈ 𝓔_q 当且仅当 v_q(n) 为偶数。若 qn < N，则 r = qn，两边的奇偶性不同，n ∉ 𝓔_q。所以 |𝓔_q| = #{N/q ≤ n < N : v_q(n) 为偶数} = N − 1 − 2A。
- 于是 **ρ = (N − 1)/A − 2 → q − 1**。当 (q + 1)A = N − 1 时恰好等于 q − 1（例如 N = 401、q = 7 时 A = 50）。
- 结论：引理 L_q 中的常数不能小于 q − 1 − o(1)。第 8 节的 "q − 2" 是一个较粗的估计，在此更正。

## 20. 定理 W：对一切素数 N 成立的弱形式引理 L_q（严格），以及 B = 0 时的刚性（2026-11-27 21:18）

陈述与证明见 DESIGN.md 第 15 节（提交 704cfbf）。要点如下。

**(1) 余链结构**：令 c̄(a)(x) = f(x) + f(ax)。它是 (ℤ/N)^× 上的 1-余链：c̄(ab) = c̄(b) + c̄(a)∘(·b)。到常数的距离 W(a) 因此满足次可加性和对称性：W(ab) ≤ W(a) + W(b)，W(a⁻¹) = W(a)。
- 刚性只给出 W(−1) = |𝓔|（按 n 计，即 2B）。
- 可加性给出另一条信息：c̄(a) 在 [1, N/a) 上恒等于 G(a)。

**(2) 定理 W**：对一切素数 N > p，|𝓔_p| ≤ 4(p − 1)B + 4Σ_{v<p} Σ_{ℓ^a∥v} a·|𝓔_ℓ|。
- 递推得 |𝓔_q| ≤ C_q·B，C_q = exp(O(q/log q))。
- 证明只用到 Thue 引理：每个 x 都可写成 x ≡ ±y·v⁻¹，其中 y < N/p，v < p。

**(3) 推论（B = 0 时的刚性）**：若对一切 n 都有 g(n)g(N − n) = η，则 g 在 [1, N − 1] 上等于平凡特征或 χ_N。这个结论可能早已为人所知（它很初等），这里不声称新颖。它是 GF(2) 实验中"完整纤维 100% 覆盖"现象的一个人工证明，但只覆盖 B = 0 的情形。

**(4) 数值核对**（E18，`m3_e18_out.txt`）：在 N = 1009、4093 上，用 10 个 g 检验 p ≤ 31，违反次数为 0。
- Thue 表示对一切 x 都存在。
- 第 4 步不等式和递推不等式全部成立。
- 定理 W 的界非常松：例如 N = 4093、q = 7（只翻转 7）时，实际 |𝓔_7| = 3070，即 6B；第 4 步的和为 19520，递推界为 29152。

**(5) 定理 W 的不足**：C_q 关于 q 是指数增长的。
- 要配合 GRH 命题 2.2（那里 q ≈ (log N)²）得到有意义的结果，至少需要 C_q 是 q 的多项式。所以定理 W 本身**不能**改进 Corrádi–Kátai 型的界。
- 损失的来源：每用一次乘数 v⁻¹，就要付出 |E_v| ≤ Σ_{ℓ|v} |𝓔_ℓ| 的完整代价。用格点计数（van der Corput 定理）对多种表示取平均也不能降低指数，因为每个乘数自身的代价会累积。
- 实际只用到 E_{v⁻¹} 与短区间 ±[1, N/p) 的交，也就是 𝓔_v 在各个"回绕点" kN/v 右侧长度为 N/(pv) 的小区间里的部分。若这些交的大小"像随机集合那样"约为 |𝓔_v|/p，那么递推是封闭的，并且给出与 q 同阶的常数。
- 反射路径证书不需要模 N 去乘 v⁻¹，所以没有这项代价。这解释了线性规划为什么能做到 ≈ q。

**下一步**：把"短区间局部化"的思想做严格。具体目标是：在回绕点附近，𝓔_v 的点数能被少数几行坏行控制。或者直接把反射路径与 Thue 表示结合：用整数恒等式 vx = kN ± y 和 vr = k′N ± py，代替模 N 的乘法。

## 22. M3-E20（探索性，非预注册）：Thue 树负载的 N 无关上界（2026-11-27 21:20）

脚本：`m3_e20_Fq_exact.py`、`m3_e20b_validate.py`、`m3_e20c_weighted.py`。

**严格事实**：
- 所有断点都是分母只含 ≤ q 的因子的有理数。N 为素数时，x/N 不可能恰好落在断点上。所以对一切素数 N > q，每个 x 的树恰好就是它所在片段的树。
- 由此，每条"记录"（片段 × 节点 × 行角色）给出的行映射是 x ↦ sx + cN，其中 s 是非零整数。所以**每条记录对每一行至多贡献 1**。
- 因此最大负载 ≤ F*(q) = max_φ #{像包含 φ 的记录}，这个界**对一切 N 成立**。
- 核对：在 N = 16381、q = 7 和 N = 4093、q = 13 上，对实际负载最高的 60 行和最小的 29 行，覆盖数都不小于实际负载，违反数为 0。

|---|---|---|---|---|---|

**解读**：
- 未加权的 F*(q) 增长很快，接近指数（记录数也是）。它虽然严格，但太松。原因在于：斜率为 s 的记录只命中像区间中模 |s| 的一个剩余类，平均只覆盖 1/|s| 的行。
- 按 1/|s| 加权的覆盖约为 2q，**是 q 的线性函数**，这就是剩余类"随机对齐"时应有的负载。
- 实测最大负载是加权值的 1.6–2.5 倍，差额来自剩余类的对齐。
- 剩下要证明的是：对任一行 ρ，满足 ρ ≡ cN (mod |s|) 的记录数 ≤ poly(q)·(加权覆盖)，并且对一切 N 一致。这是一个只与 q 有关的有限组合问题，加上同余条件的计数。
- 若这一步成立，Thue 树就给出对一切 N 成立、常数为多项式的引理 L_q。目前**没有证明**。q = 13 的实测最大负载随 N 缓慢增长（48 → 62 → 68），说明对齐效应可能随 N 积累，这是需要警惕的信号。

## 26. 引理 CF：Thue 选择就是连分数的渐近分母（严格，2026-11-27 21:30）

v(a, θ) = min{v ≥ 1 : ‖vθ‖ < 1/a}。若 w < v，则 ‖wθ‖ ≥ 1/a > ‖vθ‖，所以 v 是 ‖·θ‖ 的一个"记录"，即第二类最佳逼近。由 Lagrange 定理，它是 θ 的某个渐近分母 q_k（除去 a₁ = 1 时关于 q₁ 的标准例外）。由此得到：

**(i) A 型链**：A 型子节点保持点 θ 不动，把乘数从 q_k 降到 q_{k−1}。理由：‖q_{k−1}θ‖ < 1/q_k，并且对一切 w < q_{k−1}，‖wθ‖ ≥ ‖q_{k−2}θ‖ > 1/(q_{k−1} + q_{k−2}) ≥ 1/q_k。所以从同一点出发的 A 型链沿渐近分母下降，长度 ≤ θ 在 a 以下的渐近分母个数 = O(log a)。

**(ii) 只有渐近分母能作为子节点的乘数**：乘数 b 不是 φ 的渐近分母的实例 (b, φ) 没有 A 型父节点，只可能有 B 型父节点 (c, c⁻¹φ)。每个乘数 c 至多给出一个 B 型父节点。

**(iii) 与数据一致**：树的大小由 θ 及其倍数 {cθ} 的连分数结构控制，这解释了证书平均大小为什么是 O(log q)（第 21 节）。祖先数的证明（第 25 节第 1 步）需要统计"链上每一步都是渐近分母"的约束能留下多少条路径。这是下一步的具体数论问题。

补充（`m3_e23b_out.txt`）：祖先数的最大值与 q 的比值为 0.85（N = 65521，q = 61）、1.19（N = 65521，q = 127）、0.94（N = 262139，q = 31）、0.95（N = 262139，q = 61），随 N 缓慢增长。按重数计的行负载与 q 的比值为 6.4–7.8，随 q 和 N 都缓慢增长。

- 根层的 "y = ρ" 角色，对每个 v 最多贡献 1，合计不超过 q − 1。
- 行 1、2185、3745 的情况相同。

**严格的归结**：
- **(i) 使用同一行的实例很少**。对固定的行 ρ：
  - 作为 y 使用它的实例，对每个 (a′, v, ε) 至多一个；
  - 作为 a′y 使用它的，要求 a′ | ρ 或 a′ | N − ρ，且对每个 (a′, v) 至多一个。
  
  所以用到 ρ 的实例数 ≤ q² + 2q·d_q(ρ) = O(q²)。由此 **最大负载 ≤ O(q²)·max anc**，其中 anc 是实例的祖先数。
- **(ii) B 型父节点的刻画**：(a, w) 是 (b, z) 的 B 型父节点，必须满足 aw ≡ z 且 v(a, w) = b。这要求 a | (bz mod N) 或 a | (N − bz mod N)：因为 ‖bw/N‖ < 1/a 等价于 bz ≡ ±ay，且 ay < N。所以
  
  anc(b, z) ≤ Σ_{a ∈ I_A(b,z)} anc(a, z) + Σ_{a ∈ D_q(bz mod N), a > b} anc(a, a⁻¹z)，
  
  其中 I_A(b, z) 是一个由连分数决定的区间，D_q(w) = {a ≤ q : a | w 或 a | N − w}。

**启发式计算（不是证明）**：若把 a⁻¹z 看作"随机点"，那么 P(v(a, w) = b) ≈ (2/a)·e^{−2b/a}，祖先数满足 f(b) ≈ 2∫_b^q e^{−2b/a} f(a) da/a。代入 f(a) = (q/a)^γ，得到条件 2·2^{−γ}·Γ(γ) = 1，解为 γ = 1。所以 f(b) ≈ q/b。这与实测（最大祖先数约为 q，出现在 b = 2、3 层）同阶。

**对应用的放宽**：配合 GRH 命题 2.2 时，常数中允许出现 (log N)^{O(1)} 的因子：只要 C(q, N) ≤ (q log N)^{O(1)}，就仍然得到 |L_λ(N)| ≤ N − cN/(log N)^{O(1)}。所以剩下的目标是：
- **待证命题 A**：max anc ≤ (q log N)^{O(1)}。

难点在于沿链条反复出现小因子很多的数（光滑数）时，计数会成倍增长。这可能需要关于 (ℤ/N)^× 中乘法轨道上光滑数分布的估计。

## 39. 二阶矩的连续极限有精确公式，且相容条件与 N 无关（2026-11-27 22:29，探索性）

## 40. 严格证明的整体架构（下一步的计划，2026-11-27 22:30）

目标定理（GRH）：对一切素数 N，|L_λ(N)| ≤ N − cN/(log N)^{A}。

1. **截断**：把深度超过 k = ⌊log N/(4 log q)⌋ 的 Thue 树视为"未覆盖"。于是
   |𝓔_q| ≤ Σ_{坏行} load_k + #{n : 树深度 > k}。
2. **(P1) 深度尾部**：在连续模型中，P(深度 ≥ k) ≤ ρ^k，且 ρ < 1 与 q 无关。数值上每加一层，频数约降为原来的 1/5 到 1/8（第 27 节）。
3. **(P2) 截断后的二阶矩**：在连续模型中 ≤ poly(q)。数值上约为 1.5q²，见第 39 节。
4. **(P3) 等分布**：深度 ≤ k 的树统计量只涉及 z 模 ≤ q^{2k} = N^{1/2} 的同余条件，因此有限 N 的误差 ≤ q^{O(k)}，即 O(N^{1/2+o(1)})。
   - 也可以直接用第 39 节的精确公式：相容条件与 N 无关，每对片段的误差为 O(1)，而深度 ≤ k 的片段只有 ≤ (2q)^k 个。
5. 组合：取 q = p ∈ (P, 2P]，由 GRH 有 |𝓔_p| ≥ cN。由第 23 节（DESIGN）的论证，B ≥ c²N/(C·poly(p))，前提是 #{深度 > k} ≤ cN/4。在 p ≈ (log N)²(log log N)^{2+ε} 时，ρ^k = exp(−Θ(log N/log log N)) = o(1)，满足要求。

**风险点**：
- (P1) 中 ρ 是否真的与 q 无关，需要证明；
- (P2) 需要对 σ₂ 的递推给出解析上界，而不能逐个枚举片段，因为片段数随 q 指数增长。

## 43. 条件定理 Q：在 GRH 和假设 P1′ 下，|L_λ(N)| ≤ N − N·exp(−C(log log N)²)（2026-11-27 23:20）

**假设 P1′（只关于连续模型）**：存在绝对常数 C₀、s 和 ρ < 1，使对一切素数 q 和 k ≥ 1，
∫_{1/q}^{1} #{θ 处 Thue 树中深度为 k 的节点} dθ ≤ C₀·q^s·ρ^k。

**定理 Q（GRH + P1′ ⇒）**：存在 C，使对一切素数 N，|L_λ(N)| ≤ N − N·exp(−C(log log N)²)。

证明（除 P1′ 外都是严格的）：
1. 由 GRH（Mangerel 命题 2.2 与引理 3.1），存在素数 p ∈ (P, 2P]，使 |𝓔_p| ≥ cN，其中 P ≍ (log N)²(log log N)^{3}。
2. 取 k = ⌈(s log p + log(4C₀/c))/log(1/ρ)⌉ = O(log p)。对树深度 ≤ k 的 n 使用 Thue 树证书，其余的 n 视为未覆盖。于是
   |𝓔_p| ≤ #{n : 存在长度为 k 的路径} + Σ_{坏行} L_k(ρ)。
3. **未覆盖数**：路径由（类型序列，乘数序列）决定，至多 (2p)^k 种。每条路径的有效集合，是 θ 在 k 个条件下的交集。每个条件是 {P_iθ} 落在 O(p²) 个区间里，其中 P_i ≤ p^i。所以有效集合至多有 k·p^{k+2} 个区间。整数计数等于 N·测度 + O(区间数)。由 P1′，
   #{n : 存在长度为 k 的路径} ≤ N·C₀p^sρ^k + p^{O(k)} ≤ cN/4 + N^{o(1)}。
4. **截断后的负载**：用到行 ρ 的实例至多 1.5p² 种。对每个实例，从它回溯到根、长度 ≤ k 的路径，每一步至多 2p 种选择（父节点的乘数和类型；父节点的点是确定的）。所以 L_k(ρ) ≤ 3p²(2p)^k = exp(O(log² p))。
5. 合起来：cN ≤ cN/4 + N^{o(1)} + exp(O(log² p))·B，故 B ≥ N·exp(−O(log² p)) = N·exp(−O((log log N)²))。再由 |L_λ(N)| = N − 1 − 2|𝓔(λ)|（取适当的 η），即得结论。∎

**评注**：
- 这把 Mangerel 命题 1.4 中的指数从 6 降到 2。但它依赖于**未证明的假设 P1′**，所以目前不是定理。
- P1′ 是一个只涉及连续动力系统的确定性陈述，与 N 无关。数值上它成立，而且大约 ρ ≈ 0.2–0.45，s ≈ 1（第 42 节）。
- 若再证明二阶矩的 P2，指数可以从 (log log N)² 改进为 log log N，即 polylog 型节省。

## 44. 引理 SC（严格）：Thue 树 = 一条 B 型"脊柱" + 若干长度 O(log q) 的"毛毛虫"（2026-11-27 23:17）

**引理 SC**：设节点 (a, u) 的 Thue 选择为 v = v(a, u) = q_k(u)（引理 CF，其中 q_i 是 u 的连分数渐近分母）。那么：
- (i) A 型子节点 (q_k, u) 的 Thue 选择是 q_{k−1}。由此，从同一点 u 出发的 A 型链依次经过 q_k → q_{k−1} → q_{k−2} → …，长度 ≤ log_φ a + 2，其中 φ 是黄金比。
- (ii) 对链上的每个节点 (q_i, u)，其中 i ≤ k，它的 B 型子节点 (q_{i−1}, {q_i u}) **要么平凡，要么 Thue 选择为 1**。Thue 选择为 1 的节点只用两行，没有非平凡的子节点。

证明：记 δ_i = ‖q_i u‖，则 {q_i u} ∈ {δ_i, 1 − δ_i}。已知 δ_i < 1/q_{i+1} < 1/q_{i−1}；i = k 时，δ_k < 1/a < 1/q_{k−1}。
- 若 {q_i u} = δ_i，则 q_{i−1}·δ_i < 1，节点平凡；
- 若 {q_i u} = 1 − δ_i，则 ‖1·(1 − δ_i)‖ = δ_i < 1/q_{i−1}，所以 v = 1。∎

**推论**：整棵树由两部分组成：
- 一条**脊柱** (a₀, u₀) = (q, θ) → (a₁, u₁) → …，规则是 a_{i+1} = v(a_i, u_i)，u_{i+1} = {a_i u_i}；
- 脊柱的每个节点挂一条长度 ≤ log_φ q + 2 的毛毛虫。

所以树的深度 ≤ 脊柱长度 L + log_φ q + 3，树的大小（按重数计）≤ 2L·(log_φ q + 3)。

**数值核对**（E37，`m3_e37_out.txt`，N = 65521）：

| q | 检查的 B 型子节点数 | 违反数 | 毛毛虫最大长度 | log_φ q + 2 | 平均脊柱长度 | ln q / 1.1866 |
|---|---|---|---|---|---|---|
| 13 | 32331 | 0 | 4 | 7.3 | 2.28 | 2.16 |
| 31 | 75823 | 0 | 6 | 9.1 | 2.95 | 2.89 |
| 127 | 183838 | 0 | 9 | 12.1 | 4.08 | 4.08 |

平均脊柱长度与 ln q / (Lévy 常数) 吻合得很好。

**这解释了 E33**：独立模型让每个节点产生两个"新鲜"的子节点，而实际上 A 型子节点只引出一条确定性的毛毛虫，不再分叉。所以独立模型高估了树的规模。

**P1′ 的归结**：P1′ 等价于（至多差一个 O(log q) 的平移）下面这个更简单的假设：
- **假设 P1″（一维脊柱链的尾部）**：μ{θ ∈ (1/q, 1) : L(q, θ) ≥ ℓ} ≤ C₀·q^s·ρ^ℓ，其中脊柱是映射 (a, u) ↦ (v(a, u), {au})，一旦 au < 1 或 a = 1 就停止。

这是一个分段扩张映射的问题。每一步乘数按规律 v/a 下降：在均匀点下 E[(v/a)²] ≈ 0.24，E log(a/v) ≈ Lévy 常数。剩下要严格证明的是：沿脊柱，点的密度相对于其质量保持有界，或者只在会立刻终止的区域里集中。数值上脊柱尾部近似几何衰减：q = 127 时，从 ℓ = 7 起逐层比值约为 0.3。

## 46. 引理 F 与引理 U（严格）：P1″ 证明的两个主要部件（2026-11-27 23:22）

**引理 F（Farey 界）**：对 b ≥ 2、0 ≤ c < b 以及 2 ≤ m ≤ b，当 u 在 I_c = (c/b, (c+1)/b) 上均匀分布时，
  P(v(b, u) ≥ m) ≤ (1 − m/b)·(1 + 2b/(m − 1))。

证明：v(b, u) ≥ m 当且仅当对一切 w ≤ m − 1 都有 ‖wu‖ ≥ 1/b。
- 设 u 位于 m − 1 阶 Farey 相邻分数 p₁/q₁ < p₂/q₂ 之间。此时 min_{w≤m−1} ‖wu‖ = min(q₁(u − p₁/q₁), q₂(p₂/q₂ − u))，所以满足条件的 u 构成长度为 (b − q₁ − q₂)/(b q₁ q₂) 的子区间。
- 由于 q₁ + q₂ ≥ m，这个长度 ≤ (1 − m/b)/(q₁q₂)。
- 完全落在 I_c 内的 Farey 区间，长度之和 ≤ |I_c|，贡献 ≤ (1 − m/b)|I_c|。
- 至多两个跨越端点的 Farey 区间，因为 q₁q₂ ≥ q₁ + q₂ − 1 ≥ m − 1，每个贡献 ≤ (b − m)/(b(m − 1))。
- 除以 |I_c| = 1/b 即得。∎

**推论**：对任何"b 级集合"（端点在 (1/b)ℤ 上、长度为 1/b 的区间之并，其上的密度为均匀），
  E[(v/b)^s] ≤ κ_s(b) := ∫₀¹ s·x^{s−1}·min(1, (1 − x)(1 + 2/(x − 1/b))) dx。
- b → ∞ 时 κ₂ → 0.738；对 b ≥ 10 有 κ₂ < 0.8。
- 数值核对：b = 20、57、128、301 时，经验概率与上界之比 ≤ 0.45，sup_c E[(v/b)²] ≈ 0.50。

**引理 U（快下降后精确均匀）**：设 u′ 在若干个完整的 a′ 级区间上均匀分布，b = v(a′, u′) < a′/2。
- 若 b ∤ a′，则在条件 v(a′, u′) = b 下（再固定 j、ε），u = {a′u′} 在某个完整的 b 级区间上**精确均匀**。
- 若 b | a′，则 u ∈ (0, 1/b) ∪ (1 − 1/b, 1)，脊柱在下一步终止：前者平凡，后者 v = 1。

证明：
- 当 b < a′/2 时，第 45 节已说明极小性条件不排除任何 η。
- j/b 的邻域长度为 2/(a′b) < 1/a′，它跨越某个 a′ 级端点 c′/a′ 当且仅当 ja′ = c′b，即 b | a′。
- 不跨越时，邻域整个属于某个 a′ 级区间，η 取遍 (0, 1/a′)，t = a′η 在 (0, 1) 上均匀，于是 u = (c + εt)/b 在一个完整的 b 级区间上均匀。
- 跨越时 c = a′j mod b = 0，故 u = ±t/b mod 1。∎

**由此得到**：
- 根 θ 在 (1/q, 1) 上均匀，这本身就是完整 q 级区间之并。只要每一步都是快下降，引理 U 就保证每一步的点都在完整区间上均匀，再由引理 F 得 Φ_{ℓ+1} ≤ κ_s·Φ_ℓ。

**剩下的缺口**：慢下降步，即 b ∈ [a′/2, a′)。
- 这时极小性只排除 η 的一个尾段：只有满足 w ≡ ±j⁻¹ (mod b) 且 w ∈ (a′ − b, b) 的 w 起作用，每个符号至多一个。于是 t 落在 (0, τ) 上，τ = (a′ − b)/w，下一点在 I_c 的一个前缀上均匀。
- 再下一点 {bu} = t 在 (0, τ) 上均匀，又近似回到完整区间之并的情形：多出的部分是一个不完整的末区间，而首区间 (0, 1/v) 是平凡的。
- 预期的结论是"每两步至少收缩 κ_s"，即 ρ = √κ_s < 1，但不完整末区间的记账还没有写完。

完成后，P1″ 与定理 Q 就成为无条件的推导（GRH 仍然需要）。

**补充：慢下降步的处理思路（23:25，尚未完成）**：

**补充：状态类的闭合性，以及"自我修复"（23:27，严格的局部事实）**：

## 47. P1″ 的严格证明（松弛过程），以及定理 Q 在 GRH 下成立（2026-11-27 23:30，待独立复核）

**关键想法**：去掉 Thue 选择中的"极小性"，改为计数**所有**合法的乘数。这样做只会高估，但换来的过程是一个精确的马尔可夫结构。

**松弛路径**：(a₀, u₀) = (p, θ)，每一步任取 b ∈ [2, a−1] 使 ‖bu‖ < 1/a，然后令 (a, u) ↦ (b, {au})。实际的脊柱是其中一条松弛路径，因为极小的 v 也是合法的。

**引理 U′（严格）**：若 u 的分布是若干完整 a 级区间 I_c = (c/a, (c+1)/a) 上均匀分布的混合，那么在条件 ‖bu‖ < 1/a 下（b < a），{au} 的分布是若干完整 b 级区间上均匀分布的混合。

证明：
- 满足条件的集合是 ∪_k (k/b − 1/(ab), k/b + 1/(ab))。
- 若 k/b ≠ c/a，则 |k/b − c/a| = |ka − cb|/(ab) ≥ 1/(ab)。所以每个"半邻域"要么整个在 I_c 内，要么整个在 I_c 外。
- u ↦ {au} 把半邻域 (k/b, k/b + 1/(ab)) 仿射地（斜率 a）映满 b 级区间 ((ak mod b)/b, (ak mod b + 1)/b)，另一半同理。∎

**引理 V（严格）**：在 I_c 上均匀时，P(‖bu‖ < 1/a) ≤ 2/b。理由：区间 [c/a, (c+1)/a] 的长度 1/a 小于 1/b，至多含一个 k/b，贡献 ≤ 2/(ab)。因此
  E[Σ_{b=2}^{a−1} 1(‖bu‖ < 1/a)·b⁴] ≤ a⁴·(2/a)·Σ_{b<a} (b/a)³ ≤ a⁴·(2/a)·(a/4) = a⁴/2。

**命题 P1″（严格）**：
- 令 Φ_ℓ = E_θ[Σ_{长度为 ℓ 的松弛路径} a_ℓ⁴]，其中 θ 在 (1/p, 1) 上均匀，这本身是完整 p 级区间之并。
- 由引理 U′（对 ℓ 归纳）和引理 V，Φ_{ℓ+1} ≤ Φ_ℓ/2，所以 Φ_ℓ ≤ p⁴·2^{−ℓ}。
- 由于 a_ℓ ≥ 2，**μ{θ : 脊柱长度 ≥ ℓ} ≤ E[#长度为 ℓ 的松弛路径] ≤ (p/2)⁴·2^{−ℓ}**。

数值核对：

系统性的 gcd 效应很温和：至多约为均匀值的 1.6 倍，并且随深度回落。

**引理 R 的严格归结**：把松弛路径再细化，记录每一步选的是哪个 k/b 的哪一半。那么：
- 每条细化路径 π（乘数序列 a₀ … a_ℓ，P = a₀⋯a_ℓ）对应 θ 的一个长度恰为 1/P 的区间 J_π。
- 在 J_π 上，M_π = ⌊Pθ⌋ 是常数。
- 对 n ∈ N·J_π，w = Pn mod N 恰好取遍剩余类 w ≡ −M_π·N (mod P) 在 (0, N) 中的元素。理由：J_π 的长度为 1/P，所以 Pθ 不跨越整数。
- 不同细化路径的 J_π 互不相交，所以 M_π 互不相同。

由此，对乘数序列固定的全部 T 条细化路径，
  Σ_π Σ_{n∈NJ_π} d_q(w)² ≤ Σ_{a₁,a₂≤q} [N·g/(P·lcm(a₁,a₂))]·#{π : g | M_π} + O(T·q²)，其中 g = gcd(P, lcm(a₁, a₂))。

所以引理 R 归结为下面的**数字等分布命题**：
- 对每个乘数序列和每个满足 g | P、g ≤ q² 的 g，有 #{π : g | M_π} ≤ C·T/g + o(T)。
- M_π 的混合进制数字由 c₀ 和各步的 ε 确定性地给出：c_{i+1} = (a_i k_i mod a_{i+1}) − [ε_i = −1]。

这一命题尚未证明。注意：若只有 +C′ 型的误差项（而不是 o(T)），对序列求和后会产生 poly(q)·N 的项，并不足以完成证明。

**补充：可容许 M 的显式刻画（严格，00:25）**：对乘数序列 (a₀, …, a_ℓ)，P = a₀⋯a_ℓ。令 R_i = a_i·S_i，其中 S_i = a_{i+2}⋯a_ℓ（i = ℓ − 1 时 S_i = 1）。则
  𝓜_seq = {M ∈ [P/q, P) : 对一切 i < ℓ，M mod R_i ∈ [0, S_i) ∪ [R_i − S_i, R_i)}，
即 ‖M/R_i‖ < 1/a_i。

推导：第 i 个条件 ‖a_{i+1}{P_iθ}‖ < 1/a_i 等价于 ‖Q_iθ‖ < 1/a_i，其中 Q_i = a_{i+1}P_i，而 P/Q_i = R_i。在 J_π 上，θ ∈ (M/P, (M+1)/P)，于是条件变成对 M mod R_i 的一个区间条件。

**由此看到的系统性整除**：
- 最后一步（i = ℓ − 1，S = 1）要求 M ≡ 0 或 −1 (mod a_{ℓ−1})。所以对 g | a_{ℓ−1}，约一半的 M 能被 g 整除，相应的 w ≡ −MN (mod P) 也能被 g 整除。
- 因此数字等分布命题需要修正为：E[d_q(w)² | 序列] ≲ (τ(a_{ℓ−1}) + 1)²·(log q)³ + …。
- 再按引理 V（乘数的密度 ≤ 2/b）对 a_{ℓ−1} 取平均，E[τ(b)²] ≲ (log q)⁴，仍是 polylog。这与 E41 观察到的"至多 1.6 倍"相符。
- 更早各步的条件只要求 M 接近 R_i 的倍数，并不强制整除。对它们需要对区间指示函数的乘积做 Fourier 分析，证明不存在共振。下一步就做这件事。

**数值核对（00:27）**：随机生成约 300 个乘数序列（长度 1–4，P ≤ 2·10⁵），对 M ∈ [0, P) 共做了 1368758 次检验，每次比较：

计划从最后一个条件往前归纳：

## 52. 数字自动机定理（严格，已核对），以及引理 R 的 Fourier 表述（2026-11-28 01:20）

**定理 D（数字自动机）**：固定乘数序列 (a₀, …, a_ℓ)，P = a₀⋯a_ℓ，T_i = a_{i+1}⋯a_ℓ。把 M ∈ [0, P) 写成混合进制 M = Σ_i c_i T_i，其中 0 ≤ c_i < a_i。

则 θ ∈ (M/P, (M+1)/P) 满足松弛路径的全部条件，当且仅当对每个 i < ℓ，
  **a_{i+1}·c_i + c_{i+1} ≡ 0 或 −1 (mod a_i)**。

另外，节点非平凡等价于 c_i ≥ 1，"v = 1 不合法"等价于 c_i ≤ a_i − 2，所以带这两个限制的松弛″过程只是把数字限制在 [1, a_i − 2] 内。

证明：
- 令 u_i = {P_iθ} = (c_i + u_{i+1})/a_i。则 a_{i+1}u_i = (a_{i+1}c_i + c_{i+1} + u_{i+2})/a_i。
- 条件 ‖a_{i+1}u_i‖ < 1/a_i 等价于存在整数 K，使整数 a_{i+1}c_i + c_{i+1} 加上 u_{i+2} ∈ [0, 1) 落在 (Ka_i − 1, Ka_i + 1) 内。
- 这又等价于 a_{i+1}c_i + c_{i+1} ∈ {Ka_i, Ka_i − 1}。∎

数值核对：随机乘数序列，P ≤ 1.5·10⁵，共 1719920 次检验，与第 50 节的 R_i 判据不一致 0 次。

**推论**：给定 c_i 和 ε′ ∈ {0, 1}，下一位 c_{i+1} = (−a_{i+1}c_i − ε′) mod a_i 是唯一确定的，并且只有当它 < a_{i+1} 时才合法。所以整条松弛路径（及其区间 J_π）由 (c₀, ε′₀, …, ε′_{ℓ−1}) 确定。脊柱动力学就此化为一个**逐位确定的数字自动机**。

**松弛″过程下的数值观察**：
- 在 199 个随机序列、3347 个 (序列, g) 组合上，P(g | M 或 g | M+1) ≤ 1.61·(gcd(g, a_{ℓ−1})/g + 1/√g)。
- 第 50 节的反例（a₁ | a₀ 造成的"钉死"）在松弛″中消失。原因是它要求 c_i ∈ {0, a_i − 1}，而这被非平凡性和"v ≠ 1"排除了。

**引理 R 的 Fourier 表述（严格的恒等式）**：令 F 为该序列的容许集（各 J_π 之并），对 g | P，
  Σ_π e(hM_π/g) = P·F̂(−hP/g)/κ(h/g)，其中 κ(x) = (e(x) − 1)/(2πix)，且 |x| ≤ 1/2 时 |κ(x)| ≥ 2/π。

把 F 写成各个条件 1[‖Q_iθ‖ < 1/a_i] 的乘积，其中 Q_i = P/R_i，每个因子的 Fourier 系数为 β_i(r) = sin(2πr/a_i)/(πr)。于是
  F̂(hP/g) = Σ_{Σ_i r_i/R_i = h/g} Π_i β_i(r_i)。

## 54. 二阶矩路线的精确形式，以及它为什么不能靠粗略估计完成（2026-11-28 02:25，分析）

**精确形式**：
- 对细化路径 π（含行的角色），它用到的行恰为 {y ∈ (0, Y_π) : y ≡ r_π (mod m_π)}，其中：
  - y 角色时 m_π = bP_ℓ、Y = N/a_ℓ；
  - a′y 角色时 m_π = a_ℓbP_ℓ、Y = N。
- 这是因为在 J_π 上，y/N = ‖bu_ℓ‖ 是 θ 的仿射函数，斜率为 bP_ℓ，并且取遍 (0, 1/a_ℓ)。
- 于是
  S₂ = Σ_{π,π′} [min(Y, Y′)/lcm(m_π, m_π′)]·1[r_π ≡ r_π′ (mod gcd(m_π, m_π′))] + O(#对数)，
  误差项为 q^{O(k)} = N^{o(1)}，可以忽略。

**粗略估计为什么失败**：
- 若把相容指示函数 1[·] 直接放大为 1，主项就变成 ≈ q·N·Σ_{π,π′} μ_π μ_π′·gcd(m_π, m_π′)。
- 两条独立路径的 m 都是约 k 个 ≤ q 的数之积：都含根乘数 p，并且共享大量小素数因子。所以 E[gcd(m, m′)] 关于 k 是指数增长的，约为 p^{ck}。
- 因此**二阶矩必须用到余数 r_π 模 gcd(m_π, m_π′) 的等分布**，而这里的 gcd 通常是大量小素数之积，模数很大。

**结论**：
- 二阶矩路线（polylog 型节省）与引理 R（定理 Q⁺）归结为同一类问题：混合进制数字（定理 D 的自动机）对大模数的等分布。
- 定理 Q⁺ 只需要模 ≤ q² 的等分布；polylog 需要模数大到 q^{O(k)} 的版本。
- 下一步先攻较小的那个，也就是引理 R。

## 57. 对数预算截断：定理 Q⁺ 归结为一个一阶矩命题（引理 R′）；M3-E45（2026-11-28 03:45）

### 57.1 严格部分

**引理 L（对数预算）**：对脊柱节点 τ（深度 ≥ 1），记 indeg(τ) 为它的 B 型父节点个数的任一上界。称 n 在预算 T 下**已覆盖**，若 n 的脊柱长度 ≤ k，且

则对任一脊柱节点 σ，脊柱经过 σ 的已覆盖 n′ 至多 e^T 个。

证明：令 f(τ, Y) 为从 τ 回溯到深度 0 节点、且沿途（不含终点）Π(1 + indeg) ≤ Y 的路径数。

- 否则 f(τ, Y) ≤ indeg(τ)·max_{τ′} f(τ′, Y/(1 + indeg(τ))) ≤ indeg(τ)·Y/(1 + indeg(τ)) < Y。
- 每个已覆盖的 n′ 给出一条不同的回溯路径，且其乘积 ≤ e^T。∎

**推论（负载不再随深度指数增长）**：沿用第 47、49 节的局部计数（每行至多 1.5p² 个实例，每个实例至多局部于 p² + p + 1 个脊柱节点），已覆盖 n 的负载 ≤ 1.5p²(p² + p + 1)·e^T。截断深度 k 只影响覆盖率，不再进入负载。

**命题（定理 Q⁺ 的归结，GRH）**：令 Λ(p, N) := E_n[Σ_{i=1}^{len(n)} log(1 + indeg_i)]，期望取在满足 pn ≥ N 的均匀 n 上、沿**实际**脊柱。若 Λ ≤ C·log p·log log p，则
  |L_λ(N)| ≤ N − N·exp(−C′·log log N·log log log N)。
证明：取 p 与 |𝓔_p| ≥ cN 同第 47 节；k = 4 log₂ p + O(1) 使 P(len > k) ≤ c/8；T = 8Λ/c 使 P(负担 > T) ≤ c/8（Markov）。于是 cN ≤ cN/4 + o(N) + B·p^{O(1)}·e^T，B ≥ N·exp(−O(Λ + log p))。∎

**必须用实际脊柱，而不是松弛过程（对第 49 节计划的更正）**：松弛过程每一步的合法乘数平均约 2 个（θ 均匀时 E #{b : ‖bθ‖ < 1/p} = 2(p − 2)/p），而乘数大致按均匀比例下降，所以松弛路径的总质量约为 Σ_ℓ 2^ℓ·P(仍存活) ≈ p（启发式估计）。若在松弛过程上做 Markov，覆盖率要多付一个 poly(p) 因子，恰好抵消全部收益。第 49 节"沿松弛路径控制 E[d_q²]，再乘以 E[脊柱长度]"的写法混用了两种测度，应改为在实际脊柱上取期望。

  **X_i := Ω(gcd(M_i(M_i + 1), P_i))**，M_i = ⌊P_i n/N⌋。
- 第一项已是 O(log p·log log p)（E[len] = O(log p) 由 P1″）。系统性部分 X_i ≥ Ω(a_{i−1}) 精确成立，它对应的正是实际父节点 a_{i−1} 本身。

### 58.1 严格部分

**引理 L*（Kraft 型预算）**：给每条"父 → 子"边 (π → σ) 一个代价 c(σ, π) ≥ 0，并要求对每个非源节点 σ，
  Σ_{π ∈ par*(σ)} e^{−c(σ, π)} ≤ 1，
其中 par*(σ) 只含**本身在某条脊柱上**的父节点。称 n 已覆盖，若 len(n) ≤ k 且 C(n) := Σ_t c(σ_t(n), σ_{t−1}(n)) ≤ T。则对任一节点 σ，脊柱经过 σ 的已覆盖源至多 e^T 个。

证明：令 f(σ, Y) 为从 σ 回溯到源、且沿途代价和 ≤ log Y 的路径数。源上 f = 1 ≤ Y（Y ≥ 1）；否则 f(σ, Y) ≤ Σ_π f(π, Y·e^{−c(σ,π)}) ≤ Σ_π Y·e^{−c(σ,π)} ≤ Y。∎

两个特例：
- **c = log indeg*(σ)**，indeg* := |par*(σ)|。这时 C(n) = B*(n) := Σ_t log indeg*(σ_t(n))，而且**不需要第 57 节里的"+1"**：只有一个脊柱父节点的节点不花预算。
- **熵代价 c = log(anc(σ)/anc(π))**。这时 C(n) = log anc(σ_L(n))，即 n 的终点节点的祖先数，截断变成"终点祖先数 ≤ e^T"。这恰好就是第 23、54 节的二阶矩路线：所需的 E_n[anc(σ_L(n))] ≤ A₂/N。

**定理 P（有条件，GRH）**：令 Λ*(p, N) := E_n[B*(n)]。若存在绝对常数 C，使 Λ* ≤ C·log p，则
  |L_λ(N)| ≤ N − N/(log N)^A，对某个绝对常数 A 成立。
证明同第 57 节：取 T = 8Λ*/c = O(log p)，负载 ≤ 1.5p²(p² + p + 1)·e^T = p^{O(1)}，而 p ≍ (log N)²(log log N)³。∎
- 这把 Mangerel（GRH）的 e^{−C(log log N)⁶} 型节省推进到 polylog 型，但**条件 Λ* ≤ C log p 尚未证明**。
- 若只能证明 Λ* ≤ C log p·log log p，得到的是定理 Q⁺。

**剩下的缺口**：Λ* ≤ E* := E_n[Σ_t (indeg*(σ_t(n)) − 1)]，即沿 n 的脊柱汇入的"外来谱系"个数。
- 若把"候选父节点 τ = (a′, x/a′) 本身在脊柱上"用 anc(τ) 控制（并集界），E* 会被放大为 E_n[anc(σ_L(n))] − 1。数值上这个量约与 p 成正比（E42），对 L* 不够用。
- 所以需要的是：**与 n 相关的候选父节点成为脊柱节点的概率 ≲ C/a′**，而不付出它的祖先数。
- 一阶的算术部分已有一个无条件的界：Σ_{a′ | w^±} 1/a′ ≤ (π²/6)·σ(g)/g，其中 g = gcd(M(M + 1), P)，且 σ(g)/g ≤ C·log log g = O(log log p)。

## 60. 条件 Λ* ≤ C log p 的证明框架：把缺口压缩成一个"脊柱成员资格去相关"命题（2026-11-28 04:45，部分严格）

**严格的部分**：
1. Λ* ≤ E*，因为 log d ≤ d − 1。
2. E* = Σ_t E[#{τ ∈ cand(σ_t) \ {σ_{t−1}} : τ ∈ SN}]，其中 cand(σ) 是满足 a′ | w^±、thue(a′, x/a′) = a 且非平凡的候选父节点 τ = (a′, x/a′)，SN 是全体脊柱节点。
3. 算术部分对一切 M 成立（无需任何等分布）：在第 50 节的剩余类刻画下，
   E[Σ_{a′≤p} 1(a′ | w^±)/a′ | 历史] ≤ ζ(2)·(σ(g)/g + σ(g′)/g′)，其中 g = gcd(M_t, P_t)、g′ = gcd(M_t + 1, P_t)。
   推导：对 h = gcd(a′, P_t)，P(a′ | w) = (h/a′)·1[h | M_t]，所以和 ≤ Σ_{h|g} Σ_{h|a′} h/a′² = ζ(2)·Σ_{h|g} 1/h。
   由 Gronwall，σ(g)/g ≤ e^γ log log g + O(1)，而 g ≤ P_t ≤ p^{k}，所以这一项**一致地** = O(log log p)。

**待证的命题 D（脊柱成员资格去相关）**：存在绝对常数 C，使对实际脊柱上的每个节点 σ_t 和每个候选 a′，

- 以深度 t 的细化路径为条件，w_t 取遍剩余类 −M_tN (mod P_t)（第 50 节）。所以
  E[d_p(w_t) + d_p(N − w_t) | 历史] ≤ Σ_{h | g_t} Σ_{a′≤p, h|a′} 2h/a′ ≤ 2(1 + ln p)·τ(g_t)，
  其中 g_t = gcd(M_t(M_t + 1), P_t)。
- 由 Jensen，以及 τ(g_t) ≤ τ(P_t) ≤ τ(p)·τ(a₁)·τ(a₂) 和 log τ(a) ≤ log 2·Ω(a)，即得上式。∎

**由此**：Λ* ≤ O(log log p) + Σ_{t≥3} E[log indeg*(σ_t)] ≤ O(log log p) + E*_{≥3}。

### 64.1 严格部分（待复核）

设乘数序列 a₀ > a₁ > … > a_t ≥ 2，a₀ = p 为素数，并且**相邻互素**：gcd(a_i, a_{i+1}) = 1（0 ≤ i < t）。

**引理 B（反向确定性）**：在数字自动机（定理 D，数字 c_i ∈ [0, a_i)）中，给定 c_{i+1} 和 ε_i，满足 a_{i+1}c_i + c_{i+1} ≡ −ε_i (mod a_i) 的 c_i ∈ Z_{a_i} 恰有一个：c_i = (−c_{i+1} − ε_i)·a_{i+1}^{−1} mod a_i。因此：
- 合法数字串与 (ε 串, 末位 c_t) ∈ {0,1}^t × [0, a_t) 一一对应。
- 单射性：c_t 不同则末位不同；c_t 相同而 ε 不同时，在最后一个不同的下标处 c_i 不同；同一个串也不可能对应两个 ε，因为 0 ≢ −1 (mod a_i)。
- 在松弛″下（数字限制在 [1, a_i − 2]），反向链在每一层至多排除 2 个 c_t 值，所以每个 ε 串对应的合法 c_t 个数在 a_t − 2 − 2t 与 a_t − 2 之间。

**引理 I*（任意深度的精确乘积公式）**：在上述条件下，
  μ{θ ∈ [0, 1) : ‖Q_iθ‖ < 1/a_i，0 ≤ i < t} = Π_{i<t} (2/a_i)，其中 Q_i = a_{i+1}P_{i−1}。
- **证明一（组合）**：由定理 D 与引理 B，合法的 M 恰有 2^t·a_t 个，每个对应长度为 1/P 的区间，所以测度为 2^t·a_t/P = Π_{i<t}(2/a_i)。
- **证明二（Fourier 消元）**：∫Π_i f_i(Q_iθ) 只含满足 Σ k_iQ_i = 0 的项，系数为 Π_i sin(2πk_i/a_i)/(πk_i)。逐层取模：
  - 第 0 层模 a₀，由于 Q_l（l ≥ 1）都含 a₀，得 k₀a₁ ≡ 0，故 a₀ | k₀，于是 k₀ = 0 或该系数为 0。
  - 第 i 层：已有 k₀ = … = k_{i−1} = 0，除以 P_{i−1} 后模 a_i，得 k_ia_{i+1} ≡ 0，由互素得 a_i | k_i，同样只剩 k_i = 0。
  - 所以只剩全零项。∎
- 这把引理 I（只覆盖深度 2）推广到任意深度，只要相邻乘数互素。第 62 节中三个条件的反例（比值 3.75）都出现在相邻乘数不互素的情形。

**引理 T（尾数长度 ℓ = 0、1 时的整除界）**：设 q 为素数幂，q | a_j，且 gcd(q, a_{j+1}⋯a_t) = 1。

### 64.5 ℓ = 2 的格表述（严格的改写；平均情形的界尚待完成，06:35）

在相邻互素、q | a_{t−4} 且 gcd(q, a_{t−3}⋯a_t) = 1 的情形，固定 ε 串，令 m = a_{t−1}，

则 q | M 等价于 β·y(c) + c ≡ x (mod q)，x 由 ε 决定（边界 K = y + m 的情形另计）。所以满足条件的 c 的个数，就是格陪集 Λ′ + v₀ 在盒子 [0, a_t) × [0, m) 中的点数，其中
- Λ′ = {(c, y) : y ≡ Ac (mod m)，βy + c ≡ 0 (mod q)}，由于 gcd(m, q) = 1，它在 Z² 中的指标为 mq。

由此：
- 主项为 a_t·m/(mq) = a_t/q。
- 偏差来自 Λ′ 的短向量。上面的反例对应短向量 (1, −1)，条件是 A ≡ −1 (mod m) 且 β ≡ 1 (mod q)。
- 若 Λ′ 有一个 c 分量为 d、y 分量为 e 的向量，则同一条直线上的点不超过 min(a_t/d, m/|e|) + 1 个。
- 当 A 在 Z_m^* 中"随机"时，存在 d = 1 短向量的概率约为 2/q。所以对序列取平均时，偏差应由 Kronecker 序列 {Ac/m} 的平均差异控制，经典结果是 O((log m)²/a_t) 量级。

把这一步写严格，就得到 ℓ = 2 时的引理 T″。ℓ ≥ 3 的尾数是多个"模乘再提升"映射的复合，需要迭代这个论证。

**引理 T″₂（严格的平均引理，06:36，待复核）**：设 m, q ≥ 2 互素，X ≤ m，β ∈ Z_q^*，B ∈ Z，x ∈ Z_q 固定。则
  (1/m)·Σ_{A∈Z_m} #{0 ≤ c < X : β·((Ac + B) mod m) + c ≡ x (mod q)} ≤ X/q + τ(m) + σ(m)/m。

证明：
- 固定 c，令 g = gcd(c, m)。当 A 取遍 Z_m 时，z = (Ac + B) mod m 取遍 {0 ≤ z < m : z ≡ B (mod g)}（共 m/g 个值），每个值恰好出现 g 次。
- 条件等价于 z ≡ β^{−1}(x − c) (mod q)。由于 gcd(g, q) = 1，上述等差数列中满足它的 z 至多 m/(gq) + 1 个。乘以重数 g，得 ≤ m/q + g。
- 对 c 求和，并用 Σ_{c<X} gcd(c, m) ≤ Σ_{d|m} d·(X/d + 1) = X·τ(m) + σ(m)，再除以 m，并利用 X ≤ m。∎

**含义与缺口**：

## 66. 引理 F：相邻互素情形下尾数整除概率的精确 Fourier–格和公式（2026-11-28 07:33）

**设定**：纯 Bohr 系统（数字 c_i ∈ [0, a_i)），相邻乘数互素，q | a_j，gcd(q, a_{j+1}⋯a_t) = 1，尾数长度 ℓ = t − j − 2 ≥ 0。记
- sinc(x) = sin(2πx)/(2πx)；
- ĝ(k) = sin(2πk/q)/(πk)，ĝ(0) = 2/q；
- S_j = a_{j+2}⋯a_t；
- 对 l = j + 2, …, t − 1，令 w_l = a_{l+1}·a_{j+2}⋯a_{l−1}（空积为 1）。

**引理 F**：
  P(q | M(M + 1)) = Σ_{k∈Z} Σ_{(k_{j+2}, …, k_{t−1}) ∈ Z^ℓ} ĝ(k)·sinc(κ/q)·Π_{l=j+2}^{t−1} sinc(k_l/a_l)，
其中 κ = −k·S_j − q·Σ_l k_l·w_l。

**推导**：对 ∫Π_{i<t} 1[‖Q_iθ‖ < 1/a_i]·1[‖(P_t/q)θ‖ < 1/q] 作 Fourier 展开，然后逐层消元。
- 第 i < j 层：由于 q | a_{i+1}⋯a_t，k 项模 a_i 为 0，于是 k_i = 0。
- 第 j 层：k_j = (a_j/q)·κ，κ = −kS_j + qλ。
- 第 j + 1 层：k_{j+1} = 0。
- 剩下的方程为 λ + Σ_{l≥j+2} k_l·w_l = 0，它唯一确定 λ。
- 各项系数化为 sinc 因子。全零项给出主项 2/q。由引理 I*，k = 0 的其余项全部为 0。

**数值核对**：
- ℓ = 0：289 个情形全部吻合（截断误差 < 10⁻⁵；`m3_e50_out.txt`）。
- ℓ = 1：25 个情形，最大差 2.5·10⁻⁴，来自截断（`m3_e50b_out.txt`）。
- 其中 q = 2 时公式给出 1，这与 M(M + 1) 恒为偶数一致。

**状态**：消元推导是严格的。级数交换求和的收敛性（指示函数的 Fourier 系数只有 1/k 衰减，需要对称部分和或 Fejér 光滑化）尚待补写。

**意义**：
- 偏离 2/q 的部分恰好是一个 (ℓ + 1) 维格上的 sinc 乘积和。只有当 κ/q 与各 k_l/a_l 同时较小时，项才显著，也就是格 {(k, k_l)} 在相应尺度下有短向量。
- 第 64.3 节的反例（a_ta_{t−2} = 1 + q·a_{t−1}）正是这样一个短向量的来源。
