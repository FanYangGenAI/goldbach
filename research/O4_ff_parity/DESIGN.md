# O4（通宵）函数域与整数中的带符号奇偶性二点量 χ：尺度与局部性 — 预注册

> 分支 `gb/O4-ff-parity`（从 `gb/O3-function-field` 分出）。设计与两个运行器 `o4_ff_parity.py`（函数域）、`o4_int_parity.py`（整数对照）在全量运行前一同提交。

## 动机
O1 发现：基础 HL 型局部模型给出 χ 的正确均值，但给不出任何 N 依赖（𝔖(N) 在 χ 中约掉）。这留下两个问题：(i) χ 的跨 N 涨落有多大，是像随机标签那样的 1/√A 尺度，还是更大或更小？(ii) 这些涨落是否仍与 N 的局部特征相关？O1 的设计文档已经指出，基础模型 **没有** 建模 p > z 的局部因子。函数域可以对每个次数的全部 F 精确穷举，因此是检验这两点的可控环境。

## 对象
- **函数域**：对每个 n 次首一 F，配对 (G, F − G)，deg G < n。两侧都要求“粗糙”：每个不可约因子的次数 > d₀ = ⌊(n−1)/3⌋。P = 不可约，S = 恰好两个不可约因子（计重数）。用 4 次 (Z/q)ⁿ FFT 卷积得到 PP、PS、SP、SS。A、B、C、μ、χ 的定义与 O1 完全相同。
  - d₀ 的选择（如实披露）：最初用 ⌊n/3⌋，冒烟时发现 3 ∣ n 时低侧的 S 类为空（例如 n = 6）。改为 ⌊(n−1)/3⌋ 后再冒烟，然后才写本设计。
- **整数**：z = ⌊N^{1/3}⌋，定义同 O1。样本：10⁷ 取 1000 个 N，10⁸ 取 400 个，10⁹ 取 300 个，均在 [X, 1.1X) 中均匀抽取偶数（种子 2026112412）。
- **基础局部模型**：函数域中 X_pred(F) = 𝔖(F)·#X_low·#Y_top/qⁿ（类计数是精确的）；整数中用 O1 的 ρ₁、ρ₂ 积分。在两种情形下 χ_pred 都与 F（或 N）无关。
- **随机标签离散度 D**：假设每个配对独立地以基础模型的类比例取标签，用 delta 方法得到 Var_null(χ) = gᵀΣg/A。令 z = (χ − χ̄)/√Var_null，D = sd(z)。D ≈ 1 表示随机标签尺度。
- **局部特征**：log 𝔖；小因子个数 ω_small（次数 ≤ d₀ 的不同不可约因子；整数中为 ≤ z 的不同奇素因子）；大因子个数 ω_big（次数 > d₀；整数中为 > z）；“F 不可约”（整数中为“N = 2^k·p，p > z”）。R²_local 是 χ 对这四个特征做线性回归的 R²，同时报告每个特征单独的 R²。

## 计划
函数域：q=3，n=5…15；q=5，n=5…10；q=7，n=5…8；q=11、13、17，n=5、6；q=19、23、29、31，n=5。整数见上。

## 预注册判据（函数域取每个 q 的最大 n，以及整数取 10⁹）
- **H2（尺度）**：D ∈ [0.5, 2]。
- **H3（非局部性）**：R²_local < 0.1。
- **H4（若 H3 不成立，主导特征）**：四个单特征 R² 中，ω_big 最大。

## 运行前已知的信息（如实披露）
冒烟测试（函数域 q=3，n=5…8；q=5，n=5、6；整数 10⁵、10⁶ 各 200 个 N）给出：D = 1.0–1.5；R²_local = 0.15–0.66（函数域）、0.22–0.34（整数）；单特征 R² 中，ω_big 在所有情形下都最大（0.09–0.44）。冒烟时还做了两项核对：随机 5 个 F 的四类计数与逐对暴力计数一致；60 个随机 F 的 Ω 与最小因子次数与试除分解一致。因此 H3 预计不成立。这将修正 O1 的解读：χ 的 N 依赖并非“完全不在局部结构中”，而是不在 **基础** 局部模型中，因为后者漏掉了大于 z 的素因子。本检验要看这一点在更大规模上是否保持，以及解释了多大比例。

## 限定
特征回归是线性的、描述性的。R²_local 高说明存在局部结构，但还不是一个预测模型；下一步应当推导 p > z 的局部因子，给出无参数预测。
