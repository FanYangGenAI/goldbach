## 3. 严格部分与条件性推论

**引理 R₀（严格）**：设 p 为素数，𝓔 为完整纤维的少数符号集。若 t = qn（n < p）到 [1, p) 有一条反射路径 t = t₀ → t₁ → … → t_k < p，其中 t_{i+1} = d_i p − t_i，d_i | t_i，t_i/d_i < p，且每一步的两个配对 t_i/d_i 与 t_i mod p 都不在 𝓔 中，则 n ∉ 𝓔_q。于是 |𝓔_q| ≤ u_q·p + M_q·|𝓔|/2。∎（证明见 M1 RESULTS 第 5 节的反射等价式；每一步只用到两处刚性。）

**待证的引理 R（密度版）**：对每个 ε > 0，存在 L(ε)、A(ε)，使得对所有素数 p 与素数 q ≤ p^{1/10}，除至多 εp 个 n 外，qn 都有一条长度 ≤ L、乘数 ≤ A q² 的反射路径。注：给定长度与乘数上界，路径的"字"至多 (Aq²)^L 个；每一步的两个实例都是 n 的单射仿射函数，所以 M_q ≤ 2L(Aq²)^L，是 q 的多项式。数据显示实际 M_q 是线性的。

**条件性推论（GRH + 引理 R）**：Mangerel 的 Prop. 2.2（GRH）给出某个素数 q ∈ [P, 2P]（P ≈ (log p)²(log log p)^{2+ε}）使 |𝓔_q| ≥ c₀p。取 ε = c₀/2，得到 |𝓔| ≥ c₀p / (2M_{2P}) ≥ p/(log p)^{O(1)}，即

  |Σ_{n<p} λ(n)λ(p−n)| ≤ p − p/(log p)^{B}（p 为大素数，B 为绝对常数）。

这比 Mangerel 的 p − p·e^{−C(log log p)^6} 强（e^{−C(log log p)^6} 远小于 (log p)^{−B}）。这**不是** (1 − c)p，也不是 Corrádi–Kátai 猜想，只是定量改进；前提是引理 R 成立，目前它只有数值支持。

2. 核对 Mangerel Prop. 2.2 的确切形式（是对单个 q，还是对 q ∈ [P, 2P] 平均），确认推论链每一环的常数依赖。

## 5. Mangerel Prop. 2.2 的确切形式与推论链（核对，2026-11-27）

- Prop. 2.2（GRH）：对任意 ε > 0 与 P ≥ (log N)²(log log N)^{2+ε}，存在素数 q ∈ (P, 2P] 使 (1/N)Σ_a |S_λ(qa/N) − λ(q)S_λ(a/N)|² ≫ N；由 Lemma 3.1 左边 = 4|𝓔_q(N)|，且证明中对 q ∼ P 的平均为 (1/2 + o(1))N，所以存在 q 使 |𝓔_q| ≥ (1/2 − o(1))N。
- 因此推论只需要引理 R 的 ε < 1/4 版本：|𝓔| ≥ (1/4)N / M_{2P}。若 M_q ≪ q^β（数据：β ≈ 1），则 GRH 下 |L_λ(N)| ≤ N − cN/((log N)²(log log N)^{2+ε})^β（N 为素数）。
- 推论**不用** Mangerel 的 Prop. 2.1（无条件的近似伸缩对称、带 2^{q²} 损失的那一步），用引理 R 代替。抓取工具对其原文第 2 节的参数记账提出了疑问（指数 6 的来历）；我没有核对原文，推论不依赖它。

## 6. 引理 R 为什么应该成立：一个分支过程的启发式

节点 t_i 都形如 c_i N ± qn，层级 j_i = ⌊t_i/N⌋ 由 x = n/N 与 c_i 决定；"d | t_i"是 n 在模 d 下的一个同余类。从层级 j 出发，乘数 d（d | t, d > j）把层级变为 d − 1 − j；一步结束当且仅当 (j + 1) | t。对"随机"的 n，t 有因子 d 的概率约 1/d，所以从层级 j 走到层级 j′ ∈ [0, Z) 的期望分支数约为 Σ_{j′<Z} 1/(j + 1 + j′) ≈ log((j + Z)/(j + 1))。当 Z = Aq（j < q）时期望分支数 ≥ log A > 1（A > e），这是一个**超临界分支过程**，"走到某个能一步结束的低层级"的失败概率随 A 增大而趋于 0，所需步数为 O(log(1/ε))。这与数据一致（Z = 6q 时完全覆盖，平均路长 ≈ 3）。

把它变成证明需要：对短字的成功事件做 CRT 近独立估计（模数互素时独立，有公因子时修正），再用二阶矩或 Janson 不等式控制"所有分支都失败"的密度。字数 ≤ (Aq²)^L，因此 M_q 是多项式。这是下一步的主要工作。

## 7. 引理 R 的证明框架与第一个障碍（2026-11-27 13:00 轮，探索性）

**严格的框架事实**：路径上的节点都形如 t_i = c_i N + (−1)^i qn（c_0 = 0，c_{i+1} = d_{i+1} − c_i）。层级 j_i 只依赖起始层级 j_0 = ⌊qn/N⌋ 与乘数字 (d_1, …, d_i)：ε = +1 时 j_i = c_i + j_0，ε = −1 时 j_i = c_i − j_0 − 1。"d_{i+1} | t_i"是 n 的一个同余条件：gcd(d, q) = 1 时为模 d 的一个剩余类；d = qa 时需 q | c_i（只是对字的条件），然后是模 a 的一个剩余类。所以每个字的成功集合 = 一个层级区间内若干同余类的交，覆盖率完全由 (q, j_0, N 在小模数下的剩余) 决定。这解释了 M2-E1 中"与 p 几乎无关"的现象。

**来源分解**（`m2_word_types.py`，p = 1009，Z = 6q）：路径长度分布在 q = 13 时为 1:24%、2:34%、3:25%、4:8%，q = 41 时峰值移到 3–4。主导字型是 GG、FGG、GGG、QGGG（F = 乘数 q，Q = qa，G = 与 q 互素）。

**朴素二阶矩不够**（`m2_second_moment.py`，输出 `m2_e2_second_moment.txt`）：把长度 ≤ L 的所有成功路径都计数为 X(n)，Chung–Erdős 下界 E[X]²/E[X²] 只有 0.19–0.40（q = 13…41），而实际覆盖率为 0.66–0.98。原因是共享前缀的路径强正相关，X 的分布重尾。而且这个下界随 q 变差。**结论：证明不能用"所有路径一起数"的二阶矩，需要分支过程或逐层暴露（exposure）的论证。**

**对推论强度的影响**：覆盖所需的路径长度随 q 缓慢增长（BFS 最长路径：q = 5 时 5，q = 41 时 9–10）。若只能证明 L = O(log q / log log q)，则由"字数 ≤ (2Aq)^L"得到的多重度上界是 q^{O(log q / log log q)}，不是多项式。此时 GRH 推论变为

  |L_λ(N)| ≤ N − N·exp(−C(log log N)²/log log log N)，

仍强于 Mangerel 的 N − N·e^{−C(log log N)^6}，但不如 N − N/(log N)^B。若能证明 BFS 树中实际使用的字数是多项式（数据中 M_q ≈ 3.5q），就能得到后者。

**下一步**：设计逐层暴露的分支论证。按深度展开可达节点；每个新节点的"可整除事件"只依赖 n 在一个新模数下的剩余；用 CRT 证明在"新模数与已用模数互素"的子树里事件独立，再用 Galton–Watson 比较得到失败概率 ≤ 1/4。
