## 0. 动机（来自 M1 第 6–7 节与 S3 探针）

Corrádi–Kátai 型问题：对素数 p，记 𝓔 = {m < p：λ(m)λ(p−m) ≠ η}（少数符号集），𝓔_q = {n < p：λ(qn mod p) ≠ λ(q)λ(n)}。Mangerel（arXiv:2412.17199，Prop. 4.1）无条件证明 |𝓔_q| ≤ 2^{q²}|𝓔|，再用 GRH 在某个素数 q ∈ [P, 2P]（P ≈ (log p)²(log log p)^{2+ε}）上得到 |𝓔_q| ≫ p，从而 |𝓔| ≫ p·2^{−(2P)²}。损失 2^{q²} 决定了最终界的强弱。

**本线的引理（严格，见 M1 第 5 节）**：对 t > p，记 T(t)：λ(t mod p) = λ(t)。若 d ∣ t 且 t/d < p，则在 x = t/d 与 s = t mod p 两处配对都不在 𝓔 中时，T(t) ⇔ T(dp − t)。T(t) 对 t < p 平凡成立。所以：若 t = qn 到平凡节点有一条反射路径，路径上没有坏配对，则 n ∉ 𝓔_q。由此

  |𝓔_q| ≤ u_q·p + M_q·|𝓔|，

其中 u_q 为没有（受限）路径的 n 的比例，M_q 为单个配对被多少个 n 的路径用到的最大次数。

**S3 探针（已跑，探索性）**：p = 1009、4099、16411 上，q ≤ 13 时反射路径覆盖率 ≥ 99.9%，路径长 ≤ 7，M_q ≤ 77（对比 2^{169}）。只允许小乘数（d ≤ Z 或 d = q·a，a ≤ Z）时，覆盖率与 M_q **与 p 无关**（同一 (q, Z) 在 4099 与 16411 上三位小数一致），说明这是一个由同余与位置决定的"覆盖"问题。

## 1. 预注册假设（M2-E1）

对 q ∈ {5, 7, 11, 13, 17, 23, 31, 41}，Z = 2q（以及 Z = 3q 作对照），p = 1009 与 p = 2003：
- **H1（覆盖）**：Z = 3q 时 u_q ≤ 1%。否定：任一 q 上 u_q > 1%。
- **H2（多项式损失）**：M_q(Z = 3q) ≤ q²。否定：任一 q 上超过。
- **H3（与 p 无关）**：两个 p 上 u_q 相差 < 0.5 个百分点，M_q 相差 < 30%。
- 无论成败的收获：H1 失败则给出"所需 Z 随 q 的增长率"；H2 失败则说明需要更聪明的路径选择（不能用 BFS 最短路树）。

**若 H1–H2 成立**，GRH 下的推论（需另行严格证明覆盖与多重度的一般界）：|L(p)| ≤ p − c·p/M_{2P} = p − p/(log p)^{O(1)}，强于 Mangerel 的 p − p·e^{−C(log log p)^6}。
