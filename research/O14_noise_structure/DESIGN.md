# O14（通宵，GPU）整数哥德巴赫残差噪声的结构：分布、跨 N 相关、频谱 — 预注册

> 分支 `gb/O14-noise-structure`（从 `gb/O13-int-noise-locality` 分出）。设计与运行器 `o14_noise_structure.py` 在全量运行前一同提交。

## 对象
残差 z_N 与 O13 完全相同（HL 背景 + O5 一阶项，按 √b₂ 归一化），在 x = 10⁸、10⁹、10¹⁰、3×10¹⁰ 各取一个窗口（H = 2²²，约 210 万个偶数 N）。先标准化 zc = (z − z̄)/sd(z)，再报告：
- 分布：偏度、超额峰度，0.01%–99.99% 分位数，极值；
- 跨 N 自相关 ρ(L) = E[zc_N · zc_{N+2L}]，L ∈ {1, 2, 3, 4, 5, 6, 8, 10, 15, 21, 30, 50, 105, 210, 1000, 10000}；
- 频谱：zc 的功率谱中，落在小分母有理数 a/b（b ≤ 30）附近 ±16 个频点内的份额，并与这些频点占全部频点的比例比较。

## 预注册判据
- **H1（近高斯）**：10¹⁰ 与 3×10¹⁰ 上 |偏度| < 0.05，且 |超额峰度| < 0.1。
- **H2（跨 N 相关的 mod 3 结构）**：在每个规模上，L ≡ 0 (mod 3) 的滞后（3、6、15、21、30、105、210）的平均 ρ > 0，L ≢ 0 (mod 3) 的滞后（1、2、4、5、8、10、50、1000）的平均 ρ < 0。注意 N → N + 2L 中，3 ∣ L ⇔ N 与 N + 2L 同余 mod 3。
- 描述性：|ρ| 随 x 的变化；频谱份额。

## 运行前已知的信息（如实披露）
冒烟（x = 2²²、2²³，H = 2^16）：偏度 0.009 / −0.015，超额峰度 0.007 / 0.016。L ≡ 0 (mod 3) 时 ρ 为 +0.05 到 +0.10，其余为 −0.02 到 −0.04。频谱在有理数附近的份额为 0.33 / 0.32，而这些频点占全部频点的 0.27。
