# O19（通宵）整数哥德巴赫纤维上的 Liouville 和（O15 的整数版）— 预注册

> 分支 `gb/O19-int-chowla-fibre`（从 `gb/O13-int-noise-locality` 分出）。设计与运行器在全量运行前一同提交。

## 对象
Λ(N) = Σ_{1≤n<N} λ(n)·λ(N−n)，λ 为 Liouville 函数。这是二元 Chowla 型和在“固定和纤维”上的版本，也是 O15 的整数对应。
- λ 用 CPU numba 筛法算到 TOP ≈ 10⁹ + 8.4×10⁶（`lambda_sieve.py`，系统 Python），存为 int8 .npy。该文件不进 Git。
- Λ(N) 在 RTX 4090 上用分块 FFT 对窗口内的 **每个** N（奇偶都算）精确计算（`o19_int_chowla.py`，.venv）。
- 窗口：x = 10⁸、10⁹，H = 2²¹。

由对称性 n ↔ N − n，每一项都出现两次，所以“独立随机符号”模型下 sd(Λ/√N) = √2。

## 报告
- y = Λ/√N 的均值、sd、偏度、超额峰度、最大 |标准化值|，分全部 / 偶数 / 奇数 N；
- 偶数 N 上的跨 N 自相关（滞后 1、2、3、5、15、105 个偶数）；
- 偶数 N 上 y 对 O13 的五个局部特征回归的 R²。

## 预注册判据（两个窗口分别判定）
- **C1（随机符号尺度）**：sd(y)/√2 ∈ [0.9, 1.1]（全部 N）。
- **C2（近高斯）**：全部 N 上 |偏度| < 0.05，|超额峰度| < 0.1。
- **C3（非局部）**：偶数 N 上 R²_local < 0.005。

## 运行前已知的信息（如实披露）
冒烟（x = 10⁵、10⁶，H = 2^14；3 个 N 与暴力求和一致）：sd(y) = 1.407 / 1.414，即 sd/√2 = 0.995 / 1.000；偏度 ≤ 0.012，超额峰度 ≤ 0.11（10⁵ 的奇数 N 为 0.108，全部 N 为 0.078）；R²_local = 0.0009 / 0.0004。

---

## 结果（λ 筛约 1 分钟；GPU 卷积 90 秒；每个窗口 2,097,152 个 N）

| x | sd(y)/√2 | 均值 y | 偏度 | 超额峰度 | 最大 \|标准化值\| | 偶数 N 跨 N 自相关（滞后 1…105） | R²_local（偶数 N） |
|---|---|---|---|---|---|---|---|
| 10⁸ | **0.9997** | −0.0018 | 0.0012 | −0.0016 | 4.94 | \|ρ\| ≤ 0.0015 | **4.1×10⁻⁶** |
| 10⁹ | **1.0001** | −0.0001 | −0.0005 | 0.0096 | 5.06 | \|ρ\| ≤ 0.0027 | **9.3×10⁻⁶** |

奇数、偶数 N 分开看结果相同（sd 1.4135–1.4150）。

**预注册判定**：两个窗口上 **C1 ✓、C2 ✓、C3 ✓**。

**解读**：
- 整数哥德巴赫纤维上的 Liouville 和，在四位有效数字上就是独立随机符号的尺度（sd = √(2N)），并且是高斯的、跨 N 不相关、与 N 的局部特征无关。这是 O15（函数域，sd·q^{n/2} = 1.00 ± 0.05）的整数对应。
- 与哥德巴赫残差（O14、O16）对照：哥德巴赫残差是亚泊松的，并带有由孪生奇异级数决定的跨 N 协方差核；Liouville 纤维和则 **没有任何** 可测结构。也就是说，“奇偶性”本身在纤维上表现得像纯随机符号，哥德巴赫噪声中的结构来自素数（而不是奇偶性）的局部相关。
