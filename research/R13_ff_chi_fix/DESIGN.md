# R13-1（审阅修复）函数域 χ 的不对称边际：连通协方差与三变量离散度

> 分支 `gb/R13-ff-chi-fix`（从 `gb/O7-ff-refined` 分出）。这是第十三轮审阅（`chatgpt-review-o1-o24-round13.md` §2）要求的 **修复复算**，不是新的预注册检验。O4/O7 的原统计量和原判定保留不动。这里只把统计量换成正确的定义，用同样的判据重新报告。

## 修复
- 函数域中低侧（次数 < n）与高侧（次数 = n）的边际不同。正确的连通协方差是 χ_conn = c − μ_L·μ_R（审阅式 1），而 O4/O7 用的是 χ_code = c − μ_R²。
- 随机标签方差改用 (c, b_L, b_R) 的三变量 delta 方法，梯度为 (1, −μ_R, −μ_L)。
- 观测、精细预测（div / all）、D_before、D_after 与局部特征 R²（ω_big 与“F 不可约”）都用修复后的统计量重算。
- 冒烟复现了审阅中的数值：(3,5) 的 sd 为 0.17994，(3,8) 的均值为 −0.00017830、sd 为 0.06476。

**结论**：
- 修复后，χ_conn 的均值如预期约为 0（原 χ_code 的均值完全来自边际不对称项 μ_R(μ_L − μ_R)）。
- 但跨 F 的涨落几乎不变（sd 相差 < 4%），所以 O7 关于“精细局部模型预测 45%–94% 的跨 F 方差、剩余离散度 0.7–0.9”的结论在正确定义下保持。
- 与整数的镜像感知基线（O6/O11 扣除后 D = 0.87–0.95，见回应文档）相比，函数域的 0.70–0.93 与之重叠。报告中“整数 1.2 对函数域 0.8”的差别主要是基线错误造成的。
- 定义说明（审阅 §2 末）：当 3 ∣ n 时，高侧可能出现三个次数为 n/3 的不可约因子，P/S 表只保留 Ω = 1、2，所以 A 不是全部“两侧粗糙”的配对。这是本统计量定义的一部分。
