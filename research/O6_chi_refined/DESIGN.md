# O6（通宵）χ 的精细局部模型：加入大于 z 的素因子 — 预注册

> 分支 `gb/O6-chi-refined`（从 `gb/O4-ff-parity` 分出）。设计与运行器 `o6_chi_refined.py` 在全量运行前一同提交。

## 动机
O1 的基础局部模型对所有类都用同一个 𝔖(N)，所以给不出 χ 的任何 N 依赖。O4 冒烟（以及 O4 整数全量的前两个规模）显示，χ 与“N 的大于 z 的不同素因子个数 ω_big”显著相关。机制是：若 p ∣ N 且 p > z，则 p ∣ n ⇔ p ∣ N − n。素数一侧几乎不可能被 p 整除，但半素数一侧可以（s = p·m），所以 SS 配对得到一个额外的局部因子，PS、SP 配对则得到一个负的局部因子。O1 的基础模型漏掉了这些因子。

## 精细预测（无自由参数）
对 p ∣ N、p > z，记 z-粗糙半素数 s ≈ t 被 p 整除的比例为
w_p(t) = [1/(p·log(t/p))]·1{t/p > z} / ρ₂(t)，ρ₂ 同 O1。

假设除此之外模 p 的剩余在单位上均匀，相对于 PP 的配对局部因子为：
- PS：1 − w(N−t)
- SP：1 − w(t)
- SS：(p−1)·w(t)·w(N−t) + (1−w(t))·(1−w(N−t))

于是 X_pred = 𝔖(N)·∫ρ_X(t)ρ_Y(N−t)·∏_{p∣N, p>z} γ_p^{XY}(t) dt，再由它算出 χ_pred(N)。p ∤ N 的大素数因子几乎与 N 无关，只影响均值，本模型不包含。

## 样本（新样本）
10⁸ 与 10⁹ 各 300 个偶数 N，在 [X, 1.1X) 中均匀抽取（种子 2026112413），并排除 O1、O4 用过的全部 N。

## 预注册判据（与 O1 完全相同，取 10⁹，按 mod 3 组内中心化）
- 支持：相关 > 0.5、标准差比 ∈ [0.5, 2]、R²_pred > 0.25。
- 否定：相关 < 0.2 或标准差比 < 0.1。
- 其余为“部分”。
- 另报告：不分组中心化的同一统计量；χ 均值（观测、基础模型、精细模型）。

## 运行前已知的信息（如实披露）
- 冒烟（10⁶、10⁷ 各 100 个 N）：相关 0.59 / 0.67，标准差比 0.58 / 0.64，R² 0.35 / 0.45，即“支持”。精细模型的均值比观测值偏高约 25–40%（−0.0049 对 −0.0081，−0.0039 对 −0.0053），而基础模型的均值更接近观测值。
- O4 整数全量在本设计之前已经跑完 10⁷ 与 10⁸：D ≈ 1.65，R²_local ≈ 0.29，ω_big 单特征 R² 为 0.17、0.12。

## 限定
w_p 用的是密度近似。均值偏差说明模型在均值层面并不完整：p ∤ N 的因子会移动均值，但不影响跨 N 的波动。
