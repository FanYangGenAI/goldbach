# O7（通宵）函数域中 χ 的精细局部模型（O6 的函数域版本）— 预注册

> 分支 `gb/O7-ff-refined`（从 `gb/O6-chi-refined` 分出）。设计与运行器 `o7_ff_refined.py` 在全量运行前一同提交。

## 对象
与 O4 相同：F_q[t] 中每个 n 次首一 F，粗糙阈值 d₀ = ⌊(n−1)/3⌋，类为 P/S，χ 定义同 O1。这里对 **全部 F** 穷举，没有抽样。

## 精细预测（无自由参数）
对次数 k > d₀ 的不可约 π，记 |π| = q^k、u = |π| − 1。w_t、w_l 是 S 类（高侧次数 n；低侧次数 < n，含常数倍）中被 π 整除的比例。它们用精确计数得到：w_t = N_{n−k}·1{n−k > d₀}/#S_top，w_l = Σ_d (q−1)N_{d−k}/#S_low。由对称性，w 只依赖于 k。相对 PP 的配对局部因子：
- **π ∣ F**：PS：1 − w_t；SP：1 − w_l；SS：u·w_l·w_t + (1−w_l)(1−w_t)（与 O6 相同）。
- **π ∤ F**（只用于 “all” 版本）：按模 π 剩余的分布精确计算 β^{XY}/β^{PP}，其中 P 类在单位上均匀，S 类在 0 处取 w、在单位上均匀。

两个版本：
- **div**（主检验，与 O6 对应）：只用 π ∣ F 的因子。
- **all**：用全部次数 > d₀ 的 π。

X_pred(F) = #X_low·#Y_top·∏γ（𝔖(F) 与 q^{−n} 在 χ 中约掉）。

## 计划
与 O4 相同：q=3，n=5…15；q=5，n=5…10；q=7，n=5…8；q=11、13、17，n=5、6；q=19、23、29、31，n=5。

## 预注册判据（div 版本，每个 q 的最大 n）
- 支持：相关 > 0.5、标准差比 ∈ [0.5, 2]、R²_pred > 0.25；否定：相关 < 0.2 或标准差比 < 0.1；其余为“部分”（与 O1、O6 相同）。
- **H5**：扣除精细预测后的随机标签离散度 D_after ∈ [0.5, 1.2]，即剩余部分不大于随机标签噪声尺度。
- 另报告：扣除前的 D、两个版本的 χ 均值与观测均值。

## 运行前已知的信息（如实披露）
冒烟（q=3，n=5…8；q=5，n=5、6）：div 版本的相关为 0.55–0.81，R² 为 0.31–0.66，即全部“支持”；D_after 为 0.77–0.84（扣除前为 1.02–1.41）。“all” 版本的相关与 div 几乎相同，但均值更接近观测值。O4 的函数域全量运行仍在进行，结果未看。
