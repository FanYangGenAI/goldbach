# L3 方差与矩阶梯 — 实验 E3.1 预注册设计

> 分支 `gb/L3-variance-moments`（纲领中的 L3“方差刚性”，范围扩展到高阶矩）。运行前提交。

## 动机：从“几乎所有”到“每一个”差的到底是什么

记 F(N) = R(N) − N·𝔖(N)（θ 加权，𝔖 为完整奇异级数，L2 已显示这是正确的“主项”）。
- 已知（Hardy–Littlewood，在 GRH 下）：Σ_{N≤x} F(N)² ≪ x^{5/2+ε}；无条件也有非平凡的二阶矩界。二阶矩只能推出“几乎所有 N”。
- 简单的 Chebyshev 论证：在二进窗口 N ∈ [x, 2x] 中，若 Σ |F(N)|^p < (min_N N𝔖(N))^p，则窗口内每个 N 都有 R(N) > 0。
- 若 F 真的像标准差为 σ(x) ~ √x·(log x)^c 的高斯噪声，则 Σ|F|^p/(N𝔖)^p ≈ x·(σ/x)^p ~ x^{1−p/2}·polylog，**只要 p > 2 就趋于 0**。

也就是说，缺失的信息被精确定位为：**任何高于二阶的矩，只要具有其“真实”（近平方根）大小，就足以推出充分大的 N 上的哥德巴赫。** 本实验度量这些矩的真实大小与形状。

## 假设 H3

经 √𝔖(N) 异方差标准化后，F(N) 在每个二进窗口内近似高斯，方差按 x 的约一次幂增长，高阶矩比值为高斯值。

## 预测（X = 2²⁶，二进窗口 j = 12…25，即 N ∈ [2^j, 2^{j+1}) 偶数）

令 Z(N) = F(N)/√(𝔖(N))，σ²_j = Var_j(Z)。
- **P1**：j ≥ 16 时 log σ² 对 log x 的局部斜率在 [1.0, 1.25] 内（1 来自 x，额外的部分来自 log 的幂）。
- **P2**：j ≥ 18 时 m₄/m₂² ∈ [2.7, 3.3]，m₆/m₂³ ∈ [13.5, 16.5]（中心矩）。
- **P3**：反例所需的“σ 数” K_j = min_N N𝔖(N)/(σ_j√𝔖(N)) 在 j ≥ 14 时单调上升，且 K_25 ≥ 100。
- **P4**：四阶 Chebyshev 量 B₄(j) = Σ_{N∈窗口} F(N)⁴/(N𝔖(N))⁴ 在 j = 25 时 < 10⁻⁴，且随 j 下降（斜率约 −1 per doubling 的对数尺度，即按 1/x）。

## 判据

P1–P4 全成立 → 支持：数据上“每一个”与“几乎所有”之间只差一个超过二阶的矩估计；记录各阶矩的经验标度作为任何证明尝试的目标值。P2 失败 → 噪声有重尾，需重新识别结构。

## 规模

CPU，FFT 长度 2²⁸（rfft，内存约 8 GB），预计 5 分钟。

- **P1 ✗**：局部斜率在 j=16–20 时为 1.20–1.28，略超上限 1.25；j ≥ 19 后落入范围（1.14–1.23）。全局斜率 1.20。经验律：σ² ≈ 0.05·x·log³x（j=12…25 内 ±10%），比 x·log²x 多出一个缓慢增长的对数因子。
- **P2 ✗（六阶）**：m₄/m₂² = 3.15–3.19（高斯为 3，在容差内），m₆/m₂³ = 17.3–17.9（高斯 15，超出 16.5）。两者都 **不随 x 增长**，极值 max|z|/√(2ln n) = 0.94–1.11，与高斯完全一致。这是 E2.3 已发现的残余异方差（方差 ∝ 𝔖^γ，γ ≈ 0.84 而非 1）造成的轻微混合效应，而不是越来越重的尾。
- **P3 ✓**：一个反例需要 F(N) 偏离 K 个标准差，K 从 13（x=4096）单调升到 420（x=3.4×10⁷），大约按 √x/log^{3/2}x 增长。
- **P4 ✗（阈值）**：B₄ = 2.5×10⁻⁴（预测 < 10⁻⁴），按 x^{−0.65} 下降而不是 x^{−1}。原因与 P1 相同：方差多了 log 因子。**但定性结论成立：B₄ ≪ 1 且下降，B₂ > 1 且上升。**

## 矩阶梯：L3 的核心结论

在每个二进窗口里：
- **B₂ = Σ(F/N𝔖)² 从 8 增长到 35，大致按 log³x 增长。** 所以即使有人能证明二阶矩的 **真实** 大小，Chebyshev 也只能把窗口里的例外数压到 ~log³x 个，永远到不了 0。这就是“几乎所有”结果的天花板，不是技术问题而是结构问题。
- **B₄ = Σ(F/N𝔖)⁴ ≈ 2.5×10⁻⁴，并按 x^{−0.65} 继续下降。** 若能证明四阶矩（或任何 p > 2 阶矩）具有其真实大小的 x^{o(1)} 倍以内，就能推出所有充分大 N 的哥德巴赫。
- 对照已知：GRH 下二阶矩只有 x^{5/2+ε} 的界（Hardy–Littlewood），比真实的 x²·log³x 差 x^{1/2}。从二阶矩加平凡上确界插值到四阶矩，得到 x^{2k+1/2}，正好比需要的大 x^{1/2}。

**缺失的信息被定位为：一个超过二阶的矩估计，误差损失不超过 x^{o(1)}。** 数据显示这种估计在真实世界中有巨大的余量（B₄ 比 1 小四个数量级）。
