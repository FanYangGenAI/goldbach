# L2 次弧分解 — 实验 E2.1 预注册设计

> 分支 `gb/L2-minor-arc`。本文件在运行前提交，判据不得事后修改。

## 动机（墙 A）

取 θ 加权的素数指数和 S(α) = Σ_{p≤X} log p · e(pα)，则
R(N) = Σ_{p+q=N} log p log q = ∫₀¹ S(α)² e(−Nα) dα。
把 [0,1) 分为主弧 𝔐(Q) = ∪_{q≤Q, (a,q)=1} {|α − a/q| ≤ Q/(qX)} 和其余的次弧 𝔪(Q)，于是 R = R_maj + R_min。
在离散网格 α = k/L（L ≥ 2X）上，这个分解是 **精确的**（对掩膜后的 S² 做逆 FFT），所有 N 一次算出。

已知的困难：对次弧只能做 |R_min(N)| ≤ ∫_𝔪 |S|² =: T(Q)，而 T ≈ X log X 比主项 R_maj ≈ X 还大。所以证明需要 **相位相消**：真实的 |R_min(N)| 必须比 T 小至少 log X 倍。本实验度量现实中相消到底有多强、多“随机”，以及需要多大的主弧。

## 假设 H2

次弧贡献在 N 上表现为随机相位噪声：量级远小于主项，分布近高斯，不集中在特定 N 上。

## 预测（X = 2²⁴，N ∈ [X/2, X] 的全部偶数；Q ∈ {1,2,4,…,2048}）

- **P1（主弧够用）**：存在 Q₀ ≤ (log X)² ≈ 275，使 Q ≥ Q₀ 时 max_N |R_min|/R_maj < 0.5。
- **P2（随机相位）**：在 Q = 256 时，R_min 标准化后超额峰度 |κ| < 0.5，且 max|z| 落在 [0.7, 1.3]·√(2 ln n)（n 为 N 的个数）。
- **P3（相消余量）**：定义所需相消因子 need(N) = R_maj(N)/T(Q)，观测相消因子 obs(N) = |R_min(N)|/T(Q)。预测在 Q=256 时 median(need/obs) ≥ 100。
- **P4（标度）**：在 X ∈ {2²⁰, 2²², 2²⁴} 上，Q = (log X)² 时 rms(R_min)/mean(R_maj) 按 X^{−β} 下降，β > 0.3。

## 判据

- P1–P4 全部成立 → 支持：数据上的墙 A 不是“次弧太大”，而是“现有方法证明不了实际存在的巨大相消”。证明所需的相消只是对数级，而实际观测到的是幂次级。
- P2 失败 → 次弧贡献有非随机结构，深挖（这本身可能就是新信息）。
- P1 失败 → 需要的主弧比预想的大，记录 Q₀ 的实际标度。

## 规模

CPU，numpy FFT，长度 2²⁶。预计 5 分钟以内。

## 无论成败的收获

把墙 A 量化成一个数字：“证明所需的相消”和“实际存在的相消”之间的差距，以及这个差距如何随 X 变化。

## E2.1 结果（X = 2²⁴，N ∈ [X/2, X] 共 4.2×10⁶ 个偶数）

| Q | 主弧测度 | 平凡界 T/R_maj | max\|R_min\|/R_maj | median need/obs | min need/obs | 超额峰度 | max\|z\|/√(2ln n) |
|---|---|---|---|---|---|---|---|
| 2 | ~0 | 9.15 | 2.00 | 3.1 | 0.50 | 0.40 | 1.13 |
| 16 | ~0 | 7.74 | 0.40 | 35 | 2.5 | 11.1 | 3.55 |
| 64 | 3×10⁻⁴ | 6.85 | 0.146 | 129 | 6.9 | 22.2 | 5.48 |
| 256 | 5×10⁻³ | 5.89 | 0.042 | 417 | 23.8 | 13.5 | 6.69 |
| 1024 | 0.086 | 4.69 | 0.014 | 729 | 73 | 1.2 | 3.43 |
| 2048 | 0.342 | 3.22 | 0.011 | 978 | 94 | 0.48 | 2.11 |

（Q ≥ √X/2 时主弧覆盖整个圆，结果平凡，不计入。）

- **P1 ✓**：Q₀ = 16。只要分母 ≤16 的主弧，每个 N 的次弧贡献都小于主项一半。
- **P2 ✗**：次弧贡献 **强烈非高斯**（Q=256 时峰度 13.5，极值是高斯预期的 6.7 倍），集中在少数 N 上。
- **P3 ✓**：Q=256 时证明所需的相消因子只有 T/R_maj ≈ 5.9，实际中位相消比所需强 417 倍，最差的 N 也强 24 倍。
- **P4 ✗**：Q=256 固定时，rms(R_min)/R_maj 只按 X^{−0.18} 下降。

**诊断**：P2、P4 的失败很可能是同一件事。分母 q > Q 的有理点在定义上属于次弧，但它们携带奇异级数的尾项 Σ_{q>Q} μ(q)² c_q(N)/φ(q)²。当 N 被某个大于 Q 的素数整除时（c_q(N) = φ(q)），这一项会很大。这是 **确定性的算术项**，不是噪声，并且它的相对大小只取决于 Q，不随 X 衰减。→ E2.2 检验。

## E2.2 预注册：次弧 = 奇异级数尾项 + 随机相位噪声

**假设 H2'**：R_min(N) = a · N · (𝔖_K(N) − 𝔖_Q(N)) + 噪声，其中 𝔖_K(N) = Σ_{q≤K, q 无平方因子} μ(q)² c_q(N)/φ(q)²（截断奇异级数），K = 2√X。噪声近高斯。

- **P1**：X=2²⁴、Q=256 时，R_min 对尾项预测量的回归 R² ≥ 0.5，拟合系数 a ∈ [0.7, 1.3]。
- **P2**：扣除尾项后的残差 |超额峰度| < 0.5，max|z|/√(2 ln n) ∈ [0.7, 1.3]。
- **P3**：残差 rms / mean R_maj 在 X ∈ {2²⁰, 2²², 2²⁴}（Q=256）上按 X^{−β} 下降，β > 0.3。
- 判据：P1–P3 全成立 → 支持“次弧 = 可预测的算术尾项 + 真随机噪声”；P2 失败 → 还有未识别的结构。

## E2.2 结果

| X | 拟合系数 a | R² | 峰度（前→后） | max\|z\|/√(2ln n)（前→后） | 残差 rms/R_maj |
|---|---|---|---|---|---|
| 2²⁰ | 0.961 | 0.25 | 1.70 → 0.44 | 2.77 → 1.27 | 5.7×10⁻³ |
| 2²² | 0.984 | 0.49 | 5.29 → 0.47 | 3.74 → 1.24 | 3.5×10⁻³ |
| 2²⁴ | **0.995** | **0.74** | 13.5 → 0.54 | 6.69 → 1.78 | 2.1×10⁻³ |

- **P1 ✓**：系数 a = 0.995，与理论值 1 几乎完全一致，R² = 0.74。
- **P3 ✓**：残差按 X^{−0.36} 下降（β = 0.36 > 0.3）。
- **P2 ✗（勉强）**：峰度 0.54（阈值 0.5），极值 1.78（阈值 1.3）。最大残差出现在 N = 16756740 = 2²·3³·5·7·11·13·31，这是一个非常光滑的 N。它的奇异级数项来自 q = 3·5·7·11·13·31 = 465465 这样的大分母，而预注册的截断 K = 2√X = 8192 把它们漏掉了。

## E2.3 预注册：用完整奇异级数（K = ∞）

𝔖(N) − 𝔖_Q(N)，其中 𝔖(N) = 2C₂∏_{p|N, p>2}(p−1)/(p−2) 是绝对收敛的完整级数。其余定义和判据与 E2.2 完全相同（P1: R² ≥ 0.5 且 a ∈ [0.7,1.3]；P2: |峰度| < 0.5 且 max|z|/√(2ln n) ∈ [0.7,1.3]；P3: β > 0.3）。

## E2.3 结果

| X | a | R² | 峰度后 | max\|z\|/√(2ln n) 后 | 残差 rms/R_maj |
|---|---|---|---|---|---|
| 2²⁰ | 1.0013 | 0.25 | 0.44 | 1.26 | 5.7×10⁻³ |
| 2²² | 0.9986 | 0.49 | 0.47 | 1.27 | 3.5×10⁻³ |
| 2²⁴ | **0.9998** | 0.74 | 0.53 | 1.79 | 2.1×10⁻³ |

P1 ✓、P3 ✓（β = 0.36）、**P2 ✗**（与 E2.2 几乎相同）。所以截断 K 不是原因；E2.2 的诊断被否定。

### 探索性诊断（未预注册，只作为下一步假设的依据）

1. **异方差**（`e2_3_diag_hetero.py`）：残差方差随 𝔖(N) 增大，Var ∝ 𝔖(N)^γ，γ = 0.73 / 0.79 / 0.84（X = 2²⁰ / 2²² / 2²⁴，逐渐趋向 1，即“方差 ∝ 均值”）。按 𝔖^{γ/2} 标准化后：峰度 0.19 / 0.17 / 0.18，max|z|/√(2ln n) = 1.11 / 1.11 / 1.22，**都落在 P2 的阈值内**。剩余的重尾就是不同 N 的噪声幅度不同造成的混合效应，不是新结构。
2. **尾项的符号**（`e2_3_tail_sign.py`）：𝔖(N) − 𝔖_Q(N) 相对于 𝔖(N) 的负向最大只有 −2.0%（Q=256）、−0.7%（Q=1024），正向最大 +3.9%、+1.1%。经验上负向 ≈ −c·log Q/Q。**次弧里的算术部分对哥德巴赫几乎只“帮忙”**：光滑 N 的大偏差全是正的。

## L2 阶段结论

R(N) = N·𝔖(N) + G(N)，其中
- N·𝔖(N) 包含 **所有** 有理点（无论 q 大小）的算术贡献，“主弧/次弧”的划分在算术层面是人为的。次弧中可预测的部分在 X=2²⁴ 处被系数 0.9998 精确吸收。
- G(N) 是近高斯的随机相位噪声，方差 ≈ ∝ 𝔖(N)，相对大小按 X^{−0.36} 衰减。
- 墙 A 的量化：证明只需要次弧比平凡界小 T/R_maj ≈ 6 倍（≈ log X 量级），而实际中位数小 417 倍、最差的 N 也小 24 倍。困难完全在于 **证明** 相位相消，而不在于相消是否存在。
- 方法论收获：圆法分析的残差必须对完整奇异级数去趋势，并按 𝔖(N) 做异方差标准化，否则重尾会被误读为结构。
