## 2. T1：Mangerel 方法在 z > 1 处断在哪里（文献核对）

依据 arXiv:2412.17199 的证明结构：
1. **Theorem 1.2 由 Theorem 1.3 加四个分情形推出。** 非光滑 N 的情形用缩放：N = pN′，先在素数 p 上找到符号模式 (λ(b), λ(p−b))，再令 a = bN′、N − a = N′(p − b)，由完全积性得到所需符号。光滑 N 的情形用 8 = 3 + 5、4 + 4、a = b = N/2、以及 M² − d² 的构造。
2. **素数 N 的核心是"伸缩对称"。** 设 φ_d(n) = N{dn/N}，Λ_d(n) = λ(dn)λ(φ_d(n))；Plancherel 给出 (1/N)Σ_a |S(da/N) − λ(d)S(a/N)|² = 4|𝓔_d(N)|。用 Pierce 展开和互反引理（φ_{ab} = φ_a∘φ_b）递推 |𝓔_d| ≤ 2^{d²}|𝓔(N)|；再用 GRH 控制模 N 的素数特征和（P ≥ (log N)²(log log N)^{2+ε} 即可），在某个素数 p 上得到 |𝓔_p(N)| ≫ N，与递推矛盾。
3. **三处与"粗糙"不相容**：
   - 缩放构造 a = bN′ 继承了 N′ 的全部素因子；光滑情形的构造（4N′、2^kN′(·)）本身就含小素因子；
   - 传递映射 φ_a 改变 n 在小素数下的剩余类，不保持粗糙性；
   - 计数是不加权的；粗糙版本需要一个"筛权下的 Lemma 3.1"，文中没有。

   对缓慢增长的 z，粗糙配对的密度约为 (log z)^{−2}，远大于该方法的损失 e^{−C(log log N)^6}，所以**密度不是障碍，障碍是构造与传递映射不保持粗糙性**。

## 3. 由此得到的具体子目标（按可行性排序）

- **S1（最小的新台阶）**：G(z) 对某个固定的 z ≥ 3 成立（GRH 下），即每个大偶数 N = a + b，a、b 都与 6 互素且 λ(a) = λ(b) = −1。

  **已完成的一步（本轮，严格 + 数值核对）**：记 R = {1 ≤ n < N：(n, P_z) = 1}，S_z(α) = Σ_{n∈R} λ(n)e(nα)，d 与 N 互素。把 Mangerel Lemma 3.1 的 Plancherel 论证照搬到 R 上，得到精确恒等式

  (1/N) Σ_{a mod N} |S_z(da/N) − λ(d)S_z(a/N)|² = 4·#{n ∈ R ∩ φ_d^{−1}(R)：λ(dn)λ(φ_d(n)) = −1} + |R △ φ_d(R)|。

  证明：S_z(da/N) = Σ_{m∈φ_d(R)} λ(φ_d^{−1}m)e(ma/N)，按 m ∈ φ_d(R) ∩ R、φ_d(R) \ R、R \ φ_d(R) 三类写出系数后用 Plancherel。∎ 数值：`t1_identity_check.py`，6 组 (N, d, z) 两边逐位相等（输出见 `t1_identity_check_output.txt`）。

  **它说明的事**：
  - 若 P_z ∤ N（例如 N 为素数、z ≥ 3），φ_d 会打乱 n 在小素数下的剩余类，|R △ φ_d(R)| 与 |R| 同阶（N = 997、z = 3 时为 382）。这一项把"伸缩对称"完全淹没，**Mangerel 的核心情形（N 为素数）在粗糙限制下直接失效**。
  - 若 P_z ∣ N，则对 ℓ ≤ z 有 φ_d(n) ≡ dn (mod ℓ)，于是 φ_d(R) = R，余项为 0（N = 930、2310、6930 的数值都是 0），恒等式与不加限制时完全一样。此时 n ∈ R ⇔ N − n ∈ R，粗糙问题在伸缩下是封闭的。
  - 所以 S1 的正确切入点不是素数 N，而是 **P_z ∣ N 的 N**。剩下要解决的是：(i) Pierce 展开的数字 r_j < p 是小整数，与 N 不互素时 φ_{r_j} 不是双射，需要改用 z-粗糙数字的展开；(ii) 非 P_z ∣ N 的 N 需要一个新的约化（Mangerel 的缩放 a = bN′ 会继承 N′ 的小素因子，偶数 N 时 a 必为偶数）。
- **S2**：G(z) 对 z = z(N) → ∞（缓慢）成立。在 S1 的基础上追踪对 z 的依赖。
- **S3**：Mangerel Remark 5（|Λ(N)| ≤ (1 − c)N）。不在阶梯上，但是 Corrádi–Kátai 猜想的第一个定量台阶。

下一轮从 S1 的 (ii) 开始：先写出与 z# 互素版本的 Lemma 3.1，并在小 N 上数值核对恒等式。

## 4. 第一级台阶 z = 2（a、b 都是奇数）：伸缩障碍消失，问题收缩到"核心 N"（2026-11-26 续）

1. **伸缩在 z = 2 上闭合。** N 为偶数时 P₂ = 2 ∣ N，按第 3 节的判据 φ_d(R) = R 对所有奇数 d 成立（φ_d(n) = dn − kN ≡ n (mod 2)）。所以 Mangerel 的 Plancherel 桥在奇数子纤维上 **没有余项**。z ≥ 3 时则需要 P_z ∣ N，绝大多数 N 不满足。
2. **约化引理（严格）**：记 P(M) 为偶数 M 的奇数子纤维 {b 奇，0 < b < M} 上出现的符号模式 (λ(b), λ(M−b)) 的集合。对任意奇数 d ∣ N，P(N) ⊇ λ(d)·P(N/d)。证明：取 a = db，则 a、N − a = d(N/d − b) 都是奇数，λ(db) = λ(d)λ(b)。∎ 数值核对（N ≤ 4000，`z2_reduction_check.py`）：0 个反例。
   - 例：N = 2p（p 为奇素数）时 P(2) = {(+,+)}，于是 (−,−) ∈ P(2p)，即 2p = p + p。
3. **核心情形**：(−,−) 不能由任何真因子约化得到、只能直接处理的 N，在 [100, 4000] 中有 292 个，2-adic 指数主要是 2、3、5（N = 4·奇、8·奇、32·奇）。数值上每个偶数 N ∈ [6, 4000] 都有 (−,−)。
4. **G(2) 还缺什么**：在核心 N（如 N = 4p、2^k）上重做 Mangerel 的素数情形论证。Plancherel 桥已可用；仍需修改的是 Pierce 展开那一步：恒等式 Λ_p(n) = Λ_r(φ_p(n))Λ_p(θ(n)) 中的数字 r = ⌊N/n⌋ 可能是偶数，此时 θ(n) = N − rn 为偶数，离开了奇数子纤维，φ_r 也不再是双射。这是 z = 2 台阶上剩下的唯一结构性缺口（另需把 GRH 的特征和步骤从素数模改到 4p、2^k 型模，那一步看起来是常规的）。

## 5. 精确刚性的 GF(2) 结构：为什么 z = 2 台阶上 Mangerel 的递推不成立（2026-11-27，探索性，未预注册）

**设置**：完全积性 g: ℕ → {±1}，记 g(p) = (−1)^{x_p}。"奇数子纤维刚性" g(n)g(N−n) = η（所有奇数 n < N）对 (x_p, e) 是 GF(2) 上的线性方程组，可以精确求解空间。脚本 `rigidity_gf2*.py`、`certificate_search.py`、`exotic_structure.py`；输出 `m1_e2_*.txt/json`、`m1_e4_exotic.txt`。

1. **素数纤维（对照，Mangerel 的情形）**：p = 101、1009、4099、16411、32771 的完整纤维刚性，解空间维数恰为 1，就是 {g ≡ 1, g = Legendre 符号 χ_p}（η 取对应值）。这与 Mangerel 的结构定理（刚性 ⇒ λ = χ_p）完全一致，而且说明该结构定理对**一切**完全积性 ±1 函数成立，不只是 λ。
2. **2^k 的奇数子纤维**：解空间维数随 k 增长（k = 8…15：4, 6, 8, 11, 17, 28, 52, 83）。也就是说，**存在大量"异类"刚性函数，不是任何特征**。所以"刚性 ⇒ 3-等变"不可能只从完全积性推出：第 4 节遇到的偶数字缺口不是技术问题，而是真实的障碍。
3. **但异类自由度只住在大素数上**：k ≥ 10 时，把解空间限制到 200 以下的素数，恰好等于模 8 实特征 χ_{−4}、χ_8 张成的空间（维数 2）。异类基向量支撑中最小的素数约为 0.20·N（k = 12…15：839/4096、1663/8192、3347/16384、6829/32768）。一般偶数 N（2006、4022、6010、8018、9998、12000、16384、20002、30030、40004）同样成立：限制到与 N 互素的小素数后，解空间落在"导子整除 8·rad(N) 的实特征"的张成里；λ 的模式（小素数上全为 −1）从不在其中。
4. **异类解的等变缺陷**：随机取异类刚性解 g，E_3、E_5 非空，占纤维的 0.8%–3%（随 k 下降），而且**每一个**缺陷元素 n 都满足 n 或 dn mod N 含有 > N/7 的素因子。
5. **更正（同日）**：此前这里写的"因子递推引理"是同义反复，已撤回。原因：q-等变在 x = dm 处的陈述是 g(q·dm mod N) = g(q)g(dm)，d-等变在 n = qm 处的陈述是 g(dn mod N) = g(d)g(n)；两者都等价于对同一个奇数 t = dn 成立 **T(t)：g(t mod N) = g(t)**，所以"由前者推出后者"没有内容。正确的表述如下（严格）：
   - 所有等变陈述都是关于单个奇数 t > N 的陈述 T(t)。t ∈ (jN, (j+1)N) 时，借助 N 处的刚性，T(t) ⇔ g(t)g((j+1)N − t) = η，即 **(j+1)N 处的配对 (t, (j+1)N − t) 刚性**。特别地，T 在 (N, 2N) 上处处成立 ⇔ 2N 处的奇数子纤维刚性。
   - **刚性免费给出的部分**：若 d = ⌈t/N⌉ 整除 t，则 T(t) 成立。证明：x = t/d < N，u = N − x，du ∈ (0, N)，N − du = t − (d−1)N；由 du 处与 x 处的刚性，g(t − (d−1)N) = ηg(du) = ηg(d)g(u) = g(d)g(x) = g(t)。∎ 近刚性时，例外只来自 x ∈ 𝓔 或 du ∈ 𝓔，故这部分缺陷 ≤ 2|𝓔|。第 4 节中 j = 2 的情形就是 d = 3 的特例。
   - 异类解的存在说明：除上面这部分之外，T(t) 一般推不出；数据显示失败的 t 都牵涉大素数。
6. **近刚性探针（探索性，`lemma_L_probe.py`，输出 `m1_e5_lemmaL_probe.txt`）**：从异类刚性解出发随机翻转若干素数，得到 |𝓔| 从 2 到 1630 的近刚性函数。观测到 |𝓔_3|、|𝓔_5| 始终 ≲ |𝓔| + |𝓔_d(g₀)|（翻转大素数时增量恰为 |𝓔| 量级，翻转小素数时增量 ≤ 1.5|𝓔|）。这支持下面的目标引理 L，但不是证明。

**结论与修正后的目标**：在 z = 2 台阶上，Mangerel 的精确递推 |𝓔_d| ≤ C_d|𝓔| 是**错的**（异类解给出 |𝓔| = 0 而 |𝓔_3| > 0）。正确的形式应带加性误差：

  （目标引理 L）|𝓔_d(N)| ≤ C_d·|𝓔(N)| + O(#{n < N：n 或 dn mod N 有 > N/C 的素因子}) = C_d·|𝓔(N)| + O(N·log C / log N)。

加性误差是 o(N)，而 Mangerel 的 GRH 步骤给出的是 |𝓔_p| ≫ N 的下界，所以引理 L 加上他的 GRH 步骤，就能在 2^k 型核心 N 上得到 z = 2 台阶的密度版本。目前严格掌握的只有"⌈t/N⌉ ∣ t 时 T(t) 免费成立"这一部分。下一步：刻画由 N 处刚性加完全积性能推出的 T(t) 的全体（GF(2) 闭包），找出与 N 无关的推导模式，这是证明 L 的必经一步。

## 6. 刚性能推出什么：一致机制只覆盖约三分之一（2026-11-27，探索性）

脚本 `T_closure.py`、`reflection_graph.py`、`gf2_only_examples.py`；输出 `m1_e6_T_closure.txt`、`m1_e7_reflection_graph.txt`、`m1_e8_full_fibre_composite.txt`。

1. **GF(2) 闭包**：对 N = 2^k，在 (N, 3N) 中所有素因子 < N 的奇数 t 上，奇数子纤维刚性（对一切完全积性 g）推出 T(t) 的比例为 92.4%、94.1%、95.7%、96.3%、96.6%（k = 9…13），随 k 上升；续算 k = 14、15、16 为 97.0%、97.6%、98.0%。推不出的 t **全部**有 > 0.2N 的素因子（k = 9…16 中最小比值 0.203–0.355）。由此提出
   **猜想 C′**：k 充分大时，2^k 的奇数子纤维刚性（对一切完全积性 g）推出所有满足"t 与 t mod N 的素因子都 < N/5"的奇数 t ∈ (N, 3N) 上的 T(t)。"⌈t/N⌉ ∣ t"的免费区域（第 5 节，已严格证明）总被推出，但只占约 21%。
2. **反射图（严格机制）**：对奇数 t 的任一奇因子 d，若 t/d < N，则 T(t) ⇔ T(dN − t)（由 t/d 与 d(N − t/d) 两处的刚性得到；近刚性时每条边的缺陷 ≤ 2|𝓔|）。从 {t < N} 沿反射边可达的 t 都被推出，最长路径 6–7 步。**但反射闭包只占 GF(2) 闭包的约三分之一**（k = 12：1026 对 3072），没有"只在反射图里"的 t（与严格性一致）。
3. **剩下的三分之二是零散的算术巧合**：抽出的证书（例：N = 1024 时 T(1025) 由 n = 23, 25, 49, 63, 81, 99 六个方程推出，依赖 1001 = 7·11·13、961 = 31²、943 = 23·41 等具体分解）不随 N 呈现一致模式。
4. **对照：完整纤维（允许偶数 n）**：N = 101²、31³、19³、9998、4096 时刚性解空间维数都是 2。同样是 4096，奇数子纤维的维数是 17。**结构的崩塌恰好来自失去乘数 2。**

**结论**：在 z = 2 台阶上，刚性与完全积性只通过"免费区域 + 反射图"一致地起作用，覆盖约 1/3 的等变陈述；其余依赖 N − n 的具体分解，要做成对所有 N 成立的论证，需要关于这些分解的**分布**输入（等分布 / GRH 型），而不是代数恒等式。这解释了 Mangerel 的方法（素数 N 时解空间恰为 {1, χ_p}，一致的 Pierce 递推足够）为什么在奇数限制下失效。下一步的两个方向：(a) 用"反射图 + 统计"写出带 o(N) 误差的引理 L 的证明草案，统计部分需要的正是 N − n 的分解在奇数上的等分布；(b) 转向 S3（|Λ(N)| ≤ (1 − c)N，完整纤维），那里代数结构完整，障碍只在最后的特征和一步。

## 7. 异类刚性函数恰好由哥德巴赫素数构型生成（2026-11-27，命题严格，等式为猜想）

脚本 `dim_formula_general.py`，输出 `m1_e10_dim_formula.txt`；2^k 的数据见第 5 节。

**命题（严格）**：设 N 为偶数，考虑奇数子纤维刚性方程组（变量为奇素数 p < N 上的 g(p) 与 η）。
- (i) 若 p、q = N − p 都是素数且 N/3 < p ≤ N/2（且 p ∤ N），则同时翻转 g(p)、g(q) 保持刚性。原因：p、q > N/3，它们的奇数倍 ≥ 3p > N，所以 p 与 q 只出现在配对 (p, q) 中。
- (ii) 若 p、N − p、N − 3p 都是素数，N/5 < p 且 N − 3p > N/3，则同时翻转 g(p)、g(N−p)、g(N−3p) 保持刚性。原因：p 只出现在 n ∈ {p, 3p} 及其补，即配对 (p, N−p) 与 (3p, N−3p)；N−p 与 N−3p 都 > N/3，只出现在各自的那一对中。
- (iii) 这些翻转向量支撑两两不交，与刚性实特征张成的空间线性无关。
- 因此 **dim ≥ c(N) + G₁(N) + G₃(N)**。其中 c(N) 是刚性实特征张成的维数，G₁ 是两个素数都 > N/3 的哥德巴赫对个数，G₃ 是 (ii) 型"连环三元组"个数。∎

**猜想 D（等式）**：dim = c(N) + G₁(N) + G₃(N)，c(N) ∈ {1, 2, 3}。
- 证据：N = 2^8…2^15 逐一精确成立（余项为 0，c = 2）；另 12 个一般偶数（2006、3002、4004、4022、6010、8006、8018、9998、12000、16382、20002、30030）余项均为 1–3。

**推论（在猜想 D 下）**：偶数 N 有"较小素数 > N/5"的哥德巴赫表示，当且仅当奇数子纤维刚性方程组有非特征解。

**含义**：第一级台阶（z = 2）上 Mangerel 结构定理失效的全部原因，就是 N 的大素数哥德巴赫对（以及连环三元组）。任何试图在奇数子纤维上强迫"刚性 ⇒ 特征"的一致论证，都必须先绕开这些素数构型，而它们正是哥德巴赫问题本身的对象。这给出一个概念性的障碍：**Liouville 阶梯的第一级就已经和哥德巴赫纠缠在一起**，不存在"先在 λ 上爬几级、再转到素数"的廉价路径。这一推论只是猜想 D 的直接重述，不提供构造哥德巴赫对的办法：要证明维数 > c(N) 而不实际找出这些构型，需要另一种计算秩的手段。我目前没有。
