## 1. 阶梯的定义

对 z ≥ 1，称 n 为 z-粗糙，若 n 没有 ≤ z 的素因子（z = 1 时不限制）。定义

  G(z)：对每个充分大的偶数 N，存在 a + b = N，a、b 均为 z-粗糙，且 λ(a) = λ(b) = −1。

- G(1) 就是 Shusterman 问题（GRH 下已证）。
- 若 z ≥ N^{1/3}：a < N 且所有素因子 > N^{1/3}，则 Ω(a) ≤ 2；λ(a) = −1 迫使 Ω(a) = 1。所以 **G(N^{1/3}) 正好是"两个大于 N^{1/3} 的素数之和"**，即哥德巴赫（去掉一个小范围）。
- N^{1/5} < z ≤ N^{1/3} 时，λ = −1 的 z-粗糙数恰为素数或恰为三个大素数之积。

所以这是一条从"已证（条件性）"到"哥德巴赫"的单参数阶梯。任何 G(z(N))（z(N) → ∞）都是新结果，而 z = N^{1/3} 就是目标本身。

## 2. 为什么 Mangerel 的方法在 z > 1 处断掉（待理论核对）

他的论证依赖 λ 的完全积性：用小的光滑乘数 d 把纤维 N 与纤维 N/d、dN 联系起来（"近似伸缩对称"），再用 GRH 控制素数上的特征和。一旦要求 a、b 都是 z-粗糙，乘以 ≤ z 的素数就离开了被计数的集合，伸缩论证不再闭合。本线的理论任务就是精确找出这个断点，并判断 z(N) 能否缓慢增长。

## 3. 数值实验 M1-E1（预注册）

**对象**：对偶数 N 与阈值 z，记 T_z(N) = #{1 ≤ a < N：a、N−a 都 z-粗糙}，C_z^{ε₁ε₂}(N) 为其中 (λ(a), λ(N−a)) = (ε₁, ε₂) 的个数。局部独立模型：q_z(N) = 区间 [1, N) 中 z-粗糙数里 λ = −1 的比例，预测 Ĉ_z^{−−} = T_z(N)·q_z².

**样本**：N = 2^17、2^20、2^23 附近各取 30 个随机偶数（种子 20261126），另加每个尺度 4 个"高度合数" N（2^k、3·2^k、primorial 型）。z ∈ {1, 2, 3, 5, 7, 11, 31, 101, N^{0.1}, N^{0.2}, N^{0.25}, N^{1/3}}。

**假设与判据（运行前写定）**
- H1（阶梯无近失败）：每个 (尺度, z) 上 min_N C_z^{−−}/Ĉ_z^{−−} ≥ 0.8。否定：任一格点 < 0.8。
- H2（奇偶性在阶梯上是"随机"的直到 z = N^{1/3}）：z ≤ N^{0.25} 时，比值的样本标准差 ≤ 3/√Ĉ（即不超过泊松尺度 3 倍）。在 z = N^{1/3} 处不作预测（那里比值等于 r_z/Ĉ，含奇异级数，已知会偏离）。
- H3（Corrádi–Kátai 的数值形态）：|Λ(N)|/√(2N) 的样本中位数在 [0.3, 1.2] 之内，且三个尺度的 max |Λ(N)|/N 单调下降。
- 无论结果如何的收获：H1 若失败，会给出阶梯上第一个"结构性难点"所在的 z；H2 若失败，说明粗糙限制本身制造了奇偶性偏差，那正是 Mangerel 方法会断的地方的数值影子。

**规模与成本**：CPU，λ 与最小素因子筛到 2^24，预计 < 5 分钟。
