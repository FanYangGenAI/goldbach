# Q7 单系统交叉项能否预测残差 — 预注册

> 分支 `gb/Q7-cross-term-test`（从 Q6 切出）。按第九轮审阅 §7 执行。运行前提交。

## 定义（全部冻结，不拟合任何系数）

- 背景：Q6 的 v2（δ̃_z = δ_z + z·t^{−0.45}/log t，σ₀ = 0.55，B_N = R_N[I_N − T_N I_{1,N}]）。
- a₁(n) = 1/log n，a₂(n) = [z²]δ_z(n)（割线密度的二次 Taylor 系数；修补项是 z 的一次式，不影响 a₂）。
- f₁ = 1_{Ω(n)=1}（素数），f₂ = 1_{Ω(n)=2}（含素数平方）。
- 观测量：e_{m,N} = h_{m,N} − b_{m,N}，其中 h_m 为实测多项式系数，b_m = [z^m]B_N（m = 2, 3），b_m 用半径 0.3、64 点 FFT 抽取。
- 预测量（审阅式 (9)/(10)）：c_{2,N} = 2(a₁ * q₁)(N)，c_{3,N} = 2[(a₁ * f₂)(N) + (a₂ * f₁)(N) − 2(a₁ * a₂)(N)]，q₁ = f₁ − a₁。离散卷积对 2 ≤ n ≤ N−2 求和；纯平滑卷积 (a₁ * a₁)、(a₁ * a₂) 用高精度数值积分代替求和（与离散和相差 O(1)，相对 N 可忽略）。
- 样本：已保存的 Q5d（种子 2026112301，N ∈ [X, 1.1X)，X = 10⁷、10⁸、10⁹，各 40 个）与 Q4b（种子 51，X = 10⁶、10⁷、10⁸，各 60 个）。注意：这些样本已在 Q6 中探索过，本实验只用来检验一个 **事先给定、没有自由参数** 的预测量。

## 统计量（m = 2、3；pooled 与 mod 3 组内中心化）
相关系数 ρ、标准差之比 s = sd(c/N)/sd(e/N)、不拟合斜率的中心化 R²_pred（审阅式 (11)），以及未中心化均值。

## 预注册判据（针对 m = 3，Q5d 10⁹ 组，mod 3 组内中心化）
- **支持**“单系统交叉项是 m=3 主要波动的来源”：ρ > 0.5，s ∈ [0.5, 2]，R²_pred > 0.25。
- **否定**：ρ < 0.2 或 s < 0.1。
- 其余情况为“部分”。其他规模和 m = 2 只作描述。

---

## 结果（运行 6 分钟，220 个 N）

一致性检查：b₂ 的 FFT 抽取与解析式 (4) 的最大相对差为 1×10⁻¹¹ 到 6×10⁻¹¹。Q4b 10⁶ 的 pooled 结果（ρ = −0.006，幅度比 0.0135）与第九轮审阅的独立计算一致。

m = 3（mod 3 组内中心化）：

| 样本 | ρ | 幅度比 s | R²_pred |
|---|---|---|---|
| Q4b 10⁶ | 0.016 | 0.016 | 0.000 |
| Q4b 10⁷ | −0.187 | 0.007 | −0.002 |
| Q4b 10⁸ | −0.095 | 0.002 | −0.000 |
| Q5d 10⁷ | 0.108 | 0.008 | 0.002 |
| Q5d 10⁸ | −0.109 | 0.002 | −0.001 |
| **Q5d 10⁹** | **−0.173** | **0.002** | **−0.001** |

m = 2：ρ 在 −0.15 到 0.17 之间，幅度比为 0.02–0.04。

**判定：否定（预注册）。** 在全部规模（包括 10⁹）上，单系统线性交叉项 C_N 的波动幅度只有实测残差波动的 0.2%–1.6%，相关接近 0，并且幅度比随 N 增大而 **下降**。它也只能解释未中心化均值的一小部分（10⁹ 时，c₃ 的均值约为 e₃ 均值的 14%）。

**由恒等式 E_N = C_N + Q_N 得出的推论**：既然线性项 C 几乎不贡献，m = 3 的主要波动必然在 Q_N = (q*q)(N) + (d*d)(N) − B_N 里，即两个单系统误差序列（素数误差 q₁ 与半素数误差 q₂）之间的 **二次（连通）关联**，再扣去背景中的局部补偿。换句话说，主波动不是“单系统自身起伏的线性响应”，而是真正的“固定和配对关联”。这是一个排除性结论，不是对 Q_N 的正面刻画。
