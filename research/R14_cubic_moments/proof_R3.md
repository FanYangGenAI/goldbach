# 定理 R₃：三重根类型的一阶矩（三次函数域，q 为奇素数，q ≠ 3）

对象与第十四轮审阅 §4 相同：
- L = {c·g：c ∈ F_q^×，g 为一次或二次首一不可约}；
- r(F) = #{G ∈ L：F − G 为首一三次不可约}；
- 三重根类型为 {F = (t − a)³：a ∈ F_q}，R₃ = Σ_a r((t−a)³)。

**定理.**

R₃ = q(q−1)²(q+2)/6（q ≡ 1 mod 3），R₃ = q²(q−1)(q+1)/6（q ≡ 2 mod 3）。

两式与审阅的候选式 (3)、(4) 一致。下文每一步都是初等的。`verify_R3.py` 对 5 ≤ q < 110 的全部素数逐个枚举，核对了引理 1–5 中的每一个中间量；q ≤ 60 时还直接枚举了 r(t³)。全部相等。

记号：η 为 F_q 上的二次特征（η(0) = 0），“q ≡ ±1”表示 q mod 3。

## 步骤 0：平移归约
平移 t ↦ t + a 保持次数、首一性、不可约性与常数倍，因此是 L 与“首一三次不可约”集合上的双射。所以 r((t−a)³) = r(t³)，R₃ = q·r(t³)。

## 步骤 1：r(t³) 的分解
记 H = t³ + h₂t² + h₁t + h₀ 为首一三次，则 G := t³ − H = −(h₂t² + h₁t + h₀)。G ∈ L 当且仅当以下两者之一成立：
- h₂ = 0 且 h₁ ≠ 0（G 为一次式）；
- h₂ ≠ 0 且 Δ := h₁² − 4h₂h₀ 是非平方（G 为不可约二次式的常数倍）。

因此 r(t³) = A + B，其中
- A = #{H 不可约，h₂ = 0，h₁ ≠ 0}；
- B = #{H 不可约，h₂ ≠ 0，η(Δ) = −1}。

## 引理 1：A = (q−1)²/3（q ≡ 1），A = (q²−1)/3（q ≡ 2）
平移 t ↦ t + a 把 h₂ 变成 h₂ + 3a。q ≠ 3 时这是 h₂ 各值之间的双射，所以 h₂ = 0 的首一三次不可约有 π₃/q = (q²−1)/3 个。

其中 h₁ = 0 的是 t³ + h₀，它不可约当且仅当 −h₀ 不是立方：
- q ≡ 2 时立方映射是双射，这样的 h₀ 不存在；
- q ≡ 1 时非立方的 h₀ 有 2(q−1)/3 个。

两式相减即得引理 1。

## 步骤 2：B 的伸缩归约
伸缩 t ↦ λt（H ↦ λ^{−3}H(λt)）保持不可约性，把 (h₂, h₁, h₀) 变成 (h₂/λ, h₁/λ², h₀/λ³)。于是 Δ ↦ Δ/λ⁴，平方类不变。h₂ ≠ 0 的各值彼此等价，所以 B = (q−1)·B₁，其中
B₁ = #{t³ + t² + h₁t + h₀ 不可约，η(h₁² − 4h₀) = −1}。

记 I 为 h₂ = 1 的首一三次不可约个数，由引理 1 的平移论证得 I = (q²−1)/3。再记
- S = Σ_{H 不可约，h₂=1} η(Δ)；
- E₀ = #{H 不可约，h₂ = 1，Δ = 0}。

因为 1[η(Δ) = −1] = (1 − η(Δ) − 1[Δ = 0])/2，所以 **B₁ = (I − S − E₀)/2**。

## 引理 2：S = Σ_{a ≠ 3} M(a, 1) − I
这里 M(a, d) := #{c ∈ F_q：u³ + au² + cu + d 不可约}。

证明：
1. 对首一二次式 Q，有 η(disc Q) = #{Q 在 F_q 中的不同根} − 1（重根时两边都为 0）。取 Q = H − t³ = t² + h₁t + h₀，得 S = Σ_x N(x) − I，其中 N(x) = #{H 不可约，h₂ = 1，H(x) = x³}。
2. x = 0 时 h₀ = 0，H 有根 0，所以 N(0) = 0。
3. x ≠ 0 时，条件为 h₀ = −x² − h₁x。令 u = t − x，H 变为 u³ + (3x+1)u² + (3x² + 2x + h₁)u + x³，其中 u 的系数随 h₁ 取遍 F_q。所以 N(x) = M(3x+1, x³)。
4. 再令 u = xv，得 N(x) = M(3 + 1/x, 1)。当 x 取遍 F_q^× 时，3 + 1/x 取遍 F_q ∖ {3}。

## 引理 3：Σ_a M(a, 1) = (q+2)(q−1)/3（q ≡ 1），q(q+1)/3（q ≡ 2）
常数项为 1 的首一三次不可约，对应 α ∈ F_{q³} ∖ F_q 且 N(α) = −1，每个多项式对应 3 个 α。范数映射是满射，所以 N(α) = −1 的 α 共有 q² + q + 1 个。其中属于 F_q 的是 α³ = −1 的解，共 3 个（q ≡ 1）或 1 个（q ≡ 2）。减去后除以 3 即得。

由引理 2、3 得：S = (q−1)/3 − M(3, 1)（q ≡ 1），S = (q+1)/3 − M(3, 1)（q ≡ 2）。

## 引理 4：E₀ = (q−1)/3（q ≡ 1），(q+1)/3（q ≡ 2）
Δ = 0 时 H = t³ + (t+s)²，s = h₁/2。s = 0 时 H 可约。s ≠ 0 时：
- 令 t = sw，得 H = s²·(sw³ + (w+1)²)；
- 再作反转 w = 1/v（常数项为 1，不可约性保持），得 v³ + 2v² + v + s。

所以 E₀ = #{s：v³ + 2v² + v + s 在 F_q 中无根} = q − |Im φ|，其中 φ(v) = −v(v+1)²。

记 N₁、N₂、N₃ 为 φ 的纤维中恰有 1、2、3 个不同 F_q 点的值的个数：
- 纤维点数之和为 Σ Z = q，即 N₁ + 2N₂ + 3N₃ = q。
- 有重根的值只有两个分支值：φ(−1) = 0（纤维 {0, −1}）和 φ(−1/3)（纤维 {−1/3, −4/3}），所以 N₂ = 2。
- 因此 |Im φ| = N₁ + N₂ + N₃ = q − 2 − 2N₃，E₀ = 2 + 2N₃。

下面计算 N₃。有序三元组 (v₁, v₂, v₃) 满足 e₁ = −2、e₂ = 1，消去 v₃ 后对应二次曲线

C：v₁² + v₁v₂ + v₂² + 2v₁ + 2v₂ + 1 = 0。

- C 非退化（系数矩阵的行列式为 −1/4）。
- 无穷远点满足 v₁² + v₁v₂ + v₂² = 0，在 q ≡ 1 时有 2 个，在 q ≡ 2 时为 0 个（−3 是否为平方）。
- 所以 C 的仿射点数为 q − 1（q ≡ 1）或 q + 1（q ≡ 2）。
- 有坐标相等的点：v₁ = v₂ 给出 (3v+1)(v+1) = 0，共 2 点；另外两种相等关系由对称性各 2 点；不存在三者相等的点。共去掉 6 点。

于是 N₃ = (#C − 6)/6 = (q−7)/6 或 (q−5)/6，代入得 E₀ = (q−1)/3 或 (q+1)/3。

## 引理 5：M(3, 1) = E₀
M(3, 1) = q − |ψ(F_q^×)|，其中 ψ(u) = −(u³ + 3u² + 1)/u（u = 0 永远不是根）。

- 纤维点数之和为 q − 1。
- 分支值：c = 3 对应 (u+1)³，只有 1 个不同根；c = −15/4 对应二重根 1/2 加另一个根，有 2 个不同根。所以 N₂′ = 1，并且 N₁′ + 2 + 3N₃′ = q − 1。
- 因此 |Im ψ| = q − 2 − 2N₃′，M(3, 1) = 2 + 2N₃′。

N₃′ 由有序三元组 e₁ = −3、e₃ = −1 给出，消元后是仿射三次曲线

D：u₁u₂(u₁ + u₂ + 3) = 1。

- D 在 (−1, −1) 处有唯一奇点。令 u = −1 + a 展开，切锥为 a² + ab + b²，所以奇点是结点，切线在 q ≡ 1 时分裂，在 q ≡ 2 时不分裂。
- 射影结点三次曲线的光滑点数为 q − 1（分裂）或 q + 1（不分裂）。三个无穷远点 [1:0:0]、[0:1:0]、[1:−1:0] 都是光滑的有理点。
- 所以 D 的仿射点数（含奇点）为 q − 3 或 q − 1。
- 有坐标相等的点为 (−1, −1)、(1/2, 1/2)、(1/2, −4)、(−4, 1/2)，共 4 个，都满足 2u³ + 3u² − 1 = (u+1)²(2u−1) = 0。

所以 N₃′ = (q−7)/6 或 (q−5)/6 = N₃，M(3, 1) = E₀。

## 合成
由引理 2–5 得 **S = 0**，于是 B₁ = (I − E₀)/2：
- q ≡ 1：B₁ = q(q−1)/6；
- q ≡ 2：B₁ = (q+1)(q−2)/6。

r(t³) = A + (q−1)B₁：
- q ≡ 1：(q−1)²/3 + (q−1)·q(q−1)/6 = (q−1)²(q+2)/6；
- q ≡ 2：(q²−1)/3 + (q−1)(q+1)(q−2)/6 = q(q²−1)/6。

乘以 q 即得定理。∎

**标记**：全部为初等恒等式加两条标准事实：射影光滑二次曲线有 q + 1 个点；射影结点三次曲线的光滑点数为 q ∓ 1。没有引用未证明的结果。附带结论 S = 0：在 h₂ = 1 的不可约三次上，低次部分判别式的二次特征之和为 0。这是一个值得注意的消去现象。
