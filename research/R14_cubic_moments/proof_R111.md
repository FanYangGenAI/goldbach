# 定理 R₁₁₁：三个不同一次因子类型的一阶矩（q 为奇素数，q ≠ 3）

**定理.** 对两个剩余类都有 R₁₁₁ = q(q−2)(q−1)²(q+1)(q+2)/36，与候选式 (3)、(4) 一致。

`terms_R111.py` 对 q ≤ 31 逐项核对了下文的每个中间量（ΣT₂、W、ΣT₃、A、Z₀ = Z₁、N_{k0}）。各片段的符号合成已用 SymPy 核对（见文末）。

## 0. 归约
仿射群在有序三元组上自由作用，把 (a, b, c) 送到 (0, 1, γ)，其中 γ = (c−a)/(b−a)。所以

R₁₁₁ = (q(q−1)/6)·Σ_{γ∈S} r(F_γ)，其中 F_γ = t(t−1)(t−γ)，S = F_q ∖ {0, 1}。

对每个 F_γ 使用 `proof_R21.md` 的一般容斥公式与引理 A。下面只需证明

**Σ_{γ∈S} r(F_γ) = (q−2)(q−1)(q+1)(q+2)/6。**

## 1. ΣT₁ = (q−2)[(q−3)n₁ + 3(q−1)]
每个 F_γ 恰有 3 个根，其中 n₁ = (q−1)(q+2)/2。

## 2. ΣT₂
**第一部分**为 Σ_γ #{x<y：F_γ(x) ≠ F_γ(y)} = (q−2)C(q,2) − W/2，其中 W = #{(γ, x, y)：γ ∈ S，x ≠ y，F_γ(x) = F_γ(y)}。

**引理 W.** W = q² − 2q + 7（q ≡ 1），W = q² − 2q + 3（q ≡ 2）。

证明：x ≠ y 时，F_γ(x) = F_γ(y) ⇔ P(x, y) = γ(x + y − 1)，其中 P = x² + xy + y² − x − y。
- 若 x + y ≠ 1，γ 由 (x, y) 唯一确定，只需排除 γ = 0（(x, y) ∈ C₀ = {P = 0}）和 γ = 1（(x, y) ∈ C₁ = {x² + xy + y² − 2x − 2y + 1 = 0}）。
  - C₀、C₁ 都是非退化二次曲线（行列式 −1/4），无穷远点由 x² + xy + y² 决定，所以仿射点数都是 q ∓ 1。
  - C₀ 上：x = y 的点有 2 个（x ∈ {0, 2/3}）；x + y = 1 的点有 2 个（(0,1)、(1,0)）。
  - C₁ 上：x = y 的点有 2 个（x ∈ {1/3, 1}）；x + y = 1 的点也是 (0,1)、(1,0)。
- 若 x + y = 1，则 P = x² − x，需 x ∈ {0, 1}，此时任意 γ ∈ S 都可以，共 2(q−2) 个。
- 满足 x ≠ y、x + y ≠ 1 的对共 (q−1)² 个。

所以 W = (q−1)² − 2[(q ∓ 1) − 4] + 2(q−2)。∎

**第二部分**为 Σ_γ Σ_{x<y，uv≠0} (q − η(uv))/2，其中 u = F_γ(x)，v = F_γ(y)。
- 记 s_γ = Σ_x η(F_γ(x)) = −a_γ（Legendre 族的迹），则 Σ_{x<y} η(uv) = (s_γ² − (q−3))/2。
- 经典恒等式：Σ_{γ∈S} a_γ² = q² − 2q − 3。
  - 证明：展开平方。Σ_γ η((x−γ)(y−γ)) 在 x ≠ y 时为 −1，在 x = y 时为 q − 1。再扣除 γ = 0、1 两项即得。
  - 已对 q < 80 数值核对。
- 所以第二部分 = (q−2)(q/2)C(q−3, 2) − (3q − 9)/4。

## 3. ΣT₃ = A − 2Z₀ + N_{k0}
对三元子集 X 与 γ，有 F_γ − ∏(t − x) = k t² + m t + e₃，其中 k = e₁ − 1 − γ，m = γ − e₂。

**k = 0 的项**：γ = e₁ − 1 ∈ S，且需 m ≠ 0。
- N_{k0} = Σ_{γ∈S} [#{X：e₁ = γ+1} − #{X：e₁ = γ+1，e₂ = γ}]。
- 第一项为 (q−1)(q−2)/6。
- 第二项恰为 N₃(F_γ)，即 F_γ − w 有 3 个不同根的 w 的个数（这样的 X 正是 F_γ − w 的根集）。
- 由纤维计数 Σ_w Z(Z−1) = 6N₃ + 2N₂ 得 Σ_γ(6N₃ + 2N₂) = W。
- N₂(F_γ) 等于 F_γ 的 F_q 临界点个数：F_γ′ 的判别式为 4(γ² − γ + 1)。临界点个数为 1 + η(γ² − γ + 1)；当 γ² − γ + 1 = 0 时，唯一的临界点是三重点，此时 N₂ = 0。
- Σ_{γ∈S} N₂ = q − 6 − η(−3)。这里用到 Σ_{γ∈S} η(γ² − γ + 1) = −1 − 2，以及 γ² − γ + 1 = 0 的解有 1 + η(−3) 个。
- 于是 Y := Σ_γ N₃ = (q² − 4q + 21)/6（q ≡ 1）或 (q² − 4q + 13)/6（q ≡ 2），N_{k0} = (q−2)²(q−1)/6 − Y。

**k ≠ 0 的项**：需 η(Q_X(γ)) = −1，其中 Q_X(γ) = (γ − e₂)² − 4(e₁ − 1 − γ)e₃ 是关于 γ 的首一二次式，判别式为 16∏_{x∈X} x(x−1)。
- 若 X ⊄ S，Q_X 是平方，没有贡献。
- 若 X ⊂ S，全部 γ 中非平方的个数为 (q − η(∏x(x−1)))/2，再扣除 γ = 0、1 处的非平方。γ = e₁ − 1 时 Q 为平方，不必扣除。
- A := Σ_{X⊂S} (q − η(∏x(x−1)))/2。记 P、M 为 S 中 η(x(x−1)) 取 +1、−1 的个数，由 P − M = Σ η(x² − x) = −1 得 P = (q−3)/2，M = (q−1)/2。于是 Σ_X ∏η = e₃(P 个 +1，M 个 −1)。
- Z₀ := #{X ⊂ S：η(Q_X(0)) = −1}。Q_X(0) = e₂² − 4(e₁−1)e₃ 正是 R₂₁ 证明中 T₃ 的表达式，其 (ii) 部分只来自 X ⊂ S，所以 Z₀ = (ii)/6。
- Z₁ := #{X ⊂ S：η(Q_X(1)) = −1}。恒等式 Q_X(1) = Q_{1−X}(0)（SymPy 验证）给出 X ↦ 1 − X 的双射，所以 Z₁ = Z₀。

## 4. 合成
Σ_γ r(F_γ) = (q−2)|L| − ΣT₁ + ΣT₂ − ΣT₃。把以上闭式代入，用 SymPy 化简，两个剩余类都得到 (q−2)(q−1)(q+1)(q+2)/6。乘以 q(q−1)/6 即得定理。∎

**标记**：初等恒等式，加上 Legendre 族迹的二阶矩（经典，且已给出初等证明）。
