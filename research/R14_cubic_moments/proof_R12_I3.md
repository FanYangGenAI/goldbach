# 定理 R_{I₁I₂} 与 R_{I₃}：由两条线性恒等式得到（q 为奇素数，q ≠ 3）

有了 R₃、R₂₁、R₁₁₁ 的证明（`proof_R3.md`、`proof_R21.md`、`proof_R111.md`），剩下两个类型矩可以由两条线性恒等式解出。

## 恒等式 1（总和）
Σ_τ R_τ = Σ_F r(F) = |L|·|P| = (q(q²−1)/2)·((q³ − q)/3) = q²(q²−1)²/6。

（每个 (G, H) ∈ L × P 恰好对应一个 F = G + H。）

## 恒等式 2（按根数加权）
**Σ_F r(F)·Z(F) = q²(q²−1)(q−1)(q+2)/6**，其中 Z(F) 为 F 在 F_q 中的不同根数。

证明：
1. 由平移不变性，Σ_F r(F)Z(F) = Σ_x Σ_{F(x)=0} r(F) = q·Σ_{β,δ} r(t³ + βt² + δt)。
2. 交换求和次序：Σ_{β,δ} r(t³ + βt² + δt) = Σ_{G∈L} #{(β, δ)：t³ + βt² + δt − G 不可约}。
3. 对固定的 G，当 (β, δ) 取遍 F_q² 时，t³ + βt² + δt − G 的二次项与一次项系数也取遍 F_q²，常数项固定为 −g₀（g₀ 为 G 的常数项）。所以计数等于常数项为 −g₀ 的首一三次不可约个数：
   - g₀ = 0 时为 0；
   - g₀ ≠ 0 时为 (q² + q + 1 − c₃(g₀))/3，其中 c₃(g₀) = #{z ∈ F_q：z³ = g₀}。理由与 R₃ 的引理 3 相同（范数满射）。
4. L 中常数项的分布：对每个 g₀ ≠ 0，满足 G(0) = g₀ 的 G ∈ L 恰有 n₁ = (q−1) + (q²−q)/2 个。
   - 一次式 c(t+β)：cβ = g₀ 有 q − 1 个解；
   - 二次式 cQ：每个不可约 Q 恰给出一个 c = g₀/Q(0)。
5. 因为 Σ_{g₀≠0} c₃(g₀) = q − 1，所以
   Σ_{β,δ} r = n₁·[(q−1)(q² + q + 1) − (q−1)]/3 = n₁·q(q² − 1)/3。

乘以 q 即得恒等式 2。∎

`verify_rootweighted.py` 对 q = 5、7、11、13 暴力核对了第 5 步的结果。

## 解出
各类型的根数为：I₃ 为 0，I₁I₂ 为 1，111 为 3，21 为 2，3 为 1。所以
- R_{I₁I₂} = Σ_F rZ − 3R₁₁₁ − 2R₂₁ − R₃；
- R_{I₃} = Σ_F r − R_{I₁I₂} − R₁₁₁ − R₂₁ − R₃。

代入已证的 R₃、R₂₁、R₁₁₁，用 SymPy 化简，两个剩余类都与审阅的候选式 (3)、(4) 逐项相等（差为 0）。∎

**结论**：第十四轮审阅式 (3)、(4) 中的五个一阶类型矩 R_τ 全部得到证明，适用于奇素数 q ≠ 3。剩下的只有二阶矩 M₂。
