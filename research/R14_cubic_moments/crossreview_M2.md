## 逐节核对

**§2 R = Σ_{h∈L} A_P(h)。** 成立。由 A_P(−h) = A_P(h)（作代换 H → H − h）与 −L = L 得出。全部一次多项式都属于 L，所以不可约二次位移的和为 R − T。

**§3 互反双射。** 成立。逐项核对了以下几点：
- H(b) = c ≠ 0，并且 H 与 H + a(t−b) 在 t = b 处取同一个值 c，所以两次反转都保持不可约；
- K 是首一的，因为 u³ 的系数为 H(b)/c = 1；
- 第二个多项式变为 K + (a/c)u²；
- 逆映射中 H 的首项系数为 c·(1/c) = 1。

于是对每个 b，Σ_{a≠0} A_P(a(t−b)) = Σ_{d≠0} A_P(du²)。判别式为 0 的二次位移 d(t−b)² 共 q(q−1) 个，由平移不变性，它们的和也是 q·Σ_d A_P(dt²) = T。

**§4 T 的范数、迹计数。** 成立。
- 平移把 at + b 化为 at，Σ_{a≠0} A_P(at) = Σ m(m−1)。
- z ≠ 1 时，Tr((1−z)α) = 0 定义一个二维子空间。
- α ∈ F_q^× 落在其中 ⇔ Tr z = 3；β ∈ F_q^× ⇔ Tr z⁻¹ = 3。两类不相交（3 ≠ 0）。
- 范数为 1 且迹为 3 的元素，在 F_q 中只有 z = 1，在 F_q 之外有 3M(3,1) = q − ε 个。这里 M(3,1) 正是 R₃ 引理 5 的量。
