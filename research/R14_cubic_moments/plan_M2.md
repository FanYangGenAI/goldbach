# M₂ 的证明计划与当前进展（未完成）

M₂ = Σ_h A_L(h)·A_P(h)（第十四轮审阅式 6），其中 h 取遍次数 < 3 的多项式。
- A_L(h) = #{G ∈ L：G + h ∈ L}；
- A_P(h) = #{H ∈ P：H + h ∈ P}。

两者都在仿射变换 t ↦ λt + μ（连同 λ^{−3} 归一化）下不变，因此可以按 h 的仿射类分组：

| h 的类 | 个数 | 代表元 |
|---|---|---|
| 0 | 1 | 0 |
| 非零常数 | q − 1 | （A_L 已证为常数：q(q²−1)/4，审阅式 7） |
| 一次 | q(q−1) | at，a 取平方类或非平方类，各 q(q−1)/2 个 |
| 二次 | q²(q−1) | t² + e，e ∈ F_q，每个代表元对应 q(q−1) 个 h |

`m2_decomp.py` 对 q ≤ 23 精确计算了各类的值，原始输出在 `m2_out.txt`。已观察到（尚未证明）：

- **一次类**：A_L 与 A_P 在两个平方类上相同。
  - A_L(at) = (q³ + q² − 5q − 1)/4；
  - A_P(at) = (q−1)²(q+2)/9（q ≡ 1），(q+1)²(q−2)/9（q ≡ 2）。
  - 与单个常数位移不同，这些单个值本身就是 q 的多项式。
- **二次类**：A_L(t² + e) 只依赖于 e = 0、e 为平方、e 为非平方（以及 q mod 4）。单个 A_P(t² + e) 不规则，类似椭圆曲线的迹。
  - 只需要三个类和：A_P(t²)、Σ_{e 平方} A_P(t² + e)、Σ_{e 非平方} A_P(t² + e)。
  - 其中两者之和由 Σ_h A_P(h) = |P|² 决定。
- **常数类**：Σ_{h∈F_q^×} A_P(h) 已有 Bary-Soroker–Stix 的结果（审阅式 8）。也可以初等证明：
  - 它等于 Σ_{H 不可约}(q − 1 − |Im H|)；
  - |Im H| 只依赖于 H 的约化形式 t³ + pt，可以用纤维计数和二次曲线 x² + xy + y² = c 的点数算出。

**下一步**：
1. 证明一次类的两个闭式（容斥加插值计数，类似 R₂₁ 的证明）；
2. 求出并证明二次类的平方类和（或平方类与非平方类之差）；
3. 初等证明常数类的和；
4. 合成 M₂ 并与候选式 (3)、(4) 比较。
