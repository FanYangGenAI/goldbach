# 定理 R₂₁：二重根类型的一阶矩（q 为奇素数，q ≠ 3）

R₂₁ = Σ_{a≠b} r((t−a)²(t−b))。

**定理.**

R₂₁ = q²(q−1)²(q+2)/6（q ≡ 1 mod 3），R₂₁ = q(q−1)(q+1)(q²−2)/6（q ≡ 2 mod 3），

与第十四轮审阅的候选式 (3)、(4) 一致。中间量的数值核对见 `terms_R21.py`（q ≤ 43 全部相等）。

## 0. 仿射归约
仿射变换 t ↦ λt + μ（F ↦ λ^{−3}F(λt+μ)）保持“首一三次不可约”，也保持 L（常数倍不可约仍是常数倍不可约），因此保持 r。它在 {(t−a)²(t−b)：a ≠ b} 上作用自由且传递，所以 R₂₁ = q(q−1)·r(F₀)，F₀ = t²(t−1)。

## 1. 一般的容斥公式（对任意首一三次 F 成立）
三次多项式 H 不可约 ⇔ H 在 F_q 中无根。记 Z(H) 为 H 的不同根数，则对一切三次多项式（含重根情形）都有 1[Z = 0] = 1 − Z + C(Z, 2) − C(Z, 3)。取 H = F − G 对 G ∈ L 求和：

r(F) = |L| − T₁ + T₂ − T₃，其中
- T₁ = Σ_x n₁(F(x))，n₁(v) := #{G ∈ L：G(x) = v}；
- T₂ = Σ_{x<y} n₂(x, y)，n₂ := #{G ∈ L：G(x) = F(x)，G(y) = F(y)}；
- T₃ = #{三元子集 X：F − ∏_{x∈X}(t − x) ∈ L}。

这里用到：在 X 上插值 F 的次数 ≤ 2 的多项式恰为 F − ∏(t−x)。

### 引理 A（一般的 n₁、n₂）
- n₁(v) = (q−1) + (q²−q)/2（v ≠ 0），n₁(0) = q − 1。
- 记 u = F(x)，v = F(y)，则 n₂ = 1[u ≠ v] + 1[uv ≠ 0]·(q − η(uv))/2。

证明 n₂：
- 一次 G = c(t+β) 过两点 ⇔ c = (v−u)/(y−x) ≠ 0。
- 二次部分：对 c ≠ 0，插值式 G = c(t−x)(t−y) + ℓ(t) 唯一，其判别式为
  D(c) = (x−y)²c² − 2(u+v)c + m²，其中 m = (v−u)/(y−x)。
  （一次项的整理用到 m(x+y) + 2(u − mx) = u + v。）
- D 关于 c 的判别式为 16uv。uv ≠ 0 时：
  - Σ_{c∈F_q} η(D) = −1，减去 c = 0 项 η(m²) = 1[u ≠ v]；
  - D 在 F_q 中有 1 + η(uv) 个根，其中 c = 0 是根当且仅当 u = v。

  代入“非平方个数 = (q − 1 − Σ_{c≠0}η − #{c≠0 的根})/2”即得 (q − η(uv))/2。
- uv = 0 时，不可约二次式不能在 x 或 y 处取 0，所以没有二次项贡献。∎

## 2. F₀ = t²(t−1) 的各项
记 S = F_q ∖ {0, 1}。

**T₁** = (q−2)[(q−1) + (q²−q)/2] + 2(q−1) = q²(q−1)/2。

**T₂ = (q−1)³/4 + 1[q ≡ 1]。**
- 第一部分：#{x<y：F₀(x) ≠ F₀(y)} = C(q,2) − (6N₃ + 4)/2。这里 φ = t²(t−1) 的分支纤维 {0,1}、{2/3, −1/3} 给出 4。N₃ 由二次曲线 v₁² + v₁v₂ + v₂² − v₁ − v₂ = 0（e₁ = 1，e₂ = 0）计算，与 R₃ 证明的引理 4 相同：6N₃ = q − 7 或 q − 5。
- 第二部分：Σ_{x<y∈S} (q − η(F₀(x)F₀(y)))/2，其中 η(F₀(x)) = η(x−1)，并且 Σ_{x∈S} η(x−1) = −η(−1)（第十五轮审阅更正：原文误写为 −1；下面只用到它的平方 1，结论不变）。于是 Σ_{x<y} η = (1 − (q−2))/2，第二部分 = (q−3)(q−1)²/4。
- 两部分相加：q ≡ 1 时得 (q−1)³/4 + 1，q ≡ 2 时得 (q−1)³/4。

**T₃ = (q³ − 5q² + 7q + 9)/12（q ≡ 1），(q³ − 5q² + 7q + 1)/12（q ≡ 2）。**

F₀ − ∏(t − xᵢ) = (e₁ − 1)t² − e₂t + e₃。它属于 L 当且仅当：
- (i) e₁ = 1 且 e₂ ≠ 0；或
- (ii) e₁ ≠ 1 且 E := e₂² − 4(e₁−1)e₃ 为非平方。

下面按有序的不同三元组计数，最后除以 6。

- **(i)** e₁ = 1 的有序不同三元组共 (q−1)(q−2) 个（容斥）。其中 e₂ = 0 的有 6N₃ 个。
- **(ii)** 固定 x ≠ y，E 关于 z 是二次式 δz² + 2p(2−s)z + p²，其中 s = x+y，p = xy，δ = (x−y)² ≠ 0。它关于 z 的判别式为 16p²(1−x)(1−y)。
  - x、y ∈ S 时，判别式非零。全部 z 中非平方的个数为 (q − η((1−x)(1−y)))/2。
  - x 或 y ∈ {0, 1} 时，E 是 δ 乘以平方，没有非平方值。
- **扣除重复根的 z**：
  - z = 1 − s 时 e₁ = 1，E 是平方，本来就不计入，无需扣除。
  - z = x 时 η(E) = η(x² + 4y(1−x))。对固定的 x ∈ S，这是 y 的仿射双射。y ∈ {0, 1} 时取值为平方；y = x 时取值为 x(4 − 3x)。所以
    Σ_{x≠y∈S} 1[η = −1] = (q−2)(q−1)/2 − (q + η(−3) − 2)/2。
  - 由对称性，z = y 的扣除量与 z = x 相同。
- 合并：
  - Σ_{x≠y∈S} (q − η((1−x)(1−y)))/2 = (q−3)(q−1)²/2，用到 Σ_{x≠y} η((1−x)(1−y)) = 1 − (q−2)。
  - 所以 (ii) = (q−3)(q−1)²/2 − (q−2)(q−1) + (q − 2 + η(−3))。
- (i) + (ii)：q ≡ 1 时为 6 + (q−3)(q−1)²/2，q ≡ 2 时为 2 + (q−3)(q−1)²/2。除以 6 即得 T₃。

## 3. 合成
r(F₀) = q(q²−1)/2 − q²(q−1)/2 + T₂ − T₃（代数化简已用 SymPy 核对）：
- q ≡ 1：r(F₀) = q(q−1)(q+2)/6；
- q ≡ 2：r(F₀) = (q+1)(q²−2)/6。

乘以 q(q−1) 即得定理。∎

**标记**：初等恒等式；只用到单变量二次特征和的标准公式 Σ_z η(az² + bz + c) = −η(a)（判别式非零时），以及光滑二次曲线的点数。引理 A 对任意 F 成立，可以直接用于其余类型。
