# O3（通宵，探索性）函数域 F_q[t] 中的哥德巴赫问题

> 分支 `gb/O3-function-field`。**探索性，不设预注册判据。** 函数域版本的理论预测（尤其奇异级数的写法）需要先请审阅核对。运行器 `o3_function_field.py` 与本文件在全量运行前一同提交。冒烟测试（q = 3 的 n = 3…8，q = 5 的 n = 3…5）已通过，并用独立的暴力程序 `brute_check.py`（逐个试除判断不可约性）核对了 q = 3、n = 3、4 的全部 r(F)：均值与失败个数完全一致。

## 定义
- 对每个次数为 n 的首一多项式 F ∈ F_q[t]：r(F) = #{G ∈ F_q[t]：deg G < n，G ≠ 0，G = c·（首一不可约），且 F − G 是 n 次首一不可约}。这里 F − G 总是 n 次首一的。
- 计算方法：以低 n 个系数为坐标，把 r 写成加法群 (Z/q)^n 上的卷积，用 n 维 FFT 一次算出全部 F。Ω（重数计）用不可约多项式的幂对所有首一多项式做筛法得到；每个次数的不可约个数都与 Möbius 公式核对。
- **HL 型预测**：r_pred(F) = π_n · #{不可约 G, deg G < n} / q^n · 𝔖(F)，其中
  𝔖(F) = ∏_{π∤F, deg π ≤ n}(1 − 1/(|π|−1)²) · ∏_{π∣F} |π|/(|π|−1)，|π| = q^{deg π}。
  这是整数情形的直接类比。函数域里没有 p = 2 的特殊因子，因为特征 q 是奇数。
- 报告：r 的均值、最小值；**r(F) = 0 的个数（哥德巴赫失败）及例子**；r/r_pred 的均值、标准差、极值；corr(r, 𝔖)。对 q^n ≤ 6×10⁶ 的情形，另计算 Ω 扇区表（两侧 Ω ∈ {1,2,3}），并对 200 个随机 F 计算 E1 式的振幅编码纠缠熵，以及 (1,1) 格相关与 𝔖 的比值。

## 计划
q = 3，n = 3…15；q = 5，n = 3…10；q = 7，n = 3…8。

## 关注的问题
1. 小 q 时哥德巴赫在函数域中会失败（例如 F₃[t] 的 3 次、4 次已有失败）。失败只出现在小 n 吗？它与 𝔖(F) 或局部障碍有什么关系？
2. HL 型预测的精度如何随 q、n 变化？
3. 与整数情形对比：纠缠熵、(1,1) 格相关等量在函数域中是否表现出相同的结构？
