# O3（通宵，探索性）函数域 F_q[t] 中的哥德巴赫问题

> 分支 `gb/O3-function-field`。**探索性，不设预注册判据。** 函数域版本的理论预测（尤其奇异级数的写法）需要先请审阅核对。运行器 `o3_function_field.py` 与本文件在全量运行前一同提交。冒烟测试（q = 3 的 n = 3…8，q = 5 的 n = 3…5）已通过，并用独立的暴力程序 `brute_check.py`（逐个试除判断不可约性）核对了 q = 3、n = 3、4 的全部 r(F)：均值与失败个数完全一致。

## 定义
- 对每个次数为 n 的首一多项式 F ∈ F_q[t]：r(F) = #{G ∈ F_q[t]：deg G < n，G ≠ 0，G = c·（首一不可约），且 F − G 是 n 次首一不可约}。这里 F − G 总是 n 次首一的。
- 计算方法：以低 n 个系数为坐标，把 r 写成加法群 (Z/q)^n 上的卷积，用 n 维 FFT 一次算出全部 F。Ω（重数计）用不可约多项式的幂对所有首一多项式做筛法得到；每个次数的不可约个数都与 Möbius 公式核对。
- **HL 型预测**：r_pred(F) = π_n · #{不可约 G, deg G < n} / q^n · 𝔖(F)，其中
  𝔖(F) = ∏_{π∤F, deg π ≤ n}(1 − 1/(|π|−1)²) · ∏_{π∣F} |π|/(|π|−1)，|π| = q^{deg π}。
  这是整数情形的直接类比。函数域里没有 p = 2 的特殊因子，因为特征 q 是奇数。
- 报告：r 的均值、最小值；**r(F) = 0 的个数（哥德巴赫失败）及例子**；r/r_pred 的均值、标准差、极值；corr(r, 𝔖)。对 q^n ≤ 6×10⁶ 的情形，另计算 Ω 扇区表（两侧 Ω ∈ {1,2,3}），并对 200 个随机 F 计算 E1 式的振幅编码纠缠熵，以及 (1,1) 格相关与 𝔖 的比值。

## 计划
q = 3，n = 3…15；q = 5，n = 3…10；q = 7，n = 3…8。

## 关注的问题
1. 小 q 时哥德巴赫在函数域中会失败（例如 F₃[t] 的 3 次、4 次已有失败）。失败只出现在小 n 吗？它与 𝔖(F) 或局部障碍有什么关系？
2. HL 型预测的精度如何随 q、n 变化？
3. 与整数情形对比：纠缠熵、(1,1) 格相关等量在函数域中是否表现出相同的结构？

**观察（探索性，没有事前判据）：**
1. **哥德巴赫失败只出现在 F₃[t] 的 3 次（2 个）和 4 次（3 个）**。在全部测试范围内（q=3 到 15 次，约 1400 万个 F；q=5 到 10 次；q=7 到 8 次），n ≥ 5 时没有失败，且最小 r/r_pred 随 n 单调地趋向 1。
2. **3 次的失败有一个完整的初等解释（事后得到）**：两个失败是 F = t³ − t + c（c = 1, 2），即 Artin–Schreier 多项式，它在所有平移 t → t + a 下不变（这正是仿射群 Aff(F₃) 的平移部分）。由于 a³ = a，F 在 F₃ 的每一点上取值都是 c。三次多项式 F − G 不可约 ⇔ 它在 F₃ 中无根 ⇔ G 在 F₃ 上处处不取值 c。但每个一次多项式取遍所有值，而每个首一不可约二次多项式在 F₃ 上恰好取到 1 和 2 两个非零值（乘以常数后仍然如此）。因此每个 G 都在某点取值 c，F − G 有根，r(F) = 0。这是一个 **“值集”障碍**：它来自“次数相对 q 很小”，而 HL 奇异级数 𝔖(F) 完全看不见它（𝔖(F) > 0）。4 次的 3 个失败都是不可约的，且不具平移不变性；其机制未分析。
3. **HL 类比极准**：r/r_pred 的均值以约 q^{−n} 的速度趋于 1；corr(r, 𝔖) → 1。
4. **涨落的尺度是平方根级且是亚泊松的**：rel 的标准差 × √(平均 r) 在每个 q 上大致恒定（q=3 约 0.6，q=5 约 0.45，q=7 约 0.4），即 sd(r − r_pred) ≈ c_q √r，c_q < 1。整数情形的对应量（L3 系列）同样是平方根级。
5. 纠缠熵中位数随 n 单调下降到 0（q=3：0.09 → 0.0035），与整数情形 E1 的“纠缠由小素数整除性决定、且递减”一致。(1,1) 格相关 / 𝔖 在 q=5、7 时约为 1（0.98–1.01）；在 q=3 时随 n 缓慢升到 1.06，原因未查（候选：只用了 Ω ∈ {1,2,3} 的截断）。

**教训**：函数域给出一个 n ≥ 5 时完全可算的“试验田”，在那里 HL 的精度远高于整数情形。唯一的失败来自一种 𝔖 之外的局部障碍（值集），这提示整数情形中“局部 = 𝔖”的等式在函数域需要加上“小次数”修正。
