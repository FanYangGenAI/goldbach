# O15（通宵）函数域哥德巴赫纤维上的 Liouville 二点和（Chowla 型）— 预注册

> 分支 `gb/O15-ff-chowla`（从 `gb/O10-ff-largeq` 分出）。设计与运行器 `o15_ff_chowla.py` 在全量运行前一同提交。

## 对象
对每个 n 次首一 F，定义 Λ(F) = Σ_{G：deg G < n，G ≠ 0} λ(G)·λ(F − G)，其中 λ = (−1)^Ω（对 G 取首一化），l(F) = Λ(F)/(qⁿ − 1)。这是奇偶性（Liouville）在固定和纤维上的二点相关，即 χ 的“未截断”版本。函数域中的 Chowla 型结果（大 q 极限下，例如 Carmon–Rudnick）预计 l(F) 很小。

报告：
- l 的均值；
- sd(l)·q^{n/2}：如果每个配对的符号是独立随机的，该值为 1；
- max|l|；
- F 的分解型解释的 Var(l) 比例 R²_type。

## 计划
q=3，n=4…15；q=5，n=3…10；q=7，n=3…8；q=11…31，n=3…5；q=37、41、43，n=3、4；q=53…97，n=3。

## 预注册判据
- **H1（随机符号尺度）**：所有 n ≥ 4 的 (q, n)，sd(l)·q^{n/2} ∈ [0.7, 1.3]。
- **H2（非局部）**：每个 q 的最大 n（n ≥ 4）上，R²_type < 0.1。
- **H3（高斯型极值）**：所有 n ≥ 5 的 (q, n)，max|l|·q^{n/2}/√(2 ln qⁿ) < 1.5。

## 运行前已知的信息（如实披露）
冒烟（q=3，n=6、8；q=5，n=4、5；q=11，n=3、4）：n ≥ 4 时 sd(l)·q^{n/2} = 0.90–1.00，R²_type = 0.01–0.06；q=11、n=3 时为 0.46，R²_type = 0.29。均值的绝对值都很小，最大为 0.006。

---

## 结果（运行 138 秒；全部 F 穷举；逐行见 `out/o15_summary.json`、`out/o15_log.txt`）

| 情形 | sd(l)·q^{n/2} | R²_type | max\|l\|·q^{n/2}/√(2 ln qⁿ) |
|---|---|---|---|
| n ≥ 4，全部 (q, n) | **0.905–1.042** | 0.0001–0.10（随 n、q 单调下降） | 0.62–1.98 |
| q=3，n=15 | 1.003 | 0.0003 | 1.18 |
| q=5，n=10 | 0.999 | 0.0003 | 0.86 |
| q=31，n=5 | 1.002 | 0.0001 | 1.32 |
| n = 3，q = 11…97 | 0.46 → 0.145（约 1.45/√q） | 0.29 → 0.47 | 0.07–0.28 |

均值 |mean(l)|·q^{n/2} ≤ 0.2，随 n 迅速趋于 0。

**预注册判定**：
- **H1 ✓**：所有 n ≥ 4 的 sd(l)·q^{n/2} 都在 [0.905, 1.042] 内。
- **H2 ✓**：每个 q 的最大 n 上 R²_type ≤ 0.002。
- **H3 ✗**：q = 3、n = 6…10（1.52–1.98）与 q = 5、n = 6（1.52）超过 1.5；其余都通过。小 q 时极值比高斯更重，但随 n 增大回落（q=3：1.98 → 1.18）。

**解读**：
- 在函数域的哥德巴赫纤维上，Liouville 二点和的涨落 **恰好是独立随机符号的尺度**：sd·q^{n/2} = 1.00 ± 0.05，n ≥ 4 时与 F 的分解型无关。这是“奇偶性信息像随机符号一样分布”的直接数值形式。在大 q 极限下，它与已知的函数域 Chowla 型定理方向一致。在固定 q、大 n 时，这里给出的是数值证据，不是证明。
- n = 3 又是特例：涨落比随机符号小约 √q 倍，而且接近一半由分解型决定。这与 O10 中 n = 3 的特殊性（c² = 1/q，分解型主导）相同。
- 小 q（q = 3）时有更重的尾部。这与 O3 中只有 F₃[t] 有哥德巴赫失败相呼应，都是小 q 下的值集效应。这一点没有进一步分析。
