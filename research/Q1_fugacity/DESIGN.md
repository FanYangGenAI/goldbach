# Q1/Q3 双逸度配分函数：扇区转移矩阵与 Lee–Yang 零点 — 预注册

> 分支 `gb/Q1-fugacity-sectors`。框架见 gb/hub 的 `docs/research/quantum_partition_function_framework.md`。运行前提交。

## 对象

G_N(z,w) = Σ_{n=2}^{N−2} z^{Ω(n)} w^{Ω(N−n)} = Σ T_jk(N) z^j w^k；H_N(z) = G_N(z,z) = Σ_m h_m z^m，h_2 = r(N)。

## Q1：扇区相关矩阵

C_jk(N) = T_jk(N) / Ind_jk(N)，其中 Ind_jk = row_j·col_k/(N−3) 用的是同一批 n 上的实际边际分布（即“两侧粒子数独立”的预测）。C_jk 度量反射 n ↦ N−n 在扇区之间引入的相关。

- **P1（预注册）**：(1,1) 角落的相关等于奇异级数：在 N ≈ 10⁶、10⁷、10⁸ 各 30 个随机偶数上，C_11(N)/𝔖(N) 的中位数 ∈ [0.9, 1.1]，其中 𝔖(N) = 2C₂∏_{p|N,p>2}(p−1)/(p−2)。
- **描述性输出（不预设结论）**：C_jk 在 j,k ≤ 8 上的整张表，及其对 𝔖(N) 的依赖（按 N 的奇异级数大小分组）。关心的问题：(1,1) 是否只是一个光滑表面在角落的延续？

## Q3：H_N(z) 的零点

用 mpmath（50 位精度）求 H_N(z)/z² 的全部零点（次数约为 2log₂N）。

- **开放问题（预注册两种结局）**：H_N 是否 **实根性**（全部零点在负实轴上）？
  - 结局 A：对所测的全部 N 都是实根性 → 这是一个 Lee–Yang 型结构性质，值得找证明或反例；
  - 结局 B：存在非实零点 → 记录非实零点的位置、比例及最大虚部，描述零点集的形状。
- 同时记录 H_N/z² 离原点最近的零点模长 δ_N（哥德巴赫 ⇔ 原点不是 H_N/z² 的零点），以及它与 r(N)/h_3(N) 的关系。
- 对照：单系统多项式 F_x(z) = Σ_{n≤x} z^{Ω(n)} 的零点。

## 结果（运行 7 秒）

### Q1：P1 ✓
C_11(N)/𝔖(N) 的中位数：0.9965（10⁶）、0.9973（10⁷）、0.9974（10⁸）。哥德巴赫角落的扇区相关 **就是** 奇异级数。

整张相关表（N≈10⁸，30 个 N 的平均，j, k = 1…8）呈现一个 **光滑的鞍形曲面**：(1,1) 角为 1.90，沿对角线先降到约 1.0（j=k=3、4），再升到 1.74（j=k=8）；反对角方向下降（(1,8) 为 0.125）。log C_jk 对 log 𝔖(N) 的斜率在 (1,1) 恰为 **1.00**，向 (1,8) 方向变为强负（−5.3）。
**解读**：(1,1) 不是孤立的特殊点，而是一个由 “n 与 N−n 共享小素因子整除性” 决定的整体曲面在角上的值。

### Q3：结局 B（非实根性）
H_N(z)/z² 的零点大多是复数（每个 N 只有 1–5 个负实零点），模长约在 0.5–2.3 之间，离原点最近的零点模长 0.50–0.79，并不随 N 靠近原点。

**一个意料之外的规律**：最靠近原点的零点总是聚在 **z ≈ −1** 附近，成团出现（一对复零点 + 一个实零点，例如 −0.66±0.24i、−0.81）。单系统对照 F_x(z) = Σ_{n≤x} z^{Ω(n)} 在 x = 10⁸ 时，最近零点恰好是 **−1.01**（单个）。

这与 Selberg–Delange 理论完全吻合：Σ_{n≤x} z^{Ω(n)} ≈ x(log x)^{z−1}·A(z)/Γ(z)，而 1/Γ(z) 的零点正好在 0, −1, −2, …。单系统在 −1 处有 **单** 零点；双系统的对应近似为 G_N(z,w) ≈ N(log N)^{z+w−2}·𝒜_N(z,w)/(Γ(z)Γ(w))，对角线上是 1/Γ(z)²，在 0 和 −1 处各有 **二重** 零点。有限 N 时，−1 处的二重零点分裂成我们看到的零点团。

**框架内的含义**：哥德巴赫 ⇔ H_N 在原点 **恰好** 是二重零点。在上述近似中，这个二重零点正是 1/Γ(z)² 的第一个二重零点，它的“留数”就是 𝒜_N(0,0)·N/log²N，也就是 Hardy–Littlewood 预测。所以这个框架把 HL 公式重新解释为“配分函数 Γ 结构在原点的系数”。−1 附近的零点团则是同一结构的第二个成员，是一个 **可以数值检验** 的伴随预测。

## Q1b 预注册：欧拉乘积局部因子模型

**模型**（两变量 Selberg–Delange 型拟设）：
  G_N(z,w) ≈ N·(log N)^{z+w−2}·𝒜_N(z,w) / (Γ(z)Γ(w))，  𝒜_N(z,w) = ∏_p J_p(z,w; ν_p(N))·(1−1/p)^{z+w−2}，
其中 J_p 是 n 在 p 进意义下均匀分布时 E[z^{ν_p(n)} w^{ν_p(N−n)}] 的精确值：
  J_p(0) = 1 − 2/p + (1/p)·z·Z_p(z) + (1/p)·w·Z_p(w)，Z_p(z) = (1−1/p)/(1−z/p)；
  J_p(e) = (1/p)·z·w·J_p(e−1) + (1 − 1/p)，e ≥ 1。
（检验：z=w=1 时 G=N；[zw] 系数给出 N·𝔖(N)/log²N，即 HL。）模型系数 T^model_jk 由半径 1 的圆周上 128×128 点的二维 FFT 得到。模型 **没有任何拟合参数**。

**预测**（对与 Q1 相同的 N 样本，N≈10⁸）：
- **P2**：对 j, k ≤ 4，模型的相关 C^model_jk 与实测 C_jk（30 个 N 平均）满足 |log C^model − log C^obs| < 0.10。
- **P3**：用模型系数（截断到与实测相同的次数）构造多项式，其离 −1 最近的三个零点的质心，与实测零点团质心的距离 < 0.15（对 5 个 N 取中位数）。
- 描述性输出：j, k ≤ 8 的完整误差表。

## Q1b 结果（无拟合参数，运行 45 秒）

- **P2 ✓**：j, k ≤ 4 时，模型与实测的 log C 最大偏差为 0.038（10⁶）、0.034（10⁷）、**0.030**（10⁸），并随 N 减小。整张 8×8 表上的偏差大多 < 0.04，最大处在“一侧素数、另一侧高度合数”的格子，(1,6) 为 −0.135；(1,1) 角的偏差只有 0.001。
- **P3 ✓**：模型多项式在 −1 附近零点团的质心与实测质心的距离，中位数为 0.135（10⁶）、0.159（10⁷）、**0.123**（10⁸）。只有 10⁸ 的值是预注册判据，它满足 < 0.15；10⁷ 的值略高于 0.15。

**结论**：一个由“每个素数 p 的局部配分函数”乘起来、再乘以 Γ 结构的零参数公式，同时重现了：
(i) 反射在全部粒子数扇区之间的相关曲面（哥德巴赫只是其中一格）；
(ii) 配分函数零点在 −1 附近的位置。
哥德巴赫的 HL 公式是这个统一公式在 (1,1) 格的特例。

## Q2 预注册：误差在复逸度上的“相位地图”

定义误差 E_N(z,w) = G_N(z,w) − G^model_N(z,w)。由柯西估计，对任意 ρ > 0：
  |r(N) − [zw]G^model| ≤ ρ^{−2}·max_{|z|=|w|=ρ} |E_N|。
所以若存在 ρ，使 **预算 B_N(ρ) := max_{|z|=|w|=ρ}|E_N| / (ρ²·[zw]G^model) < 1**，则 r(N) > 0。这是本框架里一个精确的充分条件（它把哥德巴赫化为“配分函数误差在一个复圆周上一致地小”）。

- **P4**：相对误差 |E_N/G^model| 在圆周上的最大值出现在 arg z、arg w 都接近 π（负逸度，即“奇偶性方向”）的区域。具体判据：在 N≈10⁸ 的 5 个 N、ρ ∈ {0.5, 1} 上，最大值位置满足 |arg z| > 2π/3 且 |arg w| > 2π/3。
- **开放测量**：对每个 N 求 min_ρ B_N(ρ)，报告它的大小以及随 N 的变化趋势。只作测量，不预设结论。

## Q2 结果（10 个 N：5 个 ≈10⁶，5 个 ≈10⁸）

- **P4 ✓（10/10）**：在 ρ = 0.5 与 1 上，相对误差 |E/G^model| 的最大值都出现在 arg z ≈ arg w ≈ ±π 附近，即负逸度的“奇偶性方向”。
- 量级对比（ρ = 0.5）：正实方向的相对误差为 1%–3.5%；负实方向为 5%–200%，大 10–50 倍。ρ = 1 时，模型在 z = w = −1 处恰好为零（1/Γ(−1) = 0），相对误差发散。
- 预算 B_N(ρ)：ρ = 0.25 时为 0.16–0.31，ρ = 0.5 时为 0.26–0.55，ρ = 0.75 时为 0.7–1.4，ρ ≥ 1 时 ≫ 1。

**诚实的解读**：小 ρ 时 B < 1 **不是** 新证据。在小圆周上，|E| 主要由低阶系数（包括 (1,1) 本身）的误差决定，所以“B<1”几乎就是在说“模型的 (1,1) 系数准”，是循环的。真正有信息的是 **相位结构**：同一个半径上，误差集中在负逸度方向，比正逸度方向大一到两个数量级。这把“奇偶性障碍 = 相位信息”从一句比喻变成了可测量的事实：两变量 Selberg–Delange 拟设在正实轴附近很准（这是已知方法原则上能控制的区域），在负实轴附近则差得多（这正是二元 Chowla 所在的区域）。

## Q2b 预注册：相位误差随 N 的变化

在 z = w = +ρ 和 z = w = −ρ（ρ = 0.5）处，测相对误差 ε₊(N)、ε₋(N)，N ≈ 10⁶、10⁷、10⁸、10⁹，每个量级 10 个随机偶数（中位数）。
- **P5**：ε₊(N) 随 N 下降，大致按 1/log N（Selberg–Delange 的次级项量级）：从 10⁶ 到 10⁹，中位数至少下降 25%。
- **开放测量**：ε₋(N) 是否也下降，速度如何。如果它下降得和 ε₊ 一样快，说明“相位一致”的两变量 Selberg–Delange 在数值上成立；如果不下降，就是奇偶性方向上的结构性偏差。不预设结论。

- **P6**：在 x ∈ {0.25, 0.5, 0.75}、N ≈ 10⁹（100 个 N）上，修正模型的 |平均带符号误差| 小于原始主项模型的对应值（三个 x 全部满足）。

### Q4b：−1 附近的零点数（辐角原理 + Rouché）
圆盘 D = {|z + 1| < 0.45}。对 N ≈ 10⁶、10⁷、10⁸，各取 60 个随机偶数：
- 用辐角原理（边界 4096 点）计算真实多项式 H_N(z) 与 **未截断解析模型** M_N(z) = N(log N)^{2z−2}𝒜_N(z,z)/Γ(z)² 在 D 内的零点数 n_H、n_M；

- **P7**：模型零点数 n_M 在 3 ∣ N 与 3 ∤ N 两组之间不同，其中 3∣N 组的众数为 2、3∤N 组的众数为 3（检验模型内引理与 2 进因子的影响）。
- **P8**：在 10⁸ 的样本中，n_H = n_M 的比例 ≥ 80%。
- 开放测量：Rouché 条件成立的比例随 N 如何变化。

- **P8 ✗**：真实多项式 H_N 在同一圆盘内的零点数在 0 到 6 之间分散，与模型一致的比例只有 25%（10⁶）、25%（10⁷）、28%（10⁸）。按 mod 3 分组，真实零点数的均值看不出 2 与 3 的区别（10⁸：3∣N 为 3.41，3∤N 为 3.87）。

**解读**：在 −1 附近，模型主项极小（1/Γ(z)² 在 −1 处为零，并乘以 (log N)^{2z−2} ≈ (log N)^{−4}），真实配分函数几乎完全由“非主项”部分主导。所以 −1 附近零点的位置 **不能** 由模型预测，Q1b 的 P3“通过”主要来自选根方式（与审阅判断一致）。这和 z = w = −1 处的情况一致：模型给出 0，而真实的 Σλ(n)λ(N−n) 是 o(N)，但远大于模型。**在奇偶性方向，主项消失，涨落占主导**，这是同一现象的两种表现。比值随 N 缓慢下降（1.9×10⁴ → 8×10³），但离 1 还差得很远。
