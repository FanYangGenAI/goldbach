# O20（通宵，GPU，探索性）哥德巴赫协方差的精确“对角”部分

> 分支 `gb/O20-kernel-diagonal`（从 `gb/O16-noise-kernel` 分出）。**探索性，没有事前判据。** 冒烟结果在下文披露。

## 动机
O8、O16 发现：残差的方差小于“泊松”基线，跨 N 的协方差核 ≈ a + b·s(h)，其幅度也远小于粗略的 HL 对角估计。这里把乘积精确地分解为两部分：
- **对角部分**：r(N)·r(N+h) = Σ_{n,n′} 1_P(n)1_P(N−n)1_P(n′)1_P(N+h−n′) 中，两对素数共用一个素数的项。
  - h > 0 时等于 4·(P ∗ Q_h)(N)，其中 Q_h(m) = 1_P(m)1_P(m+h) 是“间距 h 的素数对”指示函数；
  - h = 0 时等于 2r(N)。

  这些都在 GPU 上精确计算。
- **非对角部分**：经验协方差减去对角部分，即四个不同素数的项减去 E r·E r′。

## 对象
x = 10⁹、10¹⁰，各一个窗口，H = 2²²。残差 e_N = r(N) − b₂(N)(1 + rel_pred)，同 O13。滞后 L ∈ {1, 2, 3, 4, 5, 6, 7, 8, 10, 15, 21, 30, 35, 105}，即 h = 2L。

报告每个滞后的协方差、对角部分、两者之比，以及 h = 0 时的方差分解。

## 冒烟（已运行；x = 2²²，H = 2^16）
- h = 0：Var(e) = 0.535·b₂，对角部分为 2r ≈ 2b₂，所以非对角部分抵消了对角部分的约 73%。
- h > 0：协方差 / 对角部分约为 +0.03（3 ∣ L），或 −0.02 到 −0.04（3 ∤ L）。也就是说，非对角部分抵消了约 97%–104% 的对角部分。

---

## 结果（RTX 4090；每个窗口 2,097,152 个偶数 N；逐滞后数据见 `out/o20_summary.json`）

| x | c² = Var(e)/b₂ | h = 0：Var / 对角（2r） | h > 0：协方差 / 对角，3 ∣ L | h > 0：协方差 / 对角，3 ∤ L |
|---|---|---|---|---|
| 10⁹ | 0.637 | **0.318** | +0.009 到 +0.024 | −0.006 到 −0.030 |
| 10¹⁰ | 0.669 | **0.334** | +0.018 到 +0.027 | −0.011 到 −0.029 |

**观察（探索性）**：
1. **方差**：对角部分（同一对素数被数两次，即“泊松”基线 2r）中，有约 67% 被四个不同素数的项（减去 E r·E r′）抵消，只剩 32%–33%。这个比例随 x 缓慢上升（0.318 → 0.334），与 c² ≈ 1 − 7.2/log x 一致（c²/2 = 0.318、0.334）。
2. **协方差核**：h > 0 时，对角部分 4(P∗Q_h)(N)（共用一个素数、另两数相差 h 的三元组）几乎被非对角部分 **完全** 抵消，剩下的只占 −3% 到 +3%。剩余部分的符号由 s(h) 决定：3 ∣ L 时为正，否则为负。
3. 所以 O16 的协方差核 a + b·s(h) 是两个大项之差的约 3% 余量。任何 HL 型二阶理论都必须把对角三元组和四元组的非对角相关算到约 1% 的精度，才能预测这个核。这也解释了为什么 L3c 中只算到 HL 主项的方差预测会差一倍。
