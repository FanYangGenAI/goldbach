# Q6 残差合同 v2 与残差统计（探索性）

> 分支 `gb/Q6-residual-statistics`（从 Q5 切出）。回应第八轮审阅 §7、§8。本轮全部为 **探索性** 分析，只用已保存的 300 份整数多项式（Q4b：种子 51，N ∈ [X, 1.1X)，X = 10⁶、10⁷、10⁸，各 60 个；Q5d：种子 2026112301，X = 10⁷、10⁸、10⁹，各 40 个），不重新判定 P9–P11，不扩大 N。

## 1. 背景 v2（单一解析对象）

- 单系统密度：δ̃_z(t) = δ_z(t) + z·t^{−0.45}/log t，其中 δ_z 为 Q5 的割线密度（σ₀ = 0.55，400 节点，素数截点 2×10⁵，尾项用 E₁ 近似）。[z]δ̃_z(t) = 1/log t。
- 一阶局部项（第八轮式 (10)）：B_N(z) = R_N(z)·[I_N(z) − T_N(z)·I_{1,N}(z)]，其中 I_N = ∫_2^{N−2} δ̃_z(t)δ̃_z(N−t)dt，T_N(z) = Σ_p log p·z·∂_z log r_p(z)，r_p = J_p(z,z;ν_p(N))/Z_p(z)²。
- 近似说明：I_{1,N} = ∫(Dδ)(t)δ(N−t)dt 只用未修补的 δ 计算（修补项的相对贡献约为 N^{−0.45}/log N）。因为 T_N(0) = 0、I_{1,N} = O(z²)，这不影响二次系数。
- **二次系数**：[z²]B_N = 𝔖(N)∫_2^{N−2}dt/(log t·log(N−t))（第八轮式 (4)）。
- 对照版本 A（Q5d 所用）：B^A_N = R_N·I_N^{截断}·e^{Δ_N}。

## 2. 残差与概率空间

- E_N(z) = H_N(z) − B_N(z)；D_N(z) = E_N(z)/z²（原点处可去）。E_N 包含：截点选择、未扣除的单系统振荡（第八轮式 (11) 的交叉项）、缺失的局部高阶项、非局部的加性关联。**不称为“纯固定和关联”。**
- 概率空间：在每个 [X, 1.1X) 区间的偶数中均匀独立抽取的 N（即上述两个已保存样本）；按 3∣N / 3∤N 分层。
- 统计量：在圆周 z = 0.5e^{iθ}（θ = 2πk/16）上，报告：(a) 背景版本敏感度 |B_N/B^A_N − 1| 的中位数；(b) 相对残差 ε_N(θ) = E_N/B_N 的未中心化均值（实部、虚部，含标准误）；(c) 中心化后的 Hermitian 协方差核 C(θ,θ') = E[(ε−μ)(θ)·conj((ε−μ)(θ'))]，及其主特征向量所占的方差比例与相位形状；(d) Goldbach 系数漂移 r(N)/[z²]B_N − 1。

## 3. 结果（探索性，300 份保存多项式，运行 49 秒）

**(d) Goldbach 系数漂移（背景 v2，二次系数为式 (4)）**：10⁶、10⁷、10⁸（Q4b）为 −0.21% ± 0.10%、−0.089% ± 0.038%、−0.027% ± 0.013%；Q5d 的 10⁷、10⁸、10⁹ 为 +0.004% ± 0.046%、−0.007% ± 0.016%、−0.020% ± 0.006%。10⁹ 的 3∤N 组为 −0.029% ± 0.008%（3.6 倍标准误），仍有可测偏差。

**(a) 背景版本敏感度**：v2 与 A 的相对差中位数为 0.15%–0.9%（随 N 增大而减小）。它 **大于** 正实轴（θ = 0）上的未中心化均值残差（−0.02% 到 −0.2%）。按第八轮审阅的标准，正实轴上的均值残差在背景定义统一到更高阶之前不能解释。

**(b) 未中心化均值**：θ = π/2（纯虚 z = 0.5i）的虚部均值在所有规模都约为 −0.1% 到 −0.2%，是系统性的相位偏差。θ = π（z = −0.5）的实部均值在 −9% 到 +4% 之间，符号随分组变化，且 3∤N 组的离散度很大。

**(c) 中心化协方差**：
- 用相对残差 ε = E/B 衡量时，主特征向量占 80%–97% 的方差，集中在 θ = π 附近。但这主要是因为背景在负方向较小，相对误差被放大（第六、七轮审阅已指出）。
- 改用绝对尺度 D_N/N = E_N/(z²N) 衡量（10⁹）：仍然是 **一个模态占 83%**，但它集中在 |θ| ≈ 0.4π–0.5π（虚方向附近），而不是负实轴。

## 4. Q6b（探索性）：主导涨落模态是哪个“粒子数扇区”

用 16 点 FFT（Parseval）把 D_N 在 |z| = 0.5 上的中心化方差分解到 Taylor 系数 e_m = [z^m]E_N 上，m = Ω(n)+Ω(N−n) 是“总粒子数”扇区：

| 样本 | m=2（素数+素数） | m=3（素数+半素数） | m=4 | m=5 | 主模态与 e₃ 的相关 |
|---|---|---|---|---|---|
| Q4b 10⁶ | 15% | 51% | 19% | 11% | 0.98 |
| Q4b 10⁸ | 3.6% | 51% | 17% | 18% | 0.98 |
| Q5d 10⁹ | 0.6% | 41% | 22% | 17% | 0.98 |

**解读**：在原点附近的圆周上，固定和残差的涨落主要来自 **m = 3 扇区**，即“一侧素数、一侧半素数”的配对（陈景润类型的表示）。主模态几乎就是 e₃（相关 0.98–0.99）。到 10⁹ 时，e₂、e₃、e₄、e₅ 之间也高度相关（与主模态的相关为 0.34、0.98、0.92、0.84、0.91），说明各扇区的涨落有一个共同的驱动，候选是第八轮式 (11) 中单系统误差与平均密度的交叉项。哥德巴赫所在的 m = 2 扇区在这个半径上只占很小的方差份额。

以上都是有限样本的描述性统计，没有建立任何渐近定律。

## 勘误（第九轮审阅后）
