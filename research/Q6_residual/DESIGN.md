# Q6 残差合同 v2 与残差统计（探索性）

> 分支 `gb/Q6-residual-statistics`（从 Q5 切出）。回应第八轮审阅 §7、§8。本轮全部为 **探索性** 分析，只用已保存的 300 份整数多项式（Q4b：种子 51，N ∈ [X, 1.1X)，X = 10⁶、10⁷、10⁸，各 60 个；Q5d：种子 2026112301，X = 10⁷、10⁸、10⁹，各 40 个），不重新判定 P9–P11，不扩大 N。

## 1. 背景 v2（单一解析对象）

- 单系统密度：δ̃_z(t) = δ_z(t) + z·t^{−0.45}/log t，其中 δ_z 为 Q5 的割线密度（σ₀ = 0.55，400 节点，素数截点 2×10⁵，尾项用 E₁ 近似）。[z]δ̃_z(t) = 1/log t。
- 一阶局部项（第八轮式 (10)）：B_N(z) = R_N(z)·[I_N(z) − T_N(z)·I_{1,N}(z)]，其中 I_N = ∫_2^{N−2} δ̃_z(t)δ̃_z(N−t)dt，T_N(z) = Σ_p log p·z·∂_z log r_p(z)，r_p = J_p(z,z;ν_p(N))/Z_p(z)²。
- 近似说明：I_{1,N} = ∫(Dδ)(t)δ(N−t)dt 只用未修补的 δ 计算（修补项的相对贡献约为 N^{−0.45}/log N）。因为 T_N(0) = 0、I_{1,N} = O(z²)，这不影响二次系数。
- **二次系数**：[z²]B_N = 𝔖(N)∫_2^{N−2}dt/(log t·log(N−t))（第八轮式 (4)）。
- 对照版本 A（Q5d 所用）：B^A_N = R_N·I_N^{截断}·e^{Δ_N}。

## 2. 残差与概率空间

- E_N(z) = H_N(z) − B_N(z)；D_N(z) = E_N(z)/z²（原点处可去）。E_N 包含：截点选择、未扣除的单系统振荡（第八轮式 (11) 的交叉项）、缺失的局部高阶项、非局部的加性关联。**不称为“纯固定和关联”。**
- 概率空间：在每个 [X, 1.1X) 区间的偶数中均匀独立抽取的 N（即上述两个已保存样本）；按 3∣N / 3∤N 分层。
- 统计量：在圆周 z = 0.5e^{iθ}（θ = 2πk/16）上，报告：(a) 背景版本敏感度 |B_N/B^A_N − 1| 的中位数；(b) 相对残差 ε_N(θ) = E_N/B_N 的未中心化均值（实部、虚部，含标准误）；(c) 中心化后的 Hermitian 协方差核 C(θ,θ') = E[(ε−μ)(θ)·conj((ε−μ)(θ'))]，及其主特征向量所占的方差比例与相位形状；(d) Goldbach 系数漂移 r(N)/[z²]B_N − 1。
