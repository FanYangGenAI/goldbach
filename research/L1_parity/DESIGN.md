# L1 奇偶性探针 — 实验 E1.1 预注册设计

> 分支 `gb/L1-parity-probe`。本文件在运行之前提交，判据不得事后修改。

## 动机（墙 B）

取 z = N^{1/3}。对素数 p ≤ N/2，记 m = N − p ∈ [N/2, N)。若 m 没有 ≤ z 的素因子（“z-粗糙”），则 m 只能是 **素数**（λ(m) = −1）或 **两个 > N^{1/3} 的素数之积**（λ(m) = +1）。
筛法能精确算出粗糙 m 的个数 R(N)，但由于奇偶性障碍，它无法区分这两类。哥德巴赫的反例在筛法看来等价于：**所有粗糙的 N − p 恰好都是 P₂**。

定义素数份额
  f(N) = #{p ≤ N/2 : N−p 素数} / R(N)，等价地 B(N) := 平均 λ(N−p) = 1 − 2f(N)。

本实验度量“现实离奇偶性反例有多远”，以及 f(N) 是否携带 N 的算术信息。

## 假设 H

f(N) 的行为像对每个粗糙 m 独立抛一枚硬币，硬币偏置只由 m 的大小决定，不依赖 N 的算术（N mod q、奇异级数 S(N)）。

## 预测（带容差）

- 基线 f_loc(N)：区间 [N/2, N) 内全部 z-粗糙整数中素数的加权占比（权重 1/log(N−m)，模拟 p 的密度）。渐近极限 f* = 1/(1+log 2) ≈ 0.5906；有限规模下数值另算。
- **P1**：各窗口的平均 f(N) 与 f_loc 的相对偏差 < 0.5%。
- **P2**：按 N mod 3、5、7 分类的类均值，以及与 log S(N) 的回归系数，都不显著（|t| < 3）。
- **P3**：z 分数 (f − f_loc)/√(f_loc(1−f_loc)/R) 的标准差落在 [0.3, 1.5]。
- **P4**：每个窗口里最小的 f(N) 高于 f_loc − 6·sd_binom。

## 判据

- P1–P4 全部成立 → **支持**：奇偶性信息看起来是一枚“无记忆”的硬币，哥德巴赫的奇偶性部分可以化归为一个精确目标：对移位素数的二元 Chowla 型估计 Σ_p λ(N−p)·1_{粗糙} = (1−2f*+o(1))·R(N)，且对 N 一致成立。
- P2 失败（有显著的算术依赖）→ **否定**：素数在 N−p 上的奇偶分布带有 N 的算术记忆，这正是筛法漏掉的信息，需要立刻深挖。
- P3 失败：涨落不是二项型的，需要和 L0 的 Fano 结论联合解释。

## 规模

窗口：N₀ ∈ {10⁶, 10⁷, 10⁸}，每个窗口取 2000 个连续偶数（覆盖 mod 3、5、7 的全部类）。CPU（numba），预计不到 5 分钟。

## 无论成败的收获

- 支持：得到一个量化陈述，即“距离奇偶性反例”的度量 f_min/f_loc；同时把墙 B 精确化为一个可陈述的相关性估计。
- 否定：找到了筛法看不见、却与 N 的算术相关的结构。
