# O22（通宵，GPU）噪声协方差核在 s(h) 之外的结构：ω(h) 项 — 预注册

> 分支 `gb/O22-kernel-omega`（从 `gb/O16-noise-kernel` 分出）。设计与运行器 `o22_kernel_omega.py` 在全量运行前一同提交。

## 动机（事后发现，需要新数据确认）
在 O16 的数据上（L = 1…400，x = 10⁹、10¹⁰、3×10¹⁰），线性模型 ρ ≈ a + b·s(h) 的残差标准差约为 0.004，远大于噪声标准误 0.0007。残差与 ω(h)（h = 2L 的不同奇素因子个数）的相关为 −0.27 到 −0.32。加入 ω 项后，ρ ≈ a + b·s(h) + c·ω(h)，三个规模上 c = −0.0041、−0.0046、−0.0042，AIC 明显改善（R² 从 0.887–0.928 升到 0.904–0.943）。也试过 a + b·log s、a + b·s^γ、只用 p ≤ 7 的 s、a + b(1 − 1/s)，都不如 s + ω。

## 新数据
x = 3×10⁹ 与 2×10¹⁰ 两个新窗口（H = 2²²），新滞后 L = 401…1000。

## 预注册判据（两个窗口分别判定）
- **W1**：在新滞后上，ω 项的系数 c ∈ [−0.008, −0.002]。
- **W2**：加入 ω 后 R² 至少提高 0.01。
- **W3**：线性模型残差与 ω 的相关 < −0.15。
- 描述性：两种模型的系数与 R²。

## 运行前已知的信息（如实披露）
上面的 O16 事后拟合。冒烟（x = 2²²，H = 2^16；L ≤ 1000 中 > 400 的部分）：c = −0.014，R² 从 0.908 升到 0.923，残差与 ω 的相关 −0.27。冒烟窗口小，系数大小与大窗口不可比。
