# O10（通宵，探索性）函数域大 q 极限：哥德巴赫计数是否由 F 的分解型决定

> 分支 `gb/O10-ff-largeq`（从 `gb/O7-ff-refined` 分出）。**探索性，没有事前判据。** 冒烟结果在下文披露。

## 动机
O8 发现：固定 n、q → ∞ 时，函数域方差常数 c²（HL 残差的方差 / 均值）趋于只依赖 n 的极限，且 n = 3 时 c² ≈ 1/q。在大 q 极限下，F 的“分解型”（不可约因子次数的多重集，对应置换的轮换型）按 Chebotarev/Katz 等分布服从 S_n 上的随机置换统计。如果 r(F) 的涨落主要由 F 的分解型决定，那么 c² 的极限就应当能在 S_n 上精确计算。

## 对象
对 (q, n) 穷举全部 n 次首一 F，计算：r(F)（同 O3）；HL 预测（同 O3/O8）；F 的分解型。报告：
- c²_raw = Var(r)/E r；
- c²_hl = Var(r − r_pred)/E r（即 O8 的 c²）；
- R²_type：分解型解释的 Var(r) 比例；
- R²_type_of_hl_resid：分解型解释的 HL 残差方差比例；
- 每种分解型的比例、r 的相对均值，以及 HL 残差的组内均值与方差。

## 计划
- n = 3：q = 5, 7, 11, …, 61；
- n = 4：q = 5…43；
- n = 5：q = 5…31。

## 冒烟（已运行）
q = 5，n = 3、4；q = 7，n = 3。分解型解释了 75%–83% 的 Var(r)。但 Var(r) 的大部分本来就由 𝔖 解释（R²_hl = 0.69–0.96）。分解型能解释 HL 残差的 16%–58%。

---

## 结果（运行 71 秒；全部 F 穷举）

| n | q 范围 | c²_hl（HL 残差方差 / 均值） | 分解型解释的 HL 残差比例 | 备注 |
|---|---|---|---|---|
| 3 | 5…61 | q·c²_hl = 1.00 ± 0.01（q ≥ 11） | 0.40 → 0.80（随 q 上升） | 残差 → 0，且大部分由 F 的分解型决定 |
| 4 | 5…43 | 0.139 → **0.080**（q ≥ 17 时稳定在 0.079–0.081） | 0.16 → **0.006** | 残差有非零极限，且与分解型无关 |
| 5 | 5…31 | 0.128 → **0.141**（缓慢上升） | 0.04 → **0.000** | 同上 |

HL 预测本身解释 Var(r) 的比例：n = 3 时 0.69 → 0.998，n = 4 时 0.96 → 0.9995，n = 5 时 0.99 → 0.9999。逐行数据见 `out/o10_summary.json`，其中还有每种分解型的比例、相对均值与组内残差。

**观察（探索性）**：
1. **n = 3 是特例**：HL 残差的方差恰为 均值/q，且约 80% 由 F 的分解型（三个一次、一次×二次、不可约）决定。也就是说，n = 3 时 HL 之外剩下的东西仍然是“局部”的，并且随 q 消失。
2. **n ≥ 4 时出现一个与分解型无关的极限噪声**：c²_hl → c_∞(n)，c_∞(4) ≈ 0.080，c_∞(5) ≈ 0.14（q ≤ 31 时仍在缓慢上升）。分解型对它的解释比例 → 0。在大 q 极限下，F 的分解型（Chebotarev 意义下的全部“局部”信息）完全看不到这部分涨落。
3. 这为理论提供了一个干净的目标：在 Katz 型等分布框架下，c_∞(n) 应当可以由某个单值群（大概是 S_n × S_n 或其纤维积）上的积分给出。n = 3 时极限为 0 可能对应于一个“退化”的单值群。我们没有做这个推导。
