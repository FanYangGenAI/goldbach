# Q5 背景合同：单系统解析密度 × 固定和 p 进修正 — 预注册

## 1. 定义（独立于 r(N)）

**单系统密度（Hankel 型，不截断对数展开）。** F_z(s) = Σ z^{Ω(n)} n^{−s} = ζ(s)^z B_z(s)，B_z(s) = ∏_p (1−p^{−s})^z/(1−zp^{−s})。对 |z| ≤ 1/2，把 Perron 积分的围道收缩到 s = 1 左侧的割线 [σ₀, 1) 上，定义

  δ_z(t) := (sin πz/π) ∫_{σ₀}^{1} |ζ(σ)|^z B_z(σ) t^{σ−1} dσ，σ₀ = 0.55。

对 Re z < 1，被积函数在 σ = 1 处可积。截断 σ₀ 带来的误差为相对 O(t^{σ₀−1})。δ_z 只依赖单系统的狄利克雷级数，与固定和、与 r(N) 都无关。检验：[z¹]δ_z(t) = (1 − t^{σ₀−1})/log t。

**固定和的 p 进修正（来自 Q1b，审阅已核对）。** R_N(z,w) = ∏_p J_p(z,w; ν_p(N))/(Z_p(z)Z_p(w))，其中 Z_p(z) = (1−1/p)/(1−z/p)。p ∤ N 时因子为 1 − (z−1)(w−1)/(p−1)²。

**背景。** B_N(z,w) := R_N(z,w)·∫_2^{N−2} δ_z(t)δ_w(N−t) dt；H_N 的背景取 B_N(z) := B_N(z,z)。由 [z¹]δ_z 可得 [zw]B_N = 𝔖(N)·∫(1−t^{σ₀−1})(1−(N−t)^{σ₀−1})/(log t·log(N−t)) dt，它与 𝔖(N)∫dt/(log t log(N−t)) 只差 O(N^{σ₀}) 量级。

**动机（初等恒等式）。** Σ_N G_N(z,w)t^N = F_z(t)F_w(t)，其中 F_z(t) = Σ_{n≥2} z^{Ω(n)}t^n。也就是说，一旦解除固定和约束，配分函数就精确分解为两个单系统的乘积。背景 = 单系统平均 × 局部修正；残差 = 固定和约束带来的、局部修正之外的关联。

## 2. 残差合同

E_N(z) := H_N(z) − B_N(z)。已扣除：(i) 单系统平均密度的全部对数阶（截断到 t^{σ₀−1}）；(ii) 固定和在每个素数 p 上的局部（p 进）关联。**未扣除**：单系统在短区间上的涨落（例如 ψ(x) − x 的零点振荡）；p 进修正之外的固定和关联；σ₀ 截断带来的 O(N^{σ₀}) 量级项。

## 3. 检验

- **T1（单系统一致性）**：对 z ∈ {±0.25, ±0.5, 0.5i}，∫_2^x δ_z(t)dt 与 Σ_{2≤n≤x} z^{Ω(n)} 在 x = 10⁸ 处的相对误差 < 10⁻³。
- **T2（平均漂移消失）**：对 Q4b 的 180 个 N，r(N)/b₂,N − 1 的平均值（b₂,N 为 B_N 的二次系数），在三个量级上都满足 |均值| < 3×（标准误）；作为对照，同时报告旧首项 N𝔖(N)/log²N 的平均漂移。按 (N mod 3, ν₂(N)) 分层报告。
- **T3（残差描述，不设阈值）**：在 z ∈ {±0.25, ±0.5, 0.5i} 上报告逐 N 的有符号相对残差 E_N/B_N 的均值、标准差，以及 |E_N|/√N 的中位数，并保存逐 N 的值。不拟合指数。

## 4. 结果

### T1（单系统一致性）✗（按阈值）
∫δ_z 与 Σz^{Ω(n)}（x = 10⁸）的相对误差：z = 0.25: 1.3×10⁻⁴；0.5: 4.8×10⁻⁵；0.5i: 3.1×10⁻⁴；**−0.25: 1.03×10⁻³；−0.5: 3.3×10⁻³**。负 z 处单系统和本身有抵消、数值较小，相对误差偏大，略超 10⁻³ 的阈值。

### T2（平均漂移）✗（按阈值），但漂移已缩小 30–190 倍
r(N)/b₂ − 1 的平均（每个量级 60 个 N）：

| N | 新背景 b₂（σ₀ 截断） | 旧首项 N𝔖/log²N |
|---|---|---|
| 10⁶ | +0.55% ± 0.10% | +17.2% |
| 10⁷ | +0.18% ± 0.04% | +14.3% |
| 10⁸ | +0.066% ± 0.013% | +12.3% |

剩余漂移每十倍缩小到约 0.35 倍，正好是 σ₀ 截断造成的 N^{σ₀−1} = N^{−0.45} 量级。

**Q5b（探索性诊断）**：系数改用不截断的 𝔖(N)∫dt/(log t log(N−t)) 后，漂移为 −0.21% ± 0.10%、−0.089% ± 0.038%、−0.027% ± 0.013%，都在 3 倍标准误之内。T2 的失败来自我定义中的截断，不是背景本身。

### T3（残差描述）
z = 0.5 处，新背景的平均有符号相对残差约为 −0.8%，**不随 N 减小**。分层后看得很清楚：3∣N 时约 −1.5% 到 −2.1%，3∤N 时约 −0.4%。也就是说，局部因子在二阶上还缺东西，而且对 p = 3 最明显。

### Q5c（探索性）：局部因子的“尺度平移”修正
**原理**：当 p^a ∥ n 时，n 的其余部分大小是 n/p^a，单系统密度应该在 n/p^a 处取值，而不是在 n 处。这给每一侧带来相对修正 1 − (z−1)·a·log p/log N。对局部状态求平均，得到对 log R_N 的一阶修正：
  Δ_N(z) = −(z−1)/log N · Σ_p log p·[∂_u log J_p(zu,zu;ν_p(N)) − 2∂_u log Z_p(zu)]_{u=1}。
这个修正 **没有可调参数**。

修正前 → 修正后的平均有符号相对残差：

| N, 分组 | z=0.25 | z=0.5 | z=−0.25 | z=−0.5 |
|---|---|---|---|---|
| 10⁶, 3∣N | −1.70% → +0.03% | −1.93% → −0.05% | +5.9% → +2.5% | +15.4% → +6.8% |
| 10⁶, 3∤N | −0.05% → +0.19% | −0.45% → +0.05% | −0.45% → +0.74% | −13.5% → −6.8% |
| 10⁸, 3∣N | −1.41% → −0.08% | −1.49% → −0.07% | +2.9% → +0.52% | +6.5% → +0.97% |
| 10⁸, 3∤N | −0.27% → 0.00% | −0.47% → −0.02% | −0.68% → −0.04% | −7.3% → −2.6% |

偏差及其 mod 3 分裂基本消失：正 z 处剩余不到 0.1%，负 z 处也明显缩小。这是事后发现，需要在新样本上预注册确认（Q5d）。
