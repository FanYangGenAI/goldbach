# L3c 由 Hardy–Littlewood 四元组猜想预测方差 — 实验 E3.3 预注册

> 分支 `gb/L3c-variance-from-4tuples`（从 L3b 切出）。运行前提交。

## 推导（启发式，基于 HL k 元组猜想）

θ 加权：R(N) = Σ_{a+b=N} θ(a)θ(b)。展开 R(N)² = Σ_{a,a'} θ(a)θ(N−a)θ(a')θ(N−a')，令 h = a' − a：

1. **对角项**（a' = a 与 a' = N−a 两条）：2·Σ_a θ(a)²θ(N−a)² ≈ 2·𝔖(N)·∫₀^N log t·log(N−t) dt = 2N𝔖(N)·(L² − 2L + 2 − π²/6)，L = log N。
2. **非对角项**（固定 h ≠ 0）：四个线性型 a, a+h, N−a−h, N−a 同时为素数。HL 猜想给出 Σ_a θθθθ ≈ 𝔖₄(h,N)·(N − |h|)，其中
   𝔖₄(h,N) = ∏_p (1 − ν_p/p)(1 − 1/p)^{−4}，ν_p = #{0, −h, N−h, N} 在 mod p 下的不同元素个数。只有当 p | h·N·(N−h)·(N+h) 时 ν_p < 4。
3. 由 Σ_{|h|<N}(N − |h|) = N²，有
   **V_HL(N) = 2N𝔖(N)(L² − 2L + 0.355) − N𝔖(N)² + Σ_{0<|h|<N} (𝔖₄(h,N) − 𝔖(N)²)(N − |h|)**。
   最后一项就是“奇异级数平均的二阶项”（Gallagher / Montgomery–Soundararajan 型），它决定了相对 Cramér 的折减。

## 假设 H3c

E3.2 观测到的方差（窄窗口，σ² = Var(F/√𝔖)）可以由 V_HL(N)/𝔖(N) 的窗口平均定量解释。

## 预测

在 x ∈ {2²³, 2²⁴, 2²⁵, 2²⁶} 的 GPU 窗口中，每个窗口随机取 48 个偶数 N 精确计算 V_HL(N)（对 h 全部求和，不截断），并计算 σ²_HL = mean(V_HL/𝔖)。
- **P1**：σ²_HL / σ²_obs ∈ [0.9, 1.1]（四个窗口全部满足）。
- **P2**：非对角奇异级数项为负，其绝对值占对角项的比例在 [0.6, 0.8] 之间（对应观测到的 25–31% 残留）。
- **P3（健全性检查）**：mean_h 𝔖₄(h,N)（h 为偶数）/ 𝔖(N)² 与 2 的相对差 < 1%。偶数 h 只占一半，平均到全部 h 时应为 1（Gallagher 型平均）。

## 判据

P1 成立 → 方差律由 HL 四元组猜想定量解释，“log^{2.5}”可以转化为对 Σ_h(𝔖₄ − 𝔖²)(N − |h|) 渐近的研究（纯奇异级数问题，原则上可严格处理）。P1 失败 → HL 四元组平均不足以解释方差，需要找额外来源（例如素数幂、低阶项或 HL 本身的误差）。
