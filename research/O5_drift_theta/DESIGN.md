# O5（通宵，GPU）O2 的 1/√N 漂移是不是素数计数误差的一阶项 — 预注册

> 分支 `gb/O5-drift-theta`（从 `gb/O2-gpu-drift` 分出）。设计与运行器 `o5_drift_theta.py` 在全量运行前一同提交。

## 动机
O2 测得 rel(N) = r(N)/b₂(N) − 1 的窗口平均漂移约为 −1.5/√N，其中 b₂ = 𝔖(N)∫_2^{N−2}dt/(log t log(N−t))。写 1_P = ρ + δ（ρ = 1/log，δ = d(π − li)）。展开 r(N) = Σ_n 1_P(n)1_P(N−n)，一阶（线性）项为 2Σ_n δ(n)ρ(N−n)。π − li ≈ −½li(√t) + （ζ 零点的振荡项），由此预期漂移 ≈ −2/√N 加上一个随 x 振荡的、大小为 O(1/√N) 的项。这与 L3d 的“局部平均跟随 2(ψ − x)”是同一件事，只是换成了不加权的素数计数。

## 预测量（无自由参数）
对窗口内的偶数 M（取窗口首、中、尾三点后平均）：

rel_pred(M) = 2·[Σ_{2≤p≤M−2} 1/log(M−p) − I(M)] / I(M)，其中 I(M) = ∫_2^{M−2}dt/(log t·log(M−t))。

素数和在 GPU 上精确求和（float64），积分取 epsrel = 10⁻¹²。

## 窗口
96 个窗口，起点 x_i = 2^{30 + 3i/96}（i = 0…95，取偶），对数均匀地铺满 [2^30, 2^33)，每个窗口宽 H = 2²²，窗口内全部偶数都计入。rel 的计算与 O2 完全相同。

## 预注册判据（统计量都乘 √x）
- **P1**：96 个窗口上 |rel_obs − rel_pred|·√x 的均值 < 0.5。作为对照，O2 中 |rel_obs|·√x 约为 1.4–1.8。
- **P2**：跨窗口回归 rel_obs·√x ~ rel_pred·√x，斜率 ∈ [0.7, 1.3]，且相关 > 0.5。也就是说，预测不仅要给出 −2/√x 的常数部分，还要跟上随 x 振荡的 ζ 零点部分。

## 运行前已知的信息（如实披露）
冒烟测试（8 个窗口，x ∈ [2^22, 2^25]，H = 2^16，含暴力计数核对）已经给出：|残差|·√x 的均值为 0.099，相关 0.984，斜率 1.10，P1、P2 均通过。所以本检验的问题是：这种一致性能否在大三个数量级的 x 上、在 96 个窗口上保持。

## 限定
窗口内相邻 N 不独立。这只是对窗口平均的确定性一阶修正。二次项 Σδδ（即哥德巴赫本身的涨落）不在预测中。

---

## 结果（RTX 4090，运行 900 秒，96 个窗口，x 从 1.07×10⁹ 到 8.4×10⁹）

| 统计量 | 值 |
|---|---|
| \|rel_obs\|·√x 的均值 | 2.178 |
| \|rel_obs − rel_pred\|·√x 的均值 | **0.040** |
| 跨窗口相关（rel·√x） | **0.995** |
| 回归斜率 | **0.999** |
| rel_obs·√x 的范围 | −3.61 到 −1.07（标准差 0.52） |
| 残差·√x：均值 / 标准差 | 0.008 / 0.052 |
| 窗口均值的名义标准误·√x（中位数） | 0.009 |

（逐窗数据：`out/o5_summary.json`、`out/o5_log.txt`。）

**预注册判定：P1 ✓、P2 ✓。**

**解读**：
- O2 中的 1/√N 漂移 **完全** 是素数计数误差 π − li 的一阶（线性）项：常数部分 −2/√x 来自 −½li(√t)（即 θ 与 ψ 的差，素数平方），振荡部分来自 ζ 零点。预测把漂移缩小了约 55 倍，并逐窗跟上了 ζ 零点带来的振荡（rel·√x 在 −3.6 到 −1.1 之间变化）。
- 剩余残差 0.05/√x 只有名义标准误的约 6 倍。由于相邻 N 不独立，标准误偏小，所以这个残差是否显著无法判断。
- 结论：在窗口平均的层面，“HL 背景 + 素数计数误差的一阶项”在 8.4×10⁹ 以内把哥德巴赫计数解释到约 10⁻⁶ 的相对精度。剩下的就是哥德巴赫本身的二次涨落 Σδδ。
