# O16（通宵，GPU）哥德巴赫残差噪声的协方差核：与孪生奇异级数的关系 — 预注册

> 分支 `gb/O16-noise-kernel`（从 `gb/O14-noise-structure` 分出）。设计与运行器 `o16_noise_kernel.py` 在全量运行前一同提交。

## 动机
O14 发现，残差 z_N 在不同 N 之间的相关依赖于 N − N' 的小素因子。最自然的候选是“孪生”奇异级数比 s(h) = ∏_{p∣h, p>2}(p−1)/(p−2)。这里 h = N' − N = 2L。它就是 HL 中素数对 (n, n+h) 的局部因子（去掉常数 2C₂）。

## 对象
x = 10⁹、10¹⁰、3×10¹⁰ 各取一个窗口（H = 2²²），残差同 O13/O14。用 FFT 计算 L = 1…400 的全部自相关 ρ(L)。在 O14 没有用过的“新”滞后上，计算 ρ(L) 与 s(2L) 的 Pearson、Spearman 相关，以及线性拟合 ρ ≈ a + b·s(2L)。

## 预注册判据（10¹⁰ 与 3×10¹⁰ 分别判定）
- **K1**：新滞后上 Pearson(ρ, s) > 0.8。
- **K2**：新滞后上 Spearman(ρ, s) > 0.6。
- 描述性：a、b 随 x 的变化；拟合的 R²。单个 ρ(L) 的噪声标准误约为 1/√n ≈ 7×10⁻⁴。

## 运行前已知的信息（如实披露）
冒烟（x = 2²²、2²³，H = 2^16）：Pearson 0.96 / 0.94，Spearman 0.83 / 0.79，拟合 ρ ≈ −0.12 + 0.078·s 与 ρ ≈ −0.094 + 0.063·s，R² 为 0.92 / 0.89。O14 中 16 个滞后的数值已知。

---

## 结果（RTX 4090，运行 89 秒；全部 ρ(L) 与 s(2L) 见 `out/o16_summary.json`）

| x | Pearson(ρ, s)（新滞后） | Spearman | 拟合 ρ ≈ a + b·s | R² |
|---|---|---|---|---|
| 10⁹ | 0.961 | 0.774 | −0.0376 + 0.0248·s | 0.923 |
| 10¹⁰ | **0.964** | **0.857** | −0.0408 + 0.0269·s | 0.929 |
| 3×10¹⁰ | **0.943** | **0.807** | −0.0332 + 0.0220·s | 0.890 |

单个 ρ(L) 的噪声标准误约为 7×10⁻⁴。

**预注册判定**：10¹⁰ 与 3×10¹⁰ 上 **K1 ✓、K2 ✓**。

**解读**：
- 残差噪声在 N 与 N + h 之间的相关，90% 以上的跨滞后变化由孪生奇异级数比 s(h) 线性决定：ρ(h/2) ≈ a + b·s(h)，b ≈ 0.022–0.027，a ≈ −0.035。所以“非局部噪声”的协方差核本身是局部的（由 h 的素因子决定），这与 HL 二阶统计的形状一致。
- HL 启发式中，Cov(r(N), r(N+h)) 的“对角”部分来自四个三元组和，例如 Σ 1_P(p)1_P(N−p)1_P(N+h−p)，每个约为 N/log³N 乘以一个含 s(h) 的三元奇异级数。按这个对角部分估计，斜率 b 应约为 0.3·κ（κ 为三元奇异级数与 𝔖·2C₂·s 之比的平均）。实测只有 0.027，所以与方差的情形一样（见下一条），对角项被非对角项大部分抵消。我们没有完成这个计算。
- **关于方差常数的基线（对 O8 的补充）**：整数中的 r(N) 数的是有序对 (p, N−p)，每个无序对数两次。所以独立模型下的“泊松”基线是 Var(r) ≈ 2·E r，而不是 E r。按这个基线，整数的 c²/2 在 10¹⁰ 上约为 0.34。这与函数域 q=3、n=16 的 0.31 很接近；函数域的 r(F) 不对称，基线就是 1。整数中的亚泊松程度比 O8 中按 1 计算的更强。
