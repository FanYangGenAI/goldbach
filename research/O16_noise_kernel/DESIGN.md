# O16（通宵，GPU）哥德巴赫残差噪声的协方差核：与孪生奇异级数的关系 — 预注册

> 分支 `gb/O16-noise-kernel`（从 `gb/O14-noise-structure` 分出）。设计与运行器 `o16_noise_kernel.py` 在全量运行前一同提交。

## 动机
O14 发现，残差 z_N 在不同 N 之间的相关依赖于 N − N' 的小素因子。最自然的候选是“孪生”奇异级数比 s(h) = ∏_{p∣h, p>2}(p−1)/(p−2)。这里 h = N' − N = 2L。它就是 HL 中素数对 (n, n+h) 的局部因子（去掉常数 2C₂）。

## 对象
x = 10⁹、10¹⁰、3×10¹⁰ 各取一个窗口（H = 2²²），残差同 O13/O14。用 FFT 计算 L = 1…400 的全部自相关 ρ(L)。在 O14 没有用过的“新”滞后上，计算 ρ(L) 与 s(2L) 的 Pearson、Spearman 相关，以及线性拟合 ρ ≈ a + b·s(2L)。

## 预注册判据（10¹⁰ 与 3×10¹⁰ 分别判定）
- **K1**：新滞后上 Pearson(ρ, s) > 0.8。
- **K2**：新滞后上 Spearman(ρ, s) > 0.6。
- 描述性：a、b 随 x 的变化；拟合的 R²。单个 ρ(L) 的噪声标准误约为 1/√n ≈ 7×10⁻⁴。

## 运行前已知的信息（如实披露）
冒烟（x = 2²²、2²³，H = 2^16）：Pearson 0.96 / 0.94，Spearman 0.83 / 0.79，拟合 ρ ≈ −0.12 + 0.078·s 与 ρ ≈ −0.094 + 0.063·s，R² 为 0.92 / 0.89。O14 中 16 个滞后的数值已知。
