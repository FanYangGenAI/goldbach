# L3d ζ 零点与显式公式 — 实验 E3.4 预注册

> 分支 `gb/L3d-zeros-explicit-formula`（从 L3c 切出）。运行前提交。

## 动机

E3.3 显示：方差属于“长区间”情形，不能由 HL 主项解释，应当去看零点。但要先厘清 **哪些** 零点。
用 Λ 加权，R_Λ(n) = Σ_{a+b=n} Λ(a)Λ(b)。Fujii 公式（RH 下）：
  G(x) := Σ_{n≤x} R_Λ(n) − x²/2 = −2 Σ_ρ x^{ρ+1}/(ρ(ρ+1)) + 误差，误差猜想为 O(x^{1+ε})。
对 x 求导，并与 ψ 的显式公式 ψ(x) − x = −Σ_ρ x^ρ/ρ + … 对照，得到局部版本：
  **(1/H)·Σ_{x<n≤x+H} R_Λ(n) ≈ x + 2(ψ(x) − x)**，条件是 H 远小于零点振荡的尺度 x/γ。
直观含义：x 附近哥德巴赫表示数的局部平均，跟随素数定理的误差 ψ(x) − x 起伏。

关键问题：ζ 的零点（只对应圆法里 q = 1 的主弧）能解释多少逐点方差？其余部分来自 q ≥ 2，即 Dirichlet L 函数的零点和次弧。

## 预测（X = 2²⁶，前 K = 20000 个 ζ 零点，用 mpmath 计算）

- **P1（Fujii 累积公式）**：在 x ∈ [2¹⁴, 2²⁶] 的 400 个对数等距点上，G(x) 与零点和 Z_K(x) = −2·Σ_{k≤K} 2·Re[x^{ρ_k+1}/(ρ_k(ρ_k+1))] 的相关系数 > 0.95，残差 rms / G 的 rms < 0.3。
- **P2（局部版本）**：在 x ∈ [2²⁰, 2²⁶] 上取 2000 个窗口（H = 2¹⁴），把 R̄ − x̄ 对 2(ψ(x̄) − x̄) 回归，斜率 ∈ [0.9, 1.1]，R² > 0.5。
- **P3（ζ 零点在逐点方差中的份额）**：在 x = 2²⁴ 与 2²⁶ 附近的窗口内，2(ψ(N) − N) 的方差占逐点误差 F_Λ(N) = R_Λ(N) − N𝔖(N)（偶数 N）方差的份额 < 5%。

## 判据与收获

- P1、P2 成立且 P3 成立 → ζ 零点精确控制哥德巴赫计数的“大尺度”起伏，但逐点方差（刚性）几乎全部来自 q ≥ 2，也就是所有 Dirichlet L 函数的零点，或等价地来自次弧。这会把“方差由零点对关联决定”精确化为“由整个 L 函数族的零点统计决定”，并否定“只看 ζ 就够”的简化。
- P3 失败（份额大）→ ζ 零点本身就是方差的主要来源，下一步直接在 GUE 对关联下推导。
- P1/P2 失败 → 数值或理论处理有误，先排查。

---

## E3.4 结果（前 20000 个 ζ 零点，γ_K = 18046；R_Λ 到 X = 2²⁶）

- **P1 ✓（Fujii 累积公式）**：G(x) 与零点和的相关系数 0.9997，残差 rms 比为 0.029。按 x^{3/2} 归一化后相关 0.93、残差比 0.47（小 x 处低阶项和截断占比较大）。残差 |G − Z_K|/(x log x) 最大 0.43、中位数 0.23，与猜想的 O(x^{1+ε}) 误差一致（包含零点截断的影响）。
- **P2 ✓（局部版本）**：x ∈ [10⁶, 6.7×10⁷]，H = 2¹⁴ 的 2000 个窗口上，(R̄ − x̄) 对 2(ψ(x̄) − x̄) 回归，斜率 **0.980**，R² = 0.66（按 √x 归一化后斜率 0.94、R² = 0.77）。**哥德巴赫表示数的局部平均精确地跟随素数定理误差的两倍。**
- **P3 ✓（ζ 零点的方差份额）**：x ≈ 1.7×10⁷ 和 6.7×10⁷ 处，2(ψ(N) − N) 只解释逐点误差 F_Λ 方差的 **0.19% 和 0.18%**。rms(F)/√N ≈ 16–18，而 rms(ψ − N)/√N ≈ 0.17。

## 结论

1. ζ 零点（圆法中 q = 1 的主弧）精确控制哥德巴赫计数的 **大尺度** 起伏：累积公式和局部公式都成立，斜率与理论值 1 吻合。
2. 但 ζ 零点对 **逐点方差** 的贡献可以忽略（约 0.2%）。观测到的“刚性”和 log^{2.5} 律几乎全部来自 q ≥ 2，也就是整个 Dirichlet L 函数族（或等价地，所有 q ≥ 2 的有理点附近与次弧）。
3. 修正 E3.3 的表述：方差不是由“ζ 零点的对关联”决定，而是由 **L 函数族层面的统计** 决定。这类统计已有可证明的二阶结果（Barban–Davenport–Halberstam、Montgomery–Hooley 关于素数在算术级数中分布的方差），这是下一条线的切入点。

下一步（E3.5）：用 L2 的掩膜工具，把 Var(F) 按分母 q 的二进区间分解成“方差谱”，看它是否像 Montgomery–Hooley 那样在 log q 上均匀分布。
